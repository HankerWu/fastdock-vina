# 搜索引导、配体状态与同靶亲和力的配对验证

基线为 fastdock-vina-pro 的 `a43c4bd`。本轮在 hCA II、hCA I、hCA XII、人 BRD4 第一溴结构域和 T4 溶菌酶 L99A 模型空腔上使用 20 个不同配体，分别检验局部配位、共有骨架、构型可达性和同靶排序。只有三个碳酸酐酶亚型共享同一种金属位点。比较不同受体和随机种子时重复使用同一化合物的实验标签。证据支持在有独立结构信息时引导候选生成，尚不足以替换默认姿势或亲和力评分。

## 从源码到可证伪的预测

原生 Vina 将 Zn 归入通用金属供体类型，普通网格把相互作用表示为与距离相关的函数。在 hCA II 的三尾磺酰胺系列，实验结构显示保守的金属结合头部和不同的尾部构象。实验论文还指出若干尾端电子密度较弱，其中 6WQ4 和 6WQ8 配体密度较清楚。于是分别检验受体提供的方向能否改善配位和整分子几何，以及供体配体的共有骨架能否帮助搜索柔性分子。单纯重排终端候选、增加受体位置先验、借用另一配体的已知构象是三种不同的信息条件。[Bonardi 等](https://doi.org/10.1021/acs.jmedchem.0c00733) · [AutoDock4Zn](https://doi.org/10.1021/ci500209e) · [最大公共子结构引导研究](https://doi.org/10.1021/acs.jcim.5c00201)

新增 `--search_anchor FILE`。每个配体重原子用准备配体的 PDBQT serial 标识，文件每行写 `serial x y z`，球壳对照写 `serial center_x center_y center_z shell radius`。所有点、球壳均在受体/搜索盒坐标系下，单位 Å。每个位点的偏差为到该点的距离，或到球心的距离减去半径。以 Å 为长度单位，搜索引导势取所有位点的 $4[\sqrt{1+d_i^2}-1]$ 的算术平均，参数未经病例拟合。球壳在原点使用 0.0001 Å 平滑，精确的零点仍在指定半径。位点的平均值避免较长骨架自动获得较大权重。代码对实际能量施加解析梯度，搜索使用全部轨迹。进入 Late 的候选统一用原生显式受体和配体内能重新筛选，再做不带引导的显式精修、去冗余和亲和力排序。单点、球壳、多点或混合行可用同一接口表示。另有独立的固定池姿势排序工具，允许检验在末端加回原引导项的影响。[核心实现](../src/lib/anchored_search_grid.h) · [固定池工具](../tools/rank_anchor_pool.py)

在有三个蛋白供体的适用锌位点，仅从受体估算四面体空位，根据独立的阴离子磺酰胺官能团确定配体氮。方向臂把 N 引到沿空位方向距 Zn 2 Å 的点，径向对照仅要求 N 在以 Zn 为中心、半径 2 Å 的球壳附近。共有骨架臂另从同靶的其他配体中选择最大公共子结构最大的供体，平手时按覆盖比例和标识符选。元素、形式电荷、键级、环和适用的立体条件参与匹配。等价映射采用固定的原子索引规则。只有供体的实验坐标进入搜索，待测配体实验坐标只用于事后评价。这是有参考配体条件下的迁移测试。重对接与跨受体构象混合处已按病例给出，已知靶点和已用种子没有标为新靶点验证。[骨架选择](../benchmarks/anchor_search/transfer_mapping.py) · [供体映射与独立结构核验](../benchmarks/anchor_search/transfer_holdout.md)

## 姿势与亲和力

首姿看引擎输出第一名，池命中看最多九个输出中是否有重原子 RMSD ≤2 Å 的姿势。RMSD 在叠合后的受体坐标系计算，允许化学等价置换，不再对配体单独拟合。同靶排序使用同一实验测法且相差至少三倍的分子对，在同一受体、种子下比较第一名的原生报告分。不同实验臂共享同一对照时，不能相加当成新样本。

| 体系与操作 | 首姿命中，原生 → 引导 | 池命中，原生 → 引导 | 同靶排序正确，原生 → 引导 |
|---|---:|---:|---:|
| hCA II，锌径向球壳 | 0 → 0 / 20 | 0 → 0 / 20 | 14 → 11 / 28 |
| hCA II，锌空位方向 | 0 → 0 / 20 | 0 → 0 / 20 | 14 → 13 / 28 |
| hCA II，异配体共有骨架 | 0 → 5 / 20 | 0 → 8 / 20 | 14 → 8 / 28 |
| BRD4，异配体共有骨架 | 1 → 7 / 24 | 2 → 12 / 24 | 10 → 9 / 30 |
| T4L，异配体共有骨架 | 28 → 28 / 36 | 36 → 35 / 36 | 50 → 49 / 76 |
| 独立 CA I / XII，锌空位方向，36 Å 盒 | 4 → 9 / 10 | 5 → 10 / 10 | CA I 同一对的 57 °C DSF 为 1 → 2 / 4 |
| 同一 CA I / XII，20 Å 盒的敏感性检验 | 6 → 5 / 10 | 9 → 10 / 10 | 同一对为 2 → 3 / 4 |

在主试验 hCA II 的新种子 Late 对照中，严格配位检查的首姿通过数为原生 1/20、径向 16/20、方向 20/20。三组头部 RMSD 中位数依次为 1.280、0.486、0.335 Å，剩余原子为 8.067、7.362、7.463 Å。严格检查包括距离窗、空位夹角及排除额外配位原子。上一轮常规 Vina 及其种子是另一对照。方向臂改善局部结构的效果大于远端。BRD4 全部新增首姿命中集中于共有 29 个重原子的 TG-101209 和 TG-101348，两者在 ITC 中 Kd 为 123 和 164 nM，这一对本身低于三倍门槛。跨骨架的 7 原子映射在 3MXF 坐标系偏离查询实验片段 7.35 Å，并丢失一个原本可用的候选。T4L 的邻二甲苯虽有 7/8 个重原子匹配，供体和查询片段的质心只差 0.33 Å，片段 RMSD 却达 2.73 Å。覆盖率、质心都无法充分判断结合朝向。[hCA II 原始分量](../benchmarks/anchor_search/hcaii/metal/modes.csv) · [BRD4 实验](https://doi.org/10.1038/nchembio.1471) · [T4L 量热](https://doi.org/10.1021/bi00027a006)

外部检验用了两种独立准备的小分子，乙酰唑胺与甲醋唑胺，以及 1AZM、1BZM、1JD0 三个受体结构。大盒对照有更多定位困难。小盒仍完整容纳配体，CA XII 的两个方向臂都保留约 0.98 Å 的候选，首姿却在 3.09 和 3.27 Å。仅径向引导在这两个小盒病例反而选出了约 1.56 Å 的首姿。现有结果支持更稳定的候选覆盖，不支持把首姿收益推到所有盒宽。[独立病例、温度与测法](../benchmarks/anchor_search/holdout.md)

固定输出池，在无引导精修后的姿势上加回相同的骨架势，BRD4 首姿从 7/24 到 10/24，仅按骨架几何排为 11/24。T4L 从 28/36 到 22/36，仅按几何也为 22/36。苯并呋喃四例本来在 0.59–1.01 Å，加回供体后全变成 2.97–3.09 Å。因此保留原生末端评分作为默认，另行报告供体依赖的姿势优先级。

## 配体微态、原子映射与假阳性

五个 hCA II 配体均将叔胺准备为带一个 H 的正离子，三个不等价重原子取代基的有向体积可以从衍射模型读取。6WQ5、6WQ8、6WQ9 的初始手性方向与共晶重原子排列相反。给定固定键角和刚性片段的扭转搜索不能交换这三个取代基的位置。X 射线重原子几何可以检验排列，不能直接确定该位点溶液中的质子化比例或证明某个质子的位置。

仅对这五个已核验没有其他固定立体中心的分子，比较原输入与其全坐标反射态。独立验证反射前后内部距离相同，两态在分子图、电荷、扭转树上相同。全局搜索不依实验构型挑选输入。每次比较为 2+2 条轨迹，一臂后两条仍用原态，另一臂将其给反射态，两臂同种子、预算、受体与输入信息。合池后以同一显式固定拓扑重评 INTER + INTRA，使用同一原生能量参照。候选池为两次子运行合并后的至多 18 个输出，这与上表一次至多九个的试验应分开阅读。

| 搜索与末端选姿 | 同时满足整分子 ≤2 Å 及晶体重原子排列的首姿 / 20 | 同时满足两项的候选池 / 20 |
|---|---:|---:|
| 金属点搜索，单态或双态，原生选姿 | 0、0 | 0、0 |
| 共有骨架搜索，单态，原生选姿 | 0 | 1 |
| 共有骨架搜索，双态，原生选姿 | 1 | 8 |
| 同一双态骨架池，以原生能量加原骨架项选姿 | 6 | 8 |
| 同一双态骨架池，仅以骨架几何选姿 | 6 | 8 |

上一表单态骨架引导的 5 个整分子首姿命中全部发生在与实验氮周围排列相反的输入上。双态试验按严格终点选出的 6 例仅涉及化合物 41、46，并在两个受体与种子上重复。末端加回骨架引导后，两个状态合池的 Ki 排序从 9/28 降至 7/28，20 例整体 RMSD 中位数从 5.097 升至 5.194 Å。富集正确构型、挑中一个 2 Å 候选和准确排序五个分子的结合强弱是可分别推翻的命题。[状态对照及筛选规则](../benchmarks/cutoff_switch/hcaii/ammonium_protocol.md) · [逐一能量和排序](../benchmarks/cutoff_switch/hcaii/ammonium_states/scaffold)

晶体起点的阳性对照还暴露了上一轮的评价缺陷。固定晶体原子名投影会把等价磺酰氧和环原子的编号差混入能量结论。在 6WQ4，旧投影的 Zn–N 距离在原生局部精修后为 3.583 Å，枚举化学等价映射后为 1.900 Å，整分子 RMSD 为 0.361 Å。即便用改进后的原态阳性对照，原生评分仍在十个配对池都选中了错姿。这是已知晶体的诊断，未计入预测命中率。[等价映射与回算](../benchmarks/cutoff_switch/hcaii/project_symmetries.py)

## 对排序误差的定量约束

对 732 个固定候选只改内部能，保持受体、坐标、化合物、标签不变。在已有 0.1 权重上，用介电常数 4 的 MMFF94s 配体能替代相应的 Vina 内能，T4L 的三倍排序从 50/76 降至 28/76，hCA II 从 14/28 降至 13/28，BRD4 从 10/30 降至 7/30。T4L 的 22 个净失分集中在实测最强的两种丁基苯。一个 n-丁基苯姿势的 RMSD 约 0.87 Å，却在两个种子分别得到 11.91 和 10.61 kcal/mol 的 MMFF 应变，其中 7.94 和 7.13 来自分子内范德华项。只补扭转项也未在三个体系产生一致收益。上述测试针对在另一种势上优化后保存的坐标和固定权重，不能据此排除与生成几何一致的应变模型。[分量、零点和全部消融](../benchmarks/strain_transfer/README.md) · [配体构象应变研究](https://doi.org/10.1021/jm030563w)

三套共享受体基准若按不同化合物对计数，每对取同受体/种子分差的中位数，T4L 原生和共有骨架引导各答对 12/19，BRD4 各 1/5，hCA II 从 4/7 降至 2/7。在两种算法和全部受体/种子之间都同方向的对，T4L 有 11 对且其中 3 对仍错，BRD4 为 0 对，hCA II 仅 1 对。这种一致性可描述排序敏感度，尚不足以校准可信概率。[逐化合物差值和方向](../benchmarks/anchor_search/compound_pairs.csv)

独立 CA I 的同一药物对有两个可区分的参照。57 °C 的等温 DSF 得 Kd 为 7.2 与 1.2 µM，而酯酶 Ki 相差不足三倍。25 °C、pH 7.0 的另一项 ITC 给出的 Kd 为 840 与 87.7 nM，方向相同，相差 9.58 倍。使用后一研究采用的磺酰胺 pKa 7.3 与 7.1，估算结合型游离阴离子所占比例，再用 $-RT\ln f$ 计入溶液代价，两者的相对修正仅 0.167 kcal/mol。实验结合自由能差为 1.34 kcal/mol。点引导臂的排序在两种盒宽下均未因这一修正改变。25 °C 的修正只用于同温度条件的这一对，不能补作其余分子的实测 pKa 或 57 °C 的温度修正。[原始 ITC](https://doi.org/10.3109/14756366.2014.908291) · [等温 DSF](https://doi.org/10.1038/s41598-018-37072-x) · [实现及敏感性](../benchmarks/anchor_search/holdout.md)

## 复现

从仓库根目录编译。搜索引导不需要第二张亲和力网格。单配体、刚性受体、原生 Vina 和显式 Late 精修是已验证的入口。显式指定的点或球壳必须落在搜索盒内，氢、虚拟原子和歧义序号会被拒绝。

```bash
python tools/build.py --jobs 4
python benchmarks/check_search_anchor.py build/vina /path/to/previous/vina
python benchmarks/anchor_search/run_hcaii.py build/vina /path/to/hcaii/prepared /tmp/hcaii-metal
python benchmarks/anchor_search/transfer_hcaii.py build/vina /path/to/hcaii/prepared /tmp/hcaii-scaffold
python tools/rank_anchor_pool.py /tmp/hcaii-scaffold/6WQ4_6WQ5_314159_scaffold.pdbqt \
    /tmp/hcaii-scaffold/6WQ4_6WQ5_314159_scaffold.anchor
```

C++ 数值回归覆盖平移、旋转、扭转和多位点平均。独立重建 RCSB 配体实例并叠合受体，核验了 hCA II 两个原始矩阵的 539 和 357 个输出、T4L 与 BRD4 的 1,010 个输出，以及留出 CA I/XII 两种盒的 519 个输出。前两组 hCA II 中有共同的原生对照；这些是已核验的输出次数。重复计算的 RMSD 最大绝对差不超过 0.0000011 Å。另在双态试验核验了两个矩阵合计 1,076 个输出的取代基排列和坐标。用同一全分子 RMSD 掩盖局部构型错误这个问题，比数值舍入更能影响结果的解释。[独立 hCA II 解析](../benchmarks/anchor_search/verify_hcaii.py) · [外部留出复核](../benchmarks/anchor_search/holdout_verify.py) · [双态复核](../benchmarks/cutoff_switch/hcaii/check_ammonium_states.py)
