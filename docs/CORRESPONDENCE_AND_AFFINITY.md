# 多种原子对应、受体构象与同靶亲和力排序

本轮在 FastDock Vina Pro 的全局搜索中实现多种完整骨架对应，修复 Vina 与 Vinardo 转子权重的命令行参数冲突，并在分开的实验中检验口袋水、极性溶剂化和配体扭转自由度。可复现的姿势增益出现在部分体系；同靶 Ki/Kd 改善没有跨体系重复。有依据判断两个配体的共同骨架在结合口袋中占据相同位置时，可调用搜索引导。默认亲和力评分沿用原生 Vina。

## 实现与可推翻的假设

原代码对已选 donor 与 query 的最大共同子结构分别选字典序第一组原子编号。一旦一个苯环有多个合法嵌入，或有几个等大的共同子图，编号相同的规则并不能确定哪个对应在受体坐标系中成立。预测是，若任取单个映射妨碍采样，保留所有合法对应应在相同搜索预算下改善部分化合物。若问题在于不同骨架占据不同空间位置，枚举更多等价编号仍会失败。

新的 `--search_anchor` 支持用单独一行 `OR` 分隔完整分配。第 j 组位点的平均旧引导势为 A_j，组合势为 −τ log[Σ exp(−A_j/τ)/M]。τ 固定为 0.6 个原始搜索能量单位。各组保持整套原子对应，梯度使用相应指数权重；重复或行顺序不同但内容相同的组只算一次。实现共享重复几何项，每线程保存临时梯度。该势只作用于搜索。原生显式精修、去重与最终能量另行计算。τ 没有用作实验热力学温度，映射条数也没有用作溶液布居。

`tools/make_scaffold_anchors.py` 接收带 Meeko 原子映射的查询 PDBQT 和已对齐到受体坐标的独立供体三维 SDF。共同子图比较元素、键级、环和形式电荷，再逐映射排除可辨认的四面体与双键立体冲突，要求至少六个共同原子。当枚举超限、FMCS 超时或所有最大子图嵌入都违反已编码约束时，程序明确报错。其输入约定和上限见源码。以下为已有同位骨架参考时的调用方式。

~~~bash
python tools/make_scaffold_anchors.py query.pdbqt aligned-donor.sdf assignments.txt
build/vina --ligand query.pdbqt --receptor receptor.pdbqt --config box.txt \
  --pose_selection late --search_anchor assignments.txt --out poses.pdbqt
~~~

## 三个配对矩阵与留出的随机种子

每格为同一配体、受体、随机种子，比较无引导、单对应、多对应；每臂四条轨迹，每轨迹 50,000 次目标评估预算，返回至多九个模式。总计 480 次对接、4,077 个输出姿势。旧种子 314159/271828 与冻结实现后使用的 161803/141421 分开报告。首姿命中是仅按蛋白对齐后的对称性校正重原子 RMSD ≤2 Å。候选命中允许在本格所有输出中挑最接近实验结构的姿势。它衡量生成能力，不能用于未知配体的前瞻选择。

|---|---:|---:|---:|---:|
| BRD4 首姿 | 1/48 | 15/48 | 19/48 | 8→9 /24 |
| BRD4 候选命中 | 2/48 | 24/48 | 24/48 | 12→12 /24 |
| T4L L99A 首姿 | 55/72 | 54/72 | 58/72 | 26→28 /36 |
| T4L L99A 候选命中 | 72/72 | 69/72 | 71/72 | 34→35 /36 |
| hCA II 单一初始铵构型，首姿 | 0/40 | 10/40 | 11/40 | 5→7 /20 |
| hCA II 同时要求中心氮手性方向与实验重原子坐标一致 | 0/40 | 0/40 | 0/40 | 0→0 /20 |
| BRD4 同测定至少 3 倍 Kd，逐条件判对 | 20/60 | 20/60 | 25/60 | 11→9 /30 |
| T4L 同测定至少 3 倍 Kd，逐条件判对 | 100/152 | 99/152 | 99/152 | 50→49 /76 |
| hCA II 同测定至少 3 倍 Ki，逐条件判对 | 26/56 | 19/56 | 21/56 | 11→12 /28 |

本组实验跨条件按每对预测能量差的中位数判方向，一对分子只计一次，得到 BRD4 单/多均 1/5，T4L 均 12/19，hCA II 均为 3/7。BRD4 留出种子验证了较小的姿势收益，同样的种子推翻了初期 Kd 的改善。跨随机种子属于数值重复；这些分母并非独立的实验配体数。

只看配体与受体来自不同 PDB 的格子，BRD4 的单→多对应是 12→16/40，T4L 是 50→54/68；各自的同一 PDB 子集均持平。BRD4 有 7 格从错变对、3 格从对变错。净增四例全部由 TG-101209 贡献（4O76，8→12/12）；4OGJ 另有 3 得 3 失。其与 TG-101348（4OGJ）共享 29 个原子、24 种映射；蛋白对齐后，共同骨架在晶体中的最佳 RMSD 约 0.96 Å。4OGI 和 4O77 则各有两个同样大的独立供体。用完整图映射计算，每个供体对查询晶体的最佳共有骨架 RMSD 分别为 5.16–5.43 Å 和 7.35–9.53 Å。另做 24 次等预算对接替换供体，原、新供体在这两个查询上均为首姿 0/24、候选 0/24。查询晶体仅用于这一事后误差诊断。以受体 Asn140 酰胺氢位置引导任一合适配体受体原子，又做 48 次对接；四种配体合计首姿 0/48、候选 10/48，上述两个难例候选仍为 0/24。4O77 晶体配体的氢键受体原子到最近预设氢键点还有 2.74–3.46 Å；4OGI 在自身受体中仅偏 0.58 Å，仍无整体正确的候选。48 个引导首姿中有 29 个满足 1 Å 局部接触，同时 48 个均超过 2 Å 全配体 RMSD。[BRD4 原始结构与结合实验](https://doi.org/10.1038/nchembio.1471) · [逐供体结果](../benchmarks/mapping_ensemble/results/donor/donor_geometry.csv) · [受体接触检验](../benchmarks/receptor_contact/results/summary.csv)

hCA II 另用两条轨迹搜索原始表示、两条搜索中心氮反射表示，保持总预算，与已有单映射双态实验比较。两种引导均在 8/20 个条件中生成同时满足 RMSD 与氮构型的候选，原生首姿从 1/20 降到 0/20。按骨架几何选择，首姿从 6/20 到 7/20，所选姿势的原生亲和力判向却从 10/28 到 7/28。该氮构型判据来自重原子几何，未测量溶液中两个微态的布居。病例中出现了直接可分辨的生成问题和选择问题。[hCA II 原始结构和 Ki 实验](https://doi.org/10.1021/acs.jmedchem.0c00733) · [双态逐格结果](../benchmarks/mapping_ensemble/results/states/rank_cells.csv)

对 hCA II 又发现一个输入层面的错误来源。PDBQT 明确写的是手性未指定的质子化叔胺，RDKit 读入同分子三维 SDF 时会按起始构象赋予标签。主矩阵保留上一轮按 SDF 选定的供体和中心以作配对，并在软势中排除实际翻转已指定中心的映射。冻结同一供体、按原始 SMILES 的未指定氮重新建图，6WQ4 的共同骨架从 22 变为 29 个原子，6WQ7 和 6WQ9 均从 34 变为 35。另跑 40 次单一初态多对应搜索，含正确几何与正确氮方向的候选由 0/40 到 4/40，原生首姿仍是 0/40。至少三倍 Ki 的重复判向由 21/56 到 26/56，独立化学对均为 3/7。这里改变了共同子图和氮表示，不能将增益单独归因到软最小值。[声明图逐格结果](../benchmarks/mapping_ensemble/results/hcaii_declared/cells.csv)

对声明图再做同预算双态搜索，在 10/20 个条件中找到同时满足整体 RMSD 与氮方向的姿势。几何选择命中 9/20，原生能量选择命中 0/20。前者用于不同配体的 Ki 判向只得 11/28，后者为 13/28。还用其他配体实测的供体坐标和查询输入的两个空间构型，逐映射检验中心与三个邻居的有向体积。所有映射在给定状态上同向或全逆；无有效映射时回退原先引导，所得坐标与未筛选版本完全相同。若只对全逆的一支去掉氮及第一层三个邻居的引导，原生联合首姿变为 1/20、候选仍 10/20、Ki 为 14/28；几何选择降至 8/20、Ki 为 8/28。该实验区分了可恢复的微态、选择偏差和跨分子自由能代价。[双态声明图](../benchmarks/mapping_ensemble/results/states_declared/rank_cells.csv) · [空间构型与引导约束](../benchmarks/state_correspondence)

## 外部晶体与亲和力压力测试

Merski 等人的 L99A 烷基苯系列单独固定不同配体 4W57 为供体，取同一晶体内 109–113 残基三种 F 螺旋构象，其他受体原子共享。六种查询、三种受体构象、两个种子和三臂共 108 次对接。无引导/单/多的首姿分别是 27/36、27/36、26/36，候选是 29/36、32/36、32/36。四个短链配体各臂合计首姿 24/24。正戊基苯单→多为 1→0/6，正己基苯均 2/6。三组满足实验阈值的 Kd 分子对各臂均判对，长链末两项没有可用的可比定量值。该研究是外部结构系列，同一 T4L 靶点和部分已有化学分子继续出现在这里。单独建库和第二次全量重跑，全部 108 份输出字节相同。[Merski 等原始研究](https://doi.org/10.1073/pnas.1500806112) · [外部晶体明细](../benchmarks/alkyl_holdout/README.md)

对亲和力更严的反证来自 Zhao 等人的因子 Xa 苯并咪唑系列。ChEMBL 同一 assay CHEMBL661804 有 34 条精确 Ki，按预先固定的结构判据，剔除二维化学图中仍有未指派手性中心的六条记录，保留 28 个配体。在 2P16 和 1FJS 两个外部受体中以两个种子分别对接，共 112 次。每个分子对先在同受体、同种子内作差再取中位数，295 个至少相差三倍的化学对各计一次，分数平局计半分。这些对共享 28 个配体，存在统计依赖。该系列用于亲和力，其化合物没有被赋予推断的实验姿势。

| 模型 | 四条件合并的正确方向 /295 | 同重原子数且同形式电荷 /17 |
|---|---:|---:|
| 原生 Vina | 223 | 9 |
| 去掉全局转子除数 | 146 | 8 |
| 以结合态/孤立态一维转子配分积分替代 | 204 | 3 |
| 只按重原子数、大者优先 | 74 | 8.5 |

去掉除数后，2P16 单独从 187 降到 131，1FJS 单独从 231.5 降到 157。28 次每次删一个配体，仍损失 21.6–28.2 个百分点。旧 T4L 的 12→17/19 恰与只按大小的 17/19 相同。两种受体的结果还说明同一个靶点用不同的口袋构象，可以大幅改变原生 Ki 排序。对 125 个四条件原生符号完全一致的化学对，113 个正确；然而 hCA II 的多对应引导在 3 个所有条件一致的分子对上只判对 1 个。运行间一致性不能单独校准实验可信度。[Zhao 等原始论文](https://doi.org/10.1016/S0960-894X(00)00139-6) · [配对表](../benchmarks/affinity_partition/results/size_pairs.csv) · [重算结果](../benchmarks/mapping_ensemble/results/fxa_audit.txt)

复核时还发现 `--weight_rot` 和 `--weight_vinardo_rot` 共写同一个变量，另一项的默认值会覆盖显式设置。已分离变量，分别测了评分模式、默认值、配置文件及交叉选项。真实 FXa 配体显式 Vina 转子权重为零时，由旧版 −9.192 变为 −11.879，与保存的原始能量独立还原值 −11.880 相符至打印精度。说明书所述参数现在确实能控制相应评分函数。

## 两种溶剂近似及可定位的偏差

BRD4 的四个独立非查询供体中都能看到的水，有时也会被另一配体占据。冻结候选后，原生排序的首姿为 7/24。加入保守水位置及水桥项降至 2/24。允许类型匹配的配体原子补偿水原有的蛋白极性接触，仍为 2/24。对已知查询晶体事后仅删除其实际占据的水位点，恢复到 6/24；再按已发表的 101 个 BRD4 结构分析，从四个外部结构 6MH1、5I88、4GPJ、5DLZ 推断可置换水位点，也恢复到 6/24。外部规则的四例都是从错到对，没有丢失原先命中，但 Kd 判向从 13/30 降到 7/30，原生是 9/30。其定位了错误固定水位的实际后果。外部规则在诊断后提出，其中一个供体与查询含相似片段；这不是对完全未见化学空间的前瞻验证。hCA II 双态中保守水校正使联合首姿从 1→3/20，Ki 从 9→17/28，但新增的 10 个正确重复比较全部涉及同一个弱配体 34，还损失两格。合并成统一亲和力项缺乏依据。[101 个复合物的原始结构分析](https://doi.org/10.1039/D1OB00658D) · [水模型结果](../benchmarks/water_occupancy/README.md)

另一项实验将固定坐标受体–配体库仑作用和 OBC-II 的复合物减受体减配体溶剂极化变化成对计算，在 2,067 个真实候选上评估。只算库仑或只算溶剂化的改善没有在完整循环中重复。hCA II 双态首姿 1→1/20、Ki 从 9→2/28；BRD4 转移首姿从 7→3/24、Kd 9→9/30。合并氢的 PDBQT 电荷、固定几何、溶剂边界与排除锌离子的近似都会影响两个大项之差；这次数据不能将误差唯一归因到其中一项。[OBC 原文](https://doi.org/10.1002/prot.20033) · [方法、逐项能量及独立复核](../benchmarks/polar_endpoint/README.md)

已发表的 T4L 显式溶剂结果提供了区分采样与打分的参照。同九个分子和 19 个三倍差分子对，Mobley 等结果由单姿势 13/19 到多姿势 15/19，再计入 Val111 构象释放 16/19，更换成该文 AM1-BCC 方案后 18/19。另一项 HREX-SRTI 的统一 BCC 列为 19/19，配对自由能差 MAE 0.749 kcal/mol，此处原生 Vina 为 1.178 kcal/mol。上述数字从原始发表表格复算；本轮没有重新生成那些分子动力学轨迹。两个研究使用同一模型口袋，在更复杂的靶点上仍需重新验证。[Mobley 等](https://doi.org/10.1016/j.jmb.2007.06.002) · [HREX-SRTI 原文](https://doi.org/10.1021/ct2003786) · [19 对的逐项归并](../benchmarks/affinity_partition/results/published_pairs.csv)

## 复现与核验

提供的证据压缩包以 `fdv-*` 目录名保存实际输入、原始 PDBQT、搜索日志和结果清单。以下例子从解压目录运行，`repo` 指向本项目。Python 环境需含 RDKit、Meeko、NumPy、SciPy；OBC、水和外部结构制备的附加依赖见各研究目录。

~~~bash
python "$repo/tools/build.py" --output-dir "$repo/build/ensemble" --jobs 4
p=brd4
data="$PWD/fdv-brd4"
out="$PWD/replay-brd4"
python "$repo/benchmarks/mapping_ensemble/prepare.py" "$p" "$data/prepared" "$out"
python "$repo/benchmarks/mapping_ensemble/dock_matrix.py" "$p" "$data/prepared" "$out" "$repo/build/ensemble/vina" \
  --seeds 314159 271828 161803 141421 --arms native single multi
python "$repo/benchmarks/mapping_ensemble/score_matrix.py" "$p" "$data/prepared" "$out" \
  --seeds 314159 271828 161803 141421 --arms native single multi
python "$repo/benchmarks/mapping_ensemble/verify.py" "$p" "$data" "$out"
python "$repo/benchmarks/affinity_partition/audit_fxa.py" fdv-free-cycle/activity.json fdv-fxa fdv-fxa1
~~~

T4L 使用 `t4l / fdv-pro-fixtures`，hCA II 使用 `hcaii / fdv-second`。外部晶体、溶剂和扭转积分的复现脚本分别在 alkyl_holdout、water_occupancy、polar_endpoint 和 affinity_partition。主矩阵 4,077 个姿势以独立实验 SDF、蛋白对齐和 RDKit CalcRMS 复核，最大偏差 0.00000065 Å；hCA II 另逐姿核对手性方向。额外的双态及未指定氮输入各自重新核验候选坐标。18 组查询/供体分子在独立随机重排原子编号后恢复完全相同的映射集合。160 个历史无引导与单映射对照逐字节相同。C++ 以独立标量公式和刚体/扭转有限差分核验导数，并测了映射重复、次序以及能量差很大时的数值稳定性。
