# 档案去重的独立受体验证

原始登记包含五个受体。三项未通过已登记的 8 Å 输入审查。读取对接结果前又登记了三个受体，1UY6 在 Meeko 残基模板匹配时失败。两批各有两个可用受体，分别来自 FABP4 和 HIF2α。原始失败样本、结构与制备日志均已归档。四个成功受体对应四种配体、两组近缘化学系列。每组有两个重对接和两个交叉对接组合，每个组合使用两枚种子。共晶配体用于确定已知口袋位置和离线评价。预测配体从 CCD 化学图独立制备。

| 靶点 | 条件数 | 上游 Top-1 / Top-5 / 输出池 | 父版 | 修改后 |
|---|---:|---:|---:|---:|
| FABP4 | 8 | 0 / 1 / 5 | 0 / 1 / 5 | 0 / 2 / 6 |
| HIF2α | 8 | 8 / 8 / 8 | 8 / 8 / 8 | 8 / 8 / 8 |
| 汇总 | 16 | 8 / 9 / 13 | 8 / 9 / 13 | 8 / 10 / 14 |

成功判据为受体坐标系内考虑化学图对称性与共晶配体多占位后的重原子 RMSD ≤2 Å。有正确候选的条件中，三个算法的首姿命中分别为 8/13、8/13 和 8/14。16 个条件均未产生 ≥0.5 Å 的首姿变化。所有首姿均未触发配体和受体重原子之间 0.75 倍范德华半径和的碰撞判据。

两次成功指标变化都来自 3P6E 配体在自身受体中的对接。种子 961751 的同一正确姿势从第 6 名移至第 5 名，分数 −5.151 kcal/mol，RMSD 1.358 Å。种子 684173 的父版输出池最好为 3.889 Å，修改后第 9 名为 1.800 Å（−4.813 kcal/mol），同一运行首姿保持 4.331 Å（−6.138 kcal/mol）。两次命中的参考均为 ZGC 的 B 占位，共晶中 A 和 B 占位率各为 0.50。ZGB 的两个实验占位分别为 0.70 和 0.30。两种 FABP4 配体均使用中性羧酸微态。溶液中的质子化平衡和结构水贡献未在此测定，这些数据无法单独确认哪个能量项导致 FABP4 首姿失误。

在 HIF2α 的 3H82 重对接、种子 684173，父版输出有一对重原子原序对应距离 0.921 Å 的姿势，小于 1 Å 阈值。修改后的最小距离为 1.203 Å。修改版 16 个输出池中没有小于 0.998 Å 的重复对（留出 PDBQT 三位小数舍入余量）。这一对姿势与 FABP4 的两次改善来自不同运行。输出内的距离不能直接说明较早搜索阶段或显式精修如何改变后续分支。

## 实际成本

每次运行固定单核、4 条轨迹、每条 12000 名义求值和 9 个模式。下表统计 16 个 CLI 进程，第二轮使用最终提交的程序。第一次测量的候选程序与最终源码仅差一处向量长度断言。两轮 48 个输出逐一字节相同，所有分阶段计数也一致。cells.csv 是最终程序的结果，repeat_cells.csv 为第一次计时。计数回放另行执行，未计入正式预测耗时。正式 CLI 从读取输入运行至写出 PDBQT 并退出。峰值内存为各进程范围。

修改后 hunt 局优次数由 19567 次降为 19304 次，二次局优由 3239 次增至 3469 次，显式局优由 142 次增至 144 次。总求值增加 173 次，约 0.022%。两轮总墙钟相对父版分别为 −0.055% 和 +6.89%，合并约 +3.37%。单次进程很短，当前实验不能证明严格等时的准确率提高。上游构建来自提交 3c65c0b，src/lib 与 src/main 相对 v1.2.7 标签无代码差异。上游与 Pro 的运行时间差包含既有实现差异。

## 复核与复现

独立核验使用 RCSB ModelServer 的结合态 SDF，通过 SDF 坐标在原始 PDB 中定位原子名称并重建所有配体占位，使用 Meeko 的 SMILES IDX 独立识别预测原子次序。以另一种旋转实现从原始 Cα 求受体间变换。四个受体的 423 个输出姿势与主评价最大差异 5.33×10⁻¹⁵ Å。逐姿势映射与各占位 RMSD 见 independent_modes.csv。四个成功结构周围 8 Å 内无检测到的晶格对称接触。sources.json 记录全部八次制备（原始 PDB/CCD 已缓存，时间不含网络下载）。每个输入的准备工作由三种算法共享。

在当前目录执行，Python 依赖版本见 verification.json。原始日志、计数、PDBQT 和进程成本均在 outputs.tar.xz 中。

```bash
sha256sum -c SHA256SUMS
mkdir -p work
tar -xf inputs.tar.xz -C work
tar -xf outputs.tar.xz -C work
cp cells.csv modes.csv work/
python audit_transfer.py work work
```

复算 48 个完整 CLI 运行，需提供研发基准、当前修正版、同版上游与上游计数版。上游计数补丁为 benchmarks/pair_gradient/upstream_counts.patch。Linux 上选择允许绑定的 CPU，原始试验为 CPU 4。从 RCSB 原始文件重新制备可采用 `OPENMM_CPU_THREADS=1 python prepare_inputs.py work`；精确回放可直接使用归档输入。

```bash
OPENBLAS_NUM_THREADS=1 python run_panel.py work --cpu 4 --upstream "$UPSTREAM" \
  --counter "$UPSTREAM_COUNT" --parent "$PARENT" --candidate "$CANDIDATE" --reverse
python audit_transfer.py work work
```
