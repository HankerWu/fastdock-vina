# 3P6E 的羧基在两类姿势中去了哪里？

该复合物中的 3-(4-甲氧基苯基)丙酸有两个各占 50% 的沉积构象。直接读取晶体结构，两个羧基氧到 Arg126 胍基氮和 Tyr128 酚羟基氧的最短距离均在 2.52–2.82 Å。PDB 记录显示结晶使用 pH 6.5 的 1.6 M 柠檬酸钠。三种搜索引擎共享 CCD 生成的中性羧酸微态及去水受体。

为定位已生成的正确候选为何落后，冻结重原子坐标，用未改动的上游 Vina 进行单点计算。全部六次计算使用同一受体、原搜索盒和同一游离态参考 −0.230 kcal/mol（种子 684173 的首姿内部能）。实验 A/B 的重原子取自原始沉积，唯一的极性氢按输入的局部羧基坐标系搬移；所有坐标均未再松弛。

|---|---:|---:|---|---:|---:|
| 实验 A | 0 | 2.79 / 2.52 | 162，2.62 | 25 | −5.554 / +0.398 / −3.900 |
| 实验 B | 0 | 2.62 / 2.82 | 270，2.76 | 26 | −5.798 / −0.287 / −4.635 |
| 684173，第 1 名 | 4.33 | 5.32 / 5.76 | 252，0.44 | 40 | −7.753 / −0.230 / −6.138 |
| 684173，第 9 名 | 1.80 | 3.03 / 3.16 | 270，2.06 | 23 | −6.100 / −0.208 / −4.812 |
| 961751，第 1 名 | 4.48 | 6.24 / 6.39 | 273，0.68 | 38 | −7.616 / −0.242 / −6.039 |
| 961751，第 5 名 | 1.36 | 3.98 / 2.98 | 270，0.99 | 31 | −6.533 / −0.215 / −5.160 |

在种子 684173 的固定坐标上，错误首姿相对第 9 名的分子间项有利 1.653 kcal/mol，配体内部项仅有利 0.022 kcal/mol。第 9 名的羧基更接近实验极性接触，首姿则有更多短程碳接触，并占用了实验水 252 所在的空间。另一枚种子也有相同方向。碳接触数是几何描述量，各 Vina 势能项的贡献不能仅由此确定。表中所有最近的水位点在沉积结构中的占位率为 1.00。即便是 RMSD 1.36 Å 的候选，羧基氧与水 270 也只有 0.99 Å，两者无法同时按此位置存在。

因此，当前模型给错误构象的优势主要来自受体–配体项。中性羧酸、缺失的离子相互作用和去水口袋容纳了实验水的空间都可能参与；此实验保持它们同时固定，无法分配各因素的独立自由能贡献。实验结构中的水能否真实置换取决于结合条件。共晶重原子坐标与 pH 也不能单独确定配体在口袋中的质子化态。两种晶体构象直接单点评分时没有重新优化，不能由其绝对分数推断另一构象的真实亲和力。

固定坐标已舍入至 PDBQT 的 0.001 Å。种子 961751 原搜索采用其自身最佳姿势的内部能为参考，表中统一参考后其绝对总分略有改变；同一运行内排名的分差保持不变。

## 复现

先按照父目录 README 解包输入及正式输出，然后用原生 Vina 二进制执行。native_scores.tar.xz 包含六份固定坐标及完整打分日志。fixed.csv 额外记录了甲氧基氧到侧链的距离和总分的扭转项。

```bash
python analyze.py --inputs ../work --results ../work --upstream "$UPSTREAM" --out replay
diff fixed.csv replay/fixed.csv
```
