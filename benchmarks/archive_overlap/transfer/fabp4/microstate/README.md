# 固定六个姿势，将 3P6E 配体的羧酸改为羧酸根

用同一个去水 FABP4 受体和标准 Vina 势函数，羧酸根的两个近晶体候选仍分别落后于各自的错误首姿。单独改变配体质子化态，解释不了这个模型在两个种子中的姿势误排。

| 原保存候选 | 中性羧酸，错姿 / 近晶体候选 | 羧酸根，错姿 / 近晶体候选 | 错姿的分数优势，中性 → 阴离子 |
|---|---:|---:|---:|
| 684173，第 1 名 / 第 9 名 | −6.138 / −4.812 | −6.283 / −4.926 | 1.326 → 1.357 |
| 961751，第 1 名 / 第 5 名 | −6.039 / −5.160 | −5.930 / −5.283 | 0.879 → 0.647 |

数值来自官方上游 3c65c0b 的 score-only，单位为 kcal/mol，低分排列在前。每个微态使用该微态下 684173 首姿的内部能作为所有六个姿势的共同参考，两种微态四舍五入后均为 −0.230。实验保持每一份坐标固定。[逐姿势能量和原子对应检查](scores.csv) · [原始 PDBQT、全分解日志和二进制校验值](raw.tar.xz)

六个姿势的配体内部项均保持不变。改变微态后，只有 961751 的错误首姿有不同的分子间项（−7.616 → −7.304）。684173 的两姿势分别保持 −7.753 与 −6.100，961751 的近晶体候选保持 −6.533。晶体 A 与 B 的分子间项仍分别为 −5.554、−5.798。总分变化有两个可区分的来源。

- Meeko 为中性酸的两个氧写出 OA，并保留羟基上的 HD。标准 Vina 以 AD 类型中的 OA 判断氧有受氢能力，以是否连接 HD 判断供氢能力。原羟基氧可作供体和受体，去氢后只作受体，两氧仍均为 OA。默认 SF_VINA 的非方向性氢键势使用 XS 类型，其作用项中没有逐对库仑势。对每个微态每个姿势保留拓扑、氢、坐标和类型，只将配体的部分电荷字段全部清零，12 次计算的十个打印分解值分别与原电荷逐项一致。[赋型](../../../../../src/lib/model.cpp) · [势函数选择](../../../../../src/lib/scoring_function.h)
- 去质子化还消除了羧基末端的可转动含氢分支。Meeko 写出的 TORSDOF 从 5 降至 4。Vina 实际从拓扑计算用于柔性归一化的有效扭转数，按可动键的重原子端点计数。此处六组打印能量与有效扭转数 4.5 → 4.0 一致。即使分子间项与配体内部项完全相同，总分也可以改变。对 684173，原始分子间项有利于错误姿势的差值为 1.653，两微态相同，归一化使总分差略增。961751 的分子间差从 1.083 缩至 0.771。[扭转计数与末端校正](../../../../../src/lib/conf_independent.cpp)

对于六份由原脚本归档的坐标，按照各自的 SMILES IDX 与输入准备记录交叉核对 13 个重原子，识别唯一的羧酸羟基，再在 RDKit 分子图中分别保留中性酸或去一个氢并赋 −1 形式电荷。用 Meeko 分别从两套图重建 PDBQT 扭转树、类型、氢和部分电荷。按重建后的 INDEX MAP 逐原子核对，13 个重原子的三位小数坐标在所有姿势和微态中都精确相同。中性酸的显式羟基氢放回该姿势的原坐标。Meeko 所写的各原子电荷之和分别为 −0.002 与 −1.002，受 PDBQT 舍入影响。重建的中性酸六组、每组十个能量分解值逐项重现既有官方输出。独立用修改候选维护后的 Pro 重算，12 行结果表与上游逐字节相同。

该反事实检验当前标准 Vina 的表达能力。结晶 pH 和固定重原子坐标不足以确定真实口袋中的质子化微态。离子相互作用、脱溶剂化、受体重排与水置换所付出的自由能也未由本实验测量。[共晶锚点与水位置](../README.md)

## 复算

使用 Python 3.12、RDKit 2026.09.2、Meeko 0.8.0 与已固定的官方上游二进制。程序直接读取仓库中已有的受体与六个固定姿势。重新执行会从各自的化学图生成 PDBQT 和全部能量分解日志，并验证原子对应及中性分数。

~~~bash
D=benchmarks/archive_overlap/transfer/fabp4/microstate
W=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/score.py" "$UPSTREAM" "$W"
diff "$D/scores.csv" "$W/scores.csv"
~~~
