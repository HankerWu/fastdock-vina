# 档案填满后策略的独立结构登记

先前 FABP4 与 HIF2α 面板已用于解释归档收缩后的二次局优预算分配。这里另选从未在该分支 benchmarks 文本出现的三个 PDB，均与新机制的设计数据分离：人 JNK3 1PMV、BCL-XL 2YXJ、雄激素受体 1T7T。各取主配体所在的 A 链，单一共晶受体重对接。沿用父目录的制备方法、8 Å 受体准入、图对称 RMSD 和 22.5 Å 立方已知口袋。未通过的数据保留原因，不追加样本。

每个合格受体、每个算法采用种子 438013 和 859337、单核、四条轨迹、每条 12000 求值名义上限、9 个名额。对照为原生 Vina、算法修改前 Pro、修正重叠的 Pro，以及加一位轨迹状态的研究版本。每轨迹第一次填满存档后，研究版本仅在原有新最优能量条件下触发第二次局优，档案仅因除去重叠而缩小时不重新启动填充。原生只作背景比较。按整体/逐受体报告 Top-1、Top-5、输出池、首姿 ≥0.5 Å 变化、各阶段实际调用/求值、跳过填充次数及单核 CLI 墙钟/CPU 时间。计数回放必须与正式输出一致。生效与未生效均报告，重复种子不能算作独立复合物。若机制从未触发，就报告该面板无力区分策略。
