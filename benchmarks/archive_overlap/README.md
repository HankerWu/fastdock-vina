# 一个新姿势同时覆盖两个候选时，Vina 应保留谁？

在父版 `2171470` 中，新姿势只与最近的候选竞争。一个新姿势可以比最近的候选能量好，却与另一个能量更好的候选过近；它也可能同时覆盖两个能量都较差的候选。旧算法在这两种情形下都可能把距离小于去重半径的候选留在池中。此次修复改变了实际 MC、跨轨迹合并和精修前去重的共同入口，没有新增运行选项。独立结构对照发现，几何修复能挽救一个已经找到的正确候选。首姿准确率和单位时间准确率的普遍提高仍缺乏证据。

## 线上比较规则

在当前受体坐标系中，沿用每个阶段已有的原子对应，距离为 $d(x,y)=\sqrt{\sum_i\lVert x_i-y_i\rVert^2/N}$。设去重半径为 $r$，仅当 $d<r$ 时冲突。按能量从低到高访问旧代表，平分由旧代表优先。任一更优或同分的邻居即可阻止插入。否则插入新姿势，移除它覆盖的全部低优先级代表，按容量截断。已有代表彼此分离，删除元素不会制造旧代表之间的新冲突，新代表和所有留下的代表也均满足距离要求。这和对“当前池加一个输入”按能量贪心选取分离代表等价。舍弃的历史候选不参与后续选取。

每次插入最多对现有 $K$ 个代表各作一次距离比较，至多 $O(KN)$，容量满且新能量无竞争力时直接返回。原子数、阈值和能量均沿用既有语义。构象搜索中常规保存用 1 Å，默认跨轨迹合并用 2 Å。两个运行时比较都不读真实实验坐标。离线评价使用受体坐标系中的化学图对称校正，并纳入允许的晶体占位。图同构与同序原子比较的区别可见 [Bell 和 Zhang](https://doi.org/10.1186/s13321-019-0362-7)。[修复代码](../../src/lib/coords.cpp) · [穷举回归](../check_online_pose_archive.cpp) · [Vina 原始搜索](https://doi.org/10.1002/jcc.21334)

## 真实轨迹与首次差异

原有六个靶点、66 条归档轨迹中，21 条在退出 MC 时有可确认的违规，共 27 对，另 1 对落入 0.001 Å 坐标记录的舍入不确定范围。按靶点为 DYRK1A 3/12、EPAS1 6/12、FABP4 6/12、FKBP1A 1/12、JAK2 0/6、RBP4 5/12。后续默认 2 Å 合并消除了这批历史样本的违规。[原始轨迹复算](development/historical.csv)

在本轮开发面板中，完整记录 28 格 × 两臂的插入顺序、双精度坐标、能量、入池前后代表和原子序号。两个实现都有 112 条 MC 保存流，另有各 28 条合并和 28 条精修前输入流。独立重放逐一核实全部 9,729 次更新。旧版有 29 条保存流与 1 条合并流在某次更新后发生违规，保存时最近为 0.541 Å。修复版各阶段均为零。观察器与对应的发行配置在每格的完整输出和实际计数一致。固定输入的比较只解释该次选择；连续重放使用原算法的输入流，后续真实搜索的改变由端到端对照衡量。[逐流结果](development/streams.csv) · [同状态单步替换](development/interventions.csv)

这 28 格覆盖 PTP1B、ESR1 和 PARP1 的七个配体/受体组合，各两枚种子、两档预算。相对父版，完整修复有 20 格完整输出逐字节一致，以 0.5 Å 描述首姿变化则为 1 格改善、1 格退化、26 格接近。PTP1B 的 892 在 1T49 自身受体上首姿从 10.40 降到 7.16 Å；对接到 1T48 的另一个种子/预算格却从 9.34 升到 11.58 Å，后者前五最佳同时从 9.34 改善到 4.80 Å。两例均未恢复正确姿势。分别替换轨迹内保存和后续合并表明这两例变化都来自轨迹内保存。四臂 Top-1 / Top-5 / 池命中均为 4 / 5 / 5（各 28 格）。[四臂原始结果](development/factorial/cells.csv) · [三次交错成本](development/factorial/timings.csv)

### FABP4 的正确候选为什么排到第九？

对 3P6E 的错误首姿和第九名正确候选，保持各自坐标不变，用官方 Vina 和共同游离态参考做单点计算。错误首姿在分子间项上有利 1.653 kcal/mol，配体内部项仅有利 0.022 kcal/mol。正确候选羧基氧到 Arg126 / Tyr128 的距离为 3.03 / 3.16 Å，错误首姿为 5.32 / 5.76 Å。后者同时具有更多 4.5 Å 内的碳接触，并距被输入省略的晶体水 252 仅 0.44 Å。实验结晶 pH 6.5，实际预测输入为中性羧酸。另一枚种子的 1.358 Å 姿势也与水 270 只相距 0.99 Å。这说明分子间评分主导了本例排序，单凭接触距离不能确定电荷、去溶剂化、保守水和排斥各自的因果贡献。将所有晶体水固定也可能排斥近实验构象。[六个固定坐标的原始分解及几何](transfer/fabp4/README.md)

## 仍有空位时，是否应该恢复填充阶段？

在 3T1L 的 Galectin-3 配体 16 上，修复后第 43 次保存把九个代表变成八个。原 MC 会为未满池的接受态执行第二次局优，因而本例第二次局优由 44 次变为 59 次，hunt 由 161 次降为 143 次。研究版用一个布尔位记录轨迹是否曾装满。装满后只有原来的最好能量条件可以触发保存。该病例跳过 57 次空位触发，恢复父版的完整输出。1KJL 上的配体 47 在首次分歧前尚未装满，研究版复现几何修复版的全部输出。

全开发组 112 条轨迹仅 2 条实际触发，共 51 次；26/28 个条件的完整输出与几何修复版一致。两臂 4 / 5 / 5 个命中完全相同。全新受体试验中，人 BCL-XL 和黑猩猩 AR 各两个条件，全部 16 条轨迹均未触发，三个 Pro 版本产生逐字节相同的结果。另一个登记的 JNK3 未通过受体制备。这些结果验证了何时会重新分配求值，却没有证明禁止回填有可迁移的姿势收益。保留研究补丁，生产继续采用原来的回填逻辑。[研究源码](refill/once_full.patch) · [开发组](refill/cells.csv) · [独立验证](transfer/refill/README.md)

## 同测定亲和力

47 个 Galectin-3 配体、两个受体的同一竞争性荧光偏振 Kd 系列，按两受体首姿分均值比较至少三倍差异的 403 对。单轨迹 3000 档，官方上游 / Pro 父版 / 几何修复分别为 220 / 201 / 201；单轨迹 12000 档为 179 / 182 / 191；四轨迹每条 3000 为 163 / 171 / 171。单轨迹 12000 档的 9 个方向改善中有 7 个涉及配体 6，另外 2 个涉及配体 16。等重原子数同电荷子集由 20/35 升至 21/35。父版的 282 个固定首姿在两种 Pro 实现上的十项计分值逐项一致。经验分与实测 Kd 的普遍相关性尚未改善。统一降到每条 10,800 次的预算敏感性试验中，父版与修复版分别为 190 和 194 对。修复版相对 12,000 档父版的 12 对总差距中，8 对也出现在缩短预算的父版；相同 10,800 档时的差距为 4 对。这一检查使用已见系列。完整亲和力结果、成本及数据来源见[同测定对照](affinity/README.md)。

## 复现

已有坐标和计数的复核需要 Python、NumPy、SciPy、Gemmi 和 RDKit；重新构建还需 C++14 与 Boost。输入准备另需 Meeko、PDBFixer、OpenMM。命令从仓库根目录执行。研究版本从指定的两个完整 Git 修订构建，仅用于反事实比较。

```bash
D=benchmarks/archive_overlap
python "$D/development/historical.py" | diff - "$D/development/historical.csv"
python "$D/development/verify.py"
W=$(mktemp -d)
bash "$D/build_research.sh" "$W/build" --jobs 4
python "$D/development/verify.py" --binary "$W/build/fixed/vina"
```

开发组原始包包含 56 次正常算法输出与完整观察流；阶段消融及回填附加实验证据分别在 development/factorial 和 refill。核心测试穷举 1,458,000 个有限状态更新。全量干净构建另做 28 次正常入口对接，逐一核实输出字节及各阶段求值。独立结构目录可从 RCSB 原始结构和沉积配体 SDF 重新检查全部 423 个姿势；回填面板另有 112 个姿势。
