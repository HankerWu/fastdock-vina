# 独立化学图与 MEK1 晶体环境对照

用标准 Meeko 树准备三个不同于巴瑞替尼的上市药物骨架。PDE4B–罗氟司特 (1XMU)、VEGFR2–仑伐替尼 (3WZD) 与 MEK1–考比替尼 (4LMN) 按化学结构预选。巴瑞替尼 (6WTO) 为已知的四元环阳性对照。CCD 化学图、固定的 ETKDGv3 种子 43103 与 MMFF 初始弛豫决定输入，起始配体坐标独立于晶体。实验结构只用于结构核对、口袋定位和评价。全部输入和 CCD/PDB 来源标识、散列在 results.csv 与归档 metadata.json 中。使用 RDKit 2025.09.3、Meeko 0.7.1。

逐一比对解析器得到的重原子键与 CCD 重原子键，然后对实际非键打分列表分别测量推断图和 CCD 图的最短路径，确定错误来自哪一层。

| 药物 | 父版 → 修复版，内部非键对 | CCD 图上误计的对数 | 说明 |
|---|---:|---:|---|
| 巴瑞替尼 | 208 → 202 | 6 → 0 | 四元环的键推断正确。 |
| 考比替尼 | 288 → 284 | 4 → 0 | 原推断图与 CCD 一致。四个错误项合计给同一初始构象增加 0.491205 kcal/mol。 |
| 罗氟司特 | 215 → 215 | 1 → 1 | 解析器漏推断三元环内的 21–22 键，导致 19–22 被打分。 |
| 仑伐替尼 | 281 → 281 | 1 → 1 | 解析器漏推断三元环内的 32–34 键，导致 27–34 被打分。 |

两个三元环均为未修复的独立缺陷。默认成键推断会在两端之间出现更靠近两端的第三个原子时删边。因此刚性三角形存在唯一最长边时，该边容易被删。坐标推断和完整输入键表的区别另见仓库已有的 9FA3 固定拓扑回归。这里的广度优先遍历只保证在输入给它的图上计算正确。

## 4LMN 实测姿势

4LMN 分辨率 2.80 Å，最近的 ANP 重原子距配体 2.800 Å。保留全部 35 个实验 ANP 重原子、一个配位 Mg 和所有蛋白 ATOM 记录，已解析残基无缺失重原子需要修补。沉积记录中 276–305 和 383–401 残基未解析，沿用既有准备协议留空；三个有坐标的相邻残基 275、306、382 到配体的最近重原子距离分别为 26.84、23.83、22.87 Å。ANP 的 O2A、O2B、O2G、O3G 按四价阴离子微态处理。考比替尼按 CCD SMILES 的中性微态准备。氢坐标为模型值，未枚举微态，水未纳入。母晶胞外的 Phe223 有六个重原子对距考比替尼小于 8 Å，最近 6.713 Å。在晶胞对称操作和平移下保留能够进入 24 Å 搜索盒加 8 Å 截断余量的完整刚性单元，共四个，均含 ANP 和 Mg。所有查询配体都从受体删除。晶格信息同样提供给三个算法，这一对照只评价指定晶体环境的姿势恢复。

每档一条轨迹、种子 817139、单线程、输出最多九个候选。按与新面板相同的两档预算运行。统计在受体坐标系中通过 CCD 图允许的立体等价匹配计算的重原子 RMSD。每个格子依次为首姿、全部输出最优 RMSD 和实际梯度评估次数。各臂实际输出三至四个姿势，因此 Top-5 与输出池 Oracle 相同。

| 名义上限 | 原生 Vina 1.2.7 | 父版 | 修复版 |
|---:|---|---|---|
| 3,000 | 5.501 / 5.501 Å，3,232 | 5.501 / 5.501 Å，3,222 | 9.593 / 6.141 Å，3,153 |
| 12,000 | 6.343 / 5.500 Å，12,240 | 6.343 / 5.500 Å，12,227 | 10.084 / 6.141 Å，12,134 |

两档的修复版首姿和最优姿势均退化。全部输出都大于 2 Å，所有首姿均无 0.75 倍范德华半径和阈值以下的重原子碰撞。对每档父版池中所有原始坐标使用统一零游离态参考值复算，两个评分器对两个池内的候选给出了相同次序。单独对父版首姿改用自身内部能参考值复算时，两臂亲和力也分别相同。因此这次首姿退化不能由改变父版输出池的排序解释。候选生成、筛选和精修中各环节在本例的细分归因仍未建立。两档是同一配体、同一种子的相关观测。壁钟只测单次。cells.csv 记录每阶段调用、评估与壁钟，modes.csv 记录各姿势 RMSD、接触与原分数。fixed_pools.csv 包含逐姿势相同坐标复算的分项。

## 复算

化学图核对用每个源码版本的库对象分别编译上级目录的 audit.cpp 和本目录的 graph.cpp，编译方法见 preparation/README.md。运行以下命令，其中 AUDIT_PARENT、AUDIT_FIXED、GRAPH_PARENT、GRAPH_FIXED 为对应探针的可执行文件路径。compare.py 将从 RCSB 下载各结构和对应 CCD。

```bash
D=benchmarks/bond_distance/ligands
python "$D/compare.py" "$WORK/raw" --parent "$AUDIT_PARENT" --fixed "$AUDIT_FIXED" \
  --parent-graph "$GRAPH_PARENT" --fixed-graph "$GRAPH_FIXED"
```

mek_evidence.tar.xz 附完整准备后的 4LMN 受体、配体、元数据、原始对接日志、坐标和晶格单元清单。其他三个配体的标准准备输入也在其中。可直接解包重跑，若需从原始 PDB 和 CCD 独立重做输入，再运行 prepare 子命令。UPSTREAM 为官方 1.2.7 源码编译，UPSTREAM_COUNTS 为同一上游增加调用计数的版本。脚本要求其输出坐标文件与上游逐字节一致。

```bash
export OPENMM_CPU_THREADS=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
mkdir -p "$WORK"
tar -xJf "$D/mek_evidence.tar.xz" -C "$WORK"
# 可另建目录，从 RCSB 原始数据重新准备
python "$D/mek.py" prepare "$WORK"
python "$D/mek.py" run "$WORK" --upstream "$UPSTREAM" --counts "$UPSTREAM_COUNTS" \
  --parent "$PARENT" --fixed "$FIXED"
python "$D/mek.py" fixed-pool "$WORK" --parent "$PARENT" --fixed "$FIXED"
```
