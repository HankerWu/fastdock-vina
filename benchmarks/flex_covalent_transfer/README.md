# 柔性受体的跨分区共价邻居对实际预测有什么影响

在相同起点移除移动侧链与固定主链间三键以内的非键评分，改变了 Vina 和 Vinardo 的受体内部能。在相同的 170 个既有 Vina 输出上重评分，Vina 只在 42 个候选池中的两个改变了首姿，一个改善，一个退化。重新进行对接时，历史组平均误差下降，但新加入的人蛋白在不同结构上给出相反结果。以下 RMSD 均以 Å 计。

## 条件和误差分布

初批的 PARP1、两个人尿激酶结构都不能用原定的干燥单链输入完整表示。第二批的人 SHP2 E76K–SHP099（6CMS）通过相同检查。其余结构距离配体 8 Å 内有结晶添加剂。补充分析把这些成分以 CCD 拓扑、同一组晶体坐标纳入两臂，恢复了五个结构。BTK 3OCS 中 β-巯基乙醇与 Cys481 有 2.04 Å 的共价连接，独立小分子模板不适用，保留该排除。干燥组、添加剂组及历史组分别统计。输入排除发生在对接之前。在符合各组输入条件的体系中，三臂都有输出。每个受体固定一条柔性侧链，两个 Pro 版本完全共用该信息，官方 1.2.7 对照也使用同一份 PDBQT。位点已知，侧链根据共晶配体选择，实验针对有参考结构的局部柔性对接。[首批方案](PROTOCOL.md) · [第二批](EXTENSION.md) · [晶体成分规则](SOLUTES.md) · [原始排除](results/primary/structures.json) · [保留的化学成分](results/additive/structures.json)

尿激酶 1F5K 种子 87911 是明显的反例。父版 6 个输出中首姿为 0.379 Å，修正后 4 个输出最佳为 11.447 Å，首姿为 13.666 Å。RBP4 的 1RBP→3FMZ 种子 120997 则由 14.805 改善到 2.806 Å。相同种子并未固定随后的优化和接受轨迹。局优、全局采样、候选保留都可能影响发布池，不能从上述比较断言某一特定搜索步骤导致全部差异。没有记录完整的逐步搜索池。

对 10 组共同起始坐标，以及父版全部 170 个已发布结构候选，在同一构象上分别以 Vina 和 Vinardo 调用两版显式评分。发生变化的是柔性侧链与固定受体的内部能。输出精度 0.001 下，配体–刚性受体、配体–侧链及单构象独立 score_only 分数的版本差始终为零。单构象的 unbound reference 抵消了该项，固定候选排序应以同一配体的公共参考比较 inter + intra。复算采用 40 Å 框，以容纳所有原始 24 Å 对接输出。另将同坐标的修正量加回发布的 inter + intra，保留原框壁和原始评分，两个方法都只检出 1RBP 首姿变差 0.181 Å 和 5DS3 改善 0.994 Å。原版在 40 Å 框的独立复算有一个池首选不同于原版的 24 Å 输出，该池两种方法均未检出修正导致换首。Vinardo 在同一批 Vina 搜得的池中仅 1/42 换首。[原始分项](results/primary/frozen.csv) · [添加剂组分项](results/additive/frozen.csv) · [发布参考对照](results/additive/frozen_rerank.csv)

以输入柔性受体的重原子位置为基准，PARP1–奥拉帕利的首姿配体 RMSD 下降，同时 Ser904 可动重原子的平均位移从 0.588 增至 2.595 Å，χ1 绝对位移从 25.7° 增至 159.6°。这种权衡说明配体姿势误差和受体构象误差必须分开检查。没有受体构象系综或重组自由能的校准。保留的晶体添加剂为刚性，PO4 使用 CCD 的 −3 形式电荷，阴离子质子化、添加剂在溶液中的占据率和水的化学势均未测定。[侧链逐姿势数据](results/sidechain.csv)

## 同一测定的亲和力

人 FABP4 的五个配体取自同一次 ANS 位移测定（298 K、pH 6.5），两个受体都让 Thr60 可动。对每个配体与受体，计算三个种子的首姿分数均值。实验 Kd 从 µM 转为 pKd，与负分数比较。五个配体的报告误差区间均不交叠，十个可比较的分子对均保留。分子使用已归档的中性羧酸微态，不能据此推算真实结合自由能。[原论文](https://doi.org/10.1107/S2053230X14027897) · [配体与误差](../archive_overlap/transfer/fabp4/assay/measured.csv)

|---|---:|---:|---:|
| 2NNQ | 0.90→0.80 | 0.80→0.60 | 9→8 / 10 |
| 3FR2 | 0.60→0.70 | 0.40→0.60 | 7→8 / 10 |
| 两受体等权均分 | 0.70→0.80 | 0.60→0.60 | 8→8 / 10 |

受体等权后，L2/L3 和 L2/L4（Kd 差 99 与 201 倍）转为正确，L3/L4 和布洛芬的 R/S 对映异构体（2.03 与 1.40 倍）转为错误。穷举 5⁵ 种配体级配对重抽样，3120 种有定义，Δρ 的描述性 95% 区间为 [−0.889,+1.750]。同受体不同种子和共享配体的分子对均未充当独立生物观测。没有同测定 Ki 结果，也未估计 ΔG 或 ΔΔG。[全部预测](results/primary/assay_compounds.csv) · [分子对](results/primary/assay_pairs.csv) · [不确定性](results/primary/assay_intervals.csv)

## 成本和复现

12000 预算下，历史和 6CMS 共 27 个结构条件的原/修正单进程墙钟和为 5.827/5.951 秒，CPU 为 5.730/5.912 秒；添加剂组 15 个条件为 3.036/2.977 秒、CPU 3.001/2.949 秒。相同参数但实际的 hunt、第二阶段和显式精修求值次数均有变化。全表给出每任务用时、各阶段调用数及进程资源统计。并发作业会影响墙钟；Linux wait4 获得的峰值 RSS 可能包含刚 fork 时 Python 父进程的下限。原始 12000 预算结果已记录在 cases.csv。配体生成、结晶成分及受体参数化在两个算法间共享，这轮没有单独计时。官方工具不输出相同格式的求值计数。扩预算试验见 [24000 对照](BUDGET.md)。

源自 RCSB 的 PDB 与 CCD、输入原子拓扑、对称映射、就绪的受体分区与配体均在 [输入归档](inputs.tar.xz)；全部发布姿势和控制台日志在 [预测归档](predictions.tar.xz)。新结构的 PDB、CCD 标识及 SHA256 可在归档的 source.json、metadata.json 和纳入清单中核对。下载与重制使用 NumPy 2.3.5、SciPy 1.17.0、RDKit 2025.09.3、Meeko 0.7.1、Gemmi 0.7.4、OpenMM 8.6.1、PDBFixer。高成本准备的替代方案是直接解包冻结输入，可免重下和重建。结构和实验的来源包括 [6CMS](https://doi.org/10.2210/pdb6CMS/pdb)、[5DS3](https://doi.org/10.2210/pdb5DS3/pdb)、[1F5K](https://doi.org/10.2210/pdb1F5K/pdb)、[1F5L](https://doi.org/10.2210/pdb1F5L/pdb)、[3P5O](https://doi.org/10.2210/pdb3P5O/pdb)、[5EHR](https://doi.org/10.2210/pdb5EHR/pdb)、[3OCS](https://doi.org/10.2210/pdb3OCS/pdb)。

从仓库根目录执行下列命令，使用源码基线 51c4baf、修正版和官方 1.2.7 对应的绝对路径。脚本接受每个模型的可执行文件，以 cases.csv、modes.csv 记录失败及连续误差。

```bash
D=benchmarks/flex_covalent_transfer
W=$(mktemp -d)
tar xf "$D/inputs.tar.xz" -C "$W"
python "$D/experiment.py" "$W/prepared" "$W/experiment" "$BASE" "$FIXED" "$OFFICIAL"
python "$D/experiment.py" "$W/additives" "$W/solute_run" "$BASE" "$FIXED" "$OFFICIAL" --solutes
python "$D/fixed.py" "$W/prepared" "$W/experiment" "$BASE" "$FIXED"
python "$D/fixed.py" "$W/additives" "$W/solute_run" "$BASE" "$FIXED"
python "$D/summarize.py" "$W/experiment"
python "$D/summarize.py" "$W/solute_run"
python "$D/sidechain.py" "$W/sidechain.csv" --panel "$W/experiment" "$W/prepared" --panel "$W/solute_run" "$W/additives"
```

从源数据重建输入时，使用 `OPENMM_CPU_THREADS=1 python "$D/prepare.py" "$W/prepared"`，再使用 `OPENMM_CPU_THREADS=1 python "$D/solutes.py" "$W/prepared" "$W/additives"`。以已有配体/受体文件进行重跑无需采样原始晶体作为初始配体。跨受体对齐仅用于离线测量。绝对计时以及二进制哈希随构建环境而变。

从归档解出的输入重新执行全部 270 个条件–算法组合。270 份逐姿势 PDBQT 与首次运行逐字节相同。复跑时两个队列并发，官方二进制有 12 个进程收到 SIGKILL；单进程重新运行后各自与归档字节一致，原始实验的 270 次均完成。[归档哈希和重放计数](results/release_replay.json)
