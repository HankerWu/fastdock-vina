# 柔性侧链跨文件共价邻居的迁移检验

基线为 51c4baf；两臂都用 Vina 默认评分和默认显式精修，输入、种子和搜索预算配对。拟检验移动的侧链原子和固定主链之间的近程共价邻居进入非键评分后，是否改变局优、候选与首姿。开发者没有根据本面板调整参数。比较前固定如下规则。

- 新的受体迁移测试采用人 PARP1 5DS3（09L）和人尿激酶 1F5K（BEN）、1F5L（amiloride，按条目化学成分号）。按既有结构预处理排除距配体 8 Å 内存在未建模非水原子的结构；如不通过，保留排除原因，不替补。每种受体使一条侧链可动，选择距配体最近的可旋转标准侧链（侧链重原子至配体重原子的最短距离，排除 Gly、Ala、Pro、Cys）。这是使用已知口袋位置和共晶坐标选定柔性残基的机制测试，两臂共用。对每个结构保留所有前定种子 62483、87911、120997。另运行官方 Vina 1.2.7 作参考。
- 对同一历史人 FABP4 位移测定的全部五个精确 Kd，沿用 archive_overlap/transfer/fabp4/assay 的实测值、配体输入和两个受体 2NNQ 与 3FR2（Thr60 可动）。每配体、受体和算法均用同三枚种子。按受体内种子均分做排序，另列两个受体均值。排除实验不确定区间相交或相等的配体对，预测相等记半分，列出全部原始配体与分子对，不混入其他终点。
- 搜索框各边 24 Å，已知结合位点中心；1 CPU、exhaustiveness 1、max_evals 12000、9 个输出、energy_range 100。主比较为同条件首姿受体坐标系的 CCD 对称映射重原子 RMSD 配对差。辅助为前五最小、发布池最小及与首姿之差、完整逐姿势结果及成本。按病例保留失败，种子不充当独立靶点。不从捕获的输出池推断整个搜索轨迹的真实 oracle。使用前定的构型转换失败或无输出时保持失败记录。
