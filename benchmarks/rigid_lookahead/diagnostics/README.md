# 剪枝前后的两组因果对照

实验保留原平移扫描的每个候选、同一张 0.75 Å 网格和相同的 24 个方向。在每个方向取最低能候选前，分别记录原坐标和刚体试步后的能量与晶体 RMSD。每池的九个盲选起点均进行原生显式精修。对没有入选的近晶体坐标也单独运行相同精修，这些有标签的干预仅用来检验盆地是否仍然可达。两个种子共享同一查询和受体。

| 配对 | 种子 | 全部父姿势 | 试步前→后 ≤2 Å 数 | 方向胜者中 ≤2 Å 数 | 九个输出中最佳 RMSD 和排名 | 首位 RMSD |
|---|---:|---:|---:|---:|---|---:|
| 5EPS→5C7N | 43103 | 61,152 | 5→17 | 1 | 1.641 Å，第 7 | 3.732 Å |
| 5EPS→5C7N | 43117 | 61,152 | 5→14 | 0 | 1.523 Å，第 5 | 2.574 Å |
| 3WKE→4OD0 | 43103 | 18,816 | 0→0 | 0 | 6.003 Å，第 2 | 11.811 Å |
| 3WKE→4OD0 | 43117 | 17,280 | 1→0 | 0 | 6.571 Å，第 3 | 12.110 Å |

**BRPF1。** 对种子 43103，原扫描中最低能的近晶体父姿势在其方向内排第 723。一步刚体松弛使其两颗疏水碳 9、10 的原子图能量分别下降 2.818、2.433 kcal/mol，合计占总降幅 7.649 kcal/mol 的约 69%。该起点升至方向第一，进入显式精修。单独精修未移动的父姿势后 RMSD 为 1.236 Å，精修试步后的起点为 1.641 Å。因此这次收益来自让正确盆地获得名额。种子 43117 中，步骤之后有 14 个合格坐标，全部在逐方向选择时被淘汰。该方向的胜者起点距晶体 2.152 Å，精修到 1.523 Å，说明直接用起点的 2 Å 阈值判断是否有机会命中，会漏掉一个实际成功的精修。

**EPHX2。** 对种子 43117，原来唯一合格的父姿势在全体起点中排第一。其粗分从 14.762 降至 13.254 kcal/mol，但 RMSD 从 1.953 增至 2.106 Å。同方向另一个更远的父姿势从 37.605 降至 7.728 kcal/mol，排名由方向第八升至第一。原近姿势在本方向降至第七，在每方向只取一个的筛选处丢失。若强行保留，移动前、后可分别精修至 1.802 和 1.924 Å。盲选的替代者只到 6.571 Å。该退化同时有错误方向的坐标移动和更大幅度释放远处候选排斥的相对排名效应。原子的地图分项包含 Vina 的多项贡献，仅凭此分解不能将全部降分化归为某一种化学作用。

**独立复算。** 每个原子的三线性导数通过目标网格单元两相对面插值之差计算。刚体方向使用完整的逐原子笛卡尔雅可比矩阵及 SVD 广义逆。它与预测代码的解析三线性梯度、力和力矩及惯性张量求解独立。[逐病例误差](results/kernel_errors.csv)覆盖全部 158,400 个相同起点。接受后能量最大误差小于 1.0×10⁻¹² kcal/mol，平移和旋转向量的最大分量差分别以 Å 和 rad 计，混合取最大值小于 1.2×10⁻¹⁴。单点、共线和非共线构型的可观自由度分别为 3、5、6。重原子切向 RMS 步长均为 0.75 Å，有限旋转方向导数与中心差分的最大误差为 1.56×10⁻¹⁰ kcal/mol（沿无量纲步幅参数取导数）。111 个网格内部位置的空间导数最大误差为 2.72×10⁻¹⁰ kcal/mol/Å。实际位移经有限角度旋转，未将其声称为精确的 0.75 Å 笛卡尔 RMS。

**复算。** 从实验主目录的说明构建基线 Vina、观察器并解压开发集。下列命令使用相同的 dev、vina 和 probe。Python 依赖复用上层交叉对接评估器。未计入命中的事后精修及诊断资源开销与盲运行成本分开。

```bash
D=benchmarks/rigid_lookahead/diagnostics
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python "$D/replay.py" \
  --dev "$DEV" --vina "$VINA" --probe "$PROBE" --work "$WORK" --check-kernel
python "$D/check.py" "$WORK/numeric.json"
```
