# 人凝血因子 Xa 的同测定 Ki 排序

在同一 Zhao 苯并咪唑系列中，排除侧链 Asp189 跨越刚柔分区的共价近邻后，两个受体的三倍差异分子对一致率均下降。在等重原子数、同形式电荷的 17 对中，两种受体上的一致度均上升。这个系列给出了一个可以复算的反例，无法证明对其他靶点或实验条件的普遍退化。

|---|---:|---:|---:|---:|---:|

| 2P16 | 0.410→0.221 | 0.324→0.149 | 248→215 / 374 | 201→179 / 295 | 8→11 / 17 |

原表共 34 个不同分子，均有精确的 nM Ki。在看本次结果前沿用既有配体制备决定，六个立体化学未指定的分子缺少已制备的输入。28 个已制备分子的 224 次全局对接均有输出，覆盖 28/34 原测量，28/28 已制备分子。每个受体中共有 378 对，四个实测并列，295 对达到三倍差异。两枚随机种子取首姿分数均值后，两个受体和两种算法的预测均无并列。三倍是复用的诊断口径，原实验没有给出支持逐对判别显著性的误差。原记录以人 F10 为靶点，ChEMBL 靶点置信等级 8，温度、pH、变体及重复测量不确定度缺失。这些预测没有该系列的共晶参考姿势。[赵等原始论文](https://doi.org/10.1016/S0960-894X(00)00139-6) · [PubChem AID 51686](https://pubchem.ncbi.nlm.nih.gov/bioassay/51686) · [归档的活性原表](../frozen_core/affinity/fxa_activity.json.xz)

两个受体等权平均，修正减父版的 Δρ = −0.089（描述性 95% 区间 −0.385 至 +0.228），Δτ-b = −0.096（−0.305 至 +0.142），三倍差异一致度变化 −5.59 个百分点（−17.73 至 +8.60）。两千次重抽样以化合物为单位，两臂、两枚种子和两个受体在每次抽样中保持配对。这些区间仅描述已制备同系列分子在两个固定受体上的不确定性。[逐受体汇总](results/metrics.csv) · [配对区间](results/bootstrap.csv) · [全部分子与覆盖](results/compounds.csv) · [逐分子对预测分差](results/pairs.csv)

每臂各 112 个常规 Vina 对接进程。父版与修正版的 CPU 时间合计为 29.12 和 28.44 秒，单进程墙钟相加为 31.54 和 30.51 秒，进程峰值 RSS 中位数为 24.18 和 26.90 MiB。网格搜索、二次局优及显式精修联合求值总数分别为 1,392,752 和 1,389,486。整个四路并行实验墙钟 15.75 秒。复用归档 PDBQT，完整性检查、受体切分、盒定位和提取既有配体耗时 0.53 秒。原始化学制备成本未重新计时，单次耗时差不支持性能优越性结论。[逐次分数、成本和覆盖](results/runs.csv) · [二进制和耗时记录](results/run.json)

## 复现

原始共晶 PDB 的 SHA-256 为 1FJS `240307991202f732540d06fe585a8291d541412d410a2539d5d8ce6151a6d53e`、2P16 `00ee06bbd8635d732edc7a5acd3ba255d8489976a8a382fd51cf295cdb229905`。读取链 A 的 Z34 与 GG2 的 HETATM 行，分别得到 38 和 34 个原子。随实验附上这两组原始坐标，唯一用途为复算历史结合口袋中心。所有受体、配体 PDBQT 从仓库此前冻结的归档读取，仅将预注册的同一残基切出。两部分原子记录可逐字重构原受体。[1FJS 坐标](https://files.rcsb.org/download/1FJS.pdb) · [2P16 坐标](https://files.rcsb.org/download/2P16.pdb) · [实验冻结条件](PROTOCOL.md)
