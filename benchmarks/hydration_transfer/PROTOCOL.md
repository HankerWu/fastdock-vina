# 跨受体水位点模型的独立结构验证协议

本清单冻结于本轮查看任何预测姿势之前，原始分支为 f0e6dbf。BRPF1 的原始研究报道过有序水保留与置换。另选水记录稀疏的 EPHX2 作为对照。六个交叉配对用于检验本轮以人凝血酶开发的水模型。它们不参与参数选择。3WKE 曾被旧实验列为备选受体。原协议未运行该受体。

| 家族 | 共同接收结构及定义口袋的配体 | 查询结构与配体（chain A） |
|---|---|---|
| BRPF1 | 5C7N / BMF | 5EPR / 5QY，5EPS / 5QX，5FG5 / 5XF |
| EPHX2 | 4OD0 / 2RV | 3WKE / AUB，4X6Y / S94，3ANT / S82 |

- 对每个家族另做接收结构自对接，单列诊断；其中共晶水可含相应配体的信息。
- 采用仓库既有交叉对接配体、受体、蛋白对齐和配体化学图映射流程。输入从 CCD 化学图生成，盒为接收配体重原子中心处 24 Å 立方。接收结构水是附加的实验信息。对齐和查询晶体坐标只供评价。
- 原生 Vina 与 f0e6dbf 默认 Pro，单 CPU、exhaustiveness=4、max_evals=3000 或 12000（每条轨迹名义上限）、num_modes=9、energy_range=100，种子 43103 和 43117。每个预算单独报告。原生与 Pro 均以实际 CLI 默认的精修和候选管理运行。
- 在同一批 Pro 姿势上比较原生排序、固定位点和可移动位点的事后排序。记录每姿势原始分数、固定/移动修正、对称校正 RMSD 和实际耗时。每个接收结构的预计算与每个查询的成本分别列出。冻结坐标的池覆盖应严格相同。
- 阈值为重原子 RMSD ≤2 Å，不叠合配体。分别统计首位、前五、池覆盖和有正确候选时首位命中。重复种子不当作新的复合物。保留全部退化和缺失，并公布原始输入、输出、命令及排除理由。未预设应获益。
- 不调整水参数、打分权重、盒或搜索预算去改善本面板。若需据此修改模型，全部六个配对立即归为开发集。
