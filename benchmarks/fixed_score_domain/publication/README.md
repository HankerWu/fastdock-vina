# Round-tripping native rigid poses at the search-box boundary

A second defect appeared while rescoring the published 4OCZ pools after the fixed-score API repair. For four poses, the reported raw intermolecular plus intramolecular score differed by about 40 units from the value recalculated on the same prepared graph. All four had an atom printed at z = 4.750 Å; the box began at 4.750040 Å. The 0.000040 Å projection onto the box costs 40 units under the 10⁶ per Å linear penalty. The internal-to-printed discrepancy can therefore dominate the physical ligand–receptor terms, even with a strictly valid unrounded search solution. The public grid check uses a 0.0001 Å tolerance, so these poses pass that check. The numeric wall, domain tolerance, and PDBQT precision have separate purposes.

In 8d24ebe, the existing decimal-safe rigid translation is applied after the last explicit local refinement, before calculating its final raw score and inter-pose coordinates. Native and late selection retain their respective coordinate definitions for distance filtering. A shift is possible only with one ligand, a rigid receptor and a common rigid translation that fits all bounded atoms into both the actual box and its printable interval. The existing half-millith Å boundary rule is preserved. Genuine exterior poses, impossible fits and flexible-residue coordinates need separate treatment. Each residual is the independently requested fixed-graph evaluation of the serialized pose (printed ligand–receptor + internal terms) minus its archived raw total. The final four outputs have zero wall excess. Each had at most 0.001 Å displacement of a serialized atom. All 14 other modes retained their exact printed coordinates and had |residual| ≤ 0.027; even away from a wall the fast atom-pair table and rounding of coordinates and energies limit exact recovery. The two first poses (1.762 and 10.310 Å), the number of released modes and their ranks were unchanged. All hunts, second minimizations and explicit gradient counts were identical in each pair of runs. Both late-selection pools remained byte-identical. In the centered ABL control, a single rank-nine atom changed from y = 64.028 to 64.027 Å; all energy fields and all other coordinates matched. The computed upper face is 64.027999999999992 Å. The existing helper uses a conservative representable interior decimal even when the nominal overrun results from floating-point arithmetic.
