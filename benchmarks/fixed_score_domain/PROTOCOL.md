# Fixed-coordinate scoring and the box wall

Registered against f46aa3774f9c77503b98654ec3903fbdb1c72fc0 before generating any score. This is an API/CLI and numerical mechanism experiment, independent of blind docking or affinity ranking.

Use two previously prepared benign systems. For ABL use examples/basic/1iep_receptor.pdbqt and 1iep_ligand.pdbqt. For BPTF use 7F5D/receptor.pdbqt from geometry_comparison/pose/inputs.tar.xz and the first model of poses/7F5D-7F5D-63419-armijo.pdbqt from geometry_comparison/pose/low_outputs.tar.xz. Preserve original atoms, coordinates and torsion trees. Compute a 30 Å cubic box centered on the midpoint of the input Cartesian extents. Reuse all three positive controls: native reference, fixed zero reference, and fixed reference of -3 kcal/mol. Recenter the box by +1 Å along x as a further control: the explicit receptor field at an interior point should remain the same. One CPU, fixed seed 20261128, no search, no minimization. All calls retain their logs, result status, input hashes, process CPU and elapsed time.

For the challenge, translate all ligand atoms by +40 and +41 Å along x in the original box. All bounded atoms must lie beyond the same wall; verify this from inputs and actual grid spacing. The projected receptor field and internal geometry are then constant between these translations. In the old shared-reference path the raw receptor energy should increase by 1,000,000 times the number of bounded ligand atoms upon the second translation (allow 0.01 kcal/mol for output rounding). The automatically computed reference path should reject both. Both public fixed-score entry points should reject them after repair; global-search selection and internal rescoring keep their established calling semantics. This one-axis prediction distinguishes a search-box penalty from actual receptor interactions. No thermodynamic temperature, chemical potential, equilibrium weights or standard-state free energy enters this empirical fixed-state score.

For each system and reference, run single and batch scoring on two interior poses (original and translated by +1 Å). A working batch must emit one identifiable result per input, in input order, matching every printed component of its own single invocation. Repeat the candidate batch in reverse order. Failure to reproduce any registered invariant or to extract a complete model is recorded, not silently treated as a tie. Measure predictions on the separate four-version panel; this experiment alone cannot establish a change to pose prediction or Ki/Kd accuracy.
