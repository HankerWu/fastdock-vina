# 晶体知情刚体见证的短接触检查

主分析已知，覆盖与片段两组中发布池 Oracle >5 Å 的 11、46 个池各含至少一个有 ≤2 Å 刚体下界的内部构象。尚未针对这些最优放置查询受体距离。本追加实验冻结以下穷举，以测量“几何下界能达到”到“存在无极短接触的显式放置”之间的差距。

1. 保留主分析全部 178 个池、1,537 份已发布坐标及其全部化学映射。对每一模式、每一映射，重建达到该映射内部形状下界的正旋转和质心平移。用经哈希检查的制备接收者 PDBQT 全部重原子，读取原始及各知情放置最近的跨分子重原子距离。预测与评价的原子编号、微态、接收者均沿用主方案。

2. 定义一个有限的几何见证集合，即各合法映射的单一最小二乘叠合。逐池报告有多少模式存在 RMSD ≤2 Å 且所有跨分子重原子距离 ≥2 Å 的知情放置，同时报告最佳无短接触 RMSD、见证原发布序号、映射、最近距离。若无解，保留该池，不推广为不存在其他旋转平移。各池全部纳入并另列 Oracle >5 Å；两面板分开。计数单位为池，重复种子、接收者与算法臂相依。

3. 以原始位置检查既有化学表的最近重原子距离，并用逐原子阵列与 KD-tree 对实际见证复算。保存每池最佳通过上述距离门的 3×3 正旋转和平移，给出重建全部见证的可运行代码和实耗。只检验该距离门。受体/配体应变、化学方向性、类型半径、能量、稳定性和真实搜索可达性需要额外数据。
