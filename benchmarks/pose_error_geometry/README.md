# 同一个局优器为什么会改善内部形状，却增大结合姿势误差？

在两个已发布面板的相同注入身份上，从第一次局优返回值进入第二次局优，覆盖面板有 15/30 次发生几何分量反向变化，片段面板有 25/48 次。对 EPAS1 的一个反例，内部形状更像晶体，配体质心却向远处移动，受体框架中的 RMSD 从 14.003 升至 14.464 Å。以下计算读取真实步骤与实际发布坐标。已有预测、能量函数和两次局优的参数均由父研究冻结。[主登记](PROTOCOL.md) · [判据与实现](decompose.py) · [归档的观测器](../receptor_linkage/aurora/internal_loops/rigid_capture/diagnostic.patch)

## 三项平方误差及其物理界限

对预测重原子坐标 $x_i$ 和固定受体框架中的参考位置 $y_i$，取合法化学映射集合 $\Pi$。坐标单位 Å，重原子等权。$d^2=\min_{\pi\in\Pi}N^{-1}\sum_i\|x_i-y_{\pi(i)}\|^2$ 是报告的结合姿势平方误差。$t^2=\|\bar x-\bar y\|^2$ 是质心平方误差，独立于映射；$s^2=\min_{R\in SO(3),\pi\in\Pi}N^{-1}\sum_i\|(x_i-\bar x)R-(y_{\pi(i)}-\bar y)\|^2$ 是允许任意刚体放置后的内部形状误差。反射被排除，盐型及立体化学的等价映射继承制备和 CCD 记录。离线分析中的一个刚体放置保持配体的所有内部距离。

设 $c_\pi$ 为去质心后、禁止旋转的 RMSD，$s_\pi$ 为同一映射允许正旋转的最低 RMSD。取最小化直接 RMSD 的映射 $\pi_d$，则

$$
d^2=t^2+s^2+o^2,\quad
o^2=(c_{\pi_d}^2-s_{\pi_d}^2)+(s_{\pi_d}^2-s^2).
$$

前一项是保持直接映射时可由刚体旋转释放的平方误差；后一项是允许换化学等价映射后还能释放的部分。两项均非负。$o$ 表示相对于最优定向放置余下的代价，其单位为 Å；它随分子形状变化，不能当成转角。两个端点的分项差描述坐标变化的后果，不能凭它判定某条扭转路径、力项、受体重组代价或结合自由能。若 $s>2$ Å，则仅移动该固定形状在数学上无法达到 2 Å。若 $s\le 2$ Å，则仍需检查目标位置的受体接触及其可搜索性。[Horn 的正旋转解](https://doi.org/10.1364/JOSAA.4.000629)

两个面板中，实际池 Oracle 仍大于 5 Å 的 11 和 46 池都已经生成了至少一个内部形状下界 ≤2 Å 的模式。前一面板的 11 池全部来自同一 A1120。片段面板还包括 EPAS1、BRD9 和 FABP4。反例出现在 FABP4 的 2NNQ 94727 打乱臂，发布八个模式，最好的固定形状即使知道晶体位置、允许任意刚体运动，也只能到 2.408 Å。该池实际最小值 2.912 Å。某些实例需要改变内部形状，而严重错放不能一概归因于内部形状。[覆盖全部模式](results/rigid_pose_coverage_modes.csv) · [片段全部模式](results/fragment_anchor_modes.csv)

## 把有利的刚体位置真正放回受体

直接对所有 1,537 个发布模式及其合法化学映射生成 11,768 个刚体放置。每种映射只生成该映射的最小二乘解。对全部放置直接重算对称校正 RMSD，并查询固定接收者的全部重原子。要求 RMSD ≤2 Å 且最近跨分子重原子距离 ≥2 Å。该固定距离仅用于检出极短接触。[计算前追加登记](PLACEMENTS.md) · [刚体重建与独立距离复核](placements.py)

|面板|有内部下界 ≤2 Å 的池|有满足两项条件的放置|实际 Oracle >5 Å 的池|其中有满足两项条件的放置|
|---|---:|---:|---:|---:|
|覆盖|66/66|44/66|11|0/11|
|片段|111/112|55/112|46|22/46|

A1120 两种微态合并后，在覆盖 22 个池、片段 42 个池中，均未在这批放置中找到满足两项条件的见证；单看形状下界则两组每池均可到 2 Å 内。覆盖面板的 A1120 阴离子官方 25k 和 50k 两臂中，最好的无极短接触放置为 2.010794 Å，仅比 2 Å 多 0.010794 Å；发布池 Oracle 均为 10.446 Å。这个连续值保留了阈值计数会抹去的临界情形。在片段面板的 46 个严重错位池中，FABP4 的三个、BRD9 的六个均有见证；EPAS1 两个方向分别为 8/10、5/9，A1120 为 0/18。一个明确的几何反事实是 EPAS1 4GHI 93257 的 Pro 50k。首位形状只需旋转和平移即可到 0.916 Å，重原子最短距离 2.015 Å；真实发布池最好的几何误差为 14.320 Å。可用 `rotation`、`shift` 与原始发布编号复原这组坐标，按行向量使用 `X @ rotation + shift`，映射下标从零开始。[覆盖逐池见证](results/rigid_pose_coverage_placements.csv) · [片段逐池见证](results/fragment_anchor_placements.csv)

所有最佳放置都有极短接触，只排除了本次枚举的具体叠合。偏离最佳叠合可能释放碰撞，同时保留 ≤2 Å 的 RMSD；也可能需要改动受体或配体内部自由度。历史上的 A1120 阴离子知情分叉就曾在局优后得到 1.941 Å 的姿势，最近重原子距离 2.497 Å；该状态、来源及实际路径与本次发布池刚体试验不同。通过 2 Å 距离门也不能保证所有化学接触、能量或动力学合理。两面板的原始最短距离与独立存档的 1,537 条值全等，实际最佳见证的直接全原子对距离及重算 RMSD 与主实现最大差 $4.45\times10^{-16}$ Å；该追加检查约 3.15 CPU 秒。[逐池计算收据](results/placement_check.csv) · [原始 A1120 路径](../rigid_pose_coverage/engine/README.md)

## 复算

从仓库根目录运行。原始归档在两个父研究，检查 9 个归档、共 1,660 份成员的 SHA-256，再重建受体配准、化学映射和坐标。1,537 份发布模式包括主发布表和覆盖面板的额外实际成本对照，另有 234 份连续三阶段坐标。本机使用 Python 3.12、NumPy 2.3.5、SciPy 1.17.0、RDKit 2026.09.2、Gemmi 0.7.5、Meeko 0.8.0；Meeko 由历史参考模块导入。初次调用发现缺少 Meeko，在任何真实坐标分项计算前退出；安装后按同一方案重跑。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python benchmarks/pose_error_geometry/decompose.py /tmp/pose-geometry
python benchmarks/pose_error_geometry/placements.py /tmp/pose-geometry
```

逐映射的 Kabsch 正旋转用实际重原子坐标直接求误差，另用 Horn 四元数特征值独立复核可达最低平方误差。真实坐标的两解相差至多 $5.87\times10^{-14}$ Å²，重新测量的直接 RMSD 与已发布表相差至多 $3.56\times10^{-15}$ Å。脚本另检查整体平移、旋转、对应互换及禁止镜像。两次面板诊断分别约 1.6、1.7 CPU 秒（含归档读取和核验），不是额外运行对接的成本。[诊断耗时与数值收据](results/verification.csv) · [覆盖的连续分布、逐格及原预测成本](../rigid_pose_coverage/pose/README.md) · [片段的连续分布、逐格及原预测成本](../fragment_anchor/pose/README.md)
