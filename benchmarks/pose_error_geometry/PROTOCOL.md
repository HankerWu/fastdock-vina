# 从刚体错放到内部变形，分解实际搜索与发布选择的误差

登记基线 e12604b。本诊断使用已经公布并可复算的坐标。既有总体 RMSD 与个别源态刚体下界已知，各步、各池的分项尚未计算。这是回顾性、晶体知情的机制实验。无新对接臂。

**问题。** 同一分子实际经历的 hunt→second 是否主要纠正其位置、方向或内部形状？发布首位到池 Oracle 的差距与上述哪种误差同向，哪些步骤改善一个分量却使另一个变差？两个阶段的比较均固定输入、母路径或输出池。此问题不能通过在单一源态计算最低刚体 RMSD 回答。

**固定端点。** 对接收者框架中等权重原子和父研究全部合法化学映射，以 d 表示无配体叠合的最小 RMSD。t 是预测与参考质心距。s 是对所有合法映射和一个正旋转、一个平移最优后可达的最小 RMSD。用 o²=d²−t²−s² 量化额外的居中定向误差。另输出直接 RMSD 最佳映射的内部误差 s_direct；s_direct²−s² 是换映射可释放的平方误差，d²−t²−s_direct² 是固定直接映射能释放的旋转误差。角度、内能、局部优化器的可达性不能由这些几何量推出。全部平方分量以 Å² 计。

**配对与对照。** 先处理 rigid_pose_coverage/pose 的全部主表发布臂与额外轨迹成本对照、所有具有 selected/hunt/second 坐标的干预臂；再不改定义处理 fragment_anchor/pose 全部 16 个源态和各自全部发布池及相同阶段。两个面板分别报告，有重复分子、种子与对照臂。报告每一格的三阶段绝对量、selected→hunt、hunt→second 与每池 rank1→最小受体框架 RMSD 模式的逐项有符号平方差；按实际同一 RMSD 时取最小发布序号。列出无变化、混合变化、相反方向和大误差病例。以 1e-8 Å² 作为仅用于判定浮点零的容差。补记每池最佳内部形状、是否与实际 Oracle 相同、刚体下界已大于 2 Å 的病例。每格同一算法保留一个位置。独立数值复核直接逐原子位移及正旋转 Horn 或 Kabsch 两种解，包括造例与真实坐标。任何旧表坐标 RMSD 误差超出 1e-7 Å 时，该行停止并说明原因；不换映射、排病例或重分组来获得有利方向。

**解释。** 若主导分量或符号按阶段和病例变化，实际样本否证每种实测差异均可简化为同一种几何运动。某分量的改善与总分改善可以相反。只有晶体知情的刚体下界也超过阈值时，才能断言“该内部几何不能只靠重新放置达到阈值”；有非碰撞、可搜索的低误差姿势还需独立验证。本轮不以这些晶体量作搜索势、亲和力分项或预测模型；按面板给出受体框架下完整发布分布和成本来源。
