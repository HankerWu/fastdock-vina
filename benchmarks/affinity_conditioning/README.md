# FKBP12 为什么把三甲氧基取代的配体排弱了？

Holt 等在同一次人 FKBP12 酶活性测定中报告，5 号苯基配体的表观 Ki 为 110 ± 20 nM，加上 3,4,5-三甲氧基得到的 6 号为 12 ± 5 nM。点估计相差 9.17 倍，即便按两端最接近的报告误差取值也相差 5.29 倍。温度 10 °C，pH 7.8，35 mM HEPES，胰凝乳蛋白酶偶联 PPIase 测定。论文第 9927 页表 II 及相邻正文同时说明了结构替换和测量数值。这个配体对来自已知错例。[原始测定](https://doi.org/10.1021/ja00075a008) · [原论文表 II](https://electronicsandbooks.com/edt/manual/Magazine/J/Journal%20of%20the%20American%20Chemical%20Society%20US/1993%20%20%28vol%20115%29/22%20%20%2809879-10470%29/09925-09938.pdf#page=3) · [事前方案](PROTOCOL.md)

对两个受体、各算法和种子的 26 组已发布首姿，21 组把 6 排在 5 后面。七组错例中，保持同一骨架坐标添加甲氧基确实能降低经验分，但这组骨架坐标本身在 5 号参数下失分更多。另 14 组错例在固定坐标下添加甲氧基就已失分。五组方向正确的结果中还有四组的固定骨架取代效应方向错误。两项都从同一份原子地图和真实已写坐标计算。全部 26 组对应同一个实验分子对，两张受体共享标签，部分搜索臂还发布相同坐标。[逐受体逐臂结果](results/first.csv)

## 两个可独立复算的差

在 6 号的真实发布姿势 $x_6$ 上去掉全部三个甲氧基，保留其余 27 个重原子的原有坐标并赋予 5 号真实制备的 AD4 类型、电荷和扭转数，得到 $P x_6$。同一受体上，5 号独立对接首位为 $x_5$。经验分越低越强，下面的等式精确闭合。第一项是固定骨架上的取代效应；第二项用同一套 5 号参数评价两份坐标。单位沿用 AD4 的 kcal/mol 刻度。

$$
S_6(x_6)-S_5(x_5)=[S_6(x_6)-S_5(Px_6)]+[S_5(Px_6)-S_5(x_5)].
$$

第二项包含整体位置、取向、内部构象、独立制备几何和候选选择。独立复核穷尽苯环反转和两个等价甲基交换所产生的四种有手性映射。即使选共同键长最接近的映射，234 个投影的最大共同键长差也总在 0.01148–0.01315 Å，超过两份三位小数坐标的最坏舍入差 0.00347 Å。因此这些投影都无法单靠 5 号原始 PDBQT 的转动键和刚体运动精确产生。若某个投影比 5 号原池最优分更低，它只说明当前模型在那份几何上能给出更低分。它没有给出 5 号原始搜索可达到却漏掉的姿势。两种化合物都缺本面板的独立晶体坐标，不能由这一项判定哪个骨架位置更准确。[独立化学图、手性与原子地图核验](results/independent.json)

在另行事前登记的实验中，将每个删减骨架重新放回 5 号原始刚体和可转键约束，再检查上述分解的变化。此检验有助于区分独立制备产生的环几何差及丢失的取向或扭角。[5 号可实现构象的上界和下界](MANIFOLD.md)

从 6 的坐标直接删除六条原子记录会给共同骨架留下约 +0.640 e 的已打印部分电荷总和，真实 5 号则为 +0.001 e，二者形式电荷均为零。六个共同原子的制备部分电荷改变，最大变化 0.203 e。四种映射保留相同的删除集合和原子参数，逐姿势重算的最大分差为 3.6×10⁻¹⁵。

### 与真实评分算子核对

刚性受体 AD4 的全局搜索含分子内能。在发布阶段，代码对每个模式复计，用该模式自身的分子内能作 unbound 项，两者精确抵消，然后按发布分重排。每个原子读取类型图 $A$、电势图 $E$ 和去溶剂图 $D$，电荷取自该化合物自己的 PDBQT。对正能量用 $C(u)=1000u/(1000+u)$ 限幅，其余能量原样保留。官方 1.2.7 算 $C(A)+qC(E)+|q|C(D)$，Pro 算 $C(A+qE+|q|D)$。全部原子在图内；表中保留未经限幅的三项和逐原子限幅的剩余值，因此可以直接求和复原完整端点。[原生发布流程](../../src/lib/vina.cpp) · [Pro 核心算子与上游对照](../ad4_atom_field/README.md) · [AD4 原始模型](https://doi.org/10.1002/jcc.20634)

旧 FKBP 分析中，部分坐标复核沿用了官方三通道分别限幅的算子。本次修正了共享复算函数与两处实际调用入口。对同一 Pro 坐标比较正确算子与旧算子，两种复算在 5、6 号档案的最大绝对差为 0.002583 kcal/mol。对全部 468 个已发布模式，主复算与发行 PDBQT 三位小数分数最大差为 0.002843。独立实现直接从 ASCII 地图作八角点插值，逐项重算 468 个原始姿势、234 个投影，六个主要分数栏与主程序最大差在 3×10⁻¹⁴ 以内。[共享打分程序](../cubic_grid/fkbp_ad4/analyze.py) · [逐姿势原始分和两种算子重放](results/poses.csv)

### 修复对五个历史面板的影响

受影响的两处正常调用分别来自早期 rigid_fkbp 复核与后期 fragment_anchor 复核，其他三个面板复用了这两条路径。重读全部原始 PDBQT 和受体图，逐行匹配原档复核分数，再按实际发布引擎使用不同限幅算子。五个面板的 544 个池、4,896 个模式观测中，3,744 个 Pro 模式需要更正算子；去除重复引擎池后二进制输入与受体组合共 378 个。独立复算分最大变化 0.002653 kcal/mol，与所写原生分的最坏绝对差从 0.004547 降到 0.002782。各池按重算分排序，全部首位相同，7 个池次的非首位有交换。对每臂的两个单独受体及等权共识的 15 个可靠配体对分别检验，共 1,530 个方向记录，方向变化为零。这里比较旧、新两个复核程序；对接程序的实际写出记录保留原样。后续复现应将重算分与修订表比对。[逐模式纠正](results/validation_modes.csv.gz) · [逐个测定方向](results/validation_pairs.csv.gz) · [各面板完整行数、误差和排序](results/validation_repair.csv)

从干净目录复原 rigid_fkbp 的 720 个模式以及 rigid_pose_coverage 的 1,440 个模式，通过两条真实评估入口。两个面板各自的 assay.csv 均与历史产物逐字节一致。另在同一 Python 环境分别运行修复前后官方原始的 864 个模式重算，所有输出逐字节一致；同较早归档版本的非零浮点差至多 1.78×10⁻¹⁵。独立的解析回归覆盖正负零电荷及三个图项的正负组合。原有 C++ 原子场测试中关于 $v=0,10,1000,\infty$ 的梯度、边界与电荷重新分配子例亦重新运行通过。五面板总复核 9.39 墙秒、9.39 CPU 秒；两个完整评估入口另计 8.27/8.27 和 8.92/8.89 墙秒/CPU 秒。[全档复核](repair_audit.py) · [解析端点回归](../cubic_grid/fkbp_ad4/test_map_operators.py) · [本次全档核查成本](results/validation_cost.json)

同坐标删除复算没有产生新的对接姿势或重排原始配体。本轮能定位经验打分中两项的符号和大小，无法从该结果分离溶液中甲氧基水化、口袋水置换、受体重排与构象熵。要检验真实结合效应，可对同一 5→6 替换同时定义受限复合物和溶液腿，检验两方向采样重叠和共同骨架对齐/释放的影响。仅有这些冻结姿势时尚无绝对或相对自由能精度。

## 复算

在仓库根目录运行，依赖 Python 3.12、NumPy、SciPy、RDKit、pandas。主程序逐一验证输入配体、两份 AutoGrid 图、所有源池、测定表和原档散列。CSV 保留完整双精度分解；每个 6 号模式的 placement 和 net 均以独立发布的 5 号**第一名**为参照，s5_native 栏另存同名次的实际 5 号分数。第二个程序从原始档案另行恢复映射、参数、坐标和格点，检查全部对称表示。

```bash
D=benchmarks/affinity_conditioning
W=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/replay.py" "$W"
OPENBLAS_NUM_THREADS=1 python "$D/verify.py" "$W/poses.csv" "$W/independent.json"
OPENBLAS_NUM_THREADS=1 python "$D/repair_audit.py" "$W"
python benchmarks/cubic_grid/fkbp_ad4/test_map_operators.py
for f in poses.csv first.csv summary.csv independent.json validation_repair.csv; do cmp "$W/$f" "$D/results/$f"; done
```

对接、制图和原分子制备复用已发布记录，下列时间只计本轮原档解压、读图和评分。[源池与构建成本](../rigid_pose_coverage/fkbp/README.md) · [早期官方同条件池](../cubic_grid/fkbp_ad4/README.md)

主程序一遍实测 4.30 墙秒、4.34 CPU 秒、峰值 RSS 142,156 KiB。独立复核一遍 4.15 墙秒、5.33 CPU 秒、峰值 RSS 95,244 KiB。主程序与独立检查均设置 OPENBLAS_NUM_THREADS=1，解压和 RDKit 等库可能有自身的线程调度。
