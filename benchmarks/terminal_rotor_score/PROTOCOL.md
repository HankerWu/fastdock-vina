# 固定坐标下的末端单键与 Vina 扭转分母

开发反例为 ESR1–1SJ0。普通 Vina 和 Vinardo 的受体势只对重原子生效。若一个可旋转键的任一端只有一个重邻居，则围绕该轴旋转不能改变两侧重原子的相对坐标。冻结一个仅移动氢的末端轴，原子坐标、微态、供体类型和 Vina 的势能完全相同。两种 PDBQT 分支表示应给出相同的扭转分母。保留原有每一个具有双侧重邻居的转子的权重，也保留 AD4 对输入 TORSDOF 的含义。模型是经验性可动性描述，不能据此定量推断羟基真实溶液熵。

在查看本轮新老评分的同测定结果之前，固定两个公开的人类蛋白系列，使用既有全部入组分子和已输出的首姿。Galectin-3 使用 Sörme 等人的 47 个同实验 Kd、1KJL 与 3T1L 两个受体、silent_torsion/affinity/primary 中 parent 臂的种子 214039 与 3000 次预算。因子 Xa 使用 Zhao 等人的 28 个同实验 Ki、2P16 与 1FJS 两个受体，取 frozen_core/affinity/fxa_frozen 的 271828 和 314159 两颗种子。这两个系列曾用于其他开发，在本机制中作为预选迁移验证。所有结果均固定坐标。为避免重新解析已变形坐标推断键，优先使用与原始搜索一致的配体输入拓扑，提取 C++ 模型的旧/新转子计数，再用既有首姿分数及其共同参考重算分母。另从原始 pose 文件完成可重现的同起点 CLI 得分检查。

主分析在每个化合物内先对同一受体的种子取中位数，再对受体取均值。报告 Spearman、Kendall tau-b、全部不等值对方向准确度及浓度相差至少三倍的方向准确度，预测平局记半分。每个受体分别报告。补充建模输入层面的配对基准、逐化合物影响及打印精度敏感性。不以预测表现选择规则或重新拟合 0.05846。数值不变是可证伪的实现要求；亲和力改善是待检验假设。相同配体的姿势次序在正分母下数学上不变。另用同一搜索的默认输出核验对最终模式窗口或其他按绝对分差截取步骤的影响。
