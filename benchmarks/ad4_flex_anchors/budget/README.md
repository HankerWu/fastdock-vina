# 给父版更多时间能否得到同样的精度

基于第一轮时间记录，预先选取 13100 和 24000 两个父版求值上限。复跑原来的八个查询–受体组合、三枚种子，每条件实际启动四个进程，轮换四种条件的顺序。96/96 均有合法输出；原两臂 48 份新输出与首轮原始 PDBQT 逐字节一致。所有结果共享之前的网格预计算。下表的开销是同期测试，包含图读取、建表、搜索和输出。[提前登记的预算规则](PROTOCOL.md) · [原始姿势和日志](raw.tar.xz)

13100 档的实测墙钟比修正版低 3.3%；24000 档比修正版高 11.0%。虽然父版实际求值增加约一倍，但网格读取和按原子对建表等每次进程开销并不加倍。两种扩大预算的父版均有略好的首姿中位数和 Q25，修正 12000 的输出池虽更小，首姿右尾和池内平均最佳 RMSD 更低。两种父版扩充仍未在本面板上复现修正的右尾变化；这项结论仅涉及实测的预算档位和搜索配置。[逐运行开销](results/costs.csv) · [完整 ECDF](results/ecdf.csv)

相对父版 13100 档，修正版首姿配对变化均值 −0.535 Å，中位数 −0.969 Å；相对父版 24000 档，分别为 −0.726 和 −0.981 Å。两种比较均为 16 格改善、8 格退化。分别以共享种子为整块、固定全部查询–受体组合的 95% 条件百分位区间为 [−1.683,+0.724] 和 [−1.918,+0.546] Å。两者都跨越零。RBP4 的首姿平均差贡献较大，对比 13100 和 24000 档分别为 −0.947 和 −1.065 Å；FABP4 为 −0.124 和 −0.387 Å。三枚种子、两个蛋白不支持对未知体系的精度–成本前沿作可靠估计。此扩展只考察结构，没有重复测定亲和力排序。[逐姿势](results/modes.csv) · [逐条件配对变化](results/paired.csv) · [完整分布](results/distributions.csv) · [条件区间](results/intervals.csv)
