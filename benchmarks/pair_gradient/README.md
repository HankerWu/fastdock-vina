# 径向查表梯度、8 Å 截断与真实对接结果

在父版本 `ac0a2f6` 的真实对接调用链中，原子对能量和传给 BFGS 的导数采用两套独立插值。2YWP 共晶起点的一项旋转导数甚至改变了符号。三个无拟合权重的 C++ 对照修正了不同层次的数值误差。新结构和同实验 Kd 面板没有给出可跨体系重复的精度提升，生产默认算法继续采用父版本的计算方式。[冻结协议](PROTOCOL.md) · [有限差分、逐原子对原始数据和核验](numeric/README.md)

## 从能量到最终姿势

`scoring_function.h` 的普通 Vina 势根据 XS 原子类型及表面间距 d 计算两个高斯项、重叠排斥、疏水接触及无方向氢键，默认按 8 Å 原子中心距离截断。高斯项分别为 exp[−(d/0.5)²] 和 exp[−((d−3)/2)²]，排斥项为 min(d,0)²。疏水及氢键项通过原子类型门控和分段线性距离函数计算。它们的总和是经验势。正常 Vina 模式没有显式溶剂、蛋白构象的平衡权重或逐对库仑能。[Vina 原论文](https://doi.org/10.1002/jcc.21334) · [Vina 1.2](https://doi.org/10.1021/acs.jcim.1c00203) · [加权势](../../src/lib/scoring_function.h) · [距离函数](../../src/lib/potentials.h)

1. 网格搜索用预计算的刚性受体场。配体内部和其他可动原子对另查径向表。平移、旋转或扭转提议交给 BFGS 局部优化后，Monte Carlo 按能量和温度接受候选。部分接受态在另一组能量上再次优化并进入最小值容器。每次 BFGS 试探联合计算能量和梯度。全局上限在下一次外循环才检查，实际工作量还包括搜索后显式精修。[搜索](../../src/lib/monte_carlo.cpp) · [局部优化](../../src/lib/bfgs.h) · [可动对](../../src/lib/model.cpp)
2. 正常 native 输出路径汇合轨迹并去冗余，在显式受体上精修。受体邻域先按配体原子求和，再对正能量作平滑限幅。代码用共同盒边界惩罚重新计算精修能量，并按原有方法从首姿确定未结合态参考、作构象独立校正、输出排序。固定坐标最终打分和建图用的是快速中点查表。48 份完全相同的起始／既有精修坐标在父版本及三个实验实现上，CLI 可见的十行能量分解全部一致。[显式受体](../../src/lib/non_cache.cpp) · [候选与打分](../../src/lib/vina.cpp) · [固定分数核验](local/fixed_score.csv)
3. 分支此前已有双精度 SIMD、查表与建图复用、严格 Armijo、几何预条件，以及 1 Å 范围内的平滑截断等。独立模板排序、扭转熵和 MMFF 固定首姿实验各自有不同信息及成本条件。本轮沿用原生候选上限、合并与最终打分，没有用共晶模板引导搜索。[工程优化来源](../../docs/PROVENANCE.md) · [此前截断实验](../../docs/CUTOFF_SWITCH_RESEARCH.md) · [此前固定候选结果](../frozen_core/README.md)

普通 Vina 的五个默认权重依次为 −0.035579、−0.005156、+0.840245、−0.035069、−0.587439。疏水函数在 d = 0.5 至 1.5 Å 从 1 线性降至 0，氢键在 −0.7 至 0 Å 从 1 降至 0。这两个函数各有独立的 XS 类型兼容条件。令 X 为配体与受体及可动原子间能量加内部能、减首姿未结合态内部能后的量，常规末端修正为 X/(1+0.05846 N)，N 从模型中符合条件的可动键端点计数而来。这样较灵活的配体会减小有利负分的绝对值；额外加显式扭转自由能时，需要单独检验与原有校正的重叠。[权重](../../src/main/main.cpp) · [键计数与自由度校正](../../src/lib/conf_independent.cpp)

普通扰动先在可变实体中均匀选择一次平移、旋转或某一个扭转。平移在球内取向量，旋转增量按配体回转半径缩放，选中扭转时在 [−π,π] 重抽角度。因此扭转键多的配体得到较低的刚体扰动概率。接受概率对上坡步为 exp[(Eold−Enew)/T]。原生路径可能用较硬候选优化的历史值和较软搜索目标的新值比较。分支已实现分离两者的对照。本轮保持该行为与父版本一致。BFGS 每步沿近似逆 Hessian 乘负梯度的方向回溯，用初始方向导数判断能量下降是否足够；若该导数与实算目标的方向导数异号，回溯判据和曲率更新都受影响。默认全局路径和可选严格 Armijo 的失败回退与预算行为不同，故局部实验明确报告使用哪种路径。[构象提议](../../src/lib/mutate.cpp) · [两种轨迹目标](../../docs/HUNT_CHAIN.md) · [候选去重距离](../../docs/NATIVE_MERGE_RMSD.md)

## 三个可区分的数值机制

设 q = f‖x‖²，f = 32 Å⁻²，i = floor(q)，t = q−i。在每个开区间内，原表的 E = Eᵢ + t(Eᵢ₊₁ − Eᵢ)，故 ∇ₓE = 2f(Eᵢ₊₁ − Eᵢ)x。父版本另行对预估的径向斜率插值。**精确线性**返回现有能量的分段精确导数，在节点取右导数。**单调三次**用相邻割线的调和平均值构造 Hermite 切线，在局部极值或平台取零，能量和导数来自同一个分段多项式。两者的节点能量及最终快速打分相同，单调三次改变节点间的优化能量。两种做法均为常数时间查表；单调三次需要更多浮点运算。[局部单调插值](https://doi.org/10.1137/0905021) · [实际 C++ 线性实现](../../src/lib/precalculate.h) · [单调三次实现](monotone.patch)

2YWP 的 1,661 个显式受体对中，最后两个距离格的三个接触对原生减去精确线性旋转导数贡献 +9.8501 kcal/mol/rad，其余 1,658 对合计 −0.05184。最大单对为距 Tyr A20 CZ 7.999336 Å 的配体碳。既有查表把仍有有限负值的内侧势硬连到零，在不到 0.002 Å 内制造陡坡。该对的内侧解析径向导数约 0.002158 kcal/mol/Å，父版本返回 0.92226，精确线性返回 1.84378，单调三次返回 2.48114。

据此增加的**显式受体势能平移**在精确线性控制上，只将标准 Vina 的显式受体优化势改为 U(r)−U(8⁻)，在终端区间使用内侧极限。径向导数恢复到 0.00215792。该势在截断处能量连续，左右导数仍可不同。改变近邻集合会改变总能量的相对偏移，原子级限幅也会改变合力。因此这种修正仍需接受姿势验证。相对精确线性，其网格搜索、配体内部表和最终快速打分相同。非标准截断等使用线性对照路径。[平移势实现](shifted_explicit.patch) · [截断方法的原始比较](https://doi.org/10.1063/1.3558787)

### 气相 MMFF94s 的靶点差异

另一项对 168 个历史原生首姿的独立复算，保持重原子坐标、微态和八构象参考选择一致，追查 BACE1 与因子 Xa 的 MMFF94s 差异。BACE1 原生 23/72，完整 MMFF 54/72，仅移除配体内部静电后为 48/72；因子 Xa 依次为 223/295、206/295、162/295。因子 Xa 同电荷的 205 对从 154 减至 134，跨电荷的 90 对从 69 增至 72。5 个净 +1 两性离子气相参考的异号中心距离为 3.75–4.35 Å，结合态模型的逐配体中位距离为 6.45–10.95 Å。BACE1 的非静电部分保留了新增 31 个配对积分中的 25 个。因子 Xa 的 1FJS 用完整 MMFF 退化，而 2P16 改善。气相参考和电荷类别影响评分，但静电删除实验不能测得溶液构象自由能。该诊断使用额外构象计算，只支持机制分析。[分解、单受体反例、控制子集与原始分数](../frozen_core/strain_components/README.md) · [溶液应变的一手研究](https://doi.org/10.1021/acs.jcim.6c02468)

## 保留范围与下一项可判别实验

线性精确导数作为编译期数值对照保留。单调三次及显式势能平移保留可重建的 C++ 补丁、数值测试和原始结果。它们均不改变发行默认选项。当前结果支持数值诊断和特定力表修正；未证明独立靶点、等时间下的可迁移预测提升。三个新结构靶点在所选单轨迹预算下的候选命中率很低，小探针与单个种子不能给出普适的算法排名。这里也没有验证绝对亲和力、溶液态自由能或任意受体诱导契合。

下一步最有区分力的是把相同提议的局优结果与保存触发分开测试。ADORA2A 已经定位到具体提议与三个获接受却未立即保存的近原位解，同一提议下两个优化器都能恢复正确盆地。可在独立的、受体几何容得下参考姿势的失败例上冻结相同提议和候选名额，分别测试达到近原位的概率及它们是否得到保存。REN 次名命中的例子适合固定整个池检验排序。明显碰撞的交叉参考应按受体几何另列。亲和力方面，检验游离态参考应使用新的同电荷、同骨架、同实验系列，预先固定溶剂及微态处理，并计入参考态开销。

