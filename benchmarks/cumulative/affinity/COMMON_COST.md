# Common reachable CPU budget

This timing-only addendum follows the failed attempt to reach the original stable-Pro target in the slower engines. All six CHEMBL2015090 ligands in receptor 4DJW, seed 89513, all four unchanged binaries and all matched-arm scientific settings are fixed. No concentration, docking score, pose or pair direction informs cap selection.

Use one sequential worker pinned to the largest allowed CPU ID; four engines rotate order between successive compounds and cycles. Charge every child user + system CPU from request to exit. Collect fresh cap 3000 and 96000 anchors from all six ligands. Let the common CPU target be 1.20 times the largest complete six-ligand low-anchor time, rounded up to 0.1 s. If the higher anchor of an engine is below target, take one extra anchor at 384000 for it. Choose its one common cap by straight-line interpolation of the bracketing costs, in increments of 100 calls. If a bracket cannot be formed use the closest registered cap, marking failure if more than 15% off. Collect a fresh confirmation. For an engine outside ±15%, use its confirmation cost as one additional anchor and make one last interpolated confirmation (or nearest anchor if still unbracketed). Retain both measurements, including unsuccessful matches. Report the final actual costs, the scope of any matched comparison, all rank outcomes and tuning overhead. This sensitivity does not replace the failed original target, default runs, or fixed 140-cell nominal matrix.
