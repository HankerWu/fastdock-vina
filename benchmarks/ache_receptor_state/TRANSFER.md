# Label-free cross-receptor starts versus two same-receptor searches

Follow-up registered after the graph-only search results: a sub-0.5 Å HUP mode was published on 4EY6 for one 24k seed, and 4EY7's best among all native runs exceeded 2.9 Å. No following cross-pool local transfer or pooled selection has yet run. HUP cross-state transfer is a targeted mechanistic follow-up, not an untouched-target validation.

For each ordered 4EY6/4EY7 receiver and all three registered seeds use every mode of the ordinary Pro 24k recipient pool. Keep the same modes as one source in every arm. Add (i) the other receiver's ordinary 24k pool at the same seed, aligned by the 48 common noncognate pocket Cα using only GNT and E20 to specify pockets, or (ii) a second ordinary 24k pool on the same receiver, next seed cyclically in the registered order. Control (iii) uses only the recipient's original modes, and (iv) the already registered single double-budget native run. The alternate-state and same-state two-pool methods each pay for two full searches plus native local optimization/score for up to 18 inputs. Charge the donor every time even if precomputed for other cases; report per-case actual costs and throughputs.

Keep the HUP graph, microstate, full atom record and torsion tree unchanged. Transfer full coordinates by one proper protein transform, serialized at 0.001 Å. Run the recipient's native Pro local optimization and score the exported endpoint with common unbound 0 in the same 36 Å diagnostic box; do so for every source including native receiver modes. Select by receiver score alone; stable ties recipient first then pool order. Greedily keep up to nine modes, skipping a mode if within 1 Å heavy-atom RMSD of a better retained mode (HUP has one full stereochemical automorphism). Use window 100 nominal kcal/mol relative to best. Save raw start/return files, source rank/seed, receiver scores, calls, times, loss at transfer/local refinement/duplicate removal/rank cut/final choice, and zero/failed rows. Re-run observed local outputs for actual gradient calls and compare bytes. Predictor must never read 4EY5 coordinates, HUP-bound protein, reference RMSDs or the crystal projection. Evaluator then measures all origins and endpoints, correct receptor frame, Best@5, Oracle, regret, top-1 and paired distribution. Primary comparison is (i) vs (ii); improvement simply over (iii) cannot distinguish other-receptor information from a second search. Three cells/direction; shared donor pools and receptor, no independent family or affinity claim. Does any donor start reach a distinct locally retained sub-2 Å endpoint? Is it returned and ranked first? Compare all directions and seeds without retuning.
