# 受体构象改变时，石杉碱甲的好姿势丢在哪一步？

在与多奈哌齐共晶的人 AChE 受体 4EY7 上，从另一份受体的盲搜结果生成了一个 **0.550 Å** 的石杉碱甲姿势。该姿势通过原生局优和去重，进入九个发布名额，排第七。首位为 **5.744 Å**。这使同一输入的两项损失可以分别测量：普通搜索难以把配体放入这一局部区域，成功放入后，固定干受体打分仍偏好另一姿势。复算用到同一研究的三份人 AChE 实测结构。4EY6 与加兰他敏、4EY7 与多奈哌齐共晶；只有离线评价及单列的投影对照使用石杉碱甲的 4EY5 晶体位置。[原始结构研究](https://doi.org/10.1021/jm300871x) · [实验登记](PROTOCOL.md) · [另行登记的跨受体预测](TRANSFER.md) · [轨迹追踪登记](trace/PROTOCOL.md)

## 能进入、能留下、能排第一是三个可分别验证的条件

- **常规盲搜。** 同一输入、三枚种子、官方 Vina 1.2.7 与普通 Pro 24k，另设 Pro 48k；在 4EY7 增设仅改变盒心的 Pro 24k。21/21 池成功，共 186 个姿势，3 个池首位 >5 Å，0 个空池。4EY6 的 9 个池中有 4 个在首位得到 ≤2 Å，最佳 0.408 Å；4EY7 所有 12 个池的 Oracle 均 ≥2.976 Å。4EY6 的 4 个近姿池来自两枚种子，一枚种子在三个臂上都成功。把 4EY7 盒心移到另一个已知配体的位置，3 个首位差有正有负。所有 21 池在干净目录重跑，PDBQT 字节一致。[每个种子的分数与距离](blind/results/cells.csv) · [按受体、方法的分位数](blind/results/groups.csv) · [实现和复现命令](blind/README.md)
- **实际轨迹。** 同一枚种子 1103503，4EY7 有 1/2,828 次提议进入 2 Å 内，第一次局优将它从 1.990 推至 2.288 Å。该端点被接受，未触发第二次局优。全程没有一个记录的 hunt 终点在 2 Å 内；最小值 2.121 Å。4EY6 对应为 731/2,431 个近提议，768 次近 hunt 返回、620 次近接受、229 次近二次局优，16 次近姿入轨迹池，其中 14 次后来被逐出。最终有 1 个近姿发布并排第一。该观察器只针对已知结局的同一对搜索，不能从两个运行估计盆地概率。[原始预测流、真实入池及逐出](trace/README.md)
- **同位置换受体。** 将三个旧池的全部 26 份坐标及一个近晶体投影各置入 4EY6 与 4EY7，运行 54 个原生局优。两个不同身份的“原池 Oracle 减原首位”干分差都保持正号，一组从 +1.445 缩到 +0.651，另一组从 +3.388 扩到 +4.164。Tyr124 和 Tyr337 对后一组跨态变化分别贡献 +3.195、−2.608。逐残基项可有很大变化，部分抵消后排序仍相同。投影在两份受体局优后分别为 0.429、0.451 Å。4EY6 近姿能赢过旧普通 Pro 池，但输给旧双预算和官方池的赢家；4EY7 近姿输给三池的赢家。4EY5 的 DMS A605 距配体 4.694 Å，触发事前排除，故保留其晶体参照、跳过其干受体局优。[全部固定姿势和控制误差](diagnostic/README.md) · [势函数分解](contacts/README.md)
- **无查询晶体的起点迁移。** 对三个种子做双向迁移，用两份非查询受体的共晶配体界定口袋。另一受体的全部模式经蛋白 Cα 配准进入接收受体，与接收受体自身模式相同地局优并以接收受体的干分终排。4EY7 的第七名来自 4EY6、种子 1103503 的首位，误差依次为 0.414（供体）、0.418（配准）、0.550 Å（局优），与最近的接收受体原局优端点相隔 3.317 Å。第七名得 −7.355，错误首位得 −9.313，分差 +1.958 名义 kcal/mol。Best@5 仍为 2.981 Å，Oracle 从 2.981 降到 0.550 Å，Regret 从 2.762 升至 5.194 Å。[逐步坐标与排序](transfer/README.md) · [发布的 PDBQT](transfer/results/published)

## 本轮结果的范围

当前使用固定形式中性 HUP、固定干受体和 Vina 经验势。比较的是同一配体在同一受体的条件得分。温度、受体游离占比、水化学势及两相自由能在此模型中未估计。4EY6/4EY7 都是本案的实测非查询受体，4EY7 是对本次 HUP 问题的新增受体；迁移追试在看过单受体结果后登记。所有格都来自一个骨架，没有新的同测定 AChE 分子对。故 AChE 亲和力的 ρ、τ-b、大小/电荷/柔性偏差和结合自由能误差在本实验中均无可估分母。
