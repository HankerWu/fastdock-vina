# ESR1 首次分叉、FABP4 有限试步与同方向第十试重放

[初始登记](PROTOCOL.md)与[第十试追加登记](RESCUE_PROTOCOL.md)均针对已揭盲病例。六个历史驱动库有 9,038 个变异提议。每个提议共用当时的配体、受体、网格、局优预算、可往返的构象和起始能量。[原始返回、局优试探和分叉](raw/)与[新候选的独立反事实](rescue/)分别保存。外检在 [fork_structure](../fork_structure/)。

## ESR1 交叉求解

每行在同一组提议上分别执行轮前稳定求解器和上轮被否决的 0bcae6e。每格给出实际 hunt 返回中 ≤2 Å 的个数，括号为最小连续重原子 RMSD（Å）。配准与化学映射沿用冻结外检。重复访问同一近姿可以产生多个计数。

## 真实线搜索方向

## 新候选 1c672a8e 的同态第十试

在稳定驱动的每一次原局优迭代，保留同一基态、方向、斜率及前九试。在需要第十试时，同一过程中评估新候选给出的步长并额外执行原步，用原步结果继续稳定局优。新步采用真实网格间距与全体化学重原子最大切向速度。6 库的完整稳定返回和抽样逐试记录逐字节复现。第二个进程直接执行新求解器，以真实新状态继续后续迭代。前一种测的是同一方向的反事实，后一种才计入新求解器的完整 E/G 成本。

7,817 个同态第十试中，有 3,824 个 alpha 改变。原来失败的 7,127 个原方向有 2,818 个获救，原来成功的 690 个均仍成功。六库累计每个提议平均 E/G 从 17.97 升至 32.85。解救后多做的实际迭代可再遇耗尽。FABP4 2326430 库的最佳误差从 6.824 降至 4.396 Å；没有提议达到 2 Å。六库 2,922 个返回能量下降、122 个上升（差值阈值 1e−7），1,570 个未触及第十试的提议的全部返回记录逐字节一致。[逐库分母与完整端点](rescue/comparison.csv) · [原始命令、身份和成本](rescue/costs.json)

## 复现

从仓库根目录使用 Python 3.12、NumPy、SciPy、RDKit、C++14 及 Boost 1.83。以下环境变量 W 和 BOOST 分别指向空工作目录及 Boost 前缀。默认从仓库的 SHA 核验归档重建原生输入、源态及坐标。使用已经按原程序解包的历史库可以传入 --history。执行脚本中的 candidate 指上一轮被否决的 0bcae6e；本轮研究源码使用 last_trial。

```sh
export OPENBLAS_NUM_THREADS=1
D=benchmarks/proposal_fork
python "$D/replay.py" "$D/raw"
python "$D/rescue.py" "$D/rescue"
python "$D/check.py"

mkdir -p "$W"
python "$D/build.py" stable "$W/stable" --boost "$BOOST"
python "$D/build.py" candidate "$W/candidate" --boost "$BOOST"
bash benchmarks/stage_local_hunt/build_free.sh "$W/free" "$BOOST"
python "$D/replay.py" "$W/raw" --builds "$W" --free-builds "$W/free"
python "$D/check.py" --repeat "$W/raw"
python "$D/rescue_build.py" "$W/last_trial" --boost "$BOOST"
python "$D/rescue.py" "$W/rescue" --binary "$W/last_trial/build/vina"
diff "$D/rescue/comparison.csv" "$W/rescue/comparison.csv"
```

每个 shadow.xz 记录逐提议返回状态、坐标、E/G 和耗尽数，格式沿用 bfgs_source_replay。trials.xz 为无表头 CSV，字段顺序见 replay.py 中的 TRIAL，其中 index/iteration/attempt 均从 0 计，predicted 和 actual 分别为 alpha · gᵀp 与 E(trial) − E(base)。rescues.xz 每行依次为提议序号、斜率、基态能量、原步长、新步长、原试探能量、新试探能量、原接受和新接受；同一提议多次达到第十试时按实际迭代顺序保存。六个库均来自固定的重复路径，计数不代表独立的实验配体。

四次历史自由预测真实重算共 1.282 CPU s、1.362 个逐作业墙钟秒；12 次历史交叉求解分别用 4.121、4.315 s。六次稳定路径第十试对照用 3.356、3.478 s，六次新求解器用 3.792、3.905 s。各组最大 RSS 依次为 121,704、122,692、103,412、103,480 KiB。墙钟和内存保留本执行环境的调度与诊断 I/O。第十试对照额外求值 7,817 次，不计入生产 E/G。源态与坐标的制备成本和正常发布预测在四臂结构面板单列。初次编译诊断代码引用了源树没有的距离函数，两次编译均在产生可执行文件之前失败。修为现有平方距离开方后成功重建。首次追加重放的后分析遇到两个历史模块同名，保留该次首库执行的失败记录；改用全包名后从六库起点重新执行。两次独立重放的核验与收据在 verification.json。
