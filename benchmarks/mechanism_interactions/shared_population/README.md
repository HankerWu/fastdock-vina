# 同一组游离受体占比能解释多少实测强弱顺序？

在 Sörme 的 Galectin-3 同系列中，两个受体结构分别给出的原生分差，理论上允许 403 对中的 214 对在各自最有利的混合比例下判对。一旦要求 47 个配体共享同一个游离受体占比，最高只剩 146 对。即便知道所有实测答案，也无法用两个现有构象的共同权重消除其余错误。这是对**给定结构、给定代理分数及混合形式**的检验；真实蛋白的游离态分布没有在这项研究中测量。[分析条件](PROTOCOL.md) · [逐对分差、界和交点](results/pairs.csv) · [逐测定汇总](results/summary.csv)

## 为什么每个 assay 只有一个游离态占比

设两种互斥的 apo 构象域覆盖了建模的游离受体。配体 $l$ 在每一状态下有标准态受限结合自由能 $G_{li}$。若两种 $G$ 都以各自受限的受体和同一游离配体溶液为参考，则在相同构建体、温度、缓冲条件下，配体总体缔合强度正比于

$$
K_l(p)=p\,k_{l1}+(1-p)k_{l2},\qquad k_{li}=\exp[-G_{li}/(RT)].
$$

这里 $p$ 是无配体时状态 1 的占比。结合态占比 $p k_{l1}/K_l(p)$ 可以随配体而变。历史输入是两份晶体结构与各自的单姿势经验分数；代入上式是故意给“改变构象权重就够了”这一解释最充分的机会。游离配体的构象、质子化与溶剂化若有差误，也会进入此诊断。晶体受体没有已知的相空间体积，拷贝相同结构不会产生新的物理态。[Minh 的配分函数推导](https://doi.org/10.1063/1.4751284) · [已知受限结合自由能的外部对照](../confine_release/README.md)

对测得更强的 A、更弱的 B，正确排序要求 $K_A(p)-K_B(p)>0$。这个函数对 $p$ 是仿射的。每一对可能在整个区间判对、在整个区间判错、并列，或仅在某个交点的一侧判对。汇总时先按每条边最有利的端点求逐对上界，再在所有边的交点之间计算一次变化量，找出**在同一占比上可同时达到的最高总分**。并列半分；端点、整条重合线和同时发生的交叉均保留。程序没有为预测选取任何占比。既有逐对算法只给出单条边的界，本次加上的约束是整组配体共用同一 $p$。[原来的单对计算](../../kinase_state_affinity/implementation/ensemble_affinity.py) · [本次实现](replay.py)

实验分差定义为 $D_{\rm exp}=RT\ln(K_{d,B}/K_{d,A})$；Ki 同法作条件代理。由于 $K_A(p)/K_B(p)$ 是两个状态内缔合常数比的正权平均，在任意 $p$ 下，$RT\ln[K_A(p)/K_B(p)]$ 均落在两状态分差的最小、最大值之间。实测值到该区间的距离给出此对绝对误差的下界。表中取各对下界的均值；达到每个最小误差所需的占比可能不同，因此这是宽松的下界。输出另含 RMSE 下界、等权 RMSE 与有符号偏差。这些量检验经验分数在某一能量标度下的失配，温度换算统一取 298.15 K。包含温度不明和缺少单化合物测量误差的系列。[Davis 原始测定](https://doi.org/10.1038/nbt.1990) · [各面板和参考信息](../../frozen_core/strain_rotor_interaction/README.md)

例如，以 1KJL 的占比作为 $p$，Gal3 化合物 32 比 11 强 13.85 倍，判对要求 $p>0.99539$；49 比 7 强 4.78 倍，判对又要求 $p<0.00955$。两个区间不相交。相反，PARP1 的所有三倍分离对本来就全部判对，仍有至少 1.248 kcal/mol 的配对能差 MAE 无法用权重解决。对 FXa，旧实验中的“216”有采用跨受体/种子分差中位数的另一种定义，这里是缔合强度等权后从每个配体标量求差，两者计数恰好相等。

## 复现与成本

从仓库根目录运行。原始输入（含四个种子激酶的两批 Native 结果、逐受体分数、实测浓度和框架原始参考）及其 SHA-256 可以沿结果表回查。需要 Python 与 SciPy。回放没有额外分子对接、MD 或模型拟合。主复算的墙钟约 1 秒，50 位十进制精度的独立复算约 3 秒。独立程序对全部 13 个配置、1,290 条含重复配置的分子对记录复核了分差、边界和秩统计。再让每个配体状态的能量在 ±0.0005 范围内对每个分子对单独取最有利的偏移，13 个配置的共同上界仍不变。对于原生打印分数这是半个打印步长，对于重建的转轴/固定参考分数只是同尺度的数值灵敏度检查。这些时间只衡量已保存值的复算。[输入校验和](results/inputs.json) · [独立检验](check.py)

```sh
D=benchmarks/mechanism_interactions/shared_population
W=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/replay.py" --output "$W"
for f in inputs.json pairs.csv summary.csv; do cmp "$W/$f" "$D/results/$f"; done
OPENBLAS_NUM_THREADS=1 python "$D/check.py" --precision-output "$W/precision.csv"
cmp "$W/precision.csv" "$D/results/precision.csv"
```
