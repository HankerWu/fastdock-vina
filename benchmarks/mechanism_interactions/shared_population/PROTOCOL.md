# 两种固定受体能否共同解释一组实测排序？

在本次跨测定复算前记录假设。历史面板及部分单配体对结果已经公开；本检验是回顾性诊断。给定每个配体在两个受体构象的分数，用统计力学混合形式作待否证的近似，在同一测定中所有配体必须共用一个 apo 占比。对每个分子对求可行占比集合，再比较逐对各自可达到的方向判对数和一个共同占比的上限。仅用解析交点划分区间，不搜索模型参数。标签参与求上限，不把占比和上限当作预测器。

- 第一批为 `kinase_state_affinity` 的三个 Davis Kd 面板；使用 Native 搜索，两批合计四个种子，受体内部取中位数。分别检验原生池参考与既有独立制备构象参考。等权结果须与既有独立复算相符。
- 跨测定检验使用 `frozen_core/strain_rotor_interaction/first_poses.csv.xz`。选历史五靶 Native 12k 中有两个受体的所有测定，另取已修正几何的 FXa、PARP1 SPR 与 Gal3 Sörme 的原生首姿。每个靶点与 assay 独立；单受体系列没有占比可辨问题，不进入此检验。避免重复统计同一输入的不同后处理、预算和历史归一化。逐个测定报告样本量和种子数。
- 排序沿用原研究的 ≥3 倍实验差，预测并列半分。等权报告全部配体 Spearman、Kendall τ-b。代理分数使用 298.15 K 换算，温度未知的测定按这一约定做灵敏度解释。浓度比无须单位转换。分差另报等权误差与任何占比无法突破的误差下界，单位 kcal/mol；Ki 仅作同测定条件下的代理比较。
- 正对照构造一个已知共同占比生成的测定，状态重标记和共同能量平移应不改变可达判对数。负对照包含分别可救但占比区间冲突的配体对。标签重复、测定混用、缺失配体/受体或种子须能识别。记录测试与复算成本。现有受体构象及经验分数不足以识别真实占比、受体重组势或绝对结合自由能。
