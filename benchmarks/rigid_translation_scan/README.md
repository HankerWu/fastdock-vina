# 在原生受体势上扫描配体平移，再做显式精修

BRPF1 的 5EPS 和 EPHX2 的 3WKE 都有原生全局搜索未充分覆盖的低能近晶体解。本实验检验一个具体的搜索改动。将相同数目的配体平移按空间分层，能否比独立随机平移更容易将正确盆地交给原生局部优化器？对于 5EPS，两个种子均扫到了近晶体位置，但精修前的能量筛选删去了全部这些位置。对于 3WKE，其中一轮搜索的第一个粗筛候选就在正确盆地，最终的显式能量排序又将它降至第二。两种失败需要不同的修正。总体结果支持继续使用普通 Pro 进行对接。[运行前协议](PROTOCOL.md) · [开发样本与晶体起点诊断](../hydration_transfer/README.md)

## 实现与对照

在接收配体定义的原 24 Å 盒内，对刚体查询构象求 $E(Q,t)=\sum_i V_{a_i}(Qx_i+t)$。$x_i$ 为按重原子几何中心居中的独立准备坐标，$a_i$ 从 FastDock 真实 PDBQT 拓扑及 XS 类型读取。$V$ 是接收结构预先生成的 0.75 Å 原生 Vina 相互作用图，使用 FastDock 写出的四位有效数字和三线性插值，单位为 kcal/mol。粗筛不含分子内势，同一刚体构象在旋转、平移下的内能为常数。显式精修允许 PDBQT 中已有的扭转自由度变化。评分未读取查询配体晶体坐标、共晶模板、水或查询 RMSD。[原生网格与优化](https://doi.org/10.1002/jcc.21334) · [小分子 FFT 刚体搜索的已发表先例](https://pmc.ncbi.nlm.nih.gov/articles/PMC5767528/)

每个种子用一次 Haar 旋转随机化立方体旋转群的 24 个正旋转方向。对每一方向，先求所有配体重原子均在盒内的平移区间。各轴均匀划格，格数取区间长度除以 1.5 Å 后向上取整。晶格组取各小格中心，随机对照在同一可行长方体内抽取完全相同数目的独立均匀位置，复用同一方向表。0.75 Å 地图比原 0.375 Å 网格粗一倍，平移尺度再粗一倍，构成单一预算档。24 个方向是立方群的阶数，未声称充分覆盖连续旋转。

每个方向取最低能平移。对所得 24 个构象按能量排序，按重原子固定索引、不重叠配准的 1 Å RMSD 排重，保留最多九个，与干搜索的请求输出数相同。精修调用本分支的原生显式受体 Vina::optimize，再按同配体、同参考态的 INTER+INTRA 排序，并按上述 1 Å 判据去重。评估使用保留化学图等价映射的晶体 RMSD。观测器只增加计数和固定坐标诊断输出。四个代表姿势的坐标与真实发布命令 --local_only 逐字节一致。两个种子之间不合并候选。该方法属于启发式全局初始化。

## 配对结果

每个格子为“首位／前五／候选池”的 2 Å 命中数。开发包含 BRPF1、EPHX2 的六个方向，共 12 个配对观测。为这项搜索机制预先留出的人源 PGR、PPARα 各含两个交叉方向，共八个观测。历史项目已使用这些留出结构，未将两个随机种子视为独立的生物样本。

| 方法 | 开发（12） | 留出（8） |
|---|---:|---:|
| 原版 Vina，3,000/轨迹 | 1／1／1 | 5／5／5 |
| 原版 Vina，12,000/轨迹 | 1／3／3 | 5／6／6 |
| 当轮基线 Pro，3,000/轨迹 | 1／1／1 | 5／5／5 |
| 当轮基线 Pro，12,000/轨迹 | 1／3／3 | 4／5／5 |
| 同方向、同数目随机平移 | 0／1／2 | 3／3／3 |
| 空间分层平移 | 0／1／1 | 2／3／3 |

晶格组在 PGR 的首位命中 2/4，随机组为 3/4，Pro 两预算均为 4/4。对 PPARα 分别为 0/4、0/4、1/4 和 0/4。PPARα 的 2P54 配体进入 1K7L 时，在种子 43103 的晶格候选池中得到 1.969 Å 解，首位为 12.100 Å。PGR 接收结构 1SQN 的最近修补重原子距其共晶配体 7.690 Å，旧基准曾据 8 Å 规则排除它。按本轮登记保留四个方向，作为敏感性分析移除该接收体后，留出首位为晶格 1/6、随机 1/6、Pro 低预算 3/6、高预算 2/6。全部配对的逐例分数及 RMSD 可由 [预测池](results/ranked.csv)、[逐池统计](results/cells.csv) 和 [干对照](results/baseline_cells.csv) 核查。

## 区分漏采、过早筛选与精修后错排

对两个开发失败例，在不改变任何已产生的构象、随机提议或打分的条件下回放每个方向的全部平移。晶体坐标只在本节用于诊断。$\mathrm{RMSD}^2$ 可分解为两构象重原子几何中心的平方距离加对应居中构象的均方误差；分别对晶体等价映射取最小值。另从已扫描的 ≤2 Å 位置中人为取粗分最优者，执行相同显式精修。此插入实验不计入预测命中率。

- **5EPS→5C7N。** 两个晶格种子各扫描 61,152 个位置，分别有五个 ≤2 Å 位置。最优近姿势在全局粗分中仅排第 17,508 和 17,299，在各自方向中也只排第 723 和 746。它们均在“每方向取最低能点”时丢失。强行将它们交给原生精修后得到 1.236 和 1.491 Å。更换随机平移仍丢失两个种子的全部 9、7 个近姿势；第一个种子的近姿势对照精修后还会退化到 2.529 Å。
- **3WKE→4OD0。** 第一个种子的两个搜索臂各有 18,816 个位置，两个池的最佳初始 RMSD 均大于 3.46 Å。第二个种子有 17,280 个位置，晶格中唯一的合格起点 1.953 Å 恰为该臂全局粗分第一。精修至 1.802 Å 后，按同参考 INTER+INTRA 排第二，最终首位为 12.097 Å。该种子的随机臂也找到 1.745 Å 的精修解；两臂没有共同的首位姿势收益。[全平移回放](results/trace.csv) · [各方向明细](results/orientation.csv)

在保存到 0.001 Å 的**完全相同坐标**上，以准备配体原拓扑重算 0.75 Å 地图、原生显式项以及取消正能量 curl 截断后的显式相互作用。5EPS 无可动扭转及姿势相关内能。表中“盲选”指实际最终排第一的候选，“近姿势”由晶体标签事后确定。显式精修前，0.75 Å 插值把近姿势估得更差，但在相同起点去掉网格和 curl 后，盲选构象仍领先超过 6 kcal/mol。精修大幅缩小差距，两个种子的粗分次序均得到保留。

| 5EPS 种子及候选 | 起点粗网格 | 起点显式无 curl | 精修后显式无 curl | 精修后 RMSD（Å） |
|---|---:|---:|---:|---:|
| 43103，近姿势 | 4.916 | 3.692 | −4.707 | 1.236 |
| 43103，盲选 | −2.697 | −2.788 | −4.891 | 4.443 |
| 43117，近姿势 | 4.364 | 3.408 | −4.258 | 1.491 |
| 43117，盲选 | −2.816 | −3.006 | −4.313 | 5.091 |

对 3WKE，第二种子中最终排名第二的近姿势，精修前后显式无 curl 的 INTER+INTRA 是 10.626→−5.149 kcal/mol；远离晶体的最终首位是 22.292→−8.971。后者局部松弛后领先 3.822 kcal/mol。这里的总能量使用同配体的共同零参考；它只解释本池的排序。此处没有同 assay 的亲和力数据，不能据此判断 Ki/Kd。[同坐标逐项复算](results/fixed_scores.csv)

## 实际成本与决策

在十个方向、两个种子上，两种方法各计算 649,248 个粗能量，13,663,896 个原子图插值，精修 180 个姿势。精修梯度求值分别为晶格 8,011、随机 8,583。分项计时的六个受体图构建及读取总计 1.620 秒，每查询的类型提取总计 0.035 秒。晶格及随机的探测、写入起点和精修驱动累计耗时分别为 1.749 和 2.145 秒。单一独立进程从冷启动、重建六个受体的图，到完成评估并写输出，两臂各复跑一次得到 4.84 和 4.57 秒墙钟、4.83 和 4.56 秒 CPU、144.2 和 146.1 MiB 峰值 RSS。此处“冷启动”指新进程和空输出目录，OS 页缓存仍可能命中。复跑的 360 个精修结果逐行相同。Pro 两档 20 个实际 CLI 进程时长总和为 4.35 和 6.09 秒，搜索及显式端到端梯度求值总和为 253,835 和 972,303。CLI 数字包含各次程序初始化，未计 Python 汇总基线报告的时间；粗图查值和梯度求值的成本不同。开发／验证重用已准备的受体和独立生成的配体，没有引入新的实验结构或再参数化。[分项成本](results/cost.csv) · [整进程复跑](results/cold.csv) · [逐工况基线时间](results/baseline_cost.csv)

在时间量级相近的 Pro 对照以及粗探测数完全一致的随机对照下，本实现没有提高首位命中率。单一配体构象、稀疏的定向覆盖和松弛前筛选均限制可达性。这个实验未检验有更密角网格或多配体构象的系统搜索上限。若继续研究 5EPS，值得检验能够预测有限局部松弛后能量的提议排序，并在新配体上区分新增局部求值与排序机制本身的作用。

## 重算与审计

在仓库根目录运行。需要 C++14、Boost、NumPy、SciPy 及原有交叉对接评估器使用的 RDKit、Gemmi、Meeko。数据来源与每个 PDB/CCD 的 provenance 保存于复用的制备归档。原版 AutoDock Vina 可执行文件和 Pro 可执行文件须与 [二进制记录](../hydration_transfer/results/binaries.json) 对照。编译观察器时核心源码和 .o 须来自同一代码树。以下命令中 VINA_NATIVE 指向原版可执行文件；Boost 使用常规系统路径或为两个构建命令同加 --boost-prefix。

```bash
R=$PWD
B="$R/benchmarks/rigid_translation_scan"
W=$(mktemp -d)
mkdir -p "$W/dev" "$W/hold" "$W/archive"
git worktree add --detach "$W/base" f0e6dbf
python "$W/base/tools/build.py" --output-dir "$W/build"
PRO="$W/build/vina"
python "$B/build_probe.py" "$W/build/obj" "$W/probe" --source-root "$W/base"
sha256sum -c "$B/FILES.sha256"
tar -xJf "$R/benchmarks/hydration_transfer/inputs.tar.xz" -C "$W/dev"
tar -xJf "$R/benchmarks/hydration_transfer/outputs.tar.xz" -C "$W/dev"
cp "$R/benchmarks/hydration_transfer/results/cost.csv" "$W/dev/cost.csv"
tar -xJf "$R/benchmarks/search_backtracking/pose/inputs.tar.xz" -C "$W/hold"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python "$B/run.py" --dev "$W/dev" --hold "$W/hold" --work "$W/pred" --probe "$W/probe" --vina "$PRO"
python "$B/baseline.py" --dev "$W/dev" --hold "$W/hold" --work "$W/dry" --pro "$PRO" --upstream "$VINA_NATIVE"
python "$B/trace.py" --dev "$W/dev" --work "$W/trace" --probe "$W/probe" --vina "$PRO"
python "$B/fixed.py" --dev "$W/dev" --full "$W/pred" --trace "$W/trace" --work "$W/fixed" --probe "$W/probe" --vina "$PRO"
python "$B/verify.py" --dev "$W/dev" --hold "$W/hold" --full "$W/pred" --vina "$PRO"
python "$B/cold.py" --dev "$W/dev" --hold "$W/hold" --work "$W/cold" --probe "$W/probe" --vina "$PRO"
tar -xJf "$B/outputs.tar.xz" -C "$W/archive"
```

归档包含两臂每个入选起点及精修后原始 PDBQT、每次梯度计数、留出的两版本干对接原始输出与日志、事后回放加入的晶体标签诊断起点和精修结果。地图从受体与所用二进制确定性生成。新旧对齐、立体映射和评估采用档案中的既定约定，不对配体做自由叠合。
