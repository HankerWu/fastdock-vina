# 在两种人核受体与 GSK3β 上检验氢扭转重分配

三个新晶体结构和一个已有结构均通过预登记的制备与对齐标准。四个查询均从化学图生成。2LBD（RARγ，全反式视黄酸）和 1FBY（RXRα，9-顺式视黄酸）各有一条在轴外仅移动氢的轴和五条可接收重分配的轴。这里固定的是 CCD 中性羧酸输入，结果无法外推到去质子化视黄酸。两种人 GSK3β 配体检验了两个不同边界。1Q41 的靛玉红肟只有一条轴，旋转只移动氢。1Q5K 的抑制剂有五条轴，每条均能移动重原子。两个 GSK3β 方向及其交叉各自用两个种子、两档主要预算，候选算法在这 16 个条件全部与父版输出逐字节相同。

四个体系的 X 射线分辨率、位点定义与化学角色见原始研究：[RARγ 2.06 Å](https://doi.org/10.1038/378681a0)、[RXRα 2.25 Å](https://doi.org/10.1093/emboj/19.11.2592)、[GSK3β–靛玉红肟 2.10 Å](https://doi.org/10.1016/j.jmb.2003.08.031)、[GSK3β–AR-A014418 1.94 Å](https://doi.org/10.1074/jbc.M306268200)。四种公共准备在本机合计 28.4 秒，含 CCD 请求、化学构象生成与刚性受体制备；原始 PDB 已缓存。该开销为所有实验臂共用。已记录下载源与 SHA-256。

## 主要配对

每行含两个种子与两个名义预算。数字为重原子对称性校正 RMSD ≤2 Å 的 Top-1 命中数。这一面板所有输出池只要有合格姿势，它就排在第一，因而 Top-5 和返回池 Oracle 成功数均与表中一致。

| 查询 → 受体 | 官方 | 父版 | Always | Adaptive |
|---|---:|---:|---:|---:|
| 1FBY → 1FBY | 2/4 | 2/4 | 3/4 | 2/4 |
| 2LBD → 2LBD | 1/4 | 0/4 | 0/4 | 0/4 |
| 1Q41 → 1Q41 | 2/4 | 2/4 | 2/4 | 2/4 |
| 1Q41 → 1Q5K | 0/4 | 0/4 | 0/4 | 0/4 |
| 1Q5K → 1Q41 | 0/4 | 0/4 | 0/4 | 0/4 |
| 1Q5K → 1Q5K | 0/4 | 0/4 | 0/4 | 0/4 |

在 3000 名义预算下四臂均为 2/12；12000 下依次为 3/12、2/12、3/12、2/12。候选缩短至 2550、10200 时 Always 依次为 2/12、3/12，Adaptive 为 2/12、2/12。Always 仅在 1FBY、种子 51871、高预算时把父版的失败改为成功，首姿从 5.414 降至 0.700 Å，实际总求值 12306→12159。Adaptive 在该次投出的 28 次氢专属扭转中重分配 21 次，但其首姿仍为 5.414 Å。同一查询同一种子在 3000 预算时 Always 从 5.206 退至 7.934 Å。在 2LBD、种子 67213、高预算时官方首姿为 0.691 Å；父版、Always、Adaptive 分别为 9.660、6.689、9.641 Å。Always 虽改变了整体方向，其首姿仍偏离实验结构，且与受体的严重碰撞数从 0 升到 6。

若事后按 2 Å 二值指标在父版和 Always 中选择，每 24 个主配置最多可获 5 个命中，父版和 Adaptive 均为 4 个。该门控在两个有条件启用机会的视黄酸查询中实际重分配 76/127 次，Always 159/159 次。不同轨迹改变了后续抽样与接受历史，因此两者分母不相同。以上都是重复测试同两个视黄酸异构体，1 个新增命中没有跨化学系列推断力。

## 首次分歧的反事实复算

在两个有重分配机会的查询中，使用高预算、两个种子，两种策略各重放一次。8 次观察器重放均逐字节复现预测输出及局部求值计数。2LBD 的 Adaptive、种子 51871 在所有 16 次机会均未激活。余下 7 个首次分歧中，原生提议产生的重原子位移严格为零，但随后的原生 hunt 优化消耗 26–46 次求值，重原子 RMS 位移为 0.00134–0.34817 Å。由此可见，原生氢轴抽样在这些状态兼具再次精修当前候选的作用。重分配提议的重原子 RMS 位移为 0.09149–7.50669 Å。冻结原接受态、原扭转抽样与接受随机状态后，原生分支 7/7 次被接受，重分配分支 5/7。两组局部优化共使用 245 与 253 次求值。这些观察器求值全部属于离线诊断。

1FBY、种子 51871 的 Always 在第 3 步首次改动，原始提议优化后 RMSD 5.238 Å，重分配分支为 6.917 Å；原始分支被接受，重分配被拒。后者最终得到 0.700 Å，所以首次局部变化对晶体的方向不足以解释整条轨迹的结果。Adaptive 到第 112 步才发生首次重分配，仍然被拒。要解释最终命中还需要定位其后首次进入正确盆地的步骤。[逐阶段坐标差异](first_proposal.csv) · [局部目标、接受和求值](first_hunt.csv)

## 成本与复算

24 个主要条件的四臂（官方、父版、Always、Adaptive）总求值分别为 185554、185837、185599、185749，包括 hunt、第二阶段和显式精修；局部优化调用分别为 4677、4609、4743、4654。Vina 与候选三臂的进程峰值分别约 428 MiB 与 22 MiB。官方与 Pro 在候选分组、建图、能量/梯度和其他历史改动上有差异，不能把两者的时差归给本次提议。首次单进程时长见 cells.csv。每个可激活配置另外进行了五次打乱次序的独立计时，各次都检查输出字节；这些复测的时长见 timings.csv。在可激活的八个条件先取各自五次中位数，再合计墙钟，父版 1.282 s，Always 1.288 s，Adaptive 1.328 s；缩短预算的两个候选为 1.289 s、1.310 s，均未显示全组严格等时优势。获得新增命中的 1FBY–51871 单格，中位墙钟从父版 0.1722 s 到 Always 0.1577 s，在 10200 预算下仍为 0.700 Å、0.1515 s；该格的改善能在较少实际计算下复现。单机上较小的时差不宜外推为通用加速。计时包含建图与写出，独立重放及统计脚本均不计入预测。

用 Biopython 从原 PDB 独立读取配体和口袋 Cα，使用独立 SVD 变换，Meeko 由 PDBQT 解码化学图和三维构象，使用 RDKit CalcRMS 在固定受体坐标系上重算手性相容的全图匹配。144 个池、654 个姿势相对于主评价的最大绝对误差为 0.000001254 Å。图的对称只在当前固定键级、电荷与微态下枚举。完整候选池这里指全部返回模式，未包含所有中间 MC 模式。

复现需要 Python 3.12、RDKit 2025.09.3、Meeko 0.7.1、Gemmi 0.7.4、NumPy、SciPy 和 Biopython。重新制备另外需要 OpenMM 8.6.1、PDBFixer 1.12。预测所用 C++ 编译器、编译选项和当前父版基线与上一层实验相同，在同一固定 CPU 核上串行运行。以下命令由仓库根目录执行，路径变量指向已按上一层方法构建的准确二进制。官方观察器使用同一官方提交及 benchmarks/pair_gradient/upstream_counts.patch，正式计时使用未打补丁的官方二进制。所有 24 个官方观察器重放都复现正式输出。

```bash
D=benchmarks/silent_torsion/transfer
mkdir -p "$W"
tar -xf "$D/inputs.tar.xz" -C "$W"
OPENBLAS_NUM_THREADS=1 taskset -c "$CPU" python "$D/panel.py" run "$W" --parent "$PARENT" --upstream "$UPSTREAM" --counts "$COUNTS" --always "$ALWAYS" --adaptive "$ADAPTIVE"
python "$D/panel.py" analyze "$W"
python "$D/verify.py" "$W"
python "$D/replay.py" "$W" "$ALWAYS_OBS" "$ADAPTIVE_OBS"
taskset -c "$CPU" python "$D/timing.py" "$W" "$PARENT" "$ALWAYS" "$ADAPTIVE"
```

仅复核已存结果时，将 raw.tar.xz 解包到同一工作目录，并从 analyze 步骤开始。也可以在空目录先运行 panel.py prepare，重新下载并制备四个结构。
