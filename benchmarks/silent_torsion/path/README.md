# 首次进入正确结合盆地的步骤

在主要实验完成后，选取两个 Always 新命中、1FBY 同种子低预算反例、2LBD 同种子高预算反例，回放父版、Always、Adaptive 的 12 个正式运行。所有对照使用同一父源 3d9dfb9。观察器在独立影子模型中按 PDBQT 原子号写出每一步的全精度坐标。只在运行结束后用实验对称性映射计算 RMSD。12 次重放均复现原始 PDBQT 字节、搜索/精修求值和调用计数。1FBY 每个臂的 3000 预算完整 MC 事件均与相应 12000 预算轨迹的前缀逐条完全相同，包括坐标、分项记录、选择和 MC 池。显式精修另行独立执行。记录量和额外计算均属离线归因。

### RXRα

第 118 步的上一状态距晶体 8.059 Å，原生与实际的 torsion_0 提议均为 7.379 Å。原有 hunt 优化用 37 次求值将它带到 1.576 Å；该状态被接受，二次优化以 1.496 Å 入池。从这一刻起，各次池更新均保留了 ≤2 Å 姿势。第 140 步的 hunt 到 0.701 Å，二次优化把 0.703 Å 姿势存入池，随后显式精修从 0.703 Å 到 0.700 Å，排名第一。父版和 Adaptive 的 hunt 最佳分别为 4.559 和 4.002 Å，最终二者最接近晶体的返回模式均为 5.008 Å。

在 3000 的同一段轨迹，Always 第 44 步已将 6.880 Å 的普通扭转提议经 hunt 带到 2.569 Å。该次 hunt 的目标为 −7.436，接受判定的参考能量为 −9.879，该步被拒。该预算下最佳已接受态仍为 5.176 Å。这能区分接近正确盆地、进入 ≤2 Å、通过接受及最终第一名。第 118 步进入正确盆地所需的预算超出了这一前缀。

### PTP1B

第 5 步从 2.885 Å 出发，原生和实际的 torsion_3 提议均为 2.908 Å，hunt 到 2.762 Å 并被接受。已有二次优化再用 36 次求值，把它带到 1.545 Å 并存为当时第一。此后每次池更新都含 ≤2 Å 的候选。第 67 步又得到更接近晶体的 0.850 Å hunt，已通过接受但未触发二次优化和保存。当时九个名额已满，hunt 目标 −13.541 未低于先前最佳 −14.647。显式精修最终从首个输入 1.426 Å 到 1.414 Å。另一个输入从 2.108 Å 到 1.150 Å，与排首的姿势只相距 0.940 Å，在原生 1 Å 输出间隔下被抑制。算法保留了正确盆地，同时丢失了该盆地里更像晶体的具体构象。父版/Adaptive 的最佳接受态均为 9.844 Å，整分子未进入正确盆地。

### RARγ

父版、Always、Adaptive 最佳提议分别为 5.677、5.406、5.677 Å，最佳 hunt 为 6.130、5.764、6.130 Å。三者均未在所记录阶段生成 ≤2 Å 候选。换提议改变了搜索轨迹，并未解决这一配体在该受体中的正确盆地发现问题。官方 Vina 在这个条件下的 0.691 Å 结果见独立结构主实验，官方并不在这次分阶段重放的三个臂中。

### 复现

需该父版的完整源码及 tools/build.py 生成的全部对象和构建日志，将完整路径传给 build.py。编译器、优化开关及链接参数从该构建日志继承。原生臂读取原父版 MC 实现，Always 和 Adaptive 仅应用上一层的 proposal.patch，观察器在三个臂上插入相同的记录点，未修改随机源。DEV 和 TRANSFER 是已解包原输入和正式 runs/ 的开发及独立结构面板。输出工作目录需为空。分析阶段可以直接解包本目录 raw.tar.xz，不需观察器二进制。

```bash
D=benchmarks/silent_torsion/path
python "$D/build.py" "$PARENT_TREE" "$BUILD_LOG" "$D/../proposal.patch" "$OBSERVERS"
python "$D/stages.py" observe "$DEV" "$TRANSFER" "$WORK" "$OBSERVERS"
# 或从归档重新计算
tar -xf "$D/raw.tar.xz" -C "$WORK"
python "$D/stages.py" analyze "$DEV" "$TRANSFER" "$WORK" "$OBSERVERS"
diff "$D/summary.csv" "$WORK/summary.csv"
xzcat "$D/events.csv.xz" | cmp - "$WORK/events.csv"
```

events.csv.xz 包含每一阶段的坐标摘要、RMSD、真实搜索评估计数及（适用时）优化目标；raw.tar.xz 保留按原子号关联的完整双精度坐标、正式输出与计数。source 的首步标记是尚未精修的随机初态。proposal 不记录能量，避免把复用缓冲中的前一候选能量误认为本提议的目标。explicit_in/out 的 step 列为零起始输入序号，evals 列为该次显式精修阶段累计求值，其余为 MC 阶段累计求值。pool 行在每次尝试插入后记录所有在池成员，不应把同一姿势重复出现当作独立发现。
