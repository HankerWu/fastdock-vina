# 4EY5→4EY6 已知结果后的成本与版本对照

已知预定 Pro 24k 的干、水与 Oracle 均为 3.623 Å。现在固定原查询、同一受体、制备、盒、单核、种子 1103501、三轨迹、九模式及能窗。另跑普通 Pro 的每轨迹 48000 名义求值，和官方 Vina 1.2.7 Linux x86_64 原版每轨迹 24000。使用相同分析，均报告实际输出、时间、CPU、全部 RMSD 与两种积分阶的干/固定水/Oracle/任意水占据界；这两个附加池不参加主分析的数据分母。官方版不支持分项计数，跳过该可选参数；保留原版输出。若资源或官方二进制获取确实失败则报告，不替换受体、种子，亦不将其他程序冒充原版。
