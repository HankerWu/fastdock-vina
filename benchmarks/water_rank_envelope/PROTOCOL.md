# 任意占据分布下，哪些候选不可能排第一

基线 e12604b。同位点相关性实验曾固定边际 p=0.75，只对42次换首的原首与水首做联合分布检验。本轮使用既有软排斥×水模型两个面板的全部156个固定池、全部已发布坐标、已有干分和晶体误差，允许任意占据边际与任意跨位点相关（甚至允许每池一套）。这是给模型最大便利的事后界限。使用历史已知结果选择问题，尚未计算新界限。

对模式 x 的离散受体参考水配置 n，固定核 Kx(n)=乘积 a_xi^ni；直接从原 PDB/PDBQT 与11点/轴 cubature 重建 a，使用原经验干分 E、298.15 K 和可公开的位点定义。可选择模型按 exp(-E/RT) E_q[Kx] 最大排序，要求该池至少一项有正权重。若某一个竞争者在目标具有正核的每个配置上均严格胜出，取任意共同 q 都不能使目标成为可比较的第一名。通过最大化对数核比逐位点求精确优势上界；两个核均为零的配置不能支持该目标。按打印干分差允许的 ±0.001 kcal/mol 向目标有利方向放宽，再留数值容差。空位点、精确零、极小数、并列逐一处理；小规模用穷举验证。此为充分淘汰条件。留下的每个模式可分别战胜对手不意味着存在能同时胜出所有对手的同一分布。

主要结果为每池被严格排除的候选、几何最近者是否被排除、余下模式的最小 RMSD 与原池 Oracle 的差（任意分布能取到的首姿误差下界）。记录见证对手、余量、全部模式、零位点、未换首、无影响及正反实例。按面板/靶点报告分布、原干/历史水首姿、池 Oracle、下界及成对差。另行给出真实可行的极端空配置与诚实的独立占据基线。逐模式重算历史水罚分及干分，并再现旧赢家，有出入先报告原因并修复；核的计算应保留微小非零质量，不从已饱和的 log 罚分反解零。报告输入哈希、CPU和墙钟、原始对接成本出处。本轮不使用这些标签学习 q，不改变默认算法、不推算亲和力或绝对自由能。若所有Oracle都不能被排除，本试验不支持核表达力存在此类障碍。若只有部分能排除，只对相应池及固定干分、位置积分和位点集合报告结论。
