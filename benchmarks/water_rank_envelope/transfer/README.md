## 角色、晶体信息和复核

- 查询为 4EY5 A 链中 HUP。由 CCD 化学图经 RDKit ETKDGv3（43103）、MMFF 和 Meeko 生成 PDBQT。两次独立生成，一次完全不给 4EY5 配体坐标，一次传入晶体坐标仅建立对照映射，所得文件逐字节一致，SHA-256 为 d64a5b88f14409bd13d397a53a7b10d6c8f979b0335268226af57d0dfd2bdf5f。真正送入对接程序的是前者。采用 CCD 的形式中性微态；4EY5 晶体条件 pH 7.0，未计算溶液态质子化分布。
- 受体为 4EY6 A 链的人蛋白，盒心由原配体加兰他敏 GNT 的 21 个重原子计算，和归档盒心一致，为 (−9.942238, −43.487714, 30.290810) Å。三个引擎使用相同的 24 Å 立方盒和干受体。受体准备记录无需补重原子、无金属，距原配体最近的省略非水原子为 16.49 Å。受体晶体水与原配体体现了该受体已有的结构信息。
- 只有评价读取 4EY5 晶体坐标。两侧各自配体周围 14 Å 的 64 个共同 Cα 经刚体配准后 RMSD 为 0.273 Å，查询的 18 个重原子有一个保持化学图和立体化学的映射。第二个程序从 PDB/CCD 独立建图，使用与主程序不同的旋转拟合路径，核对 26 个发布姿势的立体化学和误差。最大 RMSD 差小于 4×10⁻¹⁵ Å。
- 冻结的同一位点规则在 4EY6 的已知口袋内选出 33 个水氧。积分阶分别为 11/17，固定盲分采用独立占据 0.75。独立复核删去对各模式贡献相同的位点，分批枚举其他全部占据向量。主池两阶分别枚举 2,097,152 / 524,288 种，全部单对手证书和解析上界相差小于 10⁻¹³ kcal/mol。这一枚举核对的是已有模型，未测受体游离态水丰度或结合自由能。[位点坐标及 B 因子](sites.csv) · [逐位点核](factors.csv) · [独立数值核对](independent.json)

从仓库根目录运行以下命令。依赖 Python、RDKit、Meeko、Gemmi、NumPy、SciPy 和 pandas。check.py 默认从已归档坐标重算；传入对应二进制后执行原生对接，需将输出指定到新的空目录。原始 4EY5 PDB 和 HUP CCD 随本目录保存，4EY6 原始沉积和干受体从仓库已有档案按路径读取。已知口袋与配体微态、单一固定受体是本实验的适用条件。

```bash
D=benchmarks/water_rank_envelope/transfer
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1
for arm in pro24k pro48k official24k; do
    python "$D/check.py" "$W/input-$arm" "$W/output-$arm" --arm "$arm"
    src="$D/$arm"
    if [ "$arm" = pro24k ]; then src="$D"; fi
    for f in modes.csv factors.csv sites.csv summary.csv; do cmp "$src/$f" "$W/output-$arm/$f"; done
    python "$D/verify_pool.py" "$src" "$W/$arm-independent.json"
done
# 搜索复跑示例，PRO 为源代码建成的普通 Pro
python "$D/check.py" "$W/run" "$W/pool" --arm pro24k --vina "$PRO"
cmp "$D/dry.pdbqt" "$W/pool/dry.pdbqt"
```
