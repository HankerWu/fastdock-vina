# CH–π 接触能否帮助识别糖的结合面？

原生 Vina 在人 Galectin-1（Gal-1）产出的 104 个候选池中，38 个含距同类晶体糖环 ≤2 Å 的候选，32 个把这样的候选排第一。Galectin-3（Gal-3）相应为 8 和 4。两者都有识别错误，也都有从未生成近似糖环的池。我们在**同一批坐标**上给芳香碳–脂肪族 CH 引入已发表的相互作用势，检验结合面几何和亲和力次序。Gal-1 的典型糖环误差有所降低；将模型用于全配体姿势和实测 Kd 时效果依赖受体。[协议](PROTOCOL.md) · [原生 Galectin 候选、化学结构、对接参数和 FP 测量来源](../galectin_affinity/README.md) · [葡萄糖结构来源](../ligand_hydroxyl/glucose/README.md)

## 评分模型

对分属配体、蛋白的一对原子，要求其中之一为带 H 的饱和碳，另一为芳香碳。两种给受方向各计算一次。给定距离 $r$（Å），原始项为

$$
u(r)=-0.26\exp[-(r-4.49)^2/(2\times0.75^2)]\ \mathrm{kcal/mol},\qquad r<8\ \mathrm{Å}.
$$

取 $r\geq8$ Å 时为零。高斯参数来自 Xiao 和 Woods 对甲烷–苯三种取向的 MP2/aug-cc-pVDZ 数据拟合，拟合中保留 Vina 原有碳–碳相互作用。采用作者对无氢 Vina 对接建议的权重 0.3。设 $F=1/(1+0.05846N_\mathrm{rot})$，从原始能量分项恢复生成各池时实际使用的转子分母，逐姿势核对重建分数。选取 $S_\mathrm{native}+0.3F\sum u(r)$ 最小的姿势。分子图与 Meeko 原子映射决定配体重原子类别，标准氨基酸原子名决定蛋白类别，稠环共用的碳只计一次。额外能量是冻结坐标上的经验校正，未重新计算 Vina 原子能量压缩或搜索梯度。[物理模型](model.py) · [原论文](https://doi.org/10.1021/acs.jctc.3c00300)

原论文的参数已考虑原生势对甲烷–苯相互作用的贡献。转移到不同杂芳环、口袋溶剂和取代环境时，配对项仍可能与经验疏水评分重复。该近似按碳距离计分，没有显式 CH 朝向、融合芳环电子分布、溶剂置换或游离态自由能。实验中两个方向指哪一侧提供 CH。

## 两种给受方向为何有相反结果？

仅加入配体 CH→蛋白芳香碳时，Gal-1 的糖环均值为 3.074 Å，34 个改善，0 个退化。Gal-3 为 4.543 Å，27 个改善，6 个退化。仅用蛋白 CH→配体芳香碳，两靶点均值升至 4.537 和 5.644 Å。事后只保留配体环 CH–蛋白色氨酸对，均值分别为 3.290 和 4.580 Å。按化学类别拆分可以识别糖环接触和芳基取代基之间的竞争。仅用糖环作评估也会偏向恢复该局部结构的模型。

- Gal-1 的 1GZW、化合物 10、种子 271828，原第三名比原首位差 0.232 分，却有 0.829 Å 的糖环误差，原首位为 9.211 Å。只看配体环 CH→色氨酸项，原第三名已经占优 1.052 分。蛋白 CH→配体芳香碳反向抵消了其中 0.730 分。
- Gal-3 的 1KJL、化合物 14、种子 314159，原第四名比原首位差 0.979 分，蛋白 CH→配体芳香碳项却给其 1.609 分优势。它因而升到首位，糖环误差从 7.309 增至 13.923 Å，两候选之间的糖环–色氨酸项差为零。

这些差异可以在首次对固定候选调用新评分时解释。芳基取代基的真实位置仍然未知。[逐候选化学分解](results/localization.csv) · [逐池反事实](results/local_cells.csv) · [消融汇总](results/local_summary.csv)

## 同测定 Kd

每靶点 13 个同一论文、同一类竞争荧光偏振测定的 Kd。每受体每配体取四种子首选分数中位数，再对两个受体取算术均值。每靶点 78 对中，各有一对不同分子报告完全相同 Kd，计算全对一致率时排除该对。预测并列给半分。优先解析的对要求实测相差至少三倍，且表中所列的误差范围不重叠。统计所用 pKd 为 $6-\log_{10}(K_d/\mu\mathrm M)$，与负预测分数同向。化合物 7、15 的 Gal-1 原生受体汇总分恰好同为 −5.895，统一对汇总分保留九位小数，避免二进制舍入误差拆开这个并列。[实测原始 Table 1](https://doi.org/10.1021/acs.jmedchem.7b01626) · [标签](../galectin_affinity/table1.csv)

两靶点 Δρ 的整配体配对重采样区间分别为 [−0.355,+0.307]、[−0.419,+0.555]。Gal-3 在 1KJL 上有 24→28 个正确大差异对，在 3T1L 上为 31→27。固定原首位只改报告分数，Gal-1 已达到 19/23，Gal-3 停在 28/35。保留新首位、只读其原生评分，Gal-3 得到 31/35。修正项既改变了单分子分值，也改变了候选选择，两者对亲和力次序的贡献因体系而异。此面板只有 Kd，未做 Ki 和标准结合自由能检验。[逐受体统计](results/affinity.csv) · [每个化合物与 pKd](results/ligand_scores.csv) · [逐对方向](results/pairs.csv) · [重采样](results/affinity_intervals.csv)

仅按重原子越多结合越强进行排序，在 Gal-3 的 35 个大差异对中达到 34/35，双向模型为 29/35。限定重原子数量与电荷均相同后，Gal-1 为 3→5/7，Gal-3 为 1→1/2。两靶点各只有一个同分子式大差异对。剔除缺少芳基三唑的化合物 17，Gal-1 为 7→9/13，Gal-3 为 18→19/25。当前面板没有足够的同大小困难分子对来确立物理模型对亲和力的独立增益。[化学控制子集](results/size_control.csv)

## 复现和开销

从仓库根目录执行以下命令。依赖 Python、NumPy、SciPy、pandas、RDKit 与 Meeko。两份上游归档已包含所有坐标。逐姿势表可单独复算几何分布、配对差、全部亲和力统计。诊断脚本独立列举蛋白碳类型、用 SMARTS 识别配体、用近邻树计算原子对，以 SciPy 复核所有相关系数，并检验单对解析最优值、宽度、截断、刚体变换和含胍基的负对照。

~~~bash
B=benchmarks/ch_pi_transfer
W=$(mktemp -d)
mkdir -p "$W/gal" "$W/glucose" "$W/out"
tar xf benchmarks/galectin_affinity/evidence.tar.xz -C "$W/gal"
tar xf benchmarks/ligand_hydroxyl/glucose/evidence.tar.xz -C "$W/glucose"
export OPENBLAS_NUM_THREADS=1
python "$B/replay.py" "$W/gal" "$W/glucose" "$W/out"
python "$B/summarize.py" "$W/out"
python "$B/diagnose.py" "$W/gal" "$W/out"
cmp "$B/results/poses.csv" "$W/out/poses.csv"
cmp "$B/results/affinity.csv" "$W/out/affinity.csv"
~~~

两个人 Galectin 的测定包含同系列配体，16 个葡萄糖池只有两种蛋白。新增重排共 224 个池、1,993 个姿势，每个池都输出有效结果，无额外搜索、精修、能量梯度评估或 GPU 工作。初次单线程测量中，构建评分对象 0.112 秒，固定姿势评分 0.212 秒，从进入重放循环到写出姿势表约 0.566 秒。独立复跑另外记录含 Python 依赖启动的墙钟时间。原有搜索和输入制备成本在上游实验中单独记录。当前证据支持将单向分解保留为机理诊断，新蛋白家族按单独协议验证。[本次开销](results/cost.csv) · [独立进程](results/standalone_cost.json) · [数值复核](results/check.json) · [人 β-葡糖脑苷脂酶验证](gba1/)
