# 搜索网格、受体构象与真实亲和力的配对验证

在官方 Vina 和 FastDock 上分别重跑了真实结构与同法亲和力系列。可微三次插值明显提高了受体势及其导数的数值精度。六个人源靶点的首姿命中由 32/66 变为 30/66。独立种子和等 CPU 时间对照也支持保留三线性作为默认插值。已在默认路径修正显式精修的盒外受体梯度。

## 从物理近似到可推翻的预测

对类型为 t 的单个配体原子，受体场为 $U_t(x)=\sum_j u_{tj}(\lVert x-r_j\rVert)$。Vina 在空间格点预先求和，搜索时插值计算离格的值与梯度。三线性插值的值连续，跨格面的法向导数通常跳变。新开关 `--cubic_search_grid` 采用可分离的 Catmull–Rom 核，每轴四个采样点，以相邻格点的中心差分作为节点斜率。首末节点采用单侧割线。在盒内三次场的一阶导数连续，数值和梯度来自同一个多项式。库仑项、配体内势、额外地图和参数拟合均未引入该机制。FastDock 用所选插值做全局搜索中的局部最小化，默认 Late 设置仍用原生显式受体精修和排序。命令直接使用原有的受体、配体和配置。

```bash
build/vina --receptor receptor.pdbqt --ligand ligand.pdbqt --config box.txt \
  --pose_selection late --cubic_search_grid --seed 42 --out poses.pdbqt
```

最直接的预测是同一组格点下，离格误差应下降。更强的预测是同等计算成本下，搜索会更频繁找到原生精修能保留的近晶体姿势。要改善同靶强弱次序，还要求不同分子的分数差与同一实验条件下的相对结合自由能相符。这三个预测可以分别检验。Minh 的 85 个复合物研究测试了分子力学网格的能量变换，GALigandDock 对 0.25 Å 网格使用样条。这两项工作支持研究插值误差的必要性。对应 FastDock 的数值和分子结果见下面各自的对照。[Vina 原论文](https://doi.org/10.1002/jcc.21334) · [Minh](https://pubmed.ncbi.nlm.nih.gov/29457253/) · [GALigandDock](https://doi.org/10.1021/acs.jctc.0c01184) · [CASF-2016](https://doi.org/10.1021/acs.jcim.8b00545)

## 分子姿势及真实强弱

主姿势面板为 EPAS1、FKBP12、RBP4、FABP4、DYRK1A 和 JAK2，12 个配体与 11 个可用受体，3 个种子得到 66 个配对格。晶体坐标只用于定义已知口袋与评价。JAK2 6WTN 受体的缺失侧链未能可靠修复，保留其配体。EPAS1 的两例均含 R247E。全配体、受体坐标系下、保留手性的对称校正 RMSD 以 2 Å 为阈值。首姿 32→30，前五 37→36，所有模式 38→38。独立程序从原始 PDB/CCD 重建 1,188 个模式。另一组 20 个交叉格，官方 Vina、分支 Late、三次、加密三线性、等时间原生的首姿命中依次为 10、10、9、8、10。全部返回模式中至少有一个命中的格数为 12、13、11、14、15。[逐靶点结果](human_panel/README.md) · [等时间和官方确认](confirmation/README.md)

## 官方能力与失败机制

从本分支原始上游基线 3c65c0b 到本次核对的官方 develop bb64e5e，src/ 的后续差异集中在预计算表去重，分支已有对应机制。上游的 AD4 打分、原生侧链柔性和网格密度参数都值得实测。统一了两棵源码的编译器和 Boost。FKBP12 的 16 个配体–受体 AD4 池在分支与官方之间逐字节相同。[官方源码变化](https://github.com/forlilab/AutoDock-Vina/commit/e4e1b88eddb0dc4d0cbbcb64ef3d4a536925db14) · [Vina 1.2 方法](https://doi.org/10.1021/acs.jcim.1c00203)

- 同一个官方二进制，FKBP12 用 Vina 得 7/15、AD4 得 6/15。用 AD4 对相同的 Vina 池重排得 3/15。AD4 排对两个差向异构体对，Vina 排对一个。逐个地图插值复算 432 个 AD4 模式，误差不超过 0.00285 kcal/mol。[原始池、地图与逐对读回](fkbp_ad4/README.md)
- FABP4 和 RBP4 的三个羧酸配体，两种化学状态保持重原子起始坐标一致。18 格上的首姿，中性酸到阴离子在 Vina 为 6→5，在 AD4 为 4→6。改变质子化会同时改变供氢能力、部分电荷和羟基扭转自由度。每臂全部候选命中均为 7/18。[状态交叉实验](acid_states/README.md)
- 在 EPAS1 的一个失败种子中，三次搜索首姿误差约 14 Å，向原生势提供一个 0.52 Å 的可行姿势后，它的原始能量低 1.90 个单位。FABP4 一例则相反，1.08 Å 的投影姿势比所选远姿势高约 7.8 个单位。对于 RBP4，把 A1120 的配体内几何投影到视黄醇受体，整配体 RMSD 仅 1.42 Å，最近原子间距只有 0.57 Å。按这些碰撞选择 FABP4 Thr60 或 RBP4 Gln98 作官方柔性侧链后，24 格首姿仍为 5→5。选择阶段使用晶体答案，是事后归因。[坐标、碰撞与能量差](confirmation/cross_diagnosis.csv) · [柔性复测](flex_replay/README.md) · [独立坐标核验](official_audit/README.md)

## 默认精修的投影导数

令 Π 将配体原子坐标逐轴夹到搜索盒，显式能量为 U(Πx) + s‖x−Πx‖₁。严格盒外沿面法向移动时，Πx 在该方向恒定，法向导数只应是墙斜率 ±s。原版已钳制坐标，却叠加了受体势的法向导数。修复前 45 个数值检查中的 21 个盒外法向分量均错误。修复后 45 个全部通过。对正常大小搜索盒，132 次主姿势和 192 次 FKBP12 实验的首模型在修复前后逐字节一致。另一份 104 次激酶实验中，FAK 原生排序随修复改变一对，由 9/47 到 8/47。实测反映这种改动有时也会改变种子结局。[梯度回归](wall/README.md) · [主面板复测](human_panel/wall_replay_summary.json) · [激酶复测](affinity/wall-summary.csv)
