# 首提议平移与同测定亲和力

查询配体的起始位置会改变首姿，从而改变同一批分子的 Kd 排序。采用 [6e2513f 的研究实现](https://github.com/HankerWu/fastdock-vina/commit/6e2513f213e23db4b0da41ac5aa89945f882ac6b)，对首次提议的重原子包围盒取出可行刚体平移区间。三个臂为原生平移、所有能放入盒内的首提议重映射（candidate）、仅对越界首提议重映射（control）。三个臂交错绑定同一逻辑核。复用[切线实验的两枚种子、四个受体、13 个化合物和 12,000 名义预算](../README.md)。

| 靶点、种子 | ≥3 倍正确对，父 → 全重映射 | 两边等重原子数和电荷 | Spearman，父 → 全重映射 | Kendall τ-b，父 → 全重映射 |
|---|---:|---:|---:|---:|
| Gal-1，912743 | 13→18 / 23 | 3→5 / 7 | −0.052→0.487 | 0.013→0.348 |
| Gal-1，912749 | 19→15 / 23 | 5→5 / 7 | 0.377→0.129 | 0.271→0.065 |
| Gal-3，912743 | 17→28 / 35 | 0→1 / 2 | −0.080→0.476 | −0.039→0.323 |
| Gal-3，912749 | 22→23 / 35 | 2→0 / 2 | 0.256→0.231 | 0.219→0.194 |

全重映射与仅处理越界在 104 个受体–化合物–种子单元的完整输出池逐字节相同。每个单元的全重映射输出均与父版本不同。未修改的上游程序在前一项同输入实验测过：两枚种子的 Gal-1 为 16、19 / 23，Gal-3 为 17、22 / 35。当前父版本的全部 104 个池与前一 C++ 构建完全一致。Gal-3 仅按重原子数从大到小排序就有 34/35，只有 2 对同尺寸同净电荷。第二枚种子中，Gal-3 的方向正确总数上升 1 对，而两个匹配对都由对变错。Gal-1 总数的变化方向取决于种子。按化合物重采样后，Gal-3 两个种子的正确率变化分别为 +31.4 个百分点（描述区间 0 到 +67.7）和 +2.9 个百分点（−43.3 到 +38.7）。[分状态、分系列和分子对分层](rankings.csv) · [按分子重采样](paired_bootstrap.csv)

每行合计 52 次独立 CLI 调用。仅越界一臂的局优和联合求值次数均与全映射相同。比较不同随机种子的结果时，分母中的配体身份重复。糖环评估使用其他配体晶体中的六原子同源环，无法判断整配体真实姿势。所有首姿的受体–配体重原子最近距离都至少 2 Å。另将第一枚种子的 295 个父版本候选全部锁定，在相同原始拓扑、相同打印坐标和 unbound=0 下用三臂独立打分，所有十项分解完全一致。每个模型的坐标 SHA-256 与分解值随原始日志归档。[逐受体计数、时间和几何](cost.csv)

## 复现

使用上一级[复算说明](../README.md)中的软件环境。全部 312 个这次运行的池、原始日志、固定坐标复查、化合物/受体标识和耗时在本目录 runs.tar.xz 中。以下命令从归档复核实际输入、输出及实验表；重新对接时 PARENT、FIT、INVALID 指向同一构建，分别清除 FASTDOCK_FIRST_PLACEMENT、设置为 fit 或 invalid。三个包装实际调用的二进制 SHA-256 为 73cbac517ed881d8be7842dedb4796c96fad8f44faf66adcfdc30c598acd06fd。切线环境开关保持关闭。

```sh
D=benchmarks/hunt_overlap/affinity
W=$(mktemp -d)
tar -xf "$D/placement/runs.tar.xz" -C "$W"
OPENBLAS_NUM_THREADS=1 python "$D/evaluate.py" "$PWD" "$W/placement"
python "$D/check.py" "$PWD" "$W/placement"
cmp "$W/placement/rankings.csv" "$D/placement/rankings.csv"
for seed in 912743 912749; do
  python "$D/assay.py" run "$PWD" "$W/new" --seed "$seed" --cap 12000 --cpu 7 --parent "$PARENT" --candidate "$FIT" --control "$INVALID"
done
python "$D/assay.py" fixed "$PWD" "$W/new" --seed 912743 --cap 12000 --cpu 7 --parent "$PARENT" --candidate "$FIT" --control "$INVALID"
OPENBLAS_NUM_THREADS=1 python "$D/evaluate.py" "$PWD" "$W/new"
```
