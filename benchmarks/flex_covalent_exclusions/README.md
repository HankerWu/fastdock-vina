# 柔性侧链与刚性骨架的共价近邻

Vina 的构象相关评分对能相对运动的原子对求和，通常排除相隔三条共价键的 1–4 相互作用。这个约定也出现在分支的分子内显式原子对列表中。过去将受体拆成刚性骨架和柔性侧链后，一个可动侧链原子会读取所有刚性原子的网格场，显式精修同样会计算它与全部邻近刚性原子的相互作用。例如 CG–CB–CA–骨架 C 横跨两个表示，旧程序会把 CG 与骨架 C 当作普通非键接触。不同二面角下，该项产生不同的能量和力矩。[Vina 的原始定义](https://doi.org/10.1002/jcc.21334)

新路径沿已经建立的受体键图走至三层，得到每个可动受体原子需要排除的刚性原子集合。显式作用在累计径向势之前跳过这些原子。Vina/Vinardo 的搜索网格从该原子类型的原始格点能量中扣除相同势表产生的近邻项，再使用原有的插值、正能量限幅和盒边界惩罚。配体使用完整的共享场。该约定只针对当前经验势，其他力场可能保留或缩放 1–4 项。输入键图继承 PDBQT 几何推断和声明的转轴。AD4 的外部 AutoGrid 场没有这个刚性受体键图。

固定测试在 CG–CB–CA–C1–C2 片段上，将完整模型与只移除 C1 的模型配对。CG 对 C2 的四键相互作用应当保留，独立配体对 C1 的相互作用也应保留。三种侧链角度下，父版显式计入的 C1 项分别为 −0.011、+0.103、+0.085 kcal/mol，普通搜索网格为 +0.002、+0.113、+0.096。修正版六个差值均为 0.000，报告精度为 0.001。独立配体对 C1 的相互作用与父版一致。[原始 CLI 对照](cli_control.csv)

C++ 回归在三个角度、两个限幅下分开检验显式、三线性、三次插值的受体内能量和广义扭转梯度。它还通过 Vina 的公开 API 验证双配体、延迟拓展网格、两种评分方案的导出再导入，并检查不匹配的侧链定义。测试通过并不能证明预测姿势或亲和力更准确。构建基准版及修正版后，可独立复算六个反事实。

```sh
python benchmarks/flex_covalent_exclusions/cli_control.py "$BASE_BIN" "$FIXED_BIN" control.csv
```

导出本地生成的柔性 Vina/Vinardo 网格时，共享通道维持原有格式，另外写出 `PREFIX.flex-fields` 和每个受影响侧链原子的 `PREFIX.flex-I.map`。复用相同刚柔拆分时，一起复制这些文件及原始柔性 PDBQT。程序核对柔性原子顺序、初始坐标和转动树，然后读取专用场。仅有传统类型通道时，程序可按旧的共享场约定运行并提示这一限制。每个受影响且有有效评分类型的侧链原子多占用一个浮点网格。受体不含柔性侧链时无需额外网格。
