# 默认 BFGS 在回溯失败后保留已接受点

2X6E 的 AT9283 合法扭转放置同时暴露了两个可区分的问题。旧默认局优找到了较低的内部目标，却在一次失败的线搜索后丢失了它；取回该解之后，近晶体见证在同零点的干分比较中仍输给四个盲搜首姿。这里修复已确定的数值错误，检验它对实际对接和亲和力的后果。[放置、完整 SDF 图和固定零点对照](../receptor_linkage/aurora/PROBE.md) · [生产改动 2326430](https://github.com/HankerWu/fastdock-vina/commit/232643049094dee7fece70498f77f5271d621949)

## 从下降到回滚的完整轨迹

输入、受体、打分和梯度相同，旧默认与已有 Armijo 模式的前 34 次内部求值相同。内部目标始于 −4.598644，到第 24 次降为 −9.601457。然后十个试步全部不满足下降判据，第 34 次的实算步长为 1/512，目标为 +299.316172。旧代码将这组拒绝坐标交给 BFGS，又以未计算过的 1/1024 更新曲率。继续至第 92 次，目标升为 +1.73419×10¹¹，最终回滚至起点。修正版在这条线上停于上个已接受点 −9.601457，经公共固定参考重评给 −7.426，配体 RMSD 为 1.266 Å。内部目标包含连续插值及内部相互作用；固定参考的终端分数还使用快速查表和转子变换，两处数值量须分别解读。[父版默认轨迹](trace/parent-native.trace) · [父版严格 Armijo](trace/parent-armijo.trace) · [修复后默认轨迹](trace/fixed-native.trace) · [最终坐标](trace/fixed-native.pdbqt.gz)

改动检查方向导数是否有限且为负。沿合法方向只在实际计算的步长通过相应判据时提交坐标。耗尽十个试步后，优化器返回当前已接受点及其能量，并将模型的活动坐标恢复到这个点。原有末态对起点回退也保留。修复应用于共享该优化器的网格搜索、局部优化和末端显式精修。每种模式仍沿用其成功步骤的曲率和收敛逻辑。历史上不同的回溯插值或更严格的 Armijo 模式具有各自独立的其他改变；本修复不依赖拟合目标或更深的搜索。[回归](../check_armijo_numeric.cpp) · [正常命令行入口](../check_armijo_refinement.py) · [早期搜索阶段的线搜索试步](../search_backtracking/core/README.md)

还有一个方向相反的实物对照。1IEP 的共晶教程输入用默认 local_only 与 autobox 运行，父版越过拒绝点后给出较低的终端分 −13.274；正确停步保留起始坐标，得到 −12.513。较低的最终分数不能验证中间步长的数学一致性。针对默认入口的回归在父版失败，在修复版通过。复现之前的历史对接时可检出相应提交再运行。[数值回归输出](trace/numeric-regression.log) · [真实命令行回归](trace/cli-regression.log)
