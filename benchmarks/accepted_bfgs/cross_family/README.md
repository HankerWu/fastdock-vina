## 复现

先用各自工作树的 `tools/build.py` 构建两个版本。拓扑解析器用相同分支的 `benchmarks/receptor_linkage/aurora/probe_topology.cpp`，构建命令见该目录的 `PROBE.md`。准备两份额外工作树，各自用 `git apply --unidiff-zero /path/to/native_observer.patch` 加入三行观测输出再构建，以产生只用于读取目标和计数的二进制。可用 Python 3.12、NumPy、RDKit 和 Linux；本轮 NumPy 为 2.3.5，RDKit 为 2026.09.2。将下列路径变量设置为实际位置。CPU 为可用的单个核。

```bash
OPENBLAS_NUM_THREADS=1 taskset -c "$CPU" python "$D/replay.py" \
  "$REPO" "$PARENT_VINA" "$FIXED_VINA" "$PARSER" "$WORK"
OPENBLAS_NUM_THREADS=1 taskset -c "$CPU" python "$D/observe.py" \
  "$WORK" "$OBSERVED_PARENT_VINA" "$OBSERVED_FIXED_VINA"
python "$D/summarize.py" "$WORK"
```

`$WORK` 须为新目录。程序按 SHA-256 核验仓库已有的两份归档，并生成记录中使用的全部表格、坐标和日志。环境不同时时间和二进制哈希可变化。按既有实验设计，RMSD 服从已存图同构，在实验受体坐标系内取对称最小值。每个受体只含一种配体，此面板没有跨分子同测定亲和力排序或自由能标签。
