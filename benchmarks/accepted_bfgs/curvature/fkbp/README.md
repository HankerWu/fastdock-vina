# 初始曲率修复在 FKBP12 同一测定上的配对结果

沿用原有的 8 个配体、2 套人 FKBP12 受体 AD4 图、3 枚种子和 24,000 上限，父版 5015481 与初始曲率修复版各重新对接 48 次。Holt Table II 为 10 °C、pH 7.8 的表观 Ki，化合物 10 保留 300–600 nM 区间。按区间端点仍相差至少三倍的 15 对评方向，7 个点值评相关。每种受体先取种子中位数，两种受体等权。测定、输入校验和、历史官方 Vina 1.2.7 AD4 对照及原分析脚本与上一轮完全相同。[实验出处](https://doi.org/10.1021/ja00075a008) · [原协议与脚本](../../fkbp/PROTOCOL.md)

| 版本 | 1FKG 三倍对 | 1FKH 三倍对 | 两受体均分三倍对 | 7 个点的 Spearman ρ / Kendall τ-b |
|---|---:|---:|---:|---:|
| 官方 AD4（既有） | 6/15 | 8/15 | 6/15 | −0.179 / −0.143 |
| 5015481 | 7/15 | 8/15 | 8/15 | 0.536 / 0.429 |
| 初始曲率修复 | 3/15 | 5/15 | 5/15 | 0.071 / 0.048 |

等权受体均分丢失 8–4、8–11、9–10 三个原先正确的方向，新增零个。两版各返回 432 个姿势。48 个池中有 47 个的坐标集合变化，38 个首姿的坐标变化。评分函数未变，盲搜实际提供的候选和可能用作能量参考的内部构象均可随优化轨迹改变。这组数据体现了优化器修复后的全流程退化，不能将原因唯一归给最终评分。每对共享配体，8 个分子只覆盖一个骨架。[逐次搜索](results/runs.csv) · [分对](results/pairs.csv) · [从计分输出及坐标独立回读](results/independent.json)

两版完整对接进程的墙钟合计分别为 51.64、51.41 s，CPU 合计 50.29、49.99 s。各次交错运行一次，计时包括读图及输出，不含图生成及历史上游重跑。单次计时不足以区分这点速度差。[总成本](results/costs.csv)

从仓库根目录执行。OLD、NEW 指向对应的两个二进制，WORK 指向新目录。第一条运行两版；只复核已有输出时，可先建 WORK 并将本目录 pools.tar.xz 解包至其中，随后直接执行第二条。

```sh
D=benchmarks/accepted_bfgs
python "$D/fkbp/fkbp.py" "$PWD" "$WORK" "$OLD" "$NEW"
python "$D/fkbp/check_pools.py" "$WORK" benchmarks/cubic_grid "$WORK/independent.json"
cmp "$WORK/independent.json" "$D/curvature/fkbp/results/independent.json"
```
