# BFGS 初始度量的正定性与葡萄糖对接

共享 BFGS 的一次初始缩放会把下降方向变为上升方向。在 16 组真实对接条件中有 15 组遇到该问题。修复使其中 7 组首次受影响的局部最小化取得更低的内部目标，另外 8 组返回相同目标。高预算下整体首姿误差却上升，主要来自一组葡萄糖激酶对接。[预设检验和后续扩展](PROTOCOL.md) · [逐例差值与实测方向](results/paired.csv)

## 深入检查同一步局部最小化

设一次已经接受的步为 $s=\alpha p$，梯度变化为 $y=g_{k+1}-g_k$。若正定的对称逆 Hessian 近似 $H$ 满足割线条件 $Hy=s$，必有 $s^Ty=y^THy>0$（$y\ne0$）。父版在第一次接受步后采用 $H_0=(s^Ty/y^Ty)I$ 调整初始尺度。仅要求函数值充分下降的回溯可以接受 $s^Ty<0$ 的步。父版随后虽跳过秩二更新，负比例已写入矩阵。只要新梯度非零，下一方向 $p=-H_0g$ 就满足 $g^Tp>0$，故优化器在开始试步前即停止。该现象发生在一次**成功接受**之后，与前轮修正的回溯耗尽后保留已接受点是两个先后独立的机制。[经典缩放公式](https://users.iems.northwestern.edu/~nocedal/PDFfiles/limited-memory.pdf) · [非凸目标上的谨慎更新研究](https://doi.org/10.1137/S1052623499354242) · [前轮的失败轨迹](../README.md)

修复将已有的曲率下限放到首次缩放与秩二更新之前，并检查缩放为有限正值。曲率不足时保留当前矩阵，继续沿其给出的方向下降。各模式原本使用的坐标度量、步长试探上限和目标保留。这里维持近似度量的正定性，不能据此对具有截断和网格插值的对接势声称全局收敛。该实现作用于默认网格搜索、显式精修和共享该代码的评分模式。单点评分不执行 BFGS。[生产实现](../../../src/lib/bfgs.h) · [原生和严格模式数值回归](../../check_armijo_numeric.cpp)

一维解析函数 $f(x)=x-x^2/2$ 从 0 开始。第一步到 $-1$ 后 $s^Ty=-1$。修复后的默认 BFGS 保留单位度量，第二步到 $-3$，两步后能量确为 $-7.5$。此函数用于验证两步方向和返回坐标。

在人葡萄糖激酶 3IDH、种子 43103、每条轨迹 12000 档，首次受影响的调用从 41.2555 降至 3.6180，首步 $s^Ty=-39.1115$。父版下一方向导数为 +63.3833，保留 3.6180，累计 2 次联合能量梯度求值。修复版下一方向导数为 −1088.1290，步长 1/64 首先到 1.4203，局优最后得到 −5.6775，共 47 次求值。同一对接中，最终首姿从 0.802 变为 7.777 Å，导出池最优从 0.802 变为 3.566 Å，首姿减池最优从 0 变为 4.211 Å。局优能量、可返回的候选几何与候选的选择可以同时向不同方向变化。两条搜索轨迹在首次分歧后继续变化，此对照无法把终态差异全部归给单次调用。

初选的 3IDH、43103、3000 档没有发现非正首次曲率，两版 PDBQT 完全相同。扩展只读观测到既有面板的全部 16 组后，32 次观测输出均与对应生产坐标逐字节相同。15 组的首次受影响调用在两版中具有相同的起始与已接受能量、步长、梯度范数及曲率；15 次父版下一方向导数均为正，修复后均为负。7 次返回更低的局部目标，8 次后续回溯未进一步降低目标。父版记录的 144 个受影响调用和修复版 124 个来自各自完整轨迹，首次分歧后的个数不作一一配对。[完整观测记录和生产输出](outputs.tar.xz) · [验证程序](check.py)

## 复现

父版为 `5015481d4cf62c75bca8b4a67358364813c79c79`。测试环境使用 GCC 14、Boost 1.83、Python 3.12、NumPy、RDKit 和 Linux，生产构建的 SHA-256 存于 [binaries.json](results/binaries.json)。在父版和修复版各从对应源码运行 `python tools/build.py --boost-prefix "$BOOST" --output-dir "$BUILD"`。令 PARENT 和 FIXED 为两个源码树，OLD 和 NEW 为相应构建目录，WORK 为尚不存在的工作目录，D 为本目录，CPU 为可用的 CPU 编号。重放使用仓库现有输入，归档 SHA-256 为 `ca1c78166769f1cc5522b3a619c4db72ffab4facc585bc9edf8474d4d722cacd`。

```bash
OPENBLAS_NUM_THREADS=1 taskset -c "$CPU" python "$D/replay.py" "$OLD/vina" "$NEW/vina" "$WORK"
python "$D/observe.py" "$PARENT" "$OLD" "$BOOST" "$WORK" parent
python "$D/observe.py" "$FIXED" "$NEW" "$BOOST" "$WORK" fixed
python "$D/check.py" "$WORK"
```

outputs.tar.xz 中的 runs 含每次生产运行的 PDBQT 与计数日志；traces 中包括零事件的空文件。每三行对应一次异常首次曲率的局优。first 记录线程内调用编号、起始 FG 计数、初始能量、首次接受能量、步长、曲率和新梯度范数平方；next 记录下一方向导数、实际接受步长及最后试探能量（若方向检查即停止，该能量字段的 0 是初始化值）；finish 记录调用内实际 FG 和最终能量。用 runs 和 [摘要表](results/cells.csv) 可复核生产坐标哈希，逐份 traces 可复核首次共同事件。
