# 9GIO 的同配体、异晶型检验

在读取 9GIO 原子坐标前锁定此问题。RCSB 已确认 9GIO 具有 VH032 完整 CCD 组分 3JF、1.49 Å 单斜 C 1 2 1 晶型，并带另一 Cys77 共价配体。新结构的数据不参与此前拟合、盲搜或判定阈值。

保持 4W9H→5LLI 的已归档全部盲搜池、化学图和局优见证，按已有的口袋 Cα 清单将 9GIO 沉积实验配体变换到 5LLI 坐标系。单列配准覆盖、原子身份、占有率和备用构象。以有完整重原子的每份纯备用构象、全部保手性图对称映射为参照，报告实测复制间距离、新参照下首姿、池 Oracle 和见证 RMSD。在 9GIO 生物学装配外实测晶格最短距，和已知四方两晶格比较。打开历史查询 C 链与各替代拷贝的直接比较；没有在 9GIO 上再对接。新晶型和共价共配体同时改变，不能把全部结构变化归因于其中之一。
