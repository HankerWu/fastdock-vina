# VHL 晶格排斥的固定坐标检验

在计算邻居距离之前锁定如下设计。已知两份晶体中 C 链实验配体与邻近蛋白接触，也已知归档姿势的误差与干分。待检假设是某些盲搜首姿占据晶体邻居的空间，因此溶液用的生物学装配与晶体端点所允许的几何不同。同一受体内未触及邻居的错误姿势构成反例。协议不改变搜索和评分。

1. 使用 4W9H/VH032 与 5LLI/VH298 双向交叉的全部四臂 16 个池、完整键表的 8 个附加池，以及两枚种子在修复版下的晶体引导局优见证与盲首姿。于接收晶体 C 链坐标系原位计算；另一读数将同一配体用之前固定的共同口袋 Cα 配准回原查询晶体的 C 链。后者使用查询晶体，只是回顾性对照。每个晶体中再核对自身 C 链沉积配体在该环境下的接触。
2. 邻居为沉积晶格中所有蛋白重原子，含非零占有率的备用位形及聚合物修饰残基。排除当前 A/B/C 三聚体，在同一不对称单元的其他复合物和其他晶格像分别报告最短距离及最近原子。水、游离小分子、离子和未建模原子不参与。比较各姿势的连续最短重原子距离，同时统计既有晶格实验预设的 <2.3 Å 残留冲突。检验含有冲突的姿势按原顺序剔除后，原首、首个可保留的模式、全池最优、完全没有可保留模式的池及严重错误如何变化。全部返回模式一律保留在原始表中。
3. 十埃量级的错误姿势若仍不与晶格邻居冲突，可排除简单硬排斥对该错误的充分解释。若可实现的近晶体见证不与邻居冲突、原先胜出的错误姿势却冲突，说明晶格条件可以区分这两份固定坐标；是否在溶液有更高占比仍待独立检验。两个结构及四枚交叉条件只作配对描述；同一配体、种子和坐标的重复记录不作独立验证。不选阈值、不拟合晶格评分项、不把空池算作成功。
