# VHL 的错误姿势有多少与实测晶格相撞？

两份 VHL 晶体都能排除相当一部分已发布的盲搜姿势。接收晶体中有 69/91 个模式与邻近蛋白出现 <2.3 Å 的重原子接触。与此同时，原干分最值得解释的一次错排发生在两个均无此类接触的姿势之间。另一个方向甚至把真实实验配体原样转移过来，就会与接收晶体相撞。晶格排斥改变的是给定晶体环境下的几何可行性。[预定方案](PROTOCOL.md) · [原盲搜、化学图与见证](../README.md) · [历史晶格排斥模型](../../../../crystal_environment/README.md)

## 两个端点的区别可直接测量

对同一组配体重原子坐标 $x_i$，在给定晶格 $c$ 中定义

$$
d_c(x)=\min_{i\in L,\ j\in\mathrm{neighbours}(c)}\lVert x_i-y_{cj}\rVert,\qquad
\mathcal A_c(d_0)=\{x:d_c(x)\ge d_0\}.
$$

第二个最小化指标 $j$ 遍历 A/B/C 生物学三聚体以外的蛋白重原子，第一个指标 $i$ 遍历配体重原子。沿用既有研究的 $d_0=2.3$ Å，逐姿报告连续距离和对应原子。这个几何诊断对元素不作区别，忽略软排斥、静电、氢键吸引、水、热位移和晶格松弛。占有率大于零的备用坐标均计入；下述关键氮–氮接触的最近蛋白原子为单一位形、占有率 1。空间群均为 P 41 2 2。分别统计同一不对称单元内其他蛋白和非恒等晶格像，包含整数晶胞平移。原查询晶体列使用查询配体的实验体系作回顾性检验。[全部原子对数、最短距离、序号与对称操作](results/coordinates.csv)

| 查询坐标 | 对晶体的 RMSD，Å | 接收晶格最短距，Å | 原查询晶格最短距，Å |
|---|---:|---:|---:|
| VH032 晶体引导局优见证 | 0.761 | 3.102 | 2.778 |
| VH032 修复版首姿，27183 | 10.203 | 3.953 | 3.203 |
| VH032 修复版首姿，91439 | 11.128 | 0.318 | 0.235 |
| VH298 晶体引导局优见证 | 0.563 | 1.809 | 2.678 |
| VH298 修复版首姿，27183 | 10.671 | 2.601 | 2.400 |
| VH298 修复版首姿，91439 | 5.159 | 3.193 | 3.618 |

VH032 种子 27183 的完整化学图干分为 −6.965，优于近晶体见证的 −6.422。在这次真正错排中，错误姿势与晶格蛋白的距离甚至更大。VH032 种子 91439 的错误首姿与接收晶格有 43 对 <2.3 Å 的接触，最短的一对涉及一个晶格像的 Gln96；该池其余三个模式也全有冲突。VH298 两个粗差首姿均通过同一距离检验，近晶体见证反而在接收晶格中与 L 链 Arg182 胍基 NH2 的一个对称像相撞。

发现该反例后，追加了未局优见证与直接转移的实验坐标，以定位冲突的来源。VH298 原 5LLI 配体转移到结合 VH032 的 4W9H 后，末端腈氮与邻近 Arg182 NH2 相距 **1.990 Å**。几何拟合见证为 2.000 Å，局优后为 1.809 Å。原 5LLI 实验坐标在自身晶格相距 2.944 Å。两份晶格中对应操作与平移相同，均为 `x,-y,-z+1/2|0,1,0`。实验目标在定义的交叉 RMSD 下为零，已经落在接收晶格的排除域。即使任意移动配体其余原子，固定蛋白时，满足 2.3 Å 条件仍需该腈氮至少移动 0.310 Å（对应 37 重原子配体的 RMSD 下界约 0.051 Å）。该下界很小，无法用来解释全部数埃的误差。反向的 VH032 实验坐标在自身/接收晶格的对应最短距离为 3.306/3.638 Å。不同 R 团面对的是两个不同外部几何边界。原研究观察到 VH298 的腈基朝向溶剂；此处测到的晶格邻居不提供其在溶液中的占有率。[Frost 等原文图 1 与表 1](https://doi.org/10.1038/ncomms13312) · [四个实测拷贝的参照检验](../crystal_copies/README.md)

随后用另一项实验的 9GIO 检验 VH032。虽然 9GIO 采用单斜晶型，实测 VH032 距四方 4W9H 四个拷贝仅 0.153–0.195 Å。种子 91439 的错误首姿在该单斜晶格最近蛋白位于 6.110 Å 外，但对这一独立实测姿势仍错 11.123 Å。[同一化学组分、独立晶型与全部 VH032 候选](independent_form/README.md)

接收晶格下，有 38/91 个盲搜模式的最近距离甚至不足 1 Å。原来 11/16 个首姿超过 10 Å；筛后 5 个池无预测，剩下 11 个池中，超过 10 Å 的首姿从同一子集的 7 个变成 8 个。全体主池最接近参照的 3.319 Å 姿势来自 VH032 的双轨迹父版，其接收晶格只有一对 <2.3 Å 接触（2.170 Å）。剔除后该池首姿与 Oracle 均变成 10.203 Å；在原查询晶格，该姿势最近距离 2.673 Å，仍可保留。这 16 个池只有两个相关配体，不能由剔除数推断一般对接命中率。

模型未对晶格实施额外动力学或评分。量热及溶液占据所需的游离参考均未估计。原论文表 1 的同协议竞争荧光偏振测定中，VH032 与 VH298 的 $K_d$ 分别为 150 ± 30 与 80 ± 20 nM，中心值比 1.875，只有一个分子对，未达到历史三倍分离阈值。原文 ITC 给出 185 ± 6 与 90 ± 5 nM，前者引自其参考文献 30。本试验本身未产生新的亲和力或自由能预测。

## 复算与独立核验

在仓库根目录运行。输入使用上一级已有档案；第三个档案把完整键表的输出写到工作目录根部。Python 环境需要 NumPy、SciPy 和 Gemmi。

```bash
D=benchmarks/accepted_bfgs/curvature/transfer
W=$(mktemp -d)
tar xf "$D/evidence.tar.xz" -C "$W"
tar xf "$D/witness.tar.xz" -C "$W"
tar xf "$D/graph_control.tar.xz" -C "$W"
OPENBLAS_NUM_THREADS=1 python "$D/packing/measure.py" "$W" "$W/results"
OPENBLAS_NUM_THREADS=1 python "$D/packing/verify.py" "$W" "$W/results"
cmp "$D/packing/results/coordinates.csv" "$W/results/coordinates.csv"
cmp "$D/packing/results/pools.csv" "$W/results/pools.csv"
```

主程序显式生成与坐标包围盒相交的空间群操作和晶胞平移，以 KDTree 求距离。独立程序从原 PDB/PDBQT 重读重原子，通过 Gemmi 配准和周期邻居搜索构建局部原子云，再用全距离矩阵核验同不对称单元和其他晶格像的最小值及冲突对数。两条路径分别检查 288 个坐标/环境记录，576 个连续最小距离的最大绝对差为 3.91×10⁻¹⁴ Å，576 个原子对数全部一致；91 个主面板模式的 RMSD 与历史表一致。解包后单线程一次复算约 0.81 秒墙钟、0.80 秒 CPU；独立核验约 0.85 秒墙钟、0.83 秒 CPU。两者均包含解释器启动，未重复计算历史对接。[独立核验输出](results/verification.json)
