# 新靶点的双向交叉对接

在运行任何本轮 VHL 对接前固定。RBP4 在旧分支已有多轮实验。选取尚未在该分支签入对接评价的人 VHL 羟脯氨酸识别口袋。使用亚基 C 的 4W9H/3JF 与 5LLI/6Z3 两种独立沉积，两个查询各对接到另一种受体。两个分子同系列。本次属于预先指定的回顾性结构转移验证。

* 用受体自有共晶配体的重原子中心建立 24 Å 正方体。查询只使用 CCD 的中性手性 SMILES，ETKDGv3 固定种子 51127，单个构象，MMFF 优化。固定该配体准备几何；不从查询晶体初始化或取扭转角。保留受体 A/B/C 复合物的实验蛋白坐标，CAS 脱砷还原为 Cys；检查其以及其他链、未纳入组分与配体的距离。未解析环段不建模。若不满足完整配体图和结构可比性或有金属、非水共因子直接接触，报告排除。
* 参考姿势从查询的独立晶体经两结构共同口袋 Cα（两边离各自共晶配体≤12 Å，按链/残基号/残基身份匹配；至少 8 个）对齐到受体。评价时在受体坐标系对完整重原子图的全部保留立体化学的映射取最低 RMSD，不对配体叠合。两方向各用种子 27183、91439，单 CPU，一次轨迹 12000 次名义上限，最多九个输出，统一能窗 100。四臂为上游 Vina、原生 Pro 5015481、修复版，以及两条同上限轨迹的未修 Pro。对同一输入按同一种子配对，不因结果增减病例、变更评分或延长搜索。保留全部分数、坐标、时间、运行参数、逐模式数据、Top1/Best5/池最小和差值。只有两种交叉方向，不能推断总体性能或亲和力。
