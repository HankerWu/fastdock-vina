# VHL 的四份晶体姿势能否改变对交叉对接误差的判断？

历史 VHL 双向交叉对接使用查询晶体的 C301 配体评价。4W9H 与 5LLI 的非对称单元各含四个相同化学身份的配体，分别位于作者链 C、F、I、L。本次对全部四份坐标重新评价同一批 91 个输出，同时保留两个晶体引导的局优对照。再分别使用口袋和全链配准，检验误差的大小和配对变化方向是否依赖所选参照。此分析是在看过历史 C 链结果后设计的。[历史盲搜及引导构象](../README.md) · [4W9H 沉积](https://www.rcsb.org/structure/4W9H) · [5LLI 沉积](https://www.rcsb.org/structure/5LLI)

| 查询、接收结构 | 配准 | 六个晶体拷贝对的 RMSD 范围 / Å | 全部盲搜输出对任一拷贝的最低 RMSD / Å | 同一引导局优构象对四拷贝的 RMSD 范围 / Å |
|---|---|---:|---:|---:|
| VH032，4W9H → 5LLI | 55 个口袋 Cα | 0.088–0.205 | 3.319 | 0.692–0.761 |
| VH032，4W9H → 5LLI | 141 个全链 Cα | 0.137–0.295 | 3.389 | 0.718–0.784 |
| VH298，5LLI → 4W9H | 55 个口袋 Cα | 0.154–0.272 | 5.139 | 0.521–0.563 |
| VH298，5LLI → 4W9H | 141 个全链 Cα | 0.171–0.442 | 5.112 | 0.563–0.624 |

改变查询晶体拷贝和受体配准后，VH032 在种子 91439 的修复版首姿相对父版仍远离实验几何 2.675–2.699 Å。VH298 在种子 27183 的变化为 +0.091 至 +0.115 Å，其余两格均为零。小变化对这八个读法符号一致，但误差量级远小于盲搜池与晶体引导见证的几何差距。四拷贝及两种配准都作用于同样的预测，不能作为八个独立检验。单个拷贝的筛选、重排和再次对接均未发生。[每个姿势的八种读数](results/poses.csv) · [首姿配对差](results/paired_top1.csv)

**怎样获得同一坐标系。** 程序从两份原始 PDB 的共价键表和 CCD 立体化学模板重建八个配体，检查各份的 InChIKey、原子数、备用构象及占据率。VH032 与 VH298 的每份配体分别有 33 与 37 个完整重原子，沉积占据率均为 1。对每个查询拷贝独立确定至接收结构 C 链的刚体变换。主分析复用历史定义的 55 个共有口袋 Cα，敏感性分析取该查询四链与接收 C 链共有的全部 141 个 Cα。两种方法均只拟合蛋白，固定该变换后对配体的 12 或 24 个保留手性的化学图映射求最小 RMSD。独立重建历史 C 链口袋对照的全部 91 个值，最大绝对差为 7.11 × 10⁻¹⁵ Å。[配准与对应数](results/registrations.csv) · [所有晶体拷贝对](results/crystal_pairs.csv)

对同一受体坐标系，若 $d$ 是在同一立体化学图自同构群上最小化的 RMSD，则反三角不等式给出 $|d(x,r_1)-d(x,r_2)|\leq d(r_1,r_2)$。表中拷贝间最大距离也就给出了在对应配准下，替换这四份参照能为任一预测姿势引入的最大误差变化上界。即便使用最有利的观察拷贝，现有候选与晶体几何之间仍有较大差距。两份晶体数据由同一研究团队解析，各沉积的 REMARK 3 均报告 C/F/I/L 链的非晶体学对称约束。拷贝坐标共享衍射数据和精修模型；以上离散程度不能用作溶液平衡分布、独立结构重复的标准误或真实坐标误差界。是否因忽略晶格邻居而让错误候选得到较高的分数，是可另行检验的物理解释。[同一批坐标的晶格排斥检查](../packing/README.md)

**复算。** 从仓库根目录执行以下命令即可从父实验保存的输入、输出和见证坐标重建四个 CSV。Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、RDKit 2026.09.2，BLAS 单线程。一次完整复算用时 1.36 秒墙钟、1.36 秒 CPU，峰值常驻内存 96,968 KiB，包含依赖导入与读写。四份 CSV 两次生成逐字节一致。

```bash
D=benchmarks/accepted_bfgs/curvature/transfer/crystal_copies
W=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/replay.py" "$W"
diff -r "$W" "$D/results"
```
