## 结构与可比性

保留生物学三聚体 A/B/C，配体结合 VHL 链 C，最近的 Elongin 原子分别距配体 17.94、18.09 Å。两个 C301 配体重原子完整，最低占据率均为 1，分辨率分别为 2.10、2.40 Å。按 RCSB CCD 手性图，分别有 33、37 个重原子和 12、24 个合法原子对应。原始坐标取自之前下载的沉积文件。两方向共有 55 个离各自共晶配体 12 Å 内的口袋 Cα，叠合 RMSD 为 0.200 Å。参考姿势是在独立查询晶体上测得，再按该变换放入受体坐标系。[4W9H](https://www.rcsb.org/structure/4W9H) · [5LLI](https://www.rcsb.org/structure/5LLI) · [3JF 化学图](https://www.rcsb.org/ligand/3JF) · [6Z3 化学图](https://www.rcsb.org/ligand/6Z3)

**晶体堆积接触配体。** 来自另一晶体拷贝的 Arg182 分别在 3.31 和 2.94 Å 处，同一非对称单元中其他蛋白拷贝也近至 3.63 和 4.18 Å。评分只保留生物学三聚体，未包括这些晶格邻居或 2.81、2.76 Å 处的最近结晶水。两种受体的 C142 Val、C143 Asp 均只观察到 Cβ。初次完整重建 4W9H 侧链时 Meeko 将两个新建侧链误连成键，准备失败；改按两份沉积实际保留的重原子赋予丙氨酸模板。两残基均距配体超过 16 Å。CAS 脱砷还原为半胱氨酸，VHL 链该残基分别距配体 8.93、9.08 Å。没有补建未解析环。其余修复重原子的最近距离分别为 17.60 和 17.17 Å。由此产生的物理近似、晶格环境、低搜索上限和初始构象均可能影响相对晶体的误差。[原始沉积、元数据、输入和全部盲搜输出](evidence.tar.xz)

## 复现

在仓库根目录解包。已验证环境为 Python 3.12、RDKit 2025.09.3、Meeko 0.7.1、OpenMM 8.6.1、PDBFixer 1.12.0、Gemmi 0.7.4、NumPy 2.3.5 和 SciPy 1.17.0。

```sh
D=benchmarks/accepted_bfgs/curvature/transfer
W=$(mktemp -d)
tar -xf "$D/evidence.tar.xz" -C "$W"
OPENBLAS_NUM_THREADS=1 python "$D/evaluate.py" "$W"
for f in cells modes summary; do cmp "$W/$f.csv" "$D/results/$f.csv"; done
OPENBLAS_NUM_THREADS=1 python "$D/check.py" "$W"
```

重新准备和运行可执行

```sh
OPENMM_CPU_THREADS=1 OPENBLAS_NUM_THREADS=1 python "$D/prepare.py" "$W"
OPENBLAS_NUM_THREADS=1 python "$D/evaluate.py" "$W" \
  --official /path/to/vina_1.2.7 --parent /path/to/5015481/vina --fixed /path/to/fixed/vina
```

重制备两个受体和配体用时 10.84 墙钟秒、10.75 CPU 秒，峰值常驻内存 195,592 KiB；四份 PDBQT 逐字节复现，从头对接亦复现全部 16 份原始输出的 SHA-256。另一程序从原 PDB 用 Gemmi 重新提取口袋、SciPy 配准、Meeko 重建配体，用 RDKit 的固定坐标 RMSD 及手性图匹配独立核对 91 个姿势。最大差异为 0.000000873 Å，Meeko 以单精度读入 PDBQT 坐标。[独立复核](results/check.json)

## 事后诊断：当前几何能否表达接近晶体的姿势？

盲搜结束后，向单独程序提供查询晶体，经同一 55 个 Cα 映射到接收结构。允许平移、正规旋转和原 PDBQT 树中的扭转。对首个完整手性图映射，从直接二面角转移及零角度两个起点做最小二乘摆放；其中一次尝试达到了原有 200 次迭代上限。保留有限坐标，用所有等价对应重新评估最终几何。如此得到的是某个可实现构象给出的**误差上界**。加入独立计算的刚体片段下界后，当前表示可达的最小误差落在以下区间。区间两端用未序列化的坐标计算，在表中向外保留三位小数；紧随其后的实测 RMSD 为普通四舍五入。收紧约束后观察到更低的某次拟合值，也表明找到的姿势只提供上界。[按图对称性和刚体片段计算的下界](results/representation_bounds.csv) · [实际构象与相同零点的评分](results/witness.csv)

| 查询 | 仅刚体最佳 RMSD | 原扭转树的已证下界 ≤ 最优 ≤ 最好已知上界 | 锁定全部酰胺后的下界 ≤ 最优 ≤ 实现值 | 原扭转树所构造姿势 → 正式局优 |
|---|---:|---:|---:|---:|
| VH032，4W9H → 5LLI | 2.293 | 0.267–0.559 | 0.275–0.559 | 0.626 → 0.761 |
| VH298，5LLI → 4W9H | 1.589 | 0.294–0.506 | 0.493–0.894 | 0.505 → 0.563 |

原树包含一个可动的三级酰胺 C–N。把全部酰胺按准备态二面角冻结后，两个配体仍分别存在 0.558、0.893 Å 的构象。已锁定的二级酰胺保持输入角。VH298 初始三级酰胺 O–C–N–C 的一项二面角为 −100.3°，而晶体为 +178.1°。冻结意味着保留该初始扭曲，不能等同于纠正酰胺的平面化能量。未冻结时该二面角可到 −177.2°，但另一侧碳的二面角仍差约 52°。环内形状和局部角度在所有拟合中固定。检查全部保留的共价键长以及每条键角两端原子的距离，序列化前变化的最大值为 1.4×10⁻¹⁴ Å。[酰胺几何](results/amide.csv)

用正式局优器精修原扭转树构造的两个姿势，按 CCD 完整键表固定原子类型与共价拓扑，以相同的 `--unbound_energy 0` 对见证及盲搜首姿重评。父版与修复版分别从同一见证出发，返回相同的 RMSD 和分数。VH032 的近晶体局优分数为 −6.422，修复版两次盲搜首姿分别为 −6.965、−4.967。前者虽有 10.203 Å 的误差，却比近晶体见证更有利 0.543。VH298 的近晶体分数为 −7.405，比修复版两次首姿 −6.049、−6.490 都有利。因此这两个查询的近晶体姿势在几何上可表达，三个条件的分数也容许它胜过已发布首姿，但盲搜池没有保住这类姿势。只在所比较的见证与首姿之间作此判断，未确定它们各自的完整盆地积分。

VH032 的 PDBQT 默认推断图与完整化学图区别为零。VH298 的默认图漏掉环丙基 C34–C37 键，额外引入 30–37 和 32–37 两个内部可变原子对。完整化学图由 CCD SMILES 加氢后根据 PDBQT 的序号映射获得；保留的键数分别为 38、43。前面 16 次盲搜使用默认推断图，与实际原生 CLI 一致；上述局优及双方坐标的共同重评分使用完整图。二者的差异使 VH298 的数值归因还受三元环拓扑制约。保持相同坐标、改用默认图重评时，VH298 近晶体分数为 −7.231，修复版两个盲搜首姿为 −5.971、−6.411，这两组比较的强弱方向不变。该三元环漏边与[早先验证的遮挡判据](../../../cyclopropane_topology/README.md)一致。重新写入坐标时仅改坐标栏，键表、原子类型与初始化学图保持可审计。

额外复现运行如下。令 B 指向本次修复后的 `tools/build.py` 构建目录；Boost 安装处于自定义前缀时，应补上与构建时一致的 include、library 和运行时搜索路径。运行从盲搜压缩档中读取同一批输入及保存的首姿，无需重新盲搜。

```sh
c++ -O2 -std=c++17 -Isrc/lib benchmarks/receptor_linkage/aurora/probe_topology.cpp \
  $(find "$B/obj" -name '*.o' ! -name main.o) \
  -lboost_system -lboost_thread -lboost_serialization -lboost_filesystem -lboost_program_options \
  -pthread -o "$W/probe_topology"
OPENBLAS_NUM_THREADS=1 python "$D/witness.py" "$W" /path/to/5015481/vina "$B/vina" "$W/probe_topology"
cmp "$W/witness.csv" "$D/results/witness.csv"
cmp "$W/amide.csv" "$D/results/amide.csv"
python "$D/representation_bound.py" "$W" "$W/bounds.csv"
```

## 已知 VH298 化学图时的配对重跑

发现默认推断漏掉 VH298 环丙基的一条键后，追加了一个输入拓扑对照。保留主试验的输入坐标、候选容量、单轨迹 12,000 上限、两枚种子和两个 Pro 版本，只通过已有的 `--ligand_bonds` 传入同一配体从 CCD 化学图和准备序号映射得到的完整键表。这八次运行单列。VH032 的化学图与推断图相同，四次完整输出逐字节相同。

VH298 在修复版两个种子的首姿 RMSD 分别从 10.671 降至 4.161 Å、从 5.159 升至 8.825 Å。对应输出池 Oracle 从 6.035 降至 4.161 Å、从 5.159 升至 8.825 Å。父版使用相同完整图的首姿分别为 4.161、9.186 Å。图修正确实改变了候选生成或保留，即便恢复了正确共价键，两枚种子的发布池仍未包含前面证明可表达的亚埃姿势。[逐条件分布、哈希与计时](results/graph_control.csv) · [新坐标、原始日志与逐模式误差](graph_control.tar.xz) · [输入运动域的数学界限](REPRESENTATION.md)
