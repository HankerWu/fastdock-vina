# 整分子刚体覆盖与边长筛选的配对检验（事前登记）

起点为 2a261c9，代码与已有误差可见，以下门函数与全新种子输出在运行前冻结。问题是固定真实源态中，三边残差截断是否将配额重复分给相近的完整配体位置，以及改进覆盖能否传至最终发布。无需训练，无靶点、晶体、Ki、编号特例。晶体配体仅限离线评价，盒中心使用原协议已知结合口袋。

## 模型与运行规则

保留父实验整配体三点、腔点、所有非共线有序对应、同一正旋转三点拟合。X 为去质心的 N 行源重原子坐标，C=XᵀX/N。对行向量旋转 R、S 和全配体质心 t、u，均方位移 d²=||t-u||²+tr[(R-S)ᵀ C (R-S)]，Å²。与逐原子计算严格相同。一个端基对旋转距离的影响与其到旋转轴距离的平方成正比。它衡量冻结原子身份的位移；化学等价置换可使实际差异更小。不用共晶映射构建覆盖。指标不含亲和力或盆地概率。最远点选择在有限度量空间给出最大覆盖半径相对最优的二倍上界；稀有边缘、高排斥姿势可占配额。覆盖半径缩小不保证晶体盆地获益。重复坐标按不同对应保留身份。

五臂均对1024个候选用真实类型场粗排，取原生首个严格最小者，只给一个 hunt；后续二次局优、存档、合池及发布沿用父实验。edge 完全保留父实验按三边残差（Å²，四舍五入十位小数、原始有序对应 ID 解并列）取前1024及原顺序，允许越盒受墙势。其余四臂使用同一个新候选域：变换后所有重原子均位于给定闭合长方体内。不增加碰撞筛选。feasible_edge 在此域用原残差前1024，隔离盒的影响。coverage 首项为域内最小残差，之后最大化到已选集合的最近 d²，比较舍入到十位小数，平分取较小原始 ID；满1024即停，零距离也不重复同一 ID。uniform 在同域用 NumPy PCG64(本实例种子)均匀无放回取1024。uniform_work 完整执行同一覆盖计算后丢弃其选择，用同一 uniform 选项进真实下游，作为实测等额计算阴性对照。coverage、uniform、uniform_work 送入场前按原始 ID 升序，两个 edge 保留原边序。原生粗分完全相同时报告并列。源三点或腔点退化、域内不足1024均记录失败，不扩盒、不增种子、不用标签补位。对失败保留分母，条件汇总标明有效数。禁止以实验结果改预算、对称处理或几何权重。

## 预言与区分判据

历史16格保留原源态为诊断面板。整分子 A1120 A⁻、HA（93241）以及 5TBM→4GHI（93241）是三格可恢复对象；预言至少一格在覆盖库中恢复 ≤2 Å，记录每一格、原边长名次、新统一域是否仍有解。若零格恢复则此预言失败。其余门前无近姿的8格和 AT9283 的18个既有源态仅换门无法恢复；期望原边长已覆盖的5格有丢失风险，逐格报告得失。核心几何预言是同一可行域 coverage 比 feasible_edge 缩小最大最近距离，比较所有点的中位/P90/P95/最大最近距离、选中项的晶体 RMSD 和可行数量；在三臂相同1024、相同 hunt 下，检验相对 uniform 的连续误差和最终逐格差异。原则上可能改善最大距离但恶化接近盆地的密度、真实场排名或最终 Top-1。前述几何命题与端到端效果分别判定。历史 replay 与新预测单独列，当前研究没有把历史目标伪装为独立测试。

新姿势面板为 DYRK1A 3ANR→7AKL 及 7AKL→3ANR（各 96107、96131），A1120 的 3FMZ→1RBP 两微态（各96107）。前者两个晶体未用于选择本门函数，历史上仓库可能测试过；后者检验微态迁移。24 Å 接收体盒、CPU1、exhaustiveness=2、max_evals=25000、9 modes、energy_range=100。普通 Pro 和官方 Vina 1.2.7 均做25k与50k。额外按每个实例实测 coverage 全过程 CPU，以普通 Pro 100k、200k、400k（仍未夹住则继续倍增），结合25k/50k，以 CPU 比值对数绝对值最小的已测预算作对照，平分取小预算，实际墙钟独列。计时不读结构误差。配额与对照同一原生种子、输入与搜索选项。

FKBP12 用 Holt Table II 化合物4–11，两受体1FKG与1FKH，种子1047349，3轨迹，24k与48k Pro 和官方，9 modes，100 kcal/mol。五种筛选用同一 AD4 通道和既有制备。以16格普通 Pro 24k/48k 总 CPU 线性插值或外推至 coverage 总 CPU，所取额外预算向上取 24k 整倍数、下限24k；若两点不递增，按基线 CPU 正比换算。实测和报告最终比值。旧系列新随机源不能证明跨系列外推。七点值分别在两受体与等权上算 Spearman、Kendall τ-b，量程标签只参加满足三倍下界的方向比较（15对），8/10和9/11立体悬崖，大小、电荷、柔性偏差。分数从实际发布姿势重算。

## 核查和解释

逐分子及实例给受体框架化学对称 RMSD 分布、Best@K、真实发布池 Oracle 和 Regret，>5、>10 Å 与空池；检查图、重键和指定立体化学。保留候选与对应 ID、场排名、hunt、二次局优、入池及逐出、合池与原身份发布，后续重发现另列。记录场查询、局优计数及从制备完输入开始的全进程墙钟和 CPU。计时受同机任务调度影响。收集原始输出、哈希及失败；独立核对候选距离、发布坐标和原测定；不以多种子充当独立分子或独立家族。只有共同 Hamiltonian、互斥盆地、参考态、温度与化学势、标准体积、约束释放、两相独立起点与重叠和收敛俱备时才能给出自由能误差。本轮几何选择器保持普通 Pro 默认，任何替换默认的提议需另有迁移证据。
