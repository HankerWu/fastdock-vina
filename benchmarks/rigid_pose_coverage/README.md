# 用全配体位移覆盖腔点对应能否改善对接？

固定原生源态、腔点、1,024 个进入全配体场粗排的候选名额和唯一 hunt，最远点筛选改善了几何域最坏覆盖，在三个事前指定的漏例中找回一个近姿。对近晶体盆地的覆盖反而趋稀。在新姿势格和同测定排序上，没有证实采用此筛选相对于原边长或同预算均匀抽样的预测优势。

## 从位移覆盖到发布首位

16 个固定历史源态中，所有 221 个 ≤2 Å 有序对应都在盒内。给原边长法的 1,024 项施加盒内限制后，仍有 5 格覆盖近姿。换成最大化全配体最小位移的准则，最大覆盖半径格均值由 8.075 降至 3.257 Å，近姿却从 45 项降为 3 项，含近姿的格从 5 降至 3。A1120 A⁻（93241）得到一份 1.945 Å 候选，在原生全配体类型场排第 11；第 1 名为 13.210 Å。给第 1 名唯一搜索名额，发布首位为 15.479 Å；给第 11 名知情分叉，hunt 为 1.941 Å，二次局优为 2.170 Å，第 2 步逐出，最终首位为 2.356 Å。它既说明原边长门能丢掉可生成的近姿，也说明后续阶段各自有选择偏差。[完整旧库及实际分叉](audit/README.md)

六个新格为 DYRK1A 两分子双向交叉各两个新种子及 RBP4 同一个 A1120 的两种微态。受体系已在本仓库其他研究出现；晶体和测定均未用于当前门函数选参。三种分子、两个家族和一个酸碱配对决定了外推范围。比较从同一制备输入产生的实际发布池。最大化覆盖使这六格每一格的库最低 RMSD 都变差；6 格均值从边长的 1.835 到 2.461 Å。实际首位却相近。覆盖盲首选 6/6 进入轨迹容器、6/6 后来逐出、0/6 直接发布。首位比原生普通搜索好的实例不能全部归功于几何覆盖，其他同预算注入同样可以改写后续搜索。[逐候选及首位](pose/results/rank_stages.csv) · [逐步容器](pose/results/residency.csv)

## 碰撞能否在局部优化中修复

六格覆盖库有 6,080/6,144 个候选含小于 2 Å 的受体–配体重原子距离，边长和均匀库分别为 5,267 和 6,016 个。这是固定坐标的事后检查。历史覆盖库仅有的三个 ≤2 Å 近姿和新面板唯一一个近姿，都有如此短的接触。直接按此距离删掉所有碰撞，也会把四个近姿全部删掉。A1120 A⁻ 候选 7672 的最短接触在原生 hunt 中从 1.236 拉开至 2.497 Å，同时全配体误差从 1.945 到 1.941 Å；继续二次局优，间距增至 2.726 Å，误差升至 2.170 Å。同一模型的松弛在两个阶段给出了不同的结构后果。[两个面板全部分母](engine/results/steric_counts.csv) · [原三步坐标的独立检查](engine/results/steric_capture.csv)

## 亲和力和参考态

对 Holt 表 II 相同测定的八分子，覆盖法、原边长、均匀、官方和增加至 96k 的普通 Pro 各判对 10/15 个三倍方向；普通 Pro 24k 为 8/15。覆盖等权七点 ρ=0.357、τ-b=0.143。五个共同错对都涉及化合物 6（覆盖、原边长、盒内边长、官方 24k、Pro 96k）；化合物 6 在本面板没有可给出姿势误差的沉积结构。只有化合物 8、9 有参考坐标，四格覆盖首位和 Oracle 为 3.814/2.950 Å，均匀为 3.082/3.082 Å，普通 Pro 96k 为 3.307/1.870 Å。覆盖 16 格一遍实测 67.036/62.717 墙秒/CPU 秒；普通 Pro 24k 和 96k 分别为 25.587/22.702、58.314/58.169。已制备地图和受体为共同起点，未重复计入离线建图和制备；中断与复算成本单列。[测定、成本与截断记录](fkbp/README.md) · [逐对错在哪里](audit/results/pair_identity.csv)

覆盖改变了提议分布。相同配体源态的平移与转动不改变其内能或标准体积，也没有定义每个候选代表的统计权重。此处分子内部坐标在放置时冻结，原生搜索才允许 PDBQT 声明的扭转响应。受体、显式微态及受体图固定；水、离子、受体重组和游离配体分布均未进行一致采样。两张受体分数的算术平均是冻结的排序规则。现有结果支持识别几何和流程失配，不能分解水化、侧链或溶液参考各自的误差，也没有预测性自由能误差或不确定性。完整物理框架及历史反例见[结合系综推导](../../docs/BINDING_ENSEMBLE_AND_DOCKING.md)。
