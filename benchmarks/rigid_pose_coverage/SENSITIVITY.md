# 数值边界与成本补充检验

主方案六个新姿势格已运行。独立坐标重建在其中一格（3ANR、96107）发现，Horn 四元数和 SVD 对落在盒面上的少数对应作出不同的闭盒布尔判断。本追加检验在其反事实原生评分和发布结果可见之前登记。对所有出现差异的格（仅此一格），将生产 SVD 放置的质心和旋转保留到最后一位，仅用相同源坐标、另一路无反射 Horn 解替换 eligibility 布尔掩码。运行 feasible_edge、coverage、uniform。所有原生参数与主试验完全相同。核对两支持集差、库重叠、赢家原对应编号、选中姿势、hunt、发布池逐字节差异及对称 RMSD。此组回答浮点边界能否传至真实发布，单列于主要性能；不调容差、不用结果选数学实现。

四个 DYRK1A 格在主方案双轨迹中耗尽原生 global_steps，继续提高 max_evals 无法夹住 coverage 的实测 CPU。保留原始测值。对此四格，将 max_evals 置于已证实不再提前结束的 800000，每格以原种子做三轨迹，必要时依次增至四、五等直到 CPU 超过该格覆盖法，然后在原双轨迹饱和点与新增相邻测点中选择 CPU 比值对数绝对值最小者，平分选少轨迹。仅按时钟选择。原已夹住的两酸微态沿用原选择；列六格总成本、每格偏差及发布质量，改变轨迹数明确为扩大计算预算。若不可运行，报告失败和已达到的成本。
