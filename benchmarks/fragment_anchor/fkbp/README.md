# FKBP12 同测定的片段锚定检验

Holt 等的 Table II 报告重组人 FKBP12 在 10 °C、pH 7.8 的 PPIase 测定中的表观 Ki。化合物 4–11 按表中顺序为 186±24、110±20、12±5、250±30、10±1、7±2、300–600、300±40 nM。直接读取第 9927 页核对。七个点估计算秩相关；八分子按最近区间边界相距至少三倍，产生 15 个有向对。± 栏未并入三倍判定。每臂 1FKG、1FKH 各预测 8 个分子，两受体的发布首分等权平均，系数无热力学丰度解释。该系列有历史开发记录，本次预先固定了新种子和机制；8、9 号另有沉积坐标可评价姿势。[原论文](https://doi.org/10.1021/ja00075a008) · [表 II](https://electronicsandbooks.com/edt/manual/Magazine/J/Journal%20of%20the%20American%20Chemical%20Society%20US/1993%20%20%28vol%20115%29/22%20%20%2809879-10470%29/09925-09938.pdf#page=3) · [登记方案](../PROTOCOL.md)

每个 CLI 从带 Meeko SMILES/serial 标识的 PDBQT 与已制备的同一组 AD4 地图起算。侧车图由普通配体的 SMILES 和序号重建。八份配体的官方及 Pro 原生解析邻接、原子类型、电荷与转轴逐行复核，均与预测使用的输入一致。[图审核](../engine/ad4_graphs.json) · [实际原子与邻居](../engine/ad4_parsed.csv.gz)

七个臂为官方 Vina 1.2.7、当前 Pro、整分子三点、刚性片段三点、片段取向打乱、双预算 Pro、双预算官方。单线程、三条轨迹，每轨迹 24,000 或 48,000 次软上限。种子 1047293，最多 9 模式，分数窗 100 kcal/mol。三个提议臂使用同一次 MC 进程，在第一条轨迹第一次正常变异后将当时的所有重原子坐标、平移、四元数与扭角记录。父进程用原口袋、原腔点、选定三点、相同边长预筛和全配体形状查询，按原生重原子类型的 AD4 地图通道加总选择 1024 项中的唯一首项。正值限幅为 10 kcal/mol，越界罚按 10⁶ kcal/mol/Å 计算，保留第一并列首名。随后从 FIFO 将胜者的七个刚体分量交回正在等待的同一条轨迹，所有原有扭角与 RNG 状态保留。下游使用完整 AD4 评分并恢复常规搜索。

坐标与受体框架误差的单位为 Å，经验分为 kcal/mol；后者只作这个同测定的排序。受体、质子化及输入微态固定，扭角、平移和旋转继续搜索。没有游离相、显式水或质子交换、盆地权重、标准体积和收敛采样信息，无法估计物理 ΔG 或 ΔΔG 误差。本系列八分子形式电荷均为零，电荷效应不可辨识。

## 原始数据与复现

运行目录内可以找到每格的配置、CLI 日志、完整发布池与计时。在线组额外留存未经舍入的源态（.q、.source）、全库的原子索引和 1024 对旋转/质心、真实类型分/形状分、胜者和实际回传变换（.npz、.rank、.transform）、所选 ID 的第一/第二局优、offer 与原轨迹的逐出/终点、合并与发布（.stages、.history、.xyz、.pdbqt）。候选索引从 0 计，名次和 MC 步从 1 计。发布误差由 [check_panel.py](check_panel.py) 从 deposited PDB + CCD 重新建立局部 Cα 受体配准、保持化学和手性的对称映射后计算，全程没有拟合预测配体。未沉积的 6 个化合物保留其全部分数与发布坐标，姿势误差留空。独立以类型图、电势图、去溶剂化图及扭转项从每个已发布坐标重算 AD4 输出分。所有原始文件路径和 SHA-256 在 [raw/manifest.json](raw/manifest.json)。[原始输入校验和](results/inputs.json)

从仓库根目录执行。相应环境变量均指绝对路径，WORK 和 VERIFY 为不同的新目录。UPCOUNT 是 [原 1.2.7 计数构建](../../cavity_field_rank/fkbp/README.md)中的官方计数工具；每次官方计数必须与同一格发行版完整发布文件字节一致。PRO 是未加观察器的普通 Pro。输出成本从准备好的地图和配体起算，制备和 AutoGrid 离线建图在七臂均排除。每次在线运行均计独立启动 Python、地图读取、库生成、场筛选、下游、轨迹记录、原始数据写出与进程退出。官方计数重放、普通 Pro 重放和事后复计另列。

```bash
D=$PWD/benchmarks/fragment_anchor/fkbp
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
sh "$D/build.sh" "$BUILD" --boost-prefix "$BOOST_PREFIX" --jobs 1
python "$D/assay_runner.py" prepare "$WORK"

python "$D/pro_replay.py" "$WORK" "$PRO"

python "$D/reproduce.py" "$WORK" "$FRESH" "$BUILD/bin/vina" "$VERIFY/fresh_replay.csv"
```

只复计原始结果可以使用下列命令。核对发布身份时先用未舍入的二次局优构象与原轨迹终点、实际合池按坐标逐分量完全相等判断，再用 PDBQT 的 0.001 Å 输出精度核验写出。逐出后后来接受的 ≤2 Å 候选另列，原注入身份不会继承。

```bash
python "$D/assay_runner.py" prepare "$WORK"
python "$D/package.py" unpack "$WORK" "$D/raw"
python "$D/check_panel.py" "$WORK" "$VERIFY"
cmp "$VERIFY/assay.csv" "$D/results/assay.csv"
cmp "$VERIFY/stages.csv" "$D/results/stages.csv"
```
