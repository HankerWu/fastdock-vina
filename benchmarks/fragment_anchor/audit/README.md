把三个源锚点直接配准到**化学映射对应的晶体锚点**，可单独观察其余原子的偏离。这项使用答案的诊断给出一种指定变换的全分子误差；三点来自离散腔点时可能刚好更接近整分子最优变换。三格主检验 A⁻、HA、4GHI 的整分子锚点分别得到 2.029、1.356、2.099 Å，片段锚点为 2.560、3.033、3.490 Å。片段内的三点很刚，远端仍能因源扭角和旋转杠杆而偏移。不能用片段局部拟合好坏直接判断整个分子的刚体误差。对 AT9283 18 个旧源态，穷尽对应两种方法均为 0/18 到 2 Å。全对应的逐态最小误差中位数为 2.957/2.991 Å，门后中位数为 3.547/3.929 Å；片段最接近的一格在门前达 2.049 Å。[16 格逐态数据](results/gates_pose.csv) · [18 个旧源态](results/gates_at9283.csv)

每个对应的表内排序先用三边残差，输入顺序解并列。两个 NPZ 以 case_arm 为键，按边长排序保存全部连续误差（float32 Å，汇总用双精度）；由冻结的受体、口袋盒、源态、三点和匹配规则可以重建每个有序三角的身份。复核程序从 PDB/CCD 重新建立晶体图、等价映射和接收体配准；A⁻ 的两个共振氧可交换，HA 的羰基和羟基保留身份。代码通过独立的逐块 SVD 恢复全对应，逐项检查当次真实保留库。旧十格的整分子最低误差和理想刚体界限复现，AT9283 旧源态门前门后 36 个历史端点复现。另以独立的四元数解和 PDBQT 刚体树验证实际库。[逐对应姿势误差](results/pose_edges.npz) · [AT9283 逐对应误差](results/at9283_edges.npz) · [独立库复算](../engine/bank_reconstruction.csv)

## 已丢失的对应与保留库之间的间距

额外的事后诊断将被删去的每个 ≤2 Å 变换与 1,024 个保留变换比较。设源配体去中心后坐标矩阵为 X，含 N 个重原子。两种放置使用行向量旋转 R、S 与全配体质心 t、u。按相同源原子身份的均方位移为

$$
 d^2=\lVert t-u\rVert^2+\mathrm{tr}\left[(R-S)^\mathsf{T}(X^\mathsf{T}X/N)(R-S)\right].
$$

这个距离只需要源构象和两次变换，选出“已丢近姿”本身使用了晶体。得到的最近保留候选与丢失近姿仍可相距 1.330–2.914 Å（六个门前有、门后无近姿的库，以各库两个集合之间的最小值计）。若在同一库的 M 个对应中无放回均匀取 1024 个，且全部对应中有 k 个近姿，至少一次命中概率是 1−C(M−k,1024)/C(M,1024)。A1120 两个整分子库各有两份可行对应，概率各 6.77%；5TBM–93241 只有一份，概率 3.44%。这是有标签的稀疏程度和空间覆盖诊断。[逐库计算](results/omitted.csv)

## 独立复现

从仓库根目录运行。P 为解开 pose/archives 全部档案后的目录，F 为按 fkbp/README.md 解包得到的工作目录，W 和 OUT 为新的绝对路径。BIN 为按 engine/README.md 构建的 Vina 原生观察程序。首次计算与 FKBP 原表重算均在单线程 BLAS 运行。

~~~bash
D=$PWD/benchmarks/fragment_anchor
mkdir -p "$W" "$OUT"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python "$D/audit/edge_audit.py" at9283 "$W/aurora" "$OUT"
python "$D/audit/edge_audit.py" pose "$W/frames" "$OUT" --pose "$P"
python "$D/audit/omitted.py" "$P" "$OUT"
python "$D/audit/forks.py" "$P" "$W/forks" "$BIN" "$OUT"
python "$D/audit/endpoints.py" pose "$P" "$OUT" --pose-results "$D/pose/results" --frames "$W/independent"
python "$D/audit/endpoints.py" assay "$F" "$OUT"
~~~

112 份实际姿势池共 956 个模式、49,152 个保留候选和 11,866 份阶段快照。独立路径用原始坐标重算候选、各级状态及全部发布误差，与主分析最大差 1.34×10⁻¹⁴ Å。两路径共用已确认的 PDB/CCD 化学身份；相同坐标从不同解析和刚体计算路径互核，不构成独立生物重复。Holt Table II，第 9927 页，对应化合物 4–11 的表观 Ki 为 186、110、12、250、10、7、300–600、300 nM。[结构核对](results/pose_recount.json) · [测定原文](https://doi.org/10.1021/ja00075a008) · [测定重算](results/assay.csv)
