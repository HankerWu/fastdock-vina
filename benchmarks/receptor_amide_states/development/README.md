## 剩余错误能否通过改变翻转先验修复

设一个池中首姿为 1，竞争姿势为 j，某个位点 i 在两种姿势上的“翻转减沉积”相互作用分差为 d_ij 和 d_i1。取任意相同的受体状态先验，包括位点之间任意相关，在比较两个姿势时，有效能差的指数是各状态能差指数的加权平均。因此报告分数差有保守下界

```
(native_j - native_1) + scale * sum_i min(0, d_ij - d_i1)。
```

该式覆盖可同时实现与不能同时实现的各位点最有利选择。若所有竞争者的下界均高于 0.001（考虑原始 Vina 打印精度），则在该解析势、相同候选池和相同受体先验下，任何这类积分都无法修改首姿。这个结论不依赖选用的温度或对位点独立性的假设。它只约束两种端点身份分配和当前重原子坐标可表达的相互作用。

80 个池中有 79 个满足该判据。唯一不能排除换首姿的是 2XJJ 对 2XJG，3000 档、种子 43103，仅有一个竞争者的下界为 −0.02852。即使它能胜出，RMSD 也只可能从 3.11152 变到 3.10220 Å。所有候选中至少有一个更准确姿势的 31 个池里，30 个因此无法通过改变酰胺取向先验挽回。按 80 池均值计算，这一整类模型在既定候选和势函数上的最大可能改善约为 0.00012 Å。实际计算相邻酰胺的精确耦合后，701 个姿势的最大报告分数变化为 0.000033，全部池的完整排序一致。[各竞争者的分差界限](joint_poses.csv) · [逐池判定](joint_cells.csv)

## 固定坐标干预

对四个诊断样本，在各自真实 PDBQT 受体中只交换一个酰胺末端 N/O 的位置，并将两枚 N–H 随 N 重新定向。用本轮真实父版 fab52f7 的 `--score_only --pose_coordinates` 分别计算固定配体的分子间能。3TUH 的 Asn106 预测翻转代价 +0.55741，原生两次评分之差 +0.55897。6I62 的 Gln426 预测 −0.53979，原生 −0.53865。另两个样本覆盖 +0.523、+0.005；四例最大绝对差为 0.00156。解析式与原生距离查表的小幅差异仍列在原始结果中。[原始分项](fixed_native.csv)

```bash
B=benchmarks/receptor_amide_states
W=$(mktemp -d)
tar -xJf benchmarks/ligand_hydroxyl/transfer/inputs.tar.xz -C "$W"
tar -xJf benchmarks/ligand_hydroxyl/transfer/pools.tar.xz -C "$W"
python "$B/evaluate.py" "$W" "$W/result"
python "$B/sensitivity.py" "$W" "$W/result"
python "$B/check.py" "$W" "$PRO" "$W/result/fixed_native.csv"
```
