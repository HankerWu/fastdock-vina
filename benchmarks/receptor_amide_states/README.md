# Asn/Gln 末端氧、氮取向能解释哪些对接误差？

人 HSP90α 的冻结候选池中有近晶体姿势落在错误首姿后。一个可检验的原因是受体把 Asn/Gln 侧链末端的氧、氮指认固定下来，改变了口袋的供受氢关系。两态模型改变了候选的分数，在 80 个开发池、46 个迁移池和 12 个新 ATAD2 池中，首位候选全部与原生分数相同。这里的 138 个池有相关种子、重复受体和重复配体。研究代码保留在本目录，生产路径采用原有排序。[机制与数据冻结](PROTOCOL.md) · [亲和力、精确两态耦合与中子结构协议](VALIDATION.md)

## 两个状态怎样进入打分

在同一组重原子位置，状态 0 沿用沉积的羰基 O、酰胺 N，状态 1 交换这两个位点的相互作用类型。令 h_i 为无配体时单独交换一次的受体局部能差，d_i(x) 为在配体姿势 x 上交换身份引起的配体–受体能差。用 Vina 的两个高斯势、排斥及径向氢键函数估计这两个量。不同位点 i、j 之间，计算两对末端重原子相互作用的四个状态值，取混合差 J_ij = U11 − U10 − U01 + U00。它只修正同时翻转时单体场漏掉的部分，保留其他受体原子为固定背景。

对于二元向量 s，令 E₀(s) = Σ h_i s_i + Σ J_ij s_i s_j。Z₀ 是 exp[−E₀(s)/(RT)] 在全部 s 上的和，Zₓ 的能量另外加上 Σ d_i(x)s_i。原生分数增加 F·RT·(ln Z₀ − ln Zₓ)，其中 F 沿用原配体的 Vina 扭转归一化。温度固定在 298.15 K。独立主模型取 J=0，精确耦合对照保留所有非零 J，按连通分量在对数域做二元变量消元。远离配体的分量在两个配分和中相消。计算代价随消元时同时出现的位点数指数增长，五份亲和力受体的消元宽度为 1–2。全翻转、逐姿势选低能态、均匀先验另有单独对照。[单体场与姿势评分](model.py) · [精确耦合](coupled.py) · [直接枚举与状态重标记测试](test_coupled.py)

两端位置、其余受体重原子和非酰胺自由度固定。溶剂化、翻转时的键角调整、显式氢排斥、不同 pH 的化学势以及真实游离态构象系综均未建模。公式给出经验两态评分修正。物理依据和原始 Vina 势见 [Word 等的酰胺方向研究](https://doi.org/10.1006/jmbi.1998.2401)及 [Trott 与 Olson](https://doi.org/10.1002/jcc.21334)。

## 中子结构中的局部取向

从四份沉积结构去掉所有实验 H、D、水、配体和离子。保留观察到的蛋白重原子，用 Meeko 重新构建 H。76 条 Asn/Gln 位点记录中，43 条满足预定的完整末端和两个 N–D 位点均具有至少 0.5 的 D 占有率。所有输入的原始和准备后蛋白重原子数相同，重原子坐标一致；两份结构的 C 端羧酸盐存在等价 O/OXT 名称互换。模型的先验与沉积 N/O 指认相符的记录为 35/43。

|3TMJ，人 CA II|5 / 21|4|0.699 / 0.695|
|4G0C，人 CA II，原结构有乙酰唑胺|4 / 21|3|0.705 / 0.697|
|2R24，人醛糖还原酶|28 / 28|22|0.678 / 0.675|

醛糖还原酶的 Gln59 是明显反例，两个 D 支持沉积 N 的位置，独立先验却只给该指认 0.319 的概率。相反，两个 CA II 的 Asn230 均在 0.5 附近。表中数值是模型按经验能量给出的相对权重。只有三个不同蛋白，重复 CA II 和同一蛋白内的残基均有关联。参考来自沉积精修模型，本轮未逐位点重精修中子衍射数据。局部先验识别部分供受体环境的能力，与能否改变整个配体的首位是两项不同检验。[逐残基预测及排除](neutron/results/sites.csv) · [输入校验和与几何复核](neutron/results/summary.csv) · [3TMJ](https://www.rcsb.org/structure/3TMJ) · [4G0C](https://www.rcsb.org/structure/4G0C) · [2R24](https://www.rcsb.org/structure/2R24) · [5CE4](https://www.rcsb.org/structure/5CE4)
