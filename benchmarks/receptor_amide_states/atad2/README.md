# 人 ATAD2 溴结构域的独立姿势实验

5A82 的 YEJ 与 6YB4 的 OJH 提供两种不同的局部化学环境。5A82 共晶中，YEJ 重原子到 Asn1064 侧链 O、N 的最近距离为 2.84、2.73 Å。按实测重原子坐标固定配体，把这一个酰胺翻转后，预测配体相互作用升高 1.581 原始分值。6YB4 的 OJH 到这两个端点分别相距 3.99、3.34 Å，翻转代价只有 0.159。每个配体的四种合法原子映射给出相同结果。该诊断只在预测完成后计算。[5A82 实验沉积](https://www.rcsb.org/structure/5A82) · [6YB4 实验沉积](https://www.rcsb.org/structure/6YB4) · [实测坐标的能量对照](results/crystal_sites.csv)

从 CCD 图生成配体，从两个各自受体及共用 5A82 受体形成三种不同的配对，两个种子与两档预算。两种程序合计 24 次端到端对接都成功，各得到 108 个候选。每组候选的 RMSD 另用 PDB 实验重原子和 Meeko SMILES 映射独立核对，216 个连续误差最大分歧为 5.33×10⁻¹⁵ Å。Pro 源码为 fab52f7；官方参照是 AutoDock Vina 1.2.7。两种程序均调用单线程 CPU。原始搜索计数、实际参数、墙钟、进程 CPU 和峰值内存随每次运行保存。[预设条件](PROTOCOL.md) · [命令与计时](results/cost.csv) · [二进制版本和哈希](results/binaries.json)

12 个池只有 5A82 自对接的 12000 档、种子 43117 生成了小于 2 Å 的候选，首姿为 1.555 Å。其他 11 个池的最佳结果仍在 4.228–9.129 Å。Asn1064 在 108 个 Pro 候选中有 107 个进入 8 Å 势函数截断半径，翻转的配体相互作用差为 −0.406 到 +1.157。分数可变，两个积分模型都保留了 12 个原生首姿。Pro 与官方首姿的唯一差异出现在 6YB4 对 5A82、12000 档、种子 43103，分别为 9.676 和 5.761 Å，两者池内均有 5.406 Å 的姿势。按完整 PDBQT 原子记录的哈希逐姿势匹配，这一对 9 模式池只有 5 个输出姿势逐字相同。官方首姿仍是 Pro 第二名；Pro 的新首姿未出现在官方保留池。新首姿的分子间加分子内能为 −9.144，原首姿为 −8.883，前者在经验目标中更有利。两份输出以各自首姿的分子内能为参考，分别为 −0.685 和 +0.143，直接跨文件比较同一姿势的报告分数会包含参考偏移。轨迹更早何时分叉未作记录。[逐姿势](results/poses.csv) · [逐池](results/cells.csv) · [位点分解](results/sites.csv)

受体制备耗时各 2.24、2.09 秒，配体制备各 0.173、0.135 秒。Pro 与官方每次对接的中位墙钟为 0.236、1.272 秒。5A82 和 6YB4 的分辨率分别为 1.86、1.85 Å，配体的原子占据率均为 1.0。5A82 补齐的最近蛋白原子距配体约 40.96 Å，6YB4 无需补受体重原子。刚性干受体省略的最近结晶水仅距配体 2.63、2.71 Å；5A82 中另一个乙二醇距配体 3.61 Å。配体来自 CCD 所给中性结构，未确定 5A82 胺基的溶液质子化分布。此实验无法在采样、微态与缺失的局部环境之间分配误差，也没有定量自由能依据。6YB4 的唯一作者链名为 AAA，脚本把这条链一对一改名为 A，以便写入 PDB 的单字符链字段。原始 mmCIF 和转换后文件同时归档。

```bash
B=benchmarks/receptor_amide_states/atad2
W=$(mktemp -d)
tar -xJf "$B/inputs.tar.xz" -C "$W"
tar -xJf "$B/pools.tar.xz" -C "$W"
python "$B/run_atad2.py" check "$W"
python "$B/run_atad2.py" score "$W" --report "$W/report"
```

从原始结构重建时，在一个新建的工作目录运行 `prepare` 和 `dock`。

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 OPENMM_CPU_THREADS=1
python "$B/run_atad2.py" prepare "$W"
python "$B/run_atad2.py" dock "$W" --pro "$PRO" --upstream "$UPSTREAM"
```
