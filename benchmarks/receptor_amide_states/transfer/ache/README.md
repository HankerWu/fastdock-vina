# AChE 的同坐标质子化反事实

迁移实验的 AChE 结构 4EY6 / 4EY7 分别含加兰他敏和多奈哌齐。两个沉积文件都报告 pH 7.0；CCD 化学图生成的配体都用了电中性的三级胺。FDA 审评记录给出的水溶液 pKa 分别为 8.2 和 8.9。按单一游离碱的 Henderson–Hasselbalch 平衡，这两个数分别对应约 94% 和 99% 的质子化比例。晶体中的局部电场及环境可能改变 pKa，本次对照无法确定结合态的实际质子化概率。[加兰他敏审评](https://www.accessdata.fda.gov/drugsatfda_docs/nda/2001/21-224_REMINYL_biopharmr.pdf) · [多奈哌齐审评](https://www.accessdata.fda.gov/drugsatfda_docs/nda/97/020690Orig1s000rev.pdf) · [4EY6 / 4EY7 原始研究](https://doi.org/10.1021/jm300871x)

假设是给唯一的三级胺添加质子会改变接触能及候选生成，从而影响首姿。加质子位置由化学图决定。预先指定比较已有的中性态与单质子化态，均以各自原生评分选首姿。每个配体有两个受体，每个受体有两枚种子。首批使用迁移实验的 71993 和 72019；看到这批数据后，将模型、预算及对照固定，再用仓库已有的 43103 和 43117 检查种子敏感性。两批共享化合物和受体，不能支持跨系列推广。[实验约定](PROTOCOL.md)

每批均有 6/8 对改善，也各有 2 对退化。首批多奈哌齐的首姿均值从 11.414 降至 4.847 Å，加兰他敏从 7.295 升至 9.154 Å，其中一例交叉对接从 4.43 变为 14.13 Å。复测时，多奈哌齐的均值从 8.558 降至 7.770 Å，加兰他敏从 5.376 升至 5.773 Å。较大正效应没有在另一对种子上等幅重现。表中分位数采用第 2 型样本分位数。P90/P95 各批实际由最大的一个误差决定；独立化合物只有两个。

**固定坐标对照。** 两个微态使用完全相同的输入重原子位置、化学手性和每个扭转轴的重原子子树；每个分子的重原子 AD 类型只有三级胺的 NA → N 一处改变，阳离子新增一个 HD。用相同盲对接预算分别生成候选，再把每个姿势的物理原子、闭环标记、原有供体氢坐标按化学映射投影到两个冻结输入拓扑；从中性改为阳离子时，将新增 HD 放置在三级胺三个键方向的对面。默认 Vina 用氢决定供受体类型，未显式模拟库仑电荷相互作用。记录引擎在每个坐标处计算的能量分量。固定一种微态、同一配体和受体时，以分子间能量加配体内能排序，所有候选共用同一参考零点和扭转缩放，避免跨搜索运行套用各自首姿的游离态参考。

首批 59 个、复测 66 个输出姿势，共执行 250 次定坐标评分。在每个种子–配体–受体组合内，两种评分对中性来源池、阳离子来源池及其合并池的首选均一致。合并池的原生中性/阳离子评分首姿均值在首批均为 6.246 Å，复测均为 6.467 Å。这个对照用两份搜索预算，只用于比较相同坐标的打分决策。固定坐标下的能量变化确实非零，125 个姿势的原始分子间加分子内能差覆盖约 −0.741 至 +0.577 个 Vina 打分单位。已观察到的差异来自改变搜索时的物理表述后返回了不同候选，仍无法把差异归因到某一次提议、局部优化或归档操作。首批中性/阳离子每次对接的平均墙钟时间分别为 0.245 / 0.254 s，复测为 0.231 / 0.228 s。逐次实际评估次数见两批的 cells 表。

**构象质量。** 对所有 125 个姿势重新检查了原化学图上指定的手性中心，均与输入一致。重闭的加兰他敏 C–C 键在晶体中为 1.523 Å。首批预测为 1.462–1.587 Å；复测中性 4EY6→4EY6、种子 43117 的次选姿势达到 1.869 Å，虽然该姿势几何 RMSD 为 4.545 Å，闭环键已经严重伸长。该姿势仍在结果表里。配体–受体间近接触统计也随每个姿势提供。

**复现。** 两个输出目录分别保留逐次运行、所有模式、固定池的两种选择结果和初始结构投影审查。原始中性首批坐标在上级面板 `transfer_evidence.tar.xz`；阳离子输入/输出及中性复测的原始 PDBQT 见 `charged_and_replication.tar.xz`。使用上级 README 对应的 `fab52f7` 分支基线二进制。通过不同工作目录再次生成候选并计算 250 次定坐标评分，核对得到相同的 125 个 RMSD、250 组定坐标能量及所有首选判定，耗时独立记录。

~~~bash
D=benchmarks/receptor_amide_states/transfer
python "$D/run.py" restore /tmp/ache-input
OPENBLAS_NUM_THREADS=1 python "$D/ache/run.py" /tmp/ache-input/novel /tmp/ache-first --binary "$VINA" --output /tmp/ache-first/results
OPENBLAS_NUM_THREADS=1 python "$D/ache/run.py" /tmp/ache-input/novel /tmp/ache-repeat --replication --binary "$VINA" --output /tmp/ache-repeat/results
python "$D/ache/summarize.py" --first /tmp/ache-first/results --repeat /tmp/ache-repeat/results --output /tmp/ache-comparison.csv
~~~
