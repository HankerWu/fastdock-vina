# GAA 搜索预算与官方引擎对照

这项诊断在看到 GAA 的 2×2 搜索与重排结果后确定。保留 5NN5 和 5NN6 的两种查询、两个受体、原三枚种子、输入微态、24 Å 盒、四条单核轨迹、请求九个模式和同一能窗。对每个组合分别运行原生 Pro 每轨迹 48,000 次上限，以及未改动的官方 Vina 1.2.7 每轨迹 12,000 / 24,000 次上限。Pro 未启用 CH–π 场并保留 late、40 个精修候选和计数器；官方二进制省略这些专属参数。十二个条件构成配对单位，同一受体–查询上的三种子是重复测量。按固定实验受体对齐、对称性校正的重原子 RMSD 分析首姿、前五最佳和输出池最优。记录墙钟、CPU、峰值 RSS、实际输出数、能量与坐标；只有 Pro 提供细分求值次数。预算倍率预先固定，不依据此次对照结果调参或重选实验。进程并行会污染墙钟，全部对照顺序执行。
