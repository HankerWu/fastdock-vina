每个设置产出 12 × 9 = 108 个姿势，表中排序损失等于首姿与本次**输出池**最佳的 RMSD 差。方法共同使用实验位点定义的盒中心，每次四条单线程轨迹。官方版本缺少 Pro 的 late 选择、40 个候选精修和计数器选项；其余可共享的输入与请求输出相同。不同程序的名义上限不代表相同的实际求值数。运行耗时是该机器的单次串行测量，联合实验另有每批 0.020 与 0.026 秒的池分析时间。表中未计受体/配体初始制备和研究势的 Python 输入侧准备。CPU 时间指对接子进程，各臂的完整 RSS 与可用的求值数见附表。[运行命令、完整计时及输出哈希](results/costs.csv) · [分布与各分位数](results/summary.csv)

原生 Pro 48k 合计 2,305,143 次搜索阶段求值和 16,586 次显式精修求值，CH–π 24k 为 1,153,063 和 14,442。相对这个成本更高的原生对照，联合 24k 的平均首姿误差减少 4.017 Å，其中输出池最佳误差减少 2.684 Å，排序损失减少 1.333 Å。唯一首姿退化的是 5NN6 在自身受体、种子 43133 时，池最佳误差改善了 1.133 Å，排序损失却增加了 3.336 Å，最终首姿退化 2.203 Å。对同预算的官方 Vina，联合 24k 的 10/12 个条件改善，平均首姿误差减少 3.936 Å。GAA 的这批证据支持搜索中加入该相互作用会改变可输出的候选，并且原生扩大预算没有挽回结果。是否需要再叠加末端重排，仍须对照原四臂，不能由仅有两臂的预算实验判定。[逐病例配对差](results/paired_differences.csv) · [逐姿势评分和误差](results/modes.csv)

## 复算

运行程序的版本与哈希见 [binaries.json](results/binaries.json)。48k 原生臂使用实验二进制、关闭研究势；另一个未打补丁的分支 Pro 程序重跑后，12 个完整 PDBQT 字节均与之相同。官方程序与 GBA1 所用 1.2.7 发布文件哈希一致。核对参考坐标采用原始沉积配体的位置、配体原子映射和口袋 Cα 对齐，详见 [verify.py](../verify.py)。[原生独立回放](results/native_parity.json) · [全部 36 份原始姿势与日志](results/outputs.tar.xz)

仓库根目录下执行以下命令。GAA 指向原实验的准备目录（含 metadata.json、两份准备态与 raw/ 晶体文件）；GAA_RESULTS 指向同一 Pro 二进制的四臂结果目录；WORK 是新的本地输出目录。省略 --binaries 时，可在解出或复制存档的 results 目录后仅重算统计。

~~~sh
D=benchmarks/ch_pi_search/control
python "$D/benchmark.py" "$GAA" "$GAA_RESULTS" "$WORK" --binaries "$VINA_PRO_RESEARCH" "$VINA_OFFICIAL_127" --verify-native "$VINA_PRO_RELEASE"
~~~
