# CH–π 在对接的哪个阶段起作用？

起点 1c48466。既有 GBA1 的冻结池重排在原生每轨迹 12000 和 24000 次求值两档呈相反方向。现在检验：若相同 CH–π 吸引在第一次随机搜索和局部网格优化时就存在，它能否改善返回池的全配体最小 RMSD，继而使最终重排在两档上均受益？不改变原生显式精修与返回候选筛选，最多九个模式。因素为原生/增加 CH–π 搜索网格、输出池内原生/原论文 CH–π 重排。组合臂每个阶段均仅加一次。实验使用非芳香的糖或亚氨基糖，只有配体饱和 CH 到蛋白芳香碳的方向可能有贡献。使用上轮冻结的原论文核、权重、原子类型与转子分母。格点采用有截断的原函数，格内能量与梯度来自同一个三线性插值。晶体配体用于终点评价，搜索只使用已知口袋中心。

GBA1：完整三种质子化配体×三受体×三既有种子，分别在 12000、24000 两档运行。跨家族迁移：GCK 与 GLUT3 两个蛋白的既有四个葡萄糖病例、两枚种子、3000/12000 两档，保持其原候选与搜索设置。上述旧体系已有其他方法的结果，新搜索公式尚未在其上评价。三种蛋白分开报告。输出每格四臂首姿、前五、返回池最低 RMSD、后悔值、实际候选数、求值数及时间，报告四臂差分与组合对单项的差；在 GBA1 按查询配体整块重采样，区间仅描述这三个化合物。用已知分项和历史原生池校验，无参数调优。若增加新势的收益依赖预算、单一配体或只改善平均排序损失，不作为默认搜索势。
