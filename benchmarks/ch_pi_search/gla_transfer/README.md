# 人 α-半乳糖苷酶 A 的 CH–π 迁移实验

在同一配体 DGJ、两个野生型人 α-半乳糖苷酶 A（GLA）受体、三个固定种子上，搜索阶段引入历史 CH–π 场，六格的平均首姿误差由 9.464 降为 6.169 Å。场搜索的六个池均采用原干分首位，在这些池上再加 CH–π 重排没有换首。改善主要来自被返回的候选发生变化。两个搜索各产生 54 个姿势，全部 108 个姿势中最小误差仍为 2.621 Å。

## 实验结构与手性

3GXT 的标题和原论文把实验配体写成 DGJ，但链 A 坐标的组分是 NOJ；3S5Y 链 A 的组分是 DGJ。两者在糖环 C4 为差向异构体。根据原始坐标重建手性，与各自 CCD 有完整 11 重原子匹配，交叉使用另一手性图则失败。采用相同的 C3、C5、O4 邻居顺序，C4 标量三重积为 −2.523 和 +2.511 Å³。输入采用 3S5Y 的 DGJ 化学图，由 ETKDGv3 和 MMFF 生成坐标，只使用带 +1 电荷的环氮假设。3GXT 只作受体；参考坐标取自 3S5Y，用 56 个共同口袋 Cα 对齐到 3GXT，蛋白对齐 RMSD 为 0.259 Å。自对接使用同一份 3S5Y 参考。该校验识别的是沉积图和坐标，不能据此判定当年实际加入晶体的试剂。两格空间参照均来自同一实验配体，所以双向独立结构验证的条件未满足。[计算前协议](PROTOCOL.md) · [手性与对齐数值](results/geometry.json) · [3GXT 原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2699628/) · [3S5Y 原研究](https://doi.org/10.1016/j.chembiol.2011.10.012)

每个受体使用自身共晶小分子质心设置 24 Å 立方盒。链 A 刚性、去水，两个受体均未补建缺失侧链重原子。组织中生理 pH 与溶剂状态没有进入模型。3S5Y 研究显示 Asp170 对 DGJ 的结合有重要作用。搜索和评分均未据此增加盐桥项。三枚种子和一套化学图只能提供同一配体的配对结果。没有可供本试验排序的第二个配体。

## 正确位置能否被当前模型表达

看到 108 个输出都在 2 Å 之外后，使用已知实验姿势做非预测性定位。保持原始图生成的配体内部几何，只对全重原子做一次刚体旋转和平移，即可在两个受体上实现 1.165 Å。原生 `--local_only` 精修后分别为 1.253 Å（3GXT）和 1.338 Å（3S5Y）。这说明约束几何允许该精度。随后用完全相同的运行重放，记录每次搜索局部优化的终点和后续保存、精修阶段；12 个发布池与原输出逐字节一致。21,715 次首次局部优化终点有 103 次进入 2 Å，全部出现在三次 CH–π 场运行，属同一配体的重复访问。3GXT/43103 与 3S5Y/43133 各有 8、32 个近晶体的已接受事件没有触发第二次优化和候选入池。3S5Y/43103 有一个 1.401 Å 候选从轨迹返回并进入显式精修，误差降至 1.353 Å，在 33 个精修结果中按干势排第 13，压缩到九个最终候选时被淘汰。最近保留者与它相距 2.597 Å，大于 1 Å 去重距离。另外九次运行在记录的局部优化等检查点都未出现 2 Å 内姿势。BFGS 内部所有试探步不在这项观察之内。[各阶段回放、逐事件记录与复现](trace/README.md)

用原生显式受体、相同原子图和固定为零的共同 unbound 参考重新计分。3S5Y 中的 1.338 Å 参考引导姿势得 −3.330，六个原生/场搜索池的干分首位均更低，差 0.770–1.419 分。即使把这一近晶体姿势放回六个池，当前干分仍优先选错。3GXT 的 1.253 Å 姿势得 −4.889，有三个池的干分首位比它高 0.815–1.914 分，另外三个更低。两个受体共享同一配体，覆盖不足与辨认失败仍可在同一套预测中出现。该试验只比较两个人为放置后精修的姿势，无法确定其他近晶体姿势是否得分更优。[固定坐标与精修结果](results/reference_probe.json) · [逐池同参考竞争](results/probe_competition.csv)

## 成本与复现

24k 原生/场搜索分别实际使用 576,674/577,076 次搜索求值和 8,393/8,173 次显式精修求值。六次单 CPU 对接的墙钟总和分别为 1.485/1.794 秒，CPU 总和为 1.482/1.786 秒。池解析、CH–π 重排和几何评价共 0.0068/0.0080 秒，另有一次共用的受体制备 8.562 秒和配体制备 0.078 秒。原生双预算和官方搜索墙钟为 1.864/6.242 秒，CPU 为 1.849/6.216 秒。以上各阶段单独计时，24k 对接时间不含 Python 启动、原始输入下载、分型和辅助文件写出，不能用作完整端到端速度优势。独立程序从归档结构与坐标重新计算了 108 个候选和 24 次选姿，RMSD/重排表的最大绝对差为 5.4×10⁻¹⁵，未出现打印精度以内的首位近并列。另从基线提交 `3f21e02` 的独立干净源树编译并复跑，24 个正式与对照输出池逐字节一致，参考定位与同参考能量亦一致。[干净构建与数据哈希](results/clean_replay.json)

制备版本见输入包 `software.json`，重算使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、pandas 2.2.3 和 RDKit 2026.9.2。[成本与实际参数](results/costs.csv) · [独立复核](results/independent.json) · [历史场与构建方法](../README.md)

在仓库根目录，以已准备结构复跑。官方二进制的 SHA-256 由脚本核对。没有必要重新下载结构；原始 PDB、CCD、准备图、哈希、池与输出均随本目录归档。若需重做准备，可用包含 Meeko、PDBFixer、OpenMM 及 RDKit 的环境运行 `transfer.py "$W/work" prepare`。

```sh
D=benchmarks/ch_pi_search/gla_transfer
W=$(mktemp -d)
mkdir "$W/work" "$W/archive"
tar xf "$D/inputs.tar.xz" -C "$W/work"
tar xf "$D/outputs.tar.xz" -C "$W/archive"
cp "$D"/results/*.csv "$W/archive/"
python benchmarks/ch_pi_search/build.py --output-dir "$W/build"
python "$D/transfer.py" "$W/work" verify "$W/build/vina" "$W/archive"
python "$D/transfer.py" "$W/work" dock "$W/build/vina" "$W/rerun"
python "$D/controls.py" "$W/work" "$W/rerun" "$W/build/vina" /path/to/official/vina-1.2.7
python "$D/reference_probe.py" "$W/work" "$W/rerun" "$W/build/vina"
```
