# 主角度步长对同测定 Ki/Kd 排序的影响

例如 CHEMBL2011965 相对 CHEMBL2011982 的实测 Ki 比值为 1:285.7。候选给出的“弱配体分数减强配体分数”在 4DJW 是 −0.234，在 4GID 是 +0.4565 kcal/mol。第一份受体判反，第二份判对。同测定分子对共享化合物，在计算不确定性时须保留这种相关性。候选相对轮前有三个分层增加正确数、五个减少、一个持平。固定预算下相对官方及父版分别都是两组增加、五组减少、两组持平。[各引擎每对身份、倍数、预测分差、方向及同骨架标记](results/pairs.csv)

保留每个测定–受体–图骨架的 ρ、τ-b、分母和三倍对。四臂各 60 个骨架分组，只有 10 个分组能计算秩相关。BACE1 CHEMBL2155063/4DJW 候选的预测结合强弱与重原子数的 ρ 为 0.945，与可旋转自由度的 ρ 为 0.861。分子数只有八个，大小和柔性可共同变化。在九个分层中，制备图的形式电荷在各层内部没有变化，电荷相关性无法估计。测定真值与预测值对各描述符的相关性均已记录。[分层与偏差](results/assays.csv) · [骨架结果](results/scaffolds.csv) · [每个化合物](results/ligands.csv)

## 原生默认和实际 CPU

六个 BACE1 配体、4DJW、CHEMBL2015090、种子 89513。在各自原生默认下，四臂均为 1/14。以前瞻登记的 14.5 CPU 秒为六个配体的合计预算，四臂实际用时为官方 13.975、父版 16.627、轮前 14.077、候选 14.006 秒，均在 ±15% 内，对应 2、3、3、1 对正确。预算确认的候选 cap 为 379500 每轨迹。相同 12k 及两种子的正式分测定表与此单种子成本实验分别解释。[各次标定、实际确认参数](results/common_cost.json)

候选固定 140 次实际用时为 68.160 CPU 秒，单次墙钟合计 69.734 秒，峰值 RSS 34268 KiB。第一轮局优 / 入池前二次局优 / 显式精修的联合能量与梯度调用分别为 2997144 / 367938 / 28665。182 次候选独立运行共 228.103 CPU 秒、234.030 作业墙钟秒；同一最终确认在汇总表中有两个标签，此处只计一次。官方和父版只在历史已核对样本上有被动计数。制备共用先前冻结的输入，上次从原始记录重做测得 43.55 CPU 秒、79.18 墙钟秒；其中两份 MAPK14 受体来自已有制备，原始制备耗时未知。普通 Vina 的首姿分数在这里仅作同测定经验排序。[分阶段成本](results/costs.csv) · [命令、输入、各次成本和输出哈希](results/raw_candidate.tar.xz)

## 固定几何回归与 4OCZ

候选通过以修复前引擎为阳性对照的 92 次域、批量、错误输入与参考能测试。4OCZ 的旧两种子池在轮前和候选上各作 18 个同图独立评分，另对候选新池的 18 个模式逐一评分。54 个固定图评分中，最大坐标越界为零，固定评分与打印原始能量的最大偏差 0.027 kcal/mol。旧池使用同一参考仍选 10.310 Å（−9.773），1.762 Å 的近姿分数为 −9.764。候选重新搜索的两个首姿 RMSD 为 1.250 和 1.233 Å，合池同参考选中 1.250 Å。这个病例已在前轮揭盲。直接从 PDB/CCD、对映与化学等价映射重新核对了全部四臂的发布模式。[逐模式同图结果](controls/roundtrip.csv) · [四臂复算](controls/four_versions/independent.json) · [原始输入、输出及日志](controls/control_raw.tar.xz)

从仓库根目录可复算已发布的数据，也可用真二进制执行。以下 NEW 指未使用的临时目录，PREFIX 指域错误修复前的 f46aa37，STABLE 是轮前，CANDIDATE 是 0bb827e。

```bash
D=benchmarks/search_trial_affinity
OPENBLAS_NUM_THREADS=1 python "$D/study.py" replay "$NEW/replayed"
python "$D/verify_4ocz.py" "$NEW/4ocz-verified"
python "$D/study.py" setup "$NEW/execution"
python "$D/study.py" run "$NEW/execution" --binary "$CANDIDATE" --jobs 2
python "$D/study.py" collect "$NEW/execution" --artifacts "$NEW/new-results"
python "$D/control.py" "$PREFIX" "$STABLE" "$CANDIDATE" "$NEW/control"
```
