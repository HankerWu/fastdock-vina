# Aurora A 双受体与局部姿势积分检验

在计算跨受体分数前固定下列判据。复用 5015481 中两种有晶体参照的配体、两种受体及四个 25k Pro 种子的全部首姿。每个来源受体有一个用晶体引导的合法扭转见证和四个盲搜首姿。见证在来源受体上用 5015481 的默认 local_only 精修，AT9283 全程固定完整 SDF 图，danusertib 采用与 SDF 相同的原图。化学图在两种受体之间保持一致。只把晶体引导坐标用于检验可辨识性。

将每个中心固定在来源受体的坐标系。另一受体通过两者原冻结 12 Å 口袋的共同 Cα 对齐。另用全链共同观测的 A 链 Cα 重做。两种配准均不使用查询配体，不在另一受体中重新局优。以明确的同一零点和完整的配体内能重评来源和转移坐标。对每个中心分别计算中心分和历史 rigid_window 的 1 Å/15° 局部均匀平移球/Haar 旋转积分。报告 2048、8192 个 Sobol 点/尺度的数值差异，使用原实现的温度、权重和斜率。若收敛敏感，单列有影响的结论。

对每个近晶体与盲搜首姿配对，穷尽一个共同的游离态结构权重 p∈[0,1]。分别计算点坐标与刚体积分的跨受体混合。指定 p=1/2 仅为描述，多大权重才能交换胜者由线性混合权重解析计算。每个配对可自选 p 的可达上界与两种配体、两种来源共享同一 p 的上界分别报告。完整枚举端点、交点及其间隔。输出全部逐对原始分差，输入与运行成本。种子重复及转移姿势不作为独立配体或实测结合亚态。全链配准只作敏感性。中心窗口描述固定扭转和受体下的局部几何，模型省略游离受体占比、配体扭转盆地体积、连续诱导契合和水/离子的响应，无法独立给出标准态结合自由能。此处没有新的盲搜，也不以晶体标签选择物理权重。
