# Aurora A 完整配体图的逐坐标搜索回放

在 2X6E 的 1OL7 撤约束受体、AT9283、种子 61231 的完整图生产轨迹中，离独立共晶最近的单次求值仍有 **5.965 Å**，并被线搜索拒绝。最接近的实际提议为 6.648 Å，返回给 Monte Carlo 的最近局优结果为 7.238 Å。对这次有限搜索，扩大末端候选池或保留被 MC 拒绝的极小点均无法找回 ≤3 Å 的姿势。同一几何指标能检出历史漏边图在轨迹 2 接近晶体并被选中的过程。[测量前方案](PROTOCOL.md) · [全部分阶段统计](results/stages.csv)

完整图主例的两条轨迹共计 47,652 次 hunt、2,398 次 second 和 207 次显式精修求值。完整轨迹每个真实求值都在阈值外；这些离散坐标没有约束两个相邻点之间任何插值路径，也没有证明阈值附近不存在可达构象或吸引域。补环、磷酸化、游离配体与游离蛋白的实际状态仍有不确定性。

历史图轨迹 2 的第 698 步，首次有求值进入 3 Å。该步第 9 次求值为 2.970 Å，被线搜索拒绝；实际返回 3.038 Å。第 699 步第 10 次求值首次采纳 3 Å 内坐标（2.794 Å），随后返回、MC 接受 2.822 Å。第 705 步以 2.331 Å 返回并被接受。第 706 步从这个父构象提出 2.495 Å 的新坐标；该 hunt 第 13 次求值以 1.956 Å 首次进入 2 Å，且当场被线搜索采纳，返回 1.753 Å 后又被 MC 接受。步 706–710 连续五个 ≤2 Å 的 hunt 返回均被接受。707 步首次将 1.769 Å 写入保存池，710 步的 1.855 Å 留到全局合池并被显式精修至 1.892 Å。初次跨过 2 Å 是从已经接近晶体的几何继续局优。主病例按完整图重新搜索，从提议阶段起即缺少同等接近的输入。[漏边图全部逐事件距离及原始见证](results/at9283_inferred_61231.npz) · [完整图相同预算对照](results/at9283_complete_61231.npz)

## 实现、物理解释与复核

对受体配准后的重原子坐标，计算所有化学等价映射下的最小 RMSD，没有对配体再配准。观察器记录序号与 double 精度坐标；每次调用按真实模型序号和 PDBQT 原子序号关联。对配体树的随机初始姿态在模型副本上求坐标，避免第一次变异读到改变的搜索状态。对提出的候选，通过 hunt 的第一次求值读取已经设置在原模型上的坐标。线搜索被采纳时修改该条待输出记录上的采纳标识；失败会使模型恢复到返回构象。MC 所用 hunt 返回、二次局优返回、入池、合池、显式精修均在相应源码分支上取值。[只读观察器](observer.h) · [全部挂接位置](instrument.patch) · [Vina 原始算法](https://doi.org/10.1002/jcc.21334)

独立方法从原始 PDB、CONECT、SMILES IDX 重建受体配准和原子对应；首种方法使用 CCD、SDF 索引和另一份坐标变换实现。按晶体图分别重得 4、8 种等价映射，对全部 586,792 个事件重新计算。最大绝对差 7.46×10⁻⁹ Å，包含极大越盒试步；用 RDKit CalcRMS 对 462 份原始见证独立逐条求值的最大绝对差 3.38×10⁻¹⁴ Å。20,520 个格点局优返回全部吻合实际最后被采纳点，或无采纳时的局优起点；其中 11,436 个与最后一次被求值的坐标不同。[独立核验代码](verify_basin.py) · [核验输出](results/verified.json)

Vina 的 1.2 是 MC 接受式中采用的经验分尺度；一次变异、确定性局优和后续筛选构成的路径没有给出正则系综的盆地占比。若要比较物理盆地 A 与 B，需要在同一微观势和温度下分别积分其受约束构型权重；含可交换粒子时还要加上相应库的化学势。当前冻结受体、配体微态和隐含溶剂，没有建立两相配分函数、配体/受体游离分布、溶剂或质子化态库。几何距离单位为 Å，MC 和 BFGS 记录的能量是现行搜索分。本实验未测定温度依赖、Ki/Kd 或 1 M 标准结合自由能。受体两相、标准体积和观测定义见[统一物理说明](../../../../../docs/BINDING_ENSEMBLE_AND_DOCKING.md)。

## 复现

先按[输入解包说明](../REPRODUCE.md)恢复 WORK。确保 D、SRC、WORK 均为绝对路径。将 segment_field 已发布的原始输出解到单独目录。下面在独立代码副本上编译，生产源码不受影响。复现环境是小端 Linux x86-64、GCC、Boost 1.83、Gemmi 0.7.5、RDKit 2026.09.2、NumPy 2.3.5。SRC 可用同一对接核心的 4348b5a；非系统安装的 Boost 需按实际位置传入 --boost-prefix。

```bash
R=$(git rev-parse --show-toplevel)
D="$R/benchmarks/receptor_linkage/aurora/internal_loops/basin_trace"
mkdir -p "$WORK/segment" "$WORK/tmp"
export TMPDIR="$WORK/tmp" OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
tar xf "$D/../segment_field/raw.tar.xz" -C "$WORK/segment"
git -C "$R" worktree add --detach "$WORK/basin-src" 4348b5a
cp "$D/observer.h" "$WORK/basin-src/src/lib/basin_observer.h"
git -C "$WORK/basin-src" apply "$D/instrument.patch"
python "$WORK/basin-src/tools/build.py" --jobs 1 --boost-prefix "$BOOST_PREFIX" --output-dir "$WORK/basin-build"
python "$D/replay_basin.py" "$WORK" "$WORK/segment" "$WORK/basin-build/vina" "$WORK/basin-results" "$WORK/basin-raw"
cmp "$D/results/stages.csv" "$WORK/basin-results/stages.csv"
python "$D/verify_basin.py" "$WORK" "$WORK/basin-results" --raw "$WORK/basin-raw" > "$WORK/verified.json"
cmp "$D/results/verified.json" "$WORK/verified.json"
```

所有 .npz 收录每个事件的 1-based 轨迹、步、阶段、事件、局优求值编号及双精度 RMSD；池合并和显式精修阶段的轨迹记 0，步为相应候选编号。事件与阶段枚举见 observer.h。每阶段、每轨迹及两条轨迹合计的极小值与首次进入 2/3 Å 的原始双精度坐标、能量和行号，以及首次 hunt 返回跨界前后 MC 步的坐标均在 witness 数组中；索引从 0 开始。每个完整原始流的 SHA-256 见 runs.csv，以上命令再生全部 455,728,576 字节。仅核验已归档的见证可执行 `python "$D/verify_basin.py" "$WORK" "$D/results"`。历史文件和实验晶体从未传给搜索程序。

11 次仪器运行合计 553,109 次实际求值，全部发布池字节和日志中的搜索计数与历史生产运行一致。最终采集的程序进程合计 4.612 秒墙钟、4.555 秒 CPU；其中包含写原始坐标。相同 11 格的历史干净程序合计 3.438 秒墙钟、3.431 秒 CPU，运行时期不同，差值只能粗略衡量观察开销。第一轮采集另花约 4.536 秒墙钟、4.518 秒 CPU，随后为保留完整入界邻步见证重跑；两轮原始轨迹字节相同。独立全坐标复算用 3.601 秒墙钟、3.582 秒 CPU。研发中临时盘满和并行编译资源不足分别中断过构建；首次成功构建复用经核对源码相同的 Boost 1.83 对象，仅重编受影响的翻译单元。编译、解压和调试未完整计时。对接输入制备、受体补环与过往对照的成本见[上级档案](../REPRODUCE.md)。

最后从源码串行重编所有翻译单元，再跑一轮 11 格。该轮每个原始轨迹、压缩事件文件、发布池均与前述核验通过的版本字节相同。端到端含几何分析及压缩共 17.802 秒墙钟，其中对接程序 5.262 秒墙钟、5.241 秒 CPU。至此三轮仪器运行合计 1,659,327 次实际求值，对接进程合计约 14.410 秒墙钟、14.314 秒 CPU。[干净构建复现及二进制哈希](results/reproduction.json)
