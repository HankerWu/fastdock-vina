# 两个缺段是否都能影响这次盲搜？

固定 ae19b9f 上的 2X6E、1OL7 撤约束受体、全部原子记录顺序、两份配体和历史 Pro 生产二进制。先用四个空间干预分开 281–291、303–305 两个补入片段：每段或留在建模坐标，或把整段新增原子沿 x 轴平移 +100 Å。观察到的 2,421 条受体记录不动，原子数、类型及序号相等。所有构造仅用于定位有限程评分场的来源。单段或双段远移不代表完整物理蛋白。

几何上，如果某段重原子距全部格点都超过 XS 8 Å 截断，则它不能改变格点两体和；三线性插值及梯度也不应改变。早期分析提示短段在范围外，须复算网格和精修的适用域。竞争解释是短段也能改变运行（例如直接精修在格盒外查询、或实现有输入顺序依赖）。对同一配体和种子，同时按完整 PDBQT 字节、计算次数、每姿势 RMSD 检查：若只有长段控制空间响应，双远移应与仅短段在位相同，仅长段在位应与双段在位相同；任一不同都是反例。若双段在位与双远移也相同，该格的终点不响应；对其余格分别统计首姿和池内最优的改善与恶化。

使用已报告四种子及等规模的新种子 45101、45102、45103、45104（在查看这些输出前固定）。两配体全跑，每格采用原生搜索入口、单线程、两条轨迹、每轨迹 25000 评价额度、晚期筛选、最多九个模式；先以历史池校验精确复现。报告完整坐标、四臂逐模式与配对差、分位数、严重错姿（首姿 ≥8 Å）、各配体、计算次数与 CPU/墙时。有限种子检验随机路径对场的响应，新种子不构成另一蛋白或独立化合物。亲和力和自由能不由这个空间干预预测。

追加、读取该实验数据前：历史 AT9283 的默认推断漏掉 SDF 环丙基边 30–31，danusertib 的默认图与 SDF 相同。用同一生产 CLI 的显式完整图，在双远移、双在位两端点重复以上 16 个配体–种子条件。检验已知 1.892 Å 盲首姿在纠正图后是否保留、其他种子的方向与大小，以及 danusertib 的表示等价性能否逐字节通过；观察到相反情况保留。化学图是预先可知的输入。相同种子不能保证修正后的轨迹采样相同，同预算重搜不足以测定两个盆地的平衡质量。在缺段基线对新四种子追加官方 1.2.7 及双预算 Pro，作为计算预算与实现的参照。
