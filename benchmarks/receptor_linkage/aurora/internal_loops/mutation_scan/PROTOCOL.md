# 在完整配体图上改变单步变异的抽取顺序

锁定基线为 4348b5a。MC 对 n 个可变条目（每个配体的平移、取向及各活动扭角，加上柔性侧链的活动扭角）每次等概率抽一个。n 步内指定条目均未抽到的概率为 (1−1/n)^n。H1：有放回选择造成短窗内遗漏相互配合的自由度；随机打乱每个 n 步批次可能改善实际返回池 Oracle。H2：主要瓶颈是局优、条件评分或耦合跳跃，提议次数已足够，强制各尝试一次会妨碍有用的连续重复，或仅改变随机轨迹。即便相同初始种子，后续伪随机数的使用也会分叉；仅把效果归因于整套算法。保留长度、角度和接受规则、格点与显式精修、初始随机化和评分。

锁定两对 Aurora 交叉对接（AT9283 和 danusertib → 2X6E，均选 1OL7 撤约束模型、完整图），以及一对非激酶 BRD9（6YQW 的 82I → 6Y7L），在各对上运行从未参与选择的种子 71261、71263。AT9283 61231 另做历史诊断。不根据结果改种子、盒、对照或阈值。每进程 CPU 1，exhaustiveness 2，max_evals 25000/轨迹、9 个模式、energy_range 100，原盒（Aurora 26 Å、BRD9 24 Å），Pro late。不用晶体坐标选择或改变任何一步搜索。

对每个体系报告两枚新种子的平均配对差与每次值。三种化合物的平均 Oracle 都下降才支持该方向在本组可转移，任一未降则不能满足；任何化合物平均首姿误差或严重错姿数上升即为发布反例。两枚种子、一个非激酶不足以证明总体泛化。预期的实现校验是无放回组每个完整块每个条目恰出现一次，原生回放逐字节保留生产池。保留计数和原始坐标，包括失败。Vina 分数及这些选择机会均无热力学占比解释。

Vina 搜索来源 [Trott 与 Olson](https://doi.org/10.1002/jcc.21334)。[He 等的扫描顺序研究](https://arxiv.org/abs/1606.03432) 说明坐标更新顺序可有相反影响，文中针对 Gibbs 的混合时间定理不能套用于本研究的启发式局优。
