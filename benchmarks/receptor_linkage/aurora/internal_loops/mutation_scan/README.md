# 强制每项自由度都获得一次变异机会，能改善完整图盲搜吗？

三种配体、两个靶点各用两枚新种子做六个配对。随机无放回变异使 BRD9/82I 的一次跨晶体盲搜产生 1.059 Å 的第二名，但 Aurora 两个配体的平均 Oracle 均变差。六格首姿均值只差 0.005 Å，P95 变差 1.250 Å。达到预定的操作目标（每批自由度都提议）并没有达到跨体系几何目标。生产路径仍使用独立有放回抽取。[冻结的判据](PROTOCOL.md) · [实际输出、诊断和反序计时的逐次日志与坐标](raw.tar.xz)

## 改了哪一步

原生 Vina 每个 MC 步均匀选择一个变异条目。对单个配体而言，平移和取向各算一个条目，余下条目对应各活动扭角。AT9283、danusertib、82I 分别有 7、9、3 个条目。独立抽 n 次后，对每一项，完全漏选的概率是

$$
P(\text{本批未选})=(1-1/n)^n .
$$

实际算法在每条轨迹上对各条目做惰性 Fisher–Yates 洗牌。每取一个条目，就把它移出本批剩余集合；取尽后开始独立新排列。只有一个条目剩下时直接使用。每个完整批次每项恰出现一次，跨批最长漏选间隔上界为 2n−2 步。分组针对提议的自由度，全自由度 BFGS 在一次局优中依然可一起运动。平移、旋转、扭转幅度与分布，Metropolis、二次局优、保存、跨轨迹合并及显式精修均使用原实现。两臂初始种子相同，从变异或接受分叉后，随机流与状态会继续分叉。完整批次包含三维平移和取向条目各一次，并不意味着每根轴、方向或物理构象已遍历。[研究补丁](implementation.patch) · [原始 Vina 方法](https://doi.org/10.1002/jcc.21334)

| 配体 | 原生每项每批漏选理论概率 | 实测遗漏项 / 所有项机会 | 原生最长连续未选 / 无放回最长未选 | 原生每条轨迹每项最少–最多被选 |
|---|---:|---:|---:|---:|
| AT9283 | 34.0% | 1,577 / 4,634 | 65 / 12 步 | 85–132 |
| danusertib | 34.6% | 1,231 / 3,555 | 69 / 16 步 | 75–122 |
| 82I | 29.6% | 1,252 / 4,290 | 19 / 4 步 | 304–436 |

统计含历史 AT9283 种子；原生不足一批的结尾仅用于最长间隔。无放回组所有完整块遗漏机会为零。原生的 14 条轨迹都多次提议每项，AT9283 原生每条走了 708–830 步。观察结果否定“整条轨迹漏提议了某一自由度”对这些失败的解释。局部时序、提出的角度，以及多个自由度是否能协同进入可行区域仍有影响。每个坐标的独立次数与连续漏选间隔都可从序列复算。[每项每轨迹与完整块统计](results/draws.csv)

## 复现

先依上级 [REPRODUCE.md](../REPRODUCE.md) 生成或解开 Aurora 输入，把其绝对路径设置为 WORK。BRD9 直接解开仓内公开输入。研究补丁只应用于临时源码副本。以下使用仓库根目录，RUN 指向一个新的工作目录，PRO 指向当前核心的正常生产二进制；编译器如使用系统 Boost 可省去 --boost-prefix。

```sh
set -eu
R=$(git rev-parse --show-toplevel)
D="$R/benchmarks/receptor_linkage/aurora/internal_loops/mutation_scan"
mkdir -p "$RUN/src" "$RUN/brd9"
git archive 4348b5a src tools/build.py | tar xf - -C "$RUN/src"
(cd "$RUN/src" && git apply "$D/implementation.patch")
python "$RUN/src/tools/build.py" --jobs 3 --boost-prefix "$BOOST_PREFIX" --output-dir "$RUN/binary"
tar xf "$R/benchmarks/torsion_proposals/fixtures/inputs.tar.xz" -C "$RUN/brd9" \
  6Y7L 6YQW raw/82I.cif raw/6YQW.pdb raw/6Y7L.pdb metadata.json
python "$D/run.py" "$WORK" "$RUN/brd9" "$PRO" "$RUN/binary/vina" "$RUN/study"
python "$D/quality_cost.py" "$WORK" "$RUN/brd9" "$RUN/study" "$PRO" "$RUN/binary/vina"
for f in modes draws distributions qa; do cmp "$RUN/study/$f.csv" "$D/results/$f.csv"; done
```

该独立研究二进制默认使用随机无放回提议；设置 FD_SCAN_IID=1 可精确复现原生选择，FD_SCAN_TRACE=1 记录轨迹条目。本研究记录限单 CPU。运行器会清理这两个变量再按试验臂设置。临时源码副本不需改动生产分支。计时依机器负载而变。
