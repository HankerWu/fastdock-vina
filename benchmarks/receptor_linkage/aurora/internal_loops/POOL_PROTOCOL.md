# 相同终点评分与不同盲搜结果的追加判别

已知十个预定中心在补环时的直接分差均不变，但三个补环模型盲搜首姿不同。此方案在比较完整发布池成分和补环原子距离前记录。

取缺段 Pro 与三个补环 Pro 的全部已发布候选，各配体、种子独立比较。保留输入盲搜使用的默认拓扑，将同一份坐标分别在缺段与三种补环受体上评价。对每个姿势计算到补入重原子的最近距离。在 XS 直接两体作用范围 8 Å 外的所有姿势，固定坐标贡献应严格为零；范围内的姿势按同一正式实例的固定零点评分检验。报告每池最佳评分的所有并列模式、变化是否真正换首、候选池 Oracle 差异。不得从发布模式倒推未保存轨迹访问了哪些具体坐标。

作为对受体新增原子数量和文件顺序的控制，保留 1OL7 撤去约束后模型的全部记录、原子种类与顺序，只将添加原子平移到对接盒外、超出截断的位置。对全部两配体四种子，按同样名义预算重跑，与缺段 Pro 的输出文件逐字节比较。该构造只作数值控制。若相同，支持原子加入后空间作用场变化导致上游轨迹/候选分支变化；若仍不同，则必须另考虑输入大小或实现顺序等因素。
