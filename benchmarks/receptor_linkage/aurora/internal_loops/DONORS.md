# 独立晶体中的 Aurora A 活化环能否接触错排姿势？

相同的人 Aurora A 序列在不同实验条件下确实可给出相反的空间关系。将实验受体完整地配准到 2X6E，对同一批冻结姿势测距，1OL5、1OL7 中对应于两段缺失序列的已沉积重原子距所有姿势均大于 8 Å。在 2J4Z 中则出现多处严重重叠。2J4Z 的 His280 锚点相对 2X6E 偏移近 25 Å，显示这个可能与配体直接竞争的环形状伴随周围受体大幅重排。将这样一段坐标接回 2X6E 原锚点没有几何依据。[逐姿势、逐缺段的最短距离及原子身份](results/donor_distances.csv) · [配准误差与锚点位移](results/donor_frames.csv)

原始研究在相同的 Thr287/Thr288 双磷酸化背景下分析两份含 ADP 的晶体。1OL5 与 TPX2 结合，活化环处于活性构象。1OL7 不含 TPX2，活化环呈非活性构象。这两份结构均有全部 14 个目标残基的主链坐标，部分侧链的沉积完整性不同。另取含 ADP、镁和无机磷酸的 1MQ4，以及历史结构 2J4Z、2J50、2W1G、6CPG；后四份分别来自原受体面板及药物结构参照。全部使用激酶 A 链。1MQ4 未观察到 Arg286、Thr287。2J50 仅观察到第一段的 4/11 个残基，第二段空缺。2W1G、6CPG 分别观察到第一段的 2/11 个残基和完整的第二段。缺失残基或侧链的结构只能为相应构象的全原子最近距离给出上界。这里的转移检验属于追加的事后机制分析。[Bayliss 等的实验](https://doi.org/10.1016/S1097-2765(03)00392-7) · [1MQ4](https://www.rcsb.org/structure/1MQ4) · [原始文件来源与完整 SHA-256](results/donor_sources.json)

用全链配准复算，1OL5 与 1OL7 距十个姿势的最小值为 8.146 和 8.392 Å。2J4Z 的 AT9283 盲首姿为 2.050–3.782 Å，danusertib 盲首姿为 1.050–2.188 Å。口袋配准的 2J4Z 骨架 RMSD 为 0.807 Å，第 280 位 Cα 却偏移 24.962 Å；全链复算分别为 1.550、25.351 Å。同一 RMSD 较小的整体拟合可以掩盖决定能否接环的局部位移。

所有序列对应均检查了人源 O14965 的 DBREF 和 2X6E 的 REMARK 465。七个独立沉积共同约束了“缺口坐标在哪些构象中能直接接近配体”这一问题。细胞环境、辅因子、磷酸化、晶格和已结合配体均会影响实验构象；这里使用的是相关的几何观察，不能估算 2X6E 游离态的权重，或由最短距离恢复结合自由能。1OL5 和 1OL7 的已观测原子在上述坐标下均超出原生 XS 8 Å 两体截断；这个结论限于冻结坐标的直接原子对作用。周围激酶、水和配体联合弛豫后的响应尚待计算。[原生 XS 截断](../../../../src/lib/scoring_function.h) · [Aurora A 磷酸化和配体依赖构象平衡的测量](https://doi.org/10.1039/C8SC03669A)

## 复算

按本目录主实验准备 WORK 的 raw、coordinates 及历史结构参照文件。三份本轮新增的原始 PDB 以无损 gzip 保存于 donors。输出含 14 条配准、280 条按药物、姿势、缺段和配准区分的距离记录（包括无已沉积原子的空值）以及七个完整来源散列。Python 3.12、NumPy、SciPy，BLAS 单线程。

```bash
D=benchmarks/receptor_linkage/aurora/internal_loops
OUT=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/donor_check.py" "$WORK" "$OUT"
for f in donor_distances.csv donor_frames.csv donor_sources.json; do cmp "$D/results/$f" "$OUT/$f"; done
```

补环几何另用相同配准评价，取每段与供体共有的 N、Cα、C、O。重置手性中心氢方向并释放约束后的两个候选构象，在 281–291 段对 1OL5 的口袋框架 RMSD 为 10.170、10.828 Å，对 1OL7 为 4.866、5.785 Å，对 2J4Z 为 16.624、16.747 Å，均比较全部 44 个主链原子。这些数值测量模型与所选供体的分歧，不能给出 2X6E 原位缺段的真实误差。[四种补环坐标的逐供体差值](results/donor_model_rmsd.csv)

```bash
OPENBLAS_NUM_THREADS=1 python "$D/donor_check.py" "$WORK" "$OUT" --models \
    loop43103/completed.pdb loop43104/completed.pdb loop43103/repaired.pdb loop43104/repaired.pdb
cmp "$D/results/donor_model_rmsd.csv" "$OUT/donor_model_rmsd.csv"
```
