# Aurora A 缺失活化环、刚体评分与盲搜覆盖

用历史 2X6E 做分子力学时，受体导出会让下游程序跨过 14 个未观察残基生成两条肽键。修正坐标导出后，原有盲搜的刚体 PDBQT 数值输入保持一致。再用两份独立晶体的主链建立三套通过验收的静态受体，AT9283 在四个预定固定二选一上仍全部错排；同预算盲搜却同时出现明显改善与退化。这里把拓扑、终点能量和搜索覆盖作为三个可以分别检验的问题。[预先记录的对照](PROTOCOL.md) · [逐轮失败与追加判据](REPAIR_PROTOCOL.md) · [模板构建和验收](TEMPLATE_PROTOCOL.md) · [复算命令](REPRODUCE.md)

## 拓扑与参考态

原始沉积的 SEQRES 和 REMARK 465 均支持 His280 与 Thr292 之间缺 11 个残基 APSSRRTTLCG，Glu302 与 His306 之间缺 GRM。旧制备流程先只留下 ATOM 记录，删除 SEQRES，随后报告空的缺失序列。OpenMM 读取该单段 PDB 时实际生成两个跨段 C–N 键。在原坐标上，两键长分别为 20.722915、9.341812 Å；ff14SB 相应平衡键长为 1.335 Å，力常数为 410032 kJ mol⁻¹ nm⁻²。用孤立的键伸缩项及其梯度在 OpenMM Reference 平台和解析式交叉核验，得到 770637.174 和 131433.796 kJ/mol。如此大的数来自原坐标与错误拓扑的组合。固定同一刚体受体比较两个配体姿势时，纯受体内部常数相消；允许受体或溶剂响应时，这种拓扑则会改变动力学与系综。[数值核查](results/ff14sb_independent.json) · [PDBFixer 原始说明](https://github.com/openmm/pdbfixer/blob/master/Manual.html)

在实际制备入口中，从原始沉积读取缺段，保留作者链号，用 TER 分开观察到的片段。对 2X6E 和无内部缺段对照 2J4Z 分别重跑父版和修正版。2X6E 的边集合只减少上述两条，2J4Z 不变；全部 1998/2169 个蛋白重原子坐标、同环境重新制备的刚体 PDBQT 文件分别一致。固化归档来自另一版本 Meeko，核对其 2421/2665 行原子身份、坐标、电荷及类型均相同。TER 描述缺失信息；若要做全原子力学，还需选择真实链连通性、封端或完整补段与适当的质子化。[原始制备程序](../../../torsion_kinase_affinity/prepare_receptors.py) · [边、输出哈希和归档比对](results/export.json)

## 从隐藏自由度到可检验的命题

固定相同配体内部态、化学组成和受体框架，以分离的溶剂化伙伴为共同零点。把未保留的受体和环境坐标统记为 y，若结合与分离参考在相同的测度和相空间上定义，可以写成

$$
W(x)-W(\infty)=-RT\log\left\langle e^{-[U(x,y)-U(\infty,y)]/(RT)}\right\rangle_{\infty}.
$$

此处 x 是明确保留的配体相对位置和取向等坐标，参考平均对分离系综取。分子内部态若允许变化，也要加入平均并使用相应参考权重。对互斥盆地积分才能得到其相对概率；不同配体的标准结合自由能还涉及游离参考和标准体积。取出一套模板主链并固定，只选取了 y 的一个条件切片。不能由构建次数确定溶液占比，也不能由 Vina 搜索访问频数计算盆地积。约束和释放描述补环的准备阶段，进入本实验的三个受体在对接中均为刚体。[完整统计定义与标准态](../../../../docs/BINDING_ENSEMBLE_AND_DOCKING.md) · [结合分布理论](https://doi.org/10.1063/1.4751284)

在同一刚体、同一经验 XS 评分下，若一组新增原子距两套冻结配体坐标的所有作用原子均在 8 Å 截断外，又保持原受体的坐标、分型、配体图和未结合零点一致，这组原子对两姿势的直接分差必为零。在结合轨迹的其他位置，新增原子仍可改变经验场和有限预算算法的输出。允许口袋侧链和水响应、改变微态或扩大作用物理范围时，第一条推论的前提也会随之改变。

## 允许哪些补环进入预测

PDBFixer 两枚种子的笛卡尔补环均出现手性反转。先用手性约束修复重原子，再将四面体碳所连氢重置到正确一面并撤去约束，可恢复全部 14 个受检手性中心，仍出现 3.330 Å 的肽键，或 1.691 Å 的肽键并伴非 Pro 顺式。未经这类检查的分型或精修可能掩盖严重错误。

改用原始 Aurora A 实验供体 1OL5、1OL7，固定两侧锚点，以主链 φ/ψ 正规旋转闭合；对短段保留多起点闭合的结果，以蛋白几何选解。用 ff14SB 松弛，核对 14 个手性中心、16 条肽键的 C–N 与 ω、所有涉及新原子的重原子键、图距离超过三根键的重原子碰撞，并保留全部失败。供体均为双磷酸化晶体，1OL5 含 TPX2，1OL7 不含。补环按普通 Thr 构建；实际接收体微态和新坐标的实验误差未知。没有用配体姿势或对接结果选择模型。7 份实验构象的测距和局部锚点位移另行报告。某些构象允许活化环靠近配体，移植时却需要锚点移动近 25 Å；小的口袋 Cα 配准 RMSD 本身不能保证可接环。[供体选择、部分未观察侧链及逐项距离](DONORS.md) · [原始结构研究](https://doi.org/10.1016/S1097-2765(03)00392-7)

## 整池交叉复算与远置原子对照

四个等预算 Pro 条件产生 32 个池、285 条模式记录。将每一条按盲搜时的配体拓扑、共同未结合零点，在四种刚体受体上用同一原生评分实现求值，得到 1140 条双精度分数。与只看十个冻结中心不同，三个补环受体分别有 31、36、37 个已发布模式进入新增原子 8 Å 的作用范围，直接分数最大降低 0.057601、0.078404、0.078486。按来源池逐一选最优分，96/96 个补环对照均与缺段受体选中相同的坐标集合。再按配体和种子合并四个来源，285 条记录有 263 个逐格不同的坐标；24/24 个合并池选择对照仍全部相同。覆盖误差却随候选池来源变化，见上表。855 项新增原子距离检查中，751 项在 8 Å 或以外，其双精度直接分差均精确为零。另一条独立路径从正式 CLI 逐条核对 1140 个评分，与双精度读数最大差 0.000500 分，符合 CLI 打印精度。

逐格可见两个方向。AT9283 的种子 61231 在原缺段池内最接近晶体的模式仍有 7.383 Å，1OL7 释放态却生成了 1.892 Å 的首姿；把两个条件的候选置于共同池，缺段受体也能选中后者。Danusertib 的种子 60913 则从缺段受体的 7.202 Å 退化到 1OL7 释放态的 12.934 Å；把同一来源池换一个终点评分无法挽回这项变化。

保持 1OL7 释放态新增原子的身份和顺序，仅沿 x 平移 100 Å，使其全部超出原始搜索盒（最近 51.793 Å），原有 2421 行不变。在相同分子、种子、二进制和预算下，8/8 完整输出 PDBQT 与缺段受体逐字节相同，逐格求值计数也相同。这将观察到的首姿变化定位到产生和保留哪些候选的上游过程。得分差为零的十个中心与得分略有变化的完整池共同支持这一判断。实验没有保存每个中间构象，不能由结果判定首个发生分歧的轨迹步骤。远置只用于数值对照，不是可实现的蛋白状态。[事前整池方案](POOL_PROTOCOL.md) · [整池坐标、评分程序与远置输出](pool_control/)

## 尚待判别

这组条件对照提供了后续可证伪的方向。可以选同一化学身份的两个互斥盆地，用同一套完整体系测它们的条件权重，同时释放水、侧链和配体扭转；若仍错排，可进一步区分微态、力场参数化与实验参照。约束依赖的环模型、跨受体晶体引导、未核实的磷酸化及有限配体样本分别限定了本次归因范围。本实验没有测量溶液中各环态的占比，也没有计算绝对或相对结合自由能。
