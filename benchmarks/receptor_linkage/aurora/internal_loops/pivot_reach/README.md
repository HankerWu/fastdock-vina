# 从实际 MC 父状态做一次刚体提议，几何上可以走多远？

静态几何诊断覆盖 11 次已归档搜索的 18,806 个变异前父状态访问。一次 MC 拒绝可能重复使用同一父状态；父状态会在接受 hunt 时更新，也可能由第二次局优改写。直接读取这些事件恢复每个父状态，并将同一坐标分别交给自由刚体配准、绕任意单个配体原子旋转、相同旋转且限制整分子位移三种计算。晶体可为每行挑选最优原子、轴、角度及化学等价映射。数值是单步几何能力的上界；实际算法还依赖随机抽样、局优和多步游走。

## 推导与独立核验

对于同一配体正常的平移变异幅度 2 Å 是重原子均方根位移的上限。叠合受体后，令 D 为父状态到晶体的最小化学对称 RMSD。任何位移均方根 ≤2 Å 的一步都会满足新误差 ≥D−2 Å：对每个合法原子映射用三角不等式，再取最小。两个完整图组的最小 D 都大于 4 Å，因此从这些精确父状态出发连一次完全自由的等长位移也不能直接到达 2 Å。该结论没有对随后 BFGS 的位移设限，也没有约束其他轨迹、其他种子或多步累计位移。

给定目标对应 y、当前坐标 x 与固定的原子位置 p，用 X=x−p、Y=y−p（各行一个重原子），最小化 E(R)=‖XR−Y‖²/N，R 取正旋转。以均方位移 L(R)=‖XR−X‖²/N 度量步长。无步长限制时，对 XᵀY 作 SVD 并修正行列式；有约束时对任意 λ≥0，min [E(R)+λ(L(R)−4)] 给出带约束最优解的下界。内层仍是对 XᵀY+λXᵀX 的正旋转配准。取可行旋转作上界，只需对跨 2 Å 的分类给出上下界判据。检查全部晶体等价映射和每一颗化学重原子。解析配准使用的主程序从归档 SHA-256 核实了每一条原始二进制轨迹。独立程序从事件序列另取父状态，直接用 SciPy Rotation.align_vectors 和标量优化复核了全部 12 个四埃内的独立父事件，以及 22 条轨迹的最佳不限角度枢轴见证；后者最大差 2.29×10⁻¹⁴ Å。完整图的零值还可仅用归档受体框架 RMSD 按三角不等式复查。

## 复现

按[原始轨迹复现说明](../basin_trace/README.md)恢复 WORK 和 STREAMS。WORK 含原始接收及共晶 PDB、准备配体 PDBQT；STREAMS 为重放得到、与 basin_trace/results/runs.csv 的 11 个 SHA-256 一致的 .bin 所在目录。

```bash
D=$(git rev-parse --show-toplevel)/benchmarks/receptor_linkage/aurora/internal_loops/pivot_reach
OPENBLAS_NUM_THREADS=1 python "$D/reach.py" "$WORK" "$STREAMS" "$WORK/reach" > "$WORK/reach-cost.json"
OPENBLAS_NUM_THREADS=1 python "$D/verify.py" "$WORK" "$STREAMS" "$WORK/reach"
cmp "$D/results/parent_counts.csv" "$WORK/reach/parent_counts.csv"
```

逐状态数值及原始轨迹行号在 [parents.npz](results/parents.npz)，[逐轨迹计数](results/parent_counts.csv) 同时提供按访问与按父事件的结果。本次主分析消耗 7.04 秒墙钟、6.97 秒 CPU。第一条本机命令误选了缺少接收 PDB 的准备目录，在开跑前退出；改用同一归档输入后完成。该附加诊断没有新增对接能量求值。
