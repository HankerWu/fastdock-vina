# 刚体放置、局部捕获与真实发布的事前比较

冻结于父提交 8eafd0c6fe651f4011c0a0b66ca743e87798b0ff。历史的 344dc3b、8fc0a6e 与后续文档已核对。以下选择在新增对接、诊断分叉和新种子评价前确定。

1. AT9283 正确化学图、2X6E 加 1OL7 撤约束环、61231 原始两条轨迹。按时间取每条首步与所有整百步，另检漏边历史轨迹 2 步 706 的阳性起点。在完整图、同一内部扭角和生产 hunt 下同时检验原位、仅质心对齐、仅取向对齐、共同刚体对齐；在共同对齐位作沿受体三轴 ±2 Å、±30°以及同轴同号联合扰动。记录起止坐标、对称重原子 RMSD、短接触、能量和真实求值。沿完整图每个上述步单独作一次晶体知情共同对齐，从同前缀继续运行实际 MC 和整池发布，观察接受、保存、精修、末端名次。局优单次返回与最终发布分开。若对齐构象在近晶体局优后仍能保持且实际独立分叉能发布、原位失败，支持放置限制；若起点已近而推离，支持局部受体场/构象不合；若能形成近姿而淘汰或错排，定位首个下游损失环节。方向性样本不可外推为完整吸引域体积。
2. 真实盲搜只替换常规单配体平移提议。均匀抽一个化学重原子作固定枢轴，沿原本随机位移的方向转动。原平移长度 d，重原子到转轴均方根距离 s，转角 2 asin(min(1,d/(2s)))，轴退化回退平移；当 d>2s 可达最大位移 2s。其余提议、hunt、存储与末端分完全沿用。对照保持原平移但消耗同样的枢轴随机数，另保留未改 Pro。若局部已形成可保留接触，跨配体池 Oracle 应下降，且相对随机数对照重现；若质心移动不足或原接触错误，约束一原子会伤害覆盖，或出现跨配体逆转。Top-1、长尾与排序代价独立评价。姿势固定 AT9283、danusertib、BRD9 82I，种子 81371、81373，1 核、2 轨迹、25,000 次软限/轨迹、9 模、能窗 100。官方 Vina 与当前 Pro 另测 50,000 对照。禁止按结果选枢轴、种子、角度、受体或候选。
3. 同测定外检固定 Holt Table II 4–11 全系列、既有 1FKG/H AD4 图，单新种子 524287、1 核、3 轨迹、24,000 次/轨迹，官方、Pro、随机数匹配平移、枢轴及双预算 Pro（48,000）。按两受体各自首分等权，报七个未删失点的秩、全部可保证三倍分离对及两个立体悬崖。若可靠对增加且两悬崖不受损才支持系列迁移；方向不变、退化或有悬崖反例时列明。共晶几何单列。上述软件对齐控制、化学图接口及官方 Vina 的差异必须披露。
4. 连续 RMSD 均在受体框架、化学图对称修正，晶体只进评估与指定的阳性诊断。报逐格 Top-1、Best@5、Oracle、regret、均值、中位数、Q1/Q3、P90/P95、>5 Å 与 >10 Å、空池、键几何与立体。排序以较低经验分与较低 Ki 一致为正确。保存原始坐标、计数、命令、哈希、处理失败与软件边界；CPU 和墙钟单列。无溶液腿、标准体积积分、温度化学势采样和收敛数据，不以对接分或命中率作自由能精度。以上三枚姿势配体和 FKBP 系列均已有历史结果，独立性来自新随机流或另一家族/化学物，不宣称新发现靶点或前瞻药理。
