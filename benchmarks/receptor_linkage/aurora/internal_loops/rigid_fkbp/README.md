**坐标复算勘误。** 首次发布时，本目录的独立 AD4 检查对 Pro 输出也逐通道限幅。当前复算程序按真实引擎选择限幅顺序。历史表保留原值，运行新版所得 Pro 坐标复算分数有细小差异。原生发布分和原始姿势可各自核对。[修复及全池复核](../../../../affinity_conditioning/README.md)

Holt 等在重组人 FKBP12 的同一胰凝乳蛋白酶偶联 PPIase 测定上报告了 Table II 的八个 pipecolate ester。35 mM HEPES，pH 7.8，10 °C，25 µM 肽底物，0.5% 乙醇。逐格核对 Table II 后，化合物 4–11 的表观 Ki 依次为 186、110、12、250、10、7、300–600、300 nM。10 号的区间只参与最小倍数仍可达三倍的方向比较；七点秩相关完全排除 10 号。三倍距离按报告中心或删失边界定义；15 对共用同一批分子，未将误差条解释为置信区间。8/10 与 9/11 各自只差一个手性中心。两枚亲本自配体的共晶分别为 1FKG、1FKH，其余六个分子仅作排序及化学检查。[Holt 等，JACS 1993，Table II 及测定方法](https://doi.org/10.1021/ja00075a008) · [1FKG](https://www.rcsb.org/structure/1FKG) · [1FKH](https://www.rcsb.org/structure/1FKH)

按[事前方案](../rigid_coupled/PROTOCOL.md)，在两份既有 AD4 地图上相同配体输入、单一新种子 524287。每池单核三轨迹，24,000 名义求值/轨迹，高预算 Pro 为 48,000。比较官方 Vina 1.2.7 的 AD4 模式、当前 Pro、保留平移但消耗额外重原子选择随机数的对照、重原子枢轴旋转、双预算当前 Pro。地图间距 0.375 Å，边长 24 Å，复用原研究以相应共晶配体中心定义的口袋盒。搜索时用既有盒子，有口袋位置信息；枢轴及阈值、内部构象与排序均不读取共晶坐标。分开计算每个受体的 Top‑1 经验分，再等权平均。这个平均没有已测受体物种占比。两张图使用同样的固定制备流程，尚不足以代表蛋白构象全集。[原始输入和 AD4 定义](../../../../cubic_grid/fkbp_ad4/README.md)

## 复现

从仓库根目录执行。OFFICIAL 指向官方 Vina 1.2.7 Linux x86_64 发布二进制，SHA‑256 `f31f774f723bba7bbe6e9d1c47577020eea9a8da16424284c043d22593570644`。UPSTREAM_COUNTS 由 `python benchmarks/pair_gradient/build_arms.py "$UPSTREAM_WORK" --arms upstream-counts` 构建。BASE、SHAM、PIVOT 按[本轮构建方法](../rigid_coupled/)编译。WORK 和 OUT 为本地新目录。Python 依赖 NumPy、SciPy、RDKit、Gemmi、Meeko；读取原始 Davis 表另需 xlrd。运行脚本校验所有配体与地图 SHA；输出归档保留每个命令的完整 config、日志和 PDBQT。发布时为复用构建等待时间先运行官方，随后其余四臂以受体和配体为区组轮换运行，单池计时含程序启动、读图和输出，独立脚本的重算耗时不包含在盲搜计时里。官方分阶段求值使用[上游被动计数副本](../../../../pair_gradient/build_arms.py)独立复跑。16/16 发布池与发行版逐字节一致。计数复跑额外花费墙钟 28.718 秒、CPU 28.617 秒，单列于[counter_replay.csv](results/counter_replay.csv)。

```sh
D=benchmarks/receptor_linkage/aurora/internal_loops/rigid_fkbp
python "$D/run_panel.py" "$WORK" "$OFFICIAL" "$BASE" "$SHAM" "$PIVOT" --arms official
python "$D/run_panel.py" "$WORK" "$OFFICIAL" "$BASE" "$SHAM" "$PIVOT" --arms base sham pivot high
python "$D/counter_replay.py" "$WORK" "$UPSTREAM_COUNTS"
python "$D/evaluate.py" "$WORK" "$OUT"
python "$D/verify_exchange.py" "$DAVIS_TABLE4_XLS" "$OUT/exchange.json"
```

只做坐标、测定和计数复核时，将 `pools.tar.xz` 解至空 WORK 后执行最后两行。Davis 表下载地址和 SHA 在 exchange.json，求值及成本来自各次实际运行。CPU 指子进程 user+system 秒。程序重跑的墙钟、CPU 会随机器负载变化。
