# 用独立晶体主链闭合 2X6E 内部缺段

在两套 PDBFixer 坐标和后续笛卡尔修复仍有化学缺陷后登记。固定使用 1OL5 和 1OL7 两份具有全部所需主链原子的供体；两者属于同一原始结构研究，依次测试。生产与验收代码不读取配体、晶体见证、盲搜候选或分数。分别将目标序列 281–291 和 303–305 安放到 2X6E 原锚点。保留原受体全部已制备的重原子；补回残基为普通中性 Thr 侧链，去掉供体 pThr 的磷酸基。若供体侧链缺原子，从完整同残基供体复制并按局部主链以正规旋转放置。该操作设定化学微态，不代表测得了 2X6E 的磷酸化状态。

以左锚碳酰基定坐标，用主链 φ/ψ 正规旋转拟合右锚点，保持供体的已知手性、主链键长和肽键构型。保留扭转偏移记录。允许侧链 χ 松弛以避免碰撞，并可在固定受体重原子的条件下以 ff14SB 局优释放接环残余应变。以形成的完整蛋白逐项核查，不以打分选择模型。预设最低几何要求为所有新增手性中心与天然构型同号；涉及新残基的所有已声明重原子键长偏离 ff14SB 平衡值不超过 0.15 Å；16 条肽键均在 1.20–1.47 Å 且 ω 距 trans 不超过 35°（供体 X–Pro 若为 cis 则保留其观测）；涉及新增原子且键图距离大于 3 的非键重原子不得短于 2 Å；原宿主重原子位置保持至 PDB 写出精度。通过全部要求且 Meeko 正常识别化学拓扑才生成对接用受体。保留失败及部分成功。此验收仅筛除明显的拓扑与几何错误，无法证明补环预测正确或收敛。

两个供体从原生扭角的单一起点出发，短段右锚的拟合误差分别为 0.715、0.673 Å。力场释放后短段肽键的最大 trans 偏差分别为 38.3° 和 61.5°，第一个供体还出现一个 Cα 翻转。初次尝试单独保留。三残基双端闭合属于存在多组根的逆运动学问题。追加一次求根：长段继续使用相同起点，短段在 7 个 φ/ψ 变量上从包含原点和 16 个固定 Sobol 点的起点先解右端点约束，再按与原先相同的宿主排斥及扭转偏移目标局优。选择该同一目标最低的解进入一次 ff14SB 释放。保留各初值、闭合误差及目标值；仍使用上述全部几何验收标准。

短段的 17 个起点仍收敛到约 0.65–0.72 Å 的右端残差。两供体释放后存在超过 35° 的肽键扭曲。最后单独检验一个明确的约束模型：从上一步的同一个闭合重原子构象开始，复用本轮已登记的 500 kJ/mol 肽键 trans 余弦约束及 4000 kJ/mol 归一化手性体积约束，固定实测重原子，对分子力学势做局优。保留这一步和撤去两个约束继续局优后的两套独立结果。用原先相同验收标准与 Meeko 检查两者。通过验收的约束几何只代表在指定先验下能构成该候选，撤约束后的失败照报，两者分开标记。约束和局优内能均不加入配体评分。本步骤不改变权重、不使用查询配体或活性信息。

原始 1OL5、1OL7 供体均包含 16 条接合区肽键的参考原子。约束构建使用各自完整重建的几何；先验约束沿用上一份协议的定义，撤约束阶段的两个附加势严格为零。1OL5 约束阶段的 14 个中心均正确，最大 ω 偏差 14.12°，涉及补环的最大重原子键长偏差 0.084 Å。撤约束后 Arg304 的 Cα 翻转，未生成对接受体。1OL7 两阶段均通过，约束时最大 ω 偏差 10.78°，释放后 20.16°。后者的肽键 C–N 分布为 1.329–1.363 Å，最大重原子键长偏差 0.057 Å，固定宿主无位移。三个通过化学和 Meeko 识别检查的独立坐标可用于成对比较。每个输出均保留原受体的 2,421 条 PDBQT 原子行，只追加 134 条新原子行。包含失败的所有原始构象和日志随实验归档。

在 `WORK` 中备妥原始序列与已制备受体，从仓库根目录运行。标准输出目录 `template1OL5`、`template1OL7` 包含多起点后直接释放的失败记录。`initial` 子目录对应最初的单起点，`trans_model/restrained`、`trans_model/released` 分别保存指定 trans/手性约束和撤约束结果。每一步用力的大小是单步准备过程中的几何先验。每次 ff14SB 极小化以已制备重原子为固定支架，使用非周期 1.2 nm 非键截断，不含显式溶剂，不估计受体自由能或转变代价。

```bash
D=benchmarks/receptor_linkage/aurora/internal_loops
for donor in 1OL5 1OL7; do
    OPENMM_CPU_THREADS=1 OPENBLAS_NUM_THREADS=1 python "$D/template.py" "$WORK" "$donor" --initial
    OPENMM_CPU_THREADS=1 OPENBLAS_NUM_THREADS=1 python "$D/template.py" "$WORK" "$donor"
    OPENMM_CPU_THREADS=1 OPENBLAS_NUM_THREADS=1 python "$D/template.py" "$WORK" "$donor" --trans-model
done
```

另在只连接原始受体和已有制备输入的空工作目录，从头重建两份供体。两个扭转闭合 PDB、四个约束/释放 PDB、三个通过验收的受体 PDBQT 均与首次运行逐字节一致。1OL5 的释放阶段在复算中同样未通过。1OL7 释放受体 SHA-256 为 `614daf795f09fa31759011508a36e596068df237bc18861a247273f34349c2ea`。
