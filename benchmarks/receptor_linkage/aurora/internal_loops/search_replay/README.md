16 对匹配轨迹都在同一配体构象的局部能量/梯度求值处首先出现差异。15 对在提议后的第一次局优（hunt），1 对在 Metropolis 已经接受候选之后、保存前的第二次局优（second）。16 个首次受扰的局优中，15 个仍然返回相同配体坐标。后来共有 13 条轨迹的局优返回坐标发生分歧，在这 13 条上都是 hunt 的返回值先变、Metropolis 的接受位后变。另 3 条的局优内部出现了不同的求值，但初始构象、所有提议、局优返回值、接受与保存行为在整个回放期间相同。[测量前方案](PROTOCOL.md) · [逐轨迹比较](results/divergences.csv)

AT9283 种子 61231 在补环后产生并选中 1.892 Å 的已发布模式，原池 Oracle 是 7.383 Å。两条轨迹分别在第 112、30 步首次返回不同坐标。danusertib 种子 60913 的首姿则由 7.202 Å 退化到 12.934 Å；两条轨迹分别在第 292、46 步首次返回不同坐标。两种方向均符合局部搜索场改变访问和保留候选这一机制。即使两条轨迹都出现分歧，这个观察仍不能给某一条轨迹的某一次扰动分配最终误差的因果份额。[原始对称性校正姿势与固定池换分对照](../pool_control/README.md)

**极端的越界试步说明什么？** 两个受体共享 26 Å 名义盒、0.375 Å 网格（实际每维 70 个体素，半宽 13.125 Å）。网格查询对每个查询重原子逐轴钳位到实际网格，叠加相同的分段线性墙罚（斜率为每 Å 一百万名义分）。一维越界时，另外两维仍可得到切向的格点力。实际配体坐标可距缺段重原子数千 Å 而墙面插值发生改变。因此用真实未钳位原子的单一距离截止无法解释本次全程数值轨迹。格点本身在 8 Å 原子对范围内制表，直接查询的 8 Å 截止也不能逐点套用到三线性插值结果。[网格实现](../../../../../src/lib/grid.cpp) · [制表实现](../../../../../src/lib/cache.cpp)

16 个首变实际求值均在两臂具有同一组广义构象和同序笛卡尔坐标，补环分数减缺段分数介于 −0.7890625 与 −0.0003912。梯度也发生变化。广义梯度混合平移（分/Å）、旋转和扭角（分/弧度），CSV 的最大分量差不具备单一力的单位。其中 2 个求值是局优起点，14 个是后续回溯搜索调用。15/16 有重原子在网格外，14 个后续试步中有 13 个越界，10 个首变点有重原子在某轴越界 7,796 至接近一百万 Å。对于这 13 个越界后续试步，在两个受体上该步分数都高于或等于各自局优的初始分数。该路径的线搜索只对下降方向尝试步长，接受阈值严格低于当前分数，而之前每个已接受点的分数至多等于初始分数。因此这 13 个试步都能确定被两臂拒绝。它们给出的原子距离和分数差没有溶液构象或结合能的解释。[逐点原始距离与分数](results/probes.csv) · [线搜索判据](../../../../../src/lib/bfgs.h)

同理检查 13 次**最早改变返回几何的局优**，其中有 11 次，其第一个不同的能量/梯度求值处所有重原子都在网格内。另两次仅有一部分重原子越界。逐点检查的八个单元节点中总有节点距新增重原子小于 8 Å。这是必要几何支持，单凭最近节点不能给特定原子或正权重节点分配能量。AT9283、60943、轨迹 2 是唯一首次受扰局优当场改变返回几何的例子：内部第 8 次求值处配体至新增重原子最近 8.15 Å，插值单元节点至新增原子最近 7.87 Å，返回几何分开 0.4593 Å。已确定拒绝的极大试步与盒内的局优响应在这些数据上可以区分。[每个配体、每条轨迹的探针明细](results/probes.csv)

## 调用链、输入与对照

生产调用链依次经过 parallel_mc 的同种子任务、mutate_conf、以 hunt_cap 为参数的格点 BFGS、Metropolis 接受、条件性的二次 BFGS、轨迹内保存，随后才是合并、显式受体精修和 late 选姿。两次 BFGS 共用网格但 cap 不同；本次默认历史链的 second 也可能覆盖后续 MC 参考构象。观察器在局优内读取每次真实求值的能量与广义梯度，在返回时读取构象。普通回放对每次局优的按序二进制能量与梯度计算 64 位指纹；之后在每条轨迹的首次指纹差异及首次返回几何差异处，再运行原命令，输出 17 位有效数字的逐次能量、梯度、广义构象与重原子坐标。相同指纹为数值核查，完整双精度逐次输出用于确认每处首差。观察器限单 CPU、两轨迹、单配体刚性受体的研究副本；仪器读数不消耗随机数，不增加目标函数求值。[实现](observer.patch) · [搜索算法原文](https://doi.org/10.1002/jcc.21334)

补环的 134 条追加记录来自 1OL7 撤约束的静态受体（101 个重原子）。第三种受体保留顺序、数量和分型，只把新增原子沿 x 移动 100 Å。每种受体均使用原各四枚种子、历史推断配体图、原盒、单线程两轨迹，每条名义上限 25,000 次求值；实际步末检查上限并另计显式精修。8/8 远移运行的整个阶段轨迹文本（包括所有局优的路径指纹）和发布文件与缺段一致。24 份第一阶段和 16 份第二阶段发布池与对应历史生产输出都逐字节相同；计数、起始中心和接受统计也逐行相同。输入、归档发布姿势和输出没有使用晶体标签来引导搜索。AT9283 的历史推断图与经过化学核定的显式键图须分别解读。[受体和配体哈希](results/inputs.json) · [逐运行时间与 SHA-256](results/runs.csv)

研究原型初次只记录返回值，并假定每条轨迹均有改变的局优返回，第一组遇到完全相同的返回轨迹后停止。正式回放覆盖内部实际求值以及可检验的无变化结果。本次观察器进程的 24 次全程与 16 次局部详细回放分别使用 9.246/9.163 和 6.293/6.256 秒墙钟/CPU，共 2,011,063 次实际搜索及显式精修求值。生产版计算预算与算法参数保持历史值。这里的计时不含软件编译、此前受体建模、初次设计失败的试运行、压缩和离线核查；此前受体建模成本见上级目录。已有输出的复现使每个发布池的首姿、Best@K、Oracle、Regret 与生产版逐例相同。本次同一配体两轨迹不构成两种独立化合物。该测量没有生成新的 Ki/Kd、受体重组代价、真实溶液占比或标准自由能。[独立重读 SHA、阶段与完整求值计数](results/verified.json) · [构建和上游成本](../REPRODUCE.md)

## 复现与独立检查

先按上级 [REPRODUCE.md](../REPRODUCE.md) 解开真实输入与历史所有池到 WORK。命令中的 D、WORK、BUILD 与 SRC 使用绝对路径。源码以仓库内基线为准，可在临时副本上应用补丁，保留生产源码。编译时可按本机 Boost 配置增减 --boost-prefix 参数；本轮用 c++ 的生产 -O3 配置及 Boost 1.83，并核对所复用二进制 SHA-256 以 6a56ec3d 开头。不同链接顺序或路径可改变观察器的二进制哈希，发布坐标和逐阶段结果可独立核查。

```sh
R=$(git rev-parse --show-toplevel)
D="$R/benchmarks/receptor_linkage/aurora/internal_loops/search_replay"
SRC="$WORK/replay-src"
BUILD="$WORK/replay-build"
git -C "$R" worktree add --detach "$SRC" ae19b9fc52e7501d356e06cdc3eed296021d9147
cp "$D/observer.h" "$SRC/src/lib/"
git -C "$SRC" apply "$D/observer.patch"
python "$SRC/tools/build.py" --jobs 2 --boost-prefix "$BOOST_PREFIX" --output-dir "$BUILD"
tar xf "$D/../pool_control/raw.tar.xz" -C "$WORK" raw_far/far.pdbqt
python "$D/replay.py" "$WORK" "$WORK/raw_far/far.pdbqt" "$BUILD/vina" "$WORK/replayed"
cmp "$D/results/divergences.csv" "$WORK/replayed/divergences.csv"
python "$D/probe_geometry.py" "$WORK" "$WORK/replayed" "$WORK/replayed/probes.csv"
cmp "$D/results/probes.csv" "$WORK/replayed/probes.csv"
python "$D/verify_trace.py" "$WORK" > "$WORK/trace-verification.json"
cmp "$D/results/verified.json" "$WORK/trace-verification.json"
```

[完整 40 次原始日志、逐步轨迹与发布坐标](traces.tar.xz) 支持只读离线核查。verify_trace.py 独立读取归档、比较 40 个发布池及完整计数、重定位全阶段与逐次求值首次分歧，并直接从两份重原子坐标重新计算返回位移。probe_geometry.py 可在只解开归档、不运行对接时使用：将 traces.tar.xz 解到空目录的 raw 子目录，在该目录下放入 results/divergences.csv 的一份副本（文件名 divergences.csv），将该目录作为第二个参数即可。CSV 中空白表示该轨迹没有观察到该事件。
