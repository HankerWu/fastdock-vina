# 给定晶体位置后，刚性受体与干分能否保留它？

本节冻结引擎源版本为 `7bc6128`。下文“原生”指该版本默认设置。盲搜的 430 个主参照输出中，最小重原子 RMSD 为 2.973 Å。下面将冻结的 A 链晶体参照用于构造已知答案的输入，检验模型能否表达更接近实验的几何、局优是否保留它、干分是否认出它。仅在同一化合物和受体内比较。结果不进入盲搜分布。[盲搜协议](PROTOCOL.md) · [主参照和坐标变换](GEOMETRY.md)

**合法扭转放置。** 直接读取盲搜准备态 PDBQT 的刚体块和分支树，逐轴旋转下游完整子树，再作整体平移与无反射刚体转动，按照同一重原子对称映射最小化对参考的误差。每个等价映射从参照扭转和原准备扭转各开始一次，不使用评分选择映射。给出的误差是已构造的可行例子，无须假设求得全局最优。AT9283 的 5 根轴将仅作刚体变换的误差从 1.746 降至 0.613 Å，danusertib 的 7 根轴将 2.125 降至 0.456 Å。变换后，输入图所有已保留共价键与 1–3 端点距离的最大变化小于 8×10⁻¹⁵ Å（输出仍按 PDBQT 三位小数序列化）。这直接证明这两种配体的输入构象在已有搜索自由度内可以靠近实验位置。

**晶体重原子替换。** 另将同一中性图的重原子直接换成 A 链晶体几何，重新补氢、固定重原子，只做 MMFF94s 氢松弛。初始 RMSD 为 0.0005 Å 左右，来自坐标序列化。这一路改变了盲搜保留的部分键长、键角或环形，例如 AT9283 的保留共价键长最大变化 0.124 Å，因此只能用来检验晶体内部几何的局部兼容性。两路均按归档的 12 Å 共同 Cα 变换放入原盲搜 26 Å 盒，所有见证重原子与盒壁至少相隔 3.51 Å。[两路几何与拓扑核验](results/probe_checks.json)

**同参考读出。** 用相同受体、同一配体原子类型和拓扑，以 `--score_only --pose_coordinates ... --unbound_energy 0` 复算局优前、局优输出、4 个原生 Pro 种子的实际首姿。局优用已有原生 `--local_only` 和允许该入口使用的 `--ligand_bonds` 锁定图，不使用 local_only 控制台按姿势内部参考输出的分数。C++ 核验比较每个原子的 XS 类型、每条推断共价键和所有内部可变非键对及类型；每个锁定的图在原输入和见证上完全一致。下表中差值 = 盲首姿分数 − 见证局优后分数，正值意味着见证得分更好；单位为此同配体经验分数的能量标度。

| 受体、化合物 | 合法起点 → 局优 RMSD，Å | 同参考分数，起点 → 局优 | 盲首姿减见证，四种子范围 | 见证胜 / 4 | 晶体重原子替换后局优 RMSD，Å |
|---|---:|---:|---:|---:|---:|
| 2J4Z，danusertib | 0.456 → 2.963 | +3.826 → −6.238 | −2.984 至 −0.835 | 0 | 2.748 |
| 2X6E，danusertib | 0.456 → 1.572 | −3.354 → −8.784 | −1.222 至 +2.283 | 1 | 0.902 |

最能区分机制的是两个受体上同一个 AT9283 的反事实。在 2J4Z 中，合法放置与 Leu139 主链 O 最近仅 1.781 Å，有两对分子间重原子相距小于 2 Å；局优后这些短接触均消失，整体姿势离开原坐标。在 2X6E 中，同一合法放置没有这样的短接触，局优后仍为 1.497 Å，四个盲首姿却都比该见证得分更低。danusertib 合法放置在 2J4Z 中距 His280 Cβ 只有 1.827 Å，在 2X6E 中最近重原子距离为 2.639 Å。这些已知答案的实验约束了刚性受体兼容性与干分识别的解释，不能证明所有未记录轨迹曾经或从未访问过同一盆地。[全部阶段坐标误差与接触](results/probe_stages.csv) · [逐种子固定零点竞争](results/probe_pairs.csv)

## 环丙基拓扑与数值停滞

SDF 图与枝树表示比较，AT9283 的默认距离推断缺失 PDBQT 序号 30–31 的一条环丙基边。同一晶体几何若重新作为输入直接推断，会变成缺失 31–32。因而直接重载坐标会改变排除表。原输入图的固定和上述逐原子、逐内对核验防止了这项混淆。此前已在别的三元环证明了该推断规则的局限；这里使用既有显式图接口作对照。danusertib 默认推断的图与 SDF 相同。[原有三元环实验及源码](../../cyclopropane_topology/README.md)

仅对 AT9283 重复相同的放置和 8 个盲首姿的固定坐标评分，将局优和单点评分统一切换为完整 SDF 图。2J4Z 的合法放置在局优后为 2.296 Å，原图为 2.313 Å；直接替换晶体几何时为 1.883 Å，其干分仍输给四个盲首姿。在 2X6E 中，完整图的直接晶体放置经局优后为 1.260 Å，仍全输。

2X6E 的合法起点出现独立的数值现象。完整图的原生局优返回原坐标，得分 −3.566。沿三个笛卡尔轴各作 ±0.020 Å 的小幅整体平移，同参考最终分数中心差分为 −0.950、+4.950、−3.725 分/Å。显式局优调用 model::eval_deriv，而最终显示采用 score(0) 的能量读出并施加配体转子归一化。为直接检查局优自己的目标，使用同一局优接口，把梯度预算限制为一次，核查日志与坐标确认没有更新。起点的内部目标为 −4.59864；沿 y 轴负向移动 0.020 Å 降为 −4.73404。三个轴上**内部目标**的中心差分为 −1.231、+6.629、−4.830 每 Å。这些是有限位移的数值斜率；至少一个相邻坐标在实际局优目标上更低。用仓库已有的 Armijo 局优重放同一起点，得分降至 −7.426，RMSD 为 1.266 Å。四个盲首姿仍比它低 0.477–1.318 分。原生局优的数值停滞与能量排序不符在本例同时成立。完整图只做同坐标反事实，全套对照没有重新生成盲搜池。[差分和优化器对照](results/probe_checks.json) · [逐坐标输入、输出、日志与成键图](probe_raw.tar.xz)

另用独立的 Gemmi 蛋白拟合、从 PDB CONECT 和 Meeko SMILES IDX 得到的 RDKit 对称 RMSD 重算全部 24 个见证阶段，并从原始日志复核 96 个逐种子分差及共同零参考。最大 RMSD 差 2.1×10⁻¹⁴ Å，分差全部一致。[独立复核](results/probe_independent.json)

## 复现

在仓库根目录，首先按主研究说明解包 RUN 和 REFERENCES。BUILD 为使用上述冻结引擎版本构建的 FastDock 目录（含 obj），BOOST_PREFIX 为本机 Boost 安装前缀。在下例中可使用 Python 3、NumPy、SciPy、Gemmi、RDKit、C++14 和 Bash。

```bash
D=benchmarks/receptor_linkage/aurora
K=benchmarks/torsion_kinase_affinity/evidence.tar.xz
objects=()
for obj in "$BUILD"/obj/*.o; do
    [[ $(basename "$obj") == main.o ]] || objects+=("$obj")
done
c++ -O2 -std=c++14 -pthread -Isrc/lib -I"$BOOST_PREFIX/include" \
  "$D/probe_topology.cpp" "${objects[@]}" -L"$BOOST_PREFIX/lib" -Wl,-rpath,"$BOOST_PREFIX/lib" \
  -lboost_system -lboost_thread -lboost_serialization -lboost_filesystem -lboost_program_options \
  -o "$WORK/check_parser"
OPENBLAS_NUM_THREADS=1 python "$D/pose_probe.py" "$RUN" "$REFERENCES" "$WORK/probe" \
  "$K" "$BUILD/vina" "$WORK/check_parser"
python "$D/check_probe.py" "$RUN" "$REFERENCES" "$K" "$WORK/probe"
```
