# 结合位点水的平移与置换

凝血酶 S1 口袋提供了区分两种误差的实测例子。在同一系列中，一个配体能容纳平移了约 0.70 Å 的水，另外三个配体的取代基直接占据原来的水位置。此前把水固定成一个点后，原生首位命中从 14/30 降至 12/30。本实验将一个水位点周围的可达位置积分，检验几何松弛能否挽回这两个命中。开发与跨家族检验范围见 [protocol.json](protocol.json)。[人凝血酶结构与 ITC 原始论文](https://doi.org/10.1016/j.jmb.2009.04.051) · [历史单点对照及数据来源](../thrombin_water/README.md)

## 分数定义与适用条件

对实验水氧的位置 $x_0$（Å）和各向同性 B 因子（Å²），试用方差 $\sigma^2=B/(8\pi^2)$ 的各向同性高斯作为位置分布。B 包含静态无序、精修误差及热运动；将它转用到不同温度和不同配体的计算条件中是一项待验证的近似。先取归一化受体参考密度 $q_R(x)\propto \mathcal N(x;x_0,\sigma^2 I)A(d_R(x))$，其中 $d_R$ 为到纳入模型的最近蛋白重原子距离。$A(d)=t^2(3-2t)$，$t=\operatorname{clip}[(d-2.0)/0.6,0,1]$。对位姿 $L$ 求 $a=\int q_R(x)A(d_L(x))\,dx$，每个独立位点向干 Vina 分添加 $-RT\ln(1-p+pa)$ kcal/mol。$T=298.15$ K，单一结构观察的 $p=0.75$ 沿用历史单点对照。固定水使用 $a=A(d_L(x_0))$。$a$ 的意义是在此位置分布中还能容纳水的质量比例。

计算使用 11³ 点张量积 Gauss–Hermite 积分，独立检查积分阶数 17³。每种阶数的受体节点和归一化权重只生成一次。在有限节点的最大移动距离以外，若配体最近重原子再远出 2.6 Å，该位点贡献精确为零。受体参考分布的常数由无配体时的可达质量归一化，对远离所有位点的姿势给出零改分。多个位点取配分因子的乘积，各水可以同时存在。两个水若移动到相互冲突的位置，模型也不会识别这种冲突。固定与移动两臂都只模拟空间排斥，未赋予氢键形成的能量。默认对接路径之外的研究入口使用这些改分。此构造忽略水分子取向、水网络耦合、蛋白–水交换和配体去溶剂化。位点先验也未由溶液中水的化学势测定。该分数仅是固定池的占位敏感性实验。晶体位移参数的统计含义可参阅 IUCr 的原始报告。Ross 等采用巨正则模拟显式处理体相交换和网络协同，本实验未运行该方法。此前 GOLD 和 DOCK 已研究水的可置换性和多位置表示。[IUCr 位移参数定义](https://www.iucr.org/who-we-are/commissions/commission-on-crystallographic-nomenclature/published-reports/adp) · [水位点与巨正则自由能](https://doi.org/10.1021/jacs.5b07940) · [GOLD](https://doi.org/10.1021/jm050543p) · [DOCK 离散水构象](https://pmc.ncbi.nlm.nih.gov/articles/PMC2719016/) · [结合口袋水的热力学与溶剂重排](https://pmc.ncbi.nlm.nih.gov/articles/PMC1783395/)

## 盲选姿与实验标签

人 α-凝血酶（F2）沿用历史样本的 12 个同系列 ITC 化合物、三个受体、两个种子，每池 12 个姿势。五个化合物具有实验姿势，其余七个仍用于亲和力评价。转移 3D49 的 H:2006 水时使用既有 11 个 Cα，不读取查询配体晶体位置。ITC 为 25 °C、pH 7.8 的同一批实验，三倍差异阈值和跨六个受体/种子观测的中位差均沿用原协议。包括 37 个共享配体的比较对，没有将受体或随机种子当成独立实验标签。[实验输入、测量条件及原始搜索](../thrombin_water/README.md)

在新模型计算前指定 ESR1、PPARG、PDE4D 的全部原生双向交叉对接作为跨家族检验，两个已有预算分别每方向三个、两个种子。共 30 池、300 个姿势。这些目标已用于历史研发，此处分离的是新水模型的设计与测试。每个跨体系只使用接收受体的水和原搜索盒中心；接收受体是另一种配体的复合物。取原 24 Å 盒内的 A 链晶体水（占位 ≥0.5、B>0），要求 2.4–3.5 Å 内至少有两个蛋白 N/O，排除距蛋白重原子 <2.3 Å 或距金属 <3 Å 的位点。计数是极性邻近判据，未确定氢键取向。ESR1 两受体计 1、12 个位点，PPARG 计 10、7 个，PDE4D 计 25、27 个。[交叉对接原始数据与对齐、对称映射约定](../paired_crossdocking/README.md)

在具有结构标签的凝血酶池中，移动模型改变干基线的 8 个首位，共丢失 2 个命中。PDE4D 有 4 个首位改变，PPARG 有 1 个，ESR1 为零；三者均未跨越 2 Å 阈值。PDE4D 所有 10 池的完整次序均有变化。例如 1XOQ 配体进入 1XOM 受体，3,000 档、种子 43117 的原始第六名升到第二，首位仍是原模型 1；该池单姿水罚分最高 1.579 kcal/mol。干／固定／移动三臂的同 assay 三倍差异判对 11／10／10 对（共 37 对）。六个接收受体/种子条件各自的 Spearman 中位数依次为 −0.147、−0.049、−0.091，Kendall 为 −0.091、−0.015、−0.030。负值对应预测较低能量并未稳定给出较小 Kd。固定坐标池重用相同搜索成本，未在当前分支重新对接，也未与更长搜索比较。 [逐姿数据](results/poses.csv) · [逐池结果](results/cells.csv) · [亲和力分对](results/assay_pairs.csv)

## 首次分叉与反事实

两次丢失命中都发生在 2ZFF 接收受体的最终排名。改分前后，模型 1 与 2 的坐标、候选数量和搜索状态完全相同。

| 取代基 | 序列种子 | 干分领先量 | 正确／错误构象移动水罚分 | 首位 RMSD（Å） | 两构象交换排序时的先验 p |
|---|---:|---:|---:|---:|---:|
| 1a，间位 F | 194027 | 0.076 | 0.669／0.000 | 1.784 → 3.617 | 0.133 |
| 3a，间位 Me | 83519 | 0.187 | 0.819／0.004 | 0.462 → 5.935 | 0.273 |

最后一列是从既有两构象计算的成对交叉点。它不用于选取新的先验。受试化合物自身晶体显示间位 F、Me、Cl 均直接覆盖转移水的位置，距最近的实测水分别为 5.17、4.95、5.01 Å。在这三个实验构象上，移动模型给出的水占据后验分别为 0.00105、0.00090、0.00002，同时对每个构象仍收取约 0.821 kcal/mol 的置换罚分。对保有水的未取代化合物 5，晶体中最近水偏移 0.698 Å，罚分从固定点的 0.453 降至移动点的 0.283。对另一保有水的化合物 4，罚分反从 0.000 升至 0.127。允许平移能缓解部分边界重叠，但配体完全占据水位时，罚分趋于 $-RT\ln(1-p)$，与移动宽度几乎无关。这个饱和值已经大于两次干分领先量。证据定位了模型误差如何影响排名；真实置换自由能、配体本身的水化和直接相互作用仍无法由这组几何数据区分。 [晶体诊断](results/crystal_check.csv) · [排名交叉点](results/lost_hits.csv)

更高阶积分改变单姿分数最大 0.0330 kcal/mol，所有结构标签池首位和 ITC 分对总数一致。独立单原子非中心卡方径向积分与 11 阶估计相差 0.00316 kcal/mol，坍缩极限重现原单点势。1164 个姿势、9 个接收结构的受体预计算在本次单进程 CPU 上合计约 0.055 s，11 阶几何评分约 0.775 s，17 阶约 3.177 s。两阶积分在同一进程运行，含读取两套归档表、交叉汇总和输出的回放主体为 4.46 s 墙钟、4.44 s CPU，进程峰值 RSS 97.5 MiB。免去额外 Vina 求值。该计时依赖本机和缓存，不能据此判定与加倍对接的等时收益。几何改进没有带来净姿势或亲和力收益，研究入口单独保留。后续可以用独立溶剂模拟测定位点到体相的相对化学势，并在新配体上单独检验其对置换代价的预测。 [计时](results/timing.csv)

## 复现

Python 3.12.14、NumPy 2.3.5 和 SciPy 1.17.0。以下命令从仓库根目录运行，使用已提交的数据，不需要重新下载晶体或生成对接候选。

```bash
R=$PWD
B="$R/benchmarks/mobile_water"
T="$R/benchmarks/thrombin_water"
C="$R/benchmarks/paired_crossdocking"
W=$(mktemp -d)
mkdir -p "$W/throm" "$W/cross"
sha256sum -c "$B/inputs.sha256"
unzip -q "$T/raw.zip" -d "$W/throm"
unzip -q "$T/results.zip" -d "$W/throm"
for f in fixtures.tar.xz poses-3000.tar.xz poses-12000.tar.xz; do
  tar -xJf "$C/$f" -C "$W/cross"
done
python "$B/check.py"
OPENBLAS_NUM_THREADS=1 python "$B/replay.py" --repo "$R" --throm "$W/throm" --cross "$W/cross" --out "$W/replay"
python "$B/crystal_check.py" --repo "$R" --throm "$W/throm" --out "$W/replay/crystal_check.csv"
python "$B/attribution.py" "$W/replay"
```

从任一固定受体和同坐标系的候选池评分，可用下列入口。中心取已知接收口袋并按登记的 24 Å 立方体选水。它输出各 MODEL 的原生、固定水、移动水、高阶积分分数以及实际位点数。适用于带 MODEL 与 Vina 原生分记录的单配体刚性受体 PDBQT 输出。程序未纳入结晶对称邻体或多链间口袋中的其他链，链或位点准备不同须重新验证。

```bash
python benchmarks/mobile_water/score.py --receptor-pdb receiver.pdb --chain A \
  --center X Y Z --pool native_output.pdbqt --out scores.csv
```
