# 已锁定盲结果后的局优分叉

主协议 97b1589 已结束十格盲排序和搜索。独立评价发现两个 BRD9 库及 EPAS1 的 4GHI→5TBM、93241 含有 ≤2 Å 候选。追加问题是各场的“首次近姿名次”是否对应可由同一优化器捕获、存活的姿势。此处使用晶体标签，结果仅作事后机制诊断，不计入外推或盲预测。

对所有十库按上述条件筛出全部有近姿的库。在每个库内，分别取原形状、真实类型、置换类型排名最靠前的 ≤2 Å 候选；相同序号只跑一次。从同一 post-mutation 源态和相同随机数序列将其送入唯一 hunt 名额，重做 25k/轨迹的全搜索。原始坐标逐阶段评价，记录注入 ID 的逐出、合池、发布以及首位、池 Oracle，不以最终近姿反推 ID。比较三类排序对已知可捕获候选的遗漏方式，保留无 ≤2 Å 的库作为零覆盖。单独记录诊断计算成本。
