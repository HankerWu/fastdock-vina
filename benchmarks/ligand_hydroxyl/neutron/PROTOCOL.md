# 以配体氘的实验位置检验羟基方向

使用 Manzoni 等人的人 Galectin-3C 中子结构（DOI 10.1021/acs.jmedchem.8b00081）。6EXY 甘油的 O1/O3 向蛋白供氢，O2 主要从 Arg162 受氢。6EYM 乳糖包括两个糖环上的全部有沉积 D 坐标的羟基。冻结全部这些位点，其中包括向溶液暴露的羟基。两个复合物属于同一晶型、同一实验组、同一蛋白；此处是按文献选择的机制诊断。参考论文已公开报告方向，因此不是盲验证。独立姿势迁移在其他靶点进行。

从固定重原子重建理想 C–O–H 圆锥（0.97 Å，109.471°），用独立于实验 D 的轴和 720 等距节点。用受、供体重原子的原生 N/O 氢键强度与供氢角因子；每一对仅取一次最大值。给出平坦、只考察配体向外供氢、允许蛋白反向供氢三种对照，再检验对饱和醇氧的两个理想四面体孤电子对方向施加受氢角惩罚会否解释只受氢的羟基。该角度核没有实验拟合系数。干口袋与纳入沉积水（含其 H/D 方向）分开；后者获得额外实验输入。另以只加入配体内部隔至少四条共价键的氧受体的对照定位遗漏。其他配体羟基的 D 一律不得进入这些势。对全部有信息位点报告后验落在实验方位角 ±30° 内的质量、最低能量方位误差、简并范围及势能跨度。平坦场不报告点估计。在相同理想圆锥上评价测得的 D 的投影。此实验隔离局部非键相互作用，不含 MMFF 内禀扭转，也不代表完整主评分器或结合自由能。事前假设：O1/O3 的向外供氢可从干口袋定位；只看向外供氢难以解释 O2，反向供氢加醇氧受氢方向可能提供信息，但可能留下两个等价方向。纳入水的收益允许因位点而异。
