# 甘油与乳糖的羟基氘方向

人 Galectin-3C 的两份 1.70 Å 中子结构允许直接检验局部转角，作者在核密度图中分析了甘油的三个羟基，以及乳糖的关键供、受氢位点。实验选入两个配体的全部 11 个已建模羟基 D，D 的坐标只用于最后评价。两者由同一组发表，共用结合口袋；结果说明单个位点的机制。[原论文与核密度图](https://doi.org/10.1021/acs.jmedchem.8b00081) · [事前协议](PROTOCOL.md) · [所有位点、势能跨度和简并](results/sites.csv) · [重原子距离与反向供氢](results/contacts.csv)

干燥口袋模型将中性醇的氢沿理想 C–O–H 圆锥转动。每个节点按各接触的径向 Vina 氢键强度乘以 D–H···A 的角度因子计算吸引。若蛋白也可供氢，对同一对重原子取两个方向中较强者。蛋白或水向配体醇氧供氢时，另检验一个四面体受氢近似。设从氧指向 C 和 H 的单位向量为 c 和 h，令 m 为两者和的反向单位向量，n 为两者叉积的单位向量。两条候选孤对方向为 m/√3 ± √(2/3)n。反向供氢项再乘进入的 O···H 方向与两条向量之间较大的正余弦平方。该近似描述饱和醇，仅使用已有的氢键径向幅值。量化研究显示不同受体基团的实际方向依赖可明显不同。[氢键各向异性的量化扫描](https://pmc.ncbi.nlm.nih.gov/articles/PMC7325729/)

| 位点与输入 | 供氢模型 | 加入受氢方向后的变化 |
|---|---|---|
| 甘油 O1、O3，干口袋 | 最优供氢角与沉积 D 方位角相差 15.4°、1.2° | 改成 16.9°、7.3°。两者主要受 His158、Glu184 的受氢位置约束。 |
| 甘油 O2，干口袋 | 缺少供氢的配对受体。蛋白 Arg162 向 O2 供氢，单纯向外供氢或仅取反向供氢标量均给出平坦角势。 | 两个等深方向与实验相差 15.9° 和 104.1°。实验方位 ±30° 概率从 0.167 增至 0.185，势能跨度 0.188 kcal/mol。 |
| 乳糖葡萄糖环 O3，干口袋 | 与实验相差 9.5° | 误差缩小到 2.5°。 |
| 乳糖半乳糖环 O4、O6，干口袋 | 与实验相差 28.3°、25.3° | 误差增至 31.3°、36.3°。 |
| 乳糖半乳糖环 O3、葡萄糖环 O2，加沉积水 | 干口袋两者均无角度信息。 | 前者 ±30° 概率升到 0.240，后者降到 0.163，最优方向偏离实验约 162°。 |

干口袋下 11 个位点中有 5 个在加入孤对后角势仍完全平坦。水臂额外使用沉积水及其可用的氘方向。这里固定蛋白重原子与供氢状态，部分占据的 A 构象按单一构象处理，未重新拟合衍射数据或计算交换和水占据平衡。糖与受体的溶液态重组能也未计入。主姿势评分器里的 MMFF94s 内禀扭转项在这项局部接触消融中关闭。向新的葡萄糖复合物迁移时使用完整扭转先验。[新结构的姿势排序](../glucose/README.md)
