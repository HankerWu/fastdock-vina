# GLUT3 的单油酸甘油酯改变了哪些预测？

在人 GLUT3 的 4ZW9 晶体中，单油酸甘油酯 A502 的 O25 靠近葡萄糖 O2，α / β 异头体分别相距 2.460 和 2.488 Å。原研究将这枚脂质纳入葡萄糖配位环境。我们向已经完成预测的固定蛋白中放回三个沉积脂质，在同一批糖坐标上开关脂质，并以同样的预算重新搜索。加回脂质使两种实验构象的 Vina 相互作用能更有利。β 糖的近晶体候选覆盖增加，α 糖覆盖下降，两种糖合计首位仍为 3/8。这里使用了同一晶体提供的额外信息。[原论文及扩展数据图 4](https://doi.org/10.1038/nature14655) · [4ZW9](https://www.rcsb.org/structure/4ZW9) · [事前协议](PROTOCOL.md)

## 输入与评价

两种糖在晶体中为共存异头体，沉积占有率分别为 0.69 和 0.31，预测时按两个单独查询处理。各固定 24 Å 盒、4 条轨迹、1 CPU、原有两个种子与每轨迹 3,000/12,000 名义上限。盒定位使用实验配体。在同一蛋白坐标系，重原子按原制备文件的立体化学合法映射评价，以 RMSD ≤2 Å 为成功。一个异头体的 4 个条件共享受体与实验结果。冻坐标测试读取同一查询的 prepared 拓扑，显式原生 CLI 为两种受体分别计算 INTER、INTRA、共同零参考归一化分数。两受体上的配体 INTRA 逐项相同。[原糖结构、制备、占有率与上游 Vina 对照](../README.md)

OLC A501、A502、A503 均为 25 个重原子，满占有率，无备选位置。按 CCD 原子名和键级重建图，将全部重原子固定于沉积坐标，用 MMFF94s 仅松弛补建的氢，Meeko 0.8.0 指派部分电荷和类型。每分子在 PDBQT 中保留两个极性 H。全蛋白与每枚脂质均刚性，水仍被省略。A501 的最近糖距离为 4.59–4.69 Å，A503 距离 12.27–12.29 Å。A501 C24 与蛋白 Asn32 OD1 的沉积距离 2.18 Å，PDB 的 REMARK 500 也标注了此冲突。计算未估计脂质或蛋白自身形变的自由能。

A501 和 A502 从沉积坐标独立指派的手性、双键构型与 CCD 一致。A503 的沉积双键几何为反式，CCD 标注顺式。首轮保留全部沉积重原子。发现该差异后登记 A501+A502 敏感性试验，在完全移除 A503 的受体上重跑。[OLC 定义](https://www.rcsb.org/ligand/OLC) · [各分子原始质量记录](results/preparation.csv) · [追加试验登记](DISTANT.md)

## 同坐标与重新搜索

表中各数字依次为“首位 / 前五 / 池内命中”，每格有 4 次对接。候选池固定时的相互作用比较来自 288 次原生显式调用，覆盖 142 个盲预测姿势和两个晶体姿势。

|产生候选的受体|同坐标评分所用受体|α 糖 GLC|β 糖 BGC|
|---|---|---:|---:|
|干受体|干受体|3 / 3 / 3|0 / 2 / 2|
|干受体|三脂质|3 / 3 / 3|0 / 2 / 2|
|三脂质|三脂质|2 / 2 / 2|1 / 4 / 4|
|三脂质|干受体|2 / 2 / 2|1 / 4 / 4|
|仅保留 A501、A502 并重新搜索|同一双脂质受体|0 / 0 / 0|0 / 4 / 4|

在三脂质受体重新搜索 β 糖产生四个含正确姿势的池，最优几何误差均为 0.80–0.94 Å；其中三个池仍把 3.42–4.02 Å 的姿势排在首位。固定坐标换回干评分，四个池的阈值指标不变。α 糖 43103 种子在两档预算的原生首位均正确，加脂质重新搜索后全池最小误差反而达到 10.86、11.88 Å；43117 种子低预算则由无命中变为 0.86 Å 首位。两糖合计，低预算三项计数由 1/2/2 变为 2/3/3，高预算由 2/3/3 变为 1/3/3。[逐池](results/cells.csv) · [固定坐标](results/poses.csv)

对两种晶体糖和每池原生首位另外做权重消融。在不含 A503 的双脂质受体上，晶体坐标的相互作用变化和三脂质受体相同至输出的 12 位小数。双脂质的重新搜索却没有任何首位命中，β 糖的 4 个正确候选仍在前五。三脂质全模型和双脂质的 8 个完整文件全部不同。晶体附近 A503 超出 Vina 的 8 Å 截断，搜索仍可进入该分子附近。结果只能定位到搜索路径或候选构成受受体场改变，未测得 A503 在生理膜中的占据，也没有轨迹证据把路径分歧归因于特定初始提议。[去除 A503 的逐池对照](results/distant_control.csv)

## 短程排斥与极性吸引

下面报告在**相同晶体坐标**、**相同拓扑**上添加脂质引起的原生分子间能量变化，即含脂质减干受体，单位采用 Vina 的经验 kcal/mol 标度。删除一项时同时对两种受体将该权重设零后重算。每列单独进行删除实验。

|查询|全部原生相互作用|将氢键权重置零|将短程排斥权重置零|
|---|---:|---:|---:|
|α 糖|−1.1134|+0.4358|−2.3912|
|β 糖|−1.0872|+0.3253|−2.2570|

A502 的极性吸引与短程排斥部分抵消。其五项连续解析模型对 α 糖给出氢键 −1.549、排斥 +1.277，其余两项高斯接触 −0.674。A501 在晶体坐标的贡献主要是较远距离的第二高斯项（约 −0.17），A503 无 8 Å 内配对。葡萄糖所有碳均连氧，在 Vina 的疏水 C_H 规则下没有独立疏水配对。连续解析分项仅供定位；引擎对距离查表及正能逐原子压缩，剧烈冲突的姿势中解析增量与原生之差最大 2.32。排名全部以原生求值为准。[逐脂质连续分项](results/components.csv) · [原生权重消融](results/weight_controls.csv)

β 糖原干池（12,000，43103）提供了评分失误的配对例子。原首位 4.080 Å 姿势中的糖 O 与 OLC502 O25 仅隔 2.139 Å；恢复脂质后其原生相互作用恶化 +2.169。原次位 2.825 Å 姿势则改善 −1.097 并升为第一。池内第 3 和第 8 名分别为 1.562 和 1.152 Å，添加脂质后分别恶化 +1.786 和 +1.674。局部 O2–O25 晶体接触得到较有利能量，并不足以让整个近晶体候选盆地得到正确排名。

## 复现与成本

同一 Pro 二进制（b991eb7，SHA-256 见下）对 8 个干受体条件使用 1.781 秒墙钟，共 241,121 次搜索求值、3,043 次显式精修求值。三脂质准备耗时 0.137 秒，8 次搜索为 1.914 秒、241,353 次搜索及 2,900 次精修求值，单进程最高 RSS 123,892 KiB。去 A503 后另耗 1.909 秒，241,230 次搜索、3,043 次精修求值。288 次冻结重算合计 6.81 秒，含进程启动和解析。绝对时间是本机单次观测。对给定受体的准备可由多个配体复用。[原始运行和增加的脂质坐标](runs.tar.xz) · [预算与成本](results/cost.csv) · [二进制](results/binary.json) · [CCD 的来源和校验和](results/source.json)

从仓库根目录运行。沿用父目录的软件环境，PDB 与查询原始档案在父目录，OLC.cif 已在本目录归档。复现程序在两次独立输出目录产生相同的 16 份 PDBQT 和所有科学数据表。[复现核对](results/replay.json)

~~~bash
D=benchmarks/ligand_hydroxyl/glucose/lipid
W=$(mktemp -d)
mkdir -p "$W/sugar"
tar -xJf "$D/../evidence.tar.xz" -C "$W/sugar"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python "$D/restore.py" "$W/sugar" "$W/lipid" /path/to/pro/vina
python "$D/paired.py" "$W/sugar" "$W/lipid" /path/to/pro/vina
python "$D/controls.py" "$W/sugar" "$W/lipid" /path/to/pro/vina
~~~
