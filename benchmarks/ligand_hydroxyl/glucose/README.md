# 饱和醇的受氢方向能否改善葡萄糖姿势？

用 Galectin-3C 中子实验开发的孤对几何，在人葡萄糖激酶和葡萄糖转运体 GLUT3 上做了预先登记的重对接。两个靶点、三个晶体结构、四种受体–异头体组合，各有两个种子和两档预算。上游 1.2.7、分支基线 b991eb7 各运行 16 次，两个引擎各输出 144 个姿势。各重排方法复用同一批分支候选，运行期间没有读取晶体配体姿势，搜索盒中心使用对应的共晶位置。对称和手性匹配后，在受体原坐标系下以重原子 RMSD ≤2 Å 计为命中。[事前协议](PROTOCOL.md) · [Glucokinase 3IDH](https://www.rcsb.org/structure/3IDH) · [激活态 1V4S](https://www.rcsb.org/structure/1V4S) · [双异头体 GLUT3 的原始实验](https://doi.org/10.1038/nature14655)

先用配体羟基的 MMFF94s 先验积分，再考察两项改动。第一项将只有蛋白向醇氧供氢的一对也纳入修正。第二项用中子实验的两个理想孤对方向修正每个反向接触；该羟基所有接触在同一积分里共享转角。反向接触已纳入时，比较增加孤对方向前后的两个分数可以单独估计受氢各向异性的作用。两者均无额外搜索或精修。[氘方向与受氢核](../neutron/README.md) · [逐姿势分项](results/poses.csv)

| 每轨迹名义求值上限 | 上游 / 分支基线 | 只修正可向外供氢的接触 | 再纳入纯反向接触 | 再加入孤对方向 | 池内命中 |
|---|---:|---:|---:|---:|---:|
| 3,000 | 2 / 3 | 1 / 3 | 1 / 3 | 1 / 3 | 3/8 |
| 12,000 | 4 / 5 | 1 / 4 | 2 / 3 | 2 / 4 | 5/8 |

表中各格为首位 / 前五命中数，每档分母为 8；上游与分支基线的这些计数一致。较高预算下，加入孤对后的条件首位命中为 2/5，基线为 4/5。仅看 4ZW9 的两个异头体会掩盖 3IDH 上的退化。3IDH、高预算、种子 43103 的原生首姿 RMSD 0.793 Å，原分 −7.768；两向氢键加孤对修正后为 −2.969。第三名 RMSD 8.887 Å 的原分 −6.056，修正后为 −4.324，升至首位。天然排在前面的密集极性接触受到更大的总惩罚。1V4S 的同一查询在两个预算中合计只有一个池有近晶体姿势，各模型均选对了它。这样的对照不足以支持把这个物理项用于默认排序。[全部候选池和各臂名次](results/cells.csv)

1V4S、3IDH 的糖占据率均为 1.0。1V4S 中变构激动剂 MRK 与糖最近 16.23 Å，不能把 MRK 的亲和力算给糖。4ZW9 中 α/β 糖占据率为 0.69/0.31；同一晶体内还解析到单油酸甘油酯。其 O25 距两个异头体的 O2 分别仅 2.460 和 2.488 Å。干燥受体制备移除了这条实验观测到的局部相互作用。两种异头体、两种预算和两个种子不能视为独立蛋白样本。结构作者指出，晶化脂对生理结合和转运的影响尚未表征。[GLUT3 原论文 Extended Data Fig. 4](https://www.nature.com/articles/nature14655)

在一台机器上，这 16 次单 CPU 分支搜索墙钟合计 3.65 秒，搜寻与显式精修分别累计 482,335 和 5,835 次求值。上游 16 次合计 14.64 秒，同时涉及官方二进制与本地构建的实现和构建差异。三次受体制备约 13.37 秒，四次配体制备约 0.08 秒。144 个分支姿势的方向积分及消融合计 0.277 秒，追加受氢方向计算约 0.334 秒；均在 Python 端单线程执行。这里没有同测定亲和力终点。[原始命令与成本](results/compute.csv)

从仓库根目录复算。归档含源坐标与 CCD、准备好的 PDBQT、所有 CLI 命令、输出、日志、SHA-256 和依赖版本。用准备好的输入可跳过下载和重新制备。可单独重跑 prepare 和 dock。

~~~bash
D=benchmarks/ligand_hydroxyl/glucose
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1 OPENMM_CPU_THREADS=1 OMP_NUM_THREADS=1
tar -xf "$D/evidence.tar.xz" -C "$W"
python "$D/evaluate.py" "$W" "$W/replay"
cmp "$D/results/cells.csv" "$W/replay/cells.csv"
python "$D/run.py" "$W" prepare
python "$D/run.py" "$W" dock --upstream "$UPSTREAM_127" --pro "$BASELINE_PRO"
~~~
