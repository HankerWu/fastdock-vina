# 配体羟基的不可辨识方向与冻结坐标实验

设计基于 b991eb7，登记时未计算本研究的分数。先用历史 ESR2 的酚羟基定位机制；报告 hydroxyl_partition 的所有预存池（含 ESR2），另按验证成员预先选择的新人源结构独立预测。已经在仓库评估过的姿势集只作回顾性证据。固定三个同测定面板、旧坐标和转子标度（Gal3 Kd、FXa Ki 和 S6K1 Kd）。全程不调权或据结果更换结构。

选 Meeko SMILES 图上无电荷、携带一个显式极性氢、仅连一个芳香碳或 sp3 碳的醇/酚（要求 C 上至少一个其他重原子定义方位）；羧酸和烯醇不在范围内。对每个配体 O-H 和所有受体 N/O 受氢位点，共用一个方位角。重原子全固定。两边都能供氢时，以更好的一侧代表该重原子对。沿用既有 Vina N/O 径向强度、D–H···A 几何和转子分母。对照：原生；只对选定羟基接触用输入 H 的方向；仅将这些 H 绕 C–O 转 180 度；共用最佳角；均匀角积分；以同一配体的 MMFF94s 正二面角势为先验的积分；以及完整历史固定 H 方向项中分别替换上述羟基。主预测是只改羟基、使用 MMFF 正二面角积分。没有获得 MMFF 参数时单列，主预测严格不以均匀先验替代。角积分采用 72 点、298.15 K，设计不包含经验阈值学习、分子内非键氢键、显式水或完整溶液构象分布。

若冻结坐标的 Vina 报告和重原子 RMSD 完全不变，而输入 H 方向不同使同一重原子候选的固定角分数或池排序发生变化，即支持方向不可辨识在真实数据上影响模型的假设。积分应在任意全转角后保持不变（以同一重原子方位原点求积）。求积加密至 144 点检查稳定性。以对称性重原子 RMSD ≤2 Å 统计 Top-1、Top-5、池上限和各方向上的得失；按结构和靶点分组，不将重复种子独立计数。测定内至少三倍的分子对、平局半分，同受体取种子中位数再作受体均值，同时报告 Spearman、Kendall。没有一致预测收益就保留研究算法；不改变默认搜索或报告。

理论与数据入口见 [AutoDock Vina 的 united-atom 模型](https://doi.org/10.1002/jcc.21334)、[原作者对输出氢坐标的说明](https://autodock-vina.readthedocs.io/en/latest/faq.html)、[固定受体方向模型](../frozen_core/hydroxyl_partition)、[MMFF 扭转项](../frozen_core/hydroxyl_evidence) 和 [既有实验数据与聚合定义](../terminal_rotor_score)。
