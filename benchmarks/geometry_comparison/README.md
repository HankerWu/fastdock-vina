将两个干口袋搜索结果合并，在同一批输出坐标上更换评分受体，BRDT 的交叉首姿由 1/6 提高到 5/6。BPTF 的六个交叉方向首姿仍为 0/18。两项结果共用固定配体图与未结合态参照，仅重新评分。BRDT 的另一个晶体链能够恢复 Lys60 接触，较强配体在该链的中位分数仍然偏高。详见[等搜索预算的候选池重排](pooled_water/README.md)和[链拷贝及局部接触复算](water_transfer/chain_copies/README.md)。

计数的单位是结构或方向与随机种子的组合。首位指最低报告分数的输出姿势，候选池指最多九个实际输出姿势中至少一个满足受体坐标系、化学对称映射后的重原子 RMSD ≤ 2 Å。所有结构对接均假定结合口袋已知。
每个对照在其对应目录中记录了具体二进制、种子、预算、输入和衡量方式。不同种子组、受体版本和配对实例的分母不相加作为独立样本量。

## 使用方式

`--refinement_optimizer geometry` 适用于从刚性受体直接构建网格、单配体、Vina 势函数的常规全局对接。显式末端精修调用解析度量。独立比较可以保留其余选项，用 `--refinement_optimizer armijo` 替换该值。实测增强搜索的 Native 对照沿用原生 pose selection 和原生精修。CPU 实验用一次单独的时间标定来选择每轨迹评分上限，阈值依赖机器、受体与配体。官方基线也是指定评估上限的配置。完整命令见上述各实验目录。

在对比配体亲和力时，先固定同一受体、同一测定及配对方式，再报告分子强弱排序。BACE1 的两个酶学 Ki 系列、激酶的结合 Kd 系列和 BPTF 的两种直接测定均分别处理。对已有复合物，构象投影可以帮助决定该投入搜索、受体建模还是能量排序，其晶体输入仅用于误差诊断。
