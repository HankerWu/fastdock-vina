# Historical BFGS attribution on the frozen equal-cap panels

The measured default parent and stable have a large reciprocal Top-1 gap at 12k (20 paired cells). This follow-up was designed after seeing the parent/stable results; it is a causal historical intervention on a known panel, not a new holdout or a reason to select a per-target optimizer. No outputs from the two intermediate builds have been generated for this study yet.

Build exact historical `e7031e9aabc0b31fd371370763bc3810748a4cfa` (pre-failure-retention) and `232643049094dee7fece70498f77f5271d621949` (accepted point retained when line search fails). `6c251f51c3508454ebb34b6337948525f2a6062a` also corrects the sign of the initial inverse-Hessian scale and has identical entire `src` tree to the round-start stable `f46aa37`. Verify the only `src` difference between each pair is `src/lib/bfgs.h`; use each commit's `tools/build.py` and the primary GCC/Boost settings. Test every 12k cognate and reciprocal query and both seeds (40 runs per additional build) with exactly the baseline CLI, seed, limits and passive native counters. Use no crystal information as search input. Include bytes/logs/cost for all runs and check all metric values against their released coordinates. Report successive paired Top-1, Best@5, oracle and regret changes, per-case improvements/losses/ties, and the residual gap to the true parent. Also count hunt proposals and gradient evaluations from native logs to separate fixed cap from fixed trajectory length.

A changed paired output with a single source header changed establishes the trajectory consequence of that revision under the stated compiler/inputs, not that every trajectory saw a failed line search or negative curvature. Equal output is the negative outcome for that cell. If pre-fix results reproduce the parent, the remaining cumulative gap is near zero there; residual differences identify additional historical changes to be localized. Contrasting signs across the two revisions or across targets require retaining that heterogeneity. Both historical patches repaired real optimization defects; do not promote an uncorrected solver based on this retrospective analysis. No new physics, new retuning or stable selection in this test.
