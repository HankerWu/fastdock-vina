# 一个共同配体校正是否同时满足所有排序约束

固定父研究的 1024 节点首姿、原生与联合积分两臂、Gal1/Gal3 与三个 Davis 激酶两个面板。在一个靶点的同测定中仅保留两个精确 Kd 相差至少三倍的分子对，允许只有部分配体在多个靶点测过。对每个面板和评分臂先分析全图。然后找出在任意两靶上方向相反、且不能用两配体共同零点同时满足的配体对，从全图排除该无序配体对的所有靶点边。剩余配体与可满足的反向配对继续保留。删除已知局部矛盾仅用于检查是否仍有由三种或更多配体构成的矛盾。

对强者 i、弱者 j 设约束 b_j−b_i>S_ti−S_tj。在有向图上计算最大平均环权，并以独立线性规划验证统一放宽量的下确界，记录达到上界的具名回路或无环结果。全图和剩余图逐一给出，不根据结果改换分离阈值、排除规则或打分臂。上界使用全部实验标签，只检验共同参考项的表达能力。没有独立分子对计数、加大采样或修改默认模型。
