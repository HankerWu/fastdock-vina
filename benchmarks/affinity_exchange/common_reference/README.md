# 每对配体都能单独调对，同一套游离态参考还能让全组同时正确吗？

三个 Davis 激酶给出了一个三配体反例。对联合刚体–扭转积分的现有分数，sunitinib 与 SU-14813 的实验强弱、SU-14813 与 crizotinib 的强弱、crizotinib 与 sunitinib 的强弱，每一对都允许某个配体校正值满足自己的观测。要为这三种化合物各指定一个在所有靶点上共用的值，三条要求却相互矛盾。同样的检验在 Gal1/Gal3 上得到另一个结果。去除原研究已经识别的局部矛盾后，其余观测可以全部同时满足。[原研究](../README.md) · [本次分析条件](PROTOCOL.md)

## 跨靶点的差分约束

同一实验靶点上的 Kd 至少相差三倍时，将较强配体记为 $i$、较弱配体记为 $j$。先沿用现有分数 $S_{ti}$，再给每个配体加任意共同偏移 $b_i$。使这对排序正确要求

$$
 b_j-b_i>w_{tij},\qquad w_{tij}=S_{ti}-S_{tj}.
$$

偏移 $b_i$ 可以代表在这个经验刻度上用一个靶点无关的溶液参考修正同一配体。靶点自身的常数在同靶点相减时消去。这个假设对能用于预测的游离态模型十分宽松，每个配体都可以利用全部实验答案取不同的偏移。条件依赖的质子化、溶剂和构象响应可能不能由这样的共同偏移表示。

将每个比较写成一条从强配体指向弱配体的边。沿有向环把不等式相加，左端精确为零。因此环上边权和为零或正就足以排除所有共同参考解。反过来，有限图中所有环的权重和都严格为负时，确实存在同时满足全部约束的偏移。令 $\mu$ 为最大有向环平均权重，可将可行性定量化为

$$
\mu=\min_b\max_{tij}\{w_{tij}-(b_j-b_i)\}.
$$

这条等式适用于含有向环的图。将 $\mu$ 从每条边减去，所得图不存在正权环。从一个连接所有配体的零权源出发取各顶点的最长路径值，就得到满足所有非严格修正不等式的偏移。达到最大平均权重的环给出相反方向的界。$\mu>0$ 表示至少一个排序分差要让步这么多才可能同时达到非严格要求，严格排序的统一让步必须再大一点。$\mu<0$ 表示存在使全部可靠对都留出至少 $-\mu$ 正间隔的解。这个量既不能换算为错对数，也不估计未知配体的预测误差。

## 两个面板的完整结果

从原有 500 条首姿观测重新构建 1024 节点两个评分臂，先取同配体、靶点和受体构象内的种子中位数，再平均构象。Kd 单位统一为 nM，逐条与原始标签表核对。Gal1/Gal3 含 13 个配体，三个 Davis 激酶共 24 个有测量的配体。每条边在其自身测定内比较；同一配体可出现在多个靶点，比较对不能当作独立样本。[Galectin 原始测量](https://doi.org/10.1021/acs.jmedchem.7b01626) · [Davis 原始测量](https://doi.org/10.1038/nbt.1990) · [原始结构与积分协议](../../affinity_reference_ensemble/README.md)

## 一个没有局部矛盾的三角形

看到原生最大四环中存在被排除的非相邻配体对后，另在所有三元组内检索更容易解释的反例。要求三者中任意一对都未因两靶反向不相容而被排除。下面列出两个评分臂中满足此条件的全部非负环三元组。各行从较强者指向较弱者，分数低代表预测较强。

| 分数 | 靶点 | 较强配体 → 较弱配体 | 两者实测 Kd（nM） | 两者分数 | 要求的偏移差下界 |
|---|---|---|---|---|---:|
| 原生 | CHEK1 | LY-333531 → R406 | 540 → 2500 | −4.21225 → −8.60225 | +4.39000 |
| 原生 | AURKA | R406 → sunitinib | 160 → 1700 | −8.45950 → −7.40925 | −1.05025 |
| 原生 | S6K1 | sunitinib → LY-333531 | 48 → 210 | −7.43700 → −4.14350 | −3.29350 |
| 联合积分 | CHEK1 | sunitinib → SU-14813 | 300 → 1200 | −4.55588 → −5.32207 | +0.76619 |
| 联合积分 | S6K1 | SU-14813 → crizotinib | 150 → 640 | −4.92985 → −5.36964 | +0.43979 |
| 联合积分 | AURKA | crizotinib → sunitinib | 260 → 1700 | −5.96608 → −4.95005 | −1.01603 |

原生三式相加要求 $0>0.04625$，联合积分三式相加要求 $0>0.189945$。这两组三元组均由三个不同靶点贡献边。它们证明只检查两个配体、两个靶点会漏掉全局不相容性。原生三环量级很小；精确算术只保证归档分数下的结论，换构象、积分方法或测定条件可能改变它。这里没有重估实验误差、局部势或溶剂模型。[所有最大环与三环的逐边浓度和分数](results/witnesses.csv)

## 复算

从原始 CSV 的十进制字符构造精确有理数。对每个配体作为起点，按路径长度动态规划各顶点的最大得分，检查长度从 1 到配体总数的所有闭路。简单环长度至多等于配体数，因此不需要枚举所有简单环。脚本同时用精确偏移核查全部边的上界，并调用独立的 SciPy/HiGHS 线性规划核对八个最优值。原始输入散列已随父研究登记。主复算仅用 CPU，端到端约 1 秒，含读取输入、证书检查和输出；未重新生成姿势、运行自由能模拟或改变生产评分。[计算时间](results/cost.json) · [父研究输入散列](../results/inputs.json)

```bash
D=benchmarks/affinity_exchange/common_reference
W=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 python "$D/cycles.py" "$W"
for f in constraints optimal_offsets summary witnesses; do cmp "$W/$f.csv" "$D/results/$f.csv"; done
```
