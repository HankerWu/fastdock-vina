# 受体构象占比与共同配体参考的联合不可辨识性

## 问题与冻结范围

此前的共同游离态参考检验固定了受体聚合方式。本研究同时放开靶点特异、配体无关的 apo 状态概率及任意配体特异、跨靶点共同的加性参考。若仍存在矛盾，则无法仅靠这两种修正恢复排序。基线为 019c9ffd219c1fea7129973d26d4049a16b75682；使用此前同测定的 73 个靶点–配体条目（不是 73 个独立分子），不新增 docking、不拟合参数。四个双态靶点以四种子 native 首姿中位数作为状态代理值；S6K1 仅有一个归档受体状态，使用 primary_ligands.csv 中已归档的 native 中位数。不是对所有物理受体构象的否定。

输入来源：../../galectin_affinity/results/readback.csv、../../torsion_kinase_affinity/cells.csv、../../affinity_reference_ensemble/results/primary_ligands.csv。两态中位数的算术平均与原 primary native 表逐行一致；此核验只用于确认历史数据身份，不将算术平均当作热力学聚合。

## 推导

设 s(t,i,k) 为固定状态 k 中的经验分数，p(t,k) 为同一游离受体在各状态的占比，和为 1。共同配体参考 b(i) 与状态和靶点无关：

    G(t,i) = -RT log sum_k p(t,k) exp[-s(t,i,k)/RT] + b(i)

这是一种对固定状态分数的形式化热力学聚合；只有 s 真正为一致参考态下的状态结合自由能时，才有严格热力学解释。对同靶点两配体定义 d(t,i,j)=G(t,i)-G(t,j)-b(i)+b(j)。指数比是 exp[-(s(t,i,k)-s(t,j,k))/RT] 的正权归一化平均，故

    min_k [s(t,i,k)-s(t,j,k)] <= d(t,i,j) <= max_k [s(t,i,k)-s(t,j,k)].

两靶点交换差 X=d(t,i,j)-d(u,i,j) 消去所有共同配体参考，必落在区间 [min d_t - max d_u, max d_t - min d_u]。各靶点权重独立时单个交换区间的两个端点可达；但不同配体对共享权重，不能假定每个区间端点同时可达。若两个靶点实验排序相反且该区间只能产生反方向，则不存在联合修正。区间到实验 RT log(Kd_ti Kd_uj / (Kd_tj Kd_ui)) 的距离是固定分数模型交换误差的乐观下界；非真实自由能 MAE。

进一步构造有向边 i -> j 表示同 assay 中 i 至少强于 j 三倍，则严格正确排序要求 b(j)-b(i)>d(t,i,j)>=min_k(s_i-s_j)。在闭环求和时 b 抵消。若边权下界之和非负，任意 p 与 b 都不能使环上所有边严格正确。最大平均环权为原联合问题最优最大违约量的保守下界。用有理数算术和已有 common_reference/cycles.py 的独立 HiGHS 线性规划交叉校验；负下界不意味着原联合问题一定可行。

    S6K1 153999 -> 9829523     +7.3195
    AURKA 9829523 -> 16007391   -3.3175
    AURKA 16007391 -> 5329102   -0.1510
    S6K1 5329102 -> 153999     -3.2935

这个四边环中的每条边已通过移除直接不可恢复反转的筛选；它说明排序约束的传递性仍可间接推出同一不可兼容关系。不是四个独立反例，也不是新的真实物理能垒。全部五个强反转证书、区间及图证书见 result.json。即使每个打印的状态分数有 ±0.0005 误差，单个交换区间最多移动 0.002，四边环每边最多移动 0.001；上述正证书仍成立。此仅为打印精度敏感性分析，未评估 seed、结构、实验测量或力场不确定性。

## 解释与限制

在给定原始 native 分数、给定受体状态和共同游离态修正定义下，单独或联合调整现有状态占比和共同游离配体参考不能完全恢复亲和力排序。应优先检验结合态中缺失的靶点–配体耦合自由度，而非继续拟合参考项。尚不能区分状态遗漏、结合模式缺失、水/离子、蛋白重组、质子化和势能误差；也不能否定加入新的受体状态或结合盆地后的模型。不同靶点之间共同配体参考假设要求溶液条件可比；实验条件差异、微态差异可破坏消去。仅冻结历史首姿分数，未计算新的 RMSD、预测秩相关、真实自由能或动力学。未修改生产引擎。

后续建议以强反转配对为机制诊断起点，先检查配体身份/测定条件/结构、构象池与参考态，再在明确需要时采用一致 Hamiltonian 的显式溶剂两相自由能及盆地约束/释放计算。不要将本证书作为新的经验修正项。
