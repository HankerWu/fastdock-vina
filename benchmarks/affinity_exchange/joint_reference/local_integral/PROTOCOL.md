# 共同游离配体参考与受体占比的联合检验

上轮的共同配体参考采用受体分数的算术均值；此前的受体混合给定每个配体的能量零点。本轮在读取联合结果前固定以下问题与检验。对每个靶点共享一套任意游离受体占比，另允许每个配体有跨靶点共用的任意加数。在这种有权使用全部实验答案的模型类里，能否同时判对同一个家族内所有满足三倍实测 Kd 差异的配体对？

* 复用 500 条冻结首姿记录、按受体/配体取种子中位数、原生与联合刚体–扭转积分两臂。主分析 1024 节点，敏感性复核 8192 节点。数据源及纳入标准沿用父研究。每个家族独立分析。每个受体结构都有共同定义的条件经验分，仅作为能量刻度代理。
* 两受体采用 298.15 K 下缔合因子的算术混合，游离占比从 0 至 1；S6K1 只有一个受体。对同一靶点、两种配体的分差作两端解析检查。列出即使独立选取各靶点占比与共同配体偏移也无法同时挽救的双侧可靠反转。
* 以所有可靠边为主，剔除上一步所有不可解的无序配体对为次分析。对每个固定占比，用差分约束求最优共同配体偏移。每条不等式右侧在占比矩形上的最小值都位于端点，因而可用放松后的图给出对整块占比有效的下界。找出环或直接给出使所有排序成立的占比、偏移作为证书。对已证不相容的结论无须通过增加网格密度重复搜索。基线报告两受体等概率，另保留原先等能量均值的口径。
* 报告循环证书的能量单位、原始逐条件分数、计时及分母。给定见证可以检验某个解释是否可能；标签可见的解不作为前瞻排序或真实配体游离自由能。条件评分、相空间覆盖、受体选取、实验条件等保持原有局限。无需增加对接轨迹或向引擎添加新开关。

本方案在本轮联合结果计算前拟定。当时本地基线为 019c9ff。随后并入的 910590f 已独立分析原生臂；发布时将其作为上级研究，本扩展重心为局部运动积分、可行解，以及两路原始输入的一致性。
