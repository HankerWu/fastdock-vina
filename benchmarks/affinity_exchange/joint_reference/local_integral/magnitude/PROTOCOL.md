# 事前问题与判据

基线 ae19b9f。此前已经用标签回答同一配体共同偏移与受体混合能否恢复排序。本实验检验更强的解释：在现有能量刻度、同样状态及标签下，这两种修正再加每靶截距，是否足以同时解释全部已测浓度的**幅度**？若多靶多配体闭合交换差仍有误差，至少一个交叉项、能量刻度或实验比较条件有待修订。单个受体时的算术平均矩阵 RMSE 投影不能回答任意状态占比下的这个问题。

- 每个家族单独以所有精确 Kd 单元为统计对象。主实验重用 1024 节点首姿的两种分数；8192 节点检验数值敏感性。给零条件分数同样的截距、偏移权限，作为独立于任何相互作用建模的对照。
- 逐格求任意共同占比及偏移下的最小最大绝对残差。用靶点–配体偶环的交换差下界与可直接代入的逐格上界，在连续占比域上夹逼至 0.001 kcal/mol 以内。检查均值、Galectin 的逐格 ±1 SEM 区间；激酶无同类误差数据。
- 若排序全可行而幅度仍有严格正残差，则“排序相容即可解释观测浓度”的解释被排除。积分相对原生及零分模型的上下界区间若分离，才判断这项标签可见的最优幅度相容性改善或退化；区间重叠时保持未定。证书和实际见证仅约束冻结模型类。保留数据来源、全部输入/结果、证书及复算命令，不改对接引擎。
