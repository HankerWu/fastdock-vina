# 局部运动积分是否改变受体占比与配体参考的联合相容性？

在人 Galectin-1/3 的 13 个配体上，联合刚体–扭转积分的条件分数允许一套受体占比和配体偏移同时满足全部 58 条可靠强弱约束。固定配体零点时，任意受体占比最多分别满足 18/23 和 34/35；固定等受体占比时，任意配体偏移也无法全部满足。三个 Davis 激酶给出反例。即使两类变量都可以看完所有 Kd 再选，联合分数仍至少违反 260 条可靠约束中的六条。这个差异能回答“这两类物理遗漏原则上够不够”，还不能确定它们在溶液中的实际数值。[事前方案](PROTOCOL.md) · [全部判定](results/summary.csv)

[上一级原生分数研究](../README.md)已给出原生在全部占比下的反证。这里沿用该研究的物理模型、原生对照和同测定观测，新增联合刚体–扭转积分的条件评分，检验这些反证是否仍成立，并用显式占比及偏移解决仅凭负下界无法判定的可行性。未将原生复核计作独立数据或新增研究发现。

## 从条件结合因子得到可检验的不等式

设第一个和第二个游离受体亚态的分数为 $s_{ti0},s_{ti1}$。在同温度、共同标准态下，若它们代表给定受体亚态的标准结合自由能，共同游离受体占比 $1-p_t,p_t$ 产生

$$A_{ti}(p_t)=(1-p_t)e^{-s_{ti0}/RT}+p_t e^{-s_{ti1}/RT},\qquad S_{ti}=-RT\ln A_{ti}.$$

真实缔合常数除以标准缔合常数后无量纲。实验中代入首姿的 Vina 或局部积分经验分，取 $T=298.15$ K、$RT=0.5925$ kcal/mol 左右。调节任一受体亚态所有配体共同的能量零点，可以吸收到共同占比与每靶加数中。给每个配体再加一个跨靶点共用的能量 $b_i$，等价于把其所有结合因子乘同一正数。单受体 S6K1 只有后一种自由度。更换探针、缓冲、配体微态或改变条件结合面时，共同 $b_i$ 未必成立。[结合分布的统计力学原始推导](https://doi.org/10.1063/1.4751284)

若同一测定内配体 $i$ 的 Kd 至少比 $j$ 小三倍，定义 $w_{tij}(p_t)=S_{ti}(p_t)-S_{tj}(p_t)$。要同时恢复全部严格次序，必须对每条强→弱边满足 $b_j-b_i>w_{tij}$。沿任何有向环相加，左侧为零。$A_{ti}/A_{tj}$ 是同一 $p_t$ 的两个正仿射函数之比，其导数的符号恒定或恒零。因而每条边在任一占比区间上的精确下界取在端点。若某个环的逐边下界之和仍为正，就证明整块占比上的所有偏移都会出现至少一个严格反向的分差。同靶多条边各自最优的占比可能不同，逐边下界只会使这个反证更保守。对于只含两个靶点的一次反向配对，两靶占比独立可调，端点和也是该环的精确最小值。可行则直接输出一组 $p,b$，逐条代入检验。[逐受体分数与 Kd](results/states.csv) · [所有双靶反转](results/reversals.csv) · [环及下界](results/cycles.csv) · [可行解](results/feasible.csv)

**Galectin 的相容性如何改变。** 联合积分以 Gal1 的 4Q26 和 Gal3 的 3T1L 分别占比 1，加上结果表给出的 13 个配体偏移后，最小正确分差为 0.116416 kcal/mol。让两者各占 99.9%，保留同一组偏移，最小正确分差仍为 0.115730。高密度积分独立构造的解在 99.9% 时给 0.148679。原生对 8、9 则有直接反证，两个靶点的环权重下界为 $+0.1680-0.1375=+0.0305$ kcal/mol。两配体 Kd 在 Gal1 分别为 140、530 µM，在 Gal3 分别为 31、8.8 µM。改变受体占比、各配体共同零点仍须在至少一侧错序。相反，5/14 和 6/14 在父研究的原生算术均值下有矛盾，但允许受体占比变化后各自都存在解。给定这些标签构造的占比和偏移，不能从现有实验辨认为真实的游离受体占比或溶液自由能。只对 8/9 作已报告 SEM 的敏感性核查，四格在均值 ±1 SEM 内任意取值后，两靶保留反向且各至少相差 490/146 和 29.7/9.1，均超过三倍；这一误差盒并非联合置信区间。

## 复现与独立检验

在 2026-11-27 复核上级研究时，从 Galectin 原始读回表、Davis 原始首姿记录及 S6K1 归档中位数重算的 JSON，与从冻结中位数重算的 JSON 及上级已发布 result.json 三者解析后完全相同。扩展复核逐 PDB 标识检查本实验 500 首姿路线对应的 73 项原生条目、132 个受体条件分数及 Kd；AURKA 表格的受体排列方向不同，按状态标识对应。原生全图下界复得 0.01525 和 0.27875，激酶剩余图下界复得 0.139375。原生 Galectin 剩余图的 −0.09125 下界原先无法判断可行性，此处给出的 56 条可行解将其解决。[上级原生研究与原始数据命令](../README.md)

主程序要求 NumPy、SciPy；复核仅用 Python 标准库，独立从逐首姿原始小数重建各状态中位数，用 50 位十进制缔合因子比计算全部反转、验证每个环的闭合与下界、逐条检查所有可行解及内部占比见证。本次所有不可行图均有覆盖整个占比域的单一证书，无须把有限网格上的搜索失败解释为数学不可能。可行解验证了偏移的存在，报告的负最大违反值只对应其给定的占比。未寻找整域的精确最优值。基于既有数据的计算时间约一秒；未重复历史对接或 500 个首姿的数值积分。[复算计时](cost.json) · [父研究原始输入哈希](../../results/inputs.json)
