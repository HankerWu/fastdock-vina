# FKBP12 八配体、两受体的同测定实跑

**坐标复算勘误。** 首次发布时，本目录的独立 AD4 检查对 Pro 输出也逐通道限幅。当前复算程序按真实引擎选择限幅顺序。历史表保留原值，运行新版所得 Pro 坐标复算分数有细小差异。原生发布分和原始姿势可各自核对。[修复及全池复核](../../affinity_conditioning/README.md)

在轨迹 1 第 1 步提取实际变异后的内部构象，替换一次刚体放置，继续完整的 AD4 搜索。每组保留三条轨迹、单核、24,000 软上限、9 个模式。匹配、取向打乱和当前 Pro 从同一未干预起点分叉。种子固定为 524287，未将相同种子的轨迹、不同共晶受体或 15 对配体当成独立重复。官方 Vina 1.2.7 的 AD4 模式、当前 Pro、48,000 预算 Pro 的输入和原始发布池来自上一轮。16 次带只读观察器的 Pro 均与对应历史池逐字节一致。对三个基线及两个新臂重新从坐标计算 AD4 分数、几何和测定排序。[事前方案](../PROTOCOL.md) · [可复用的源受体、地图及配体哈希](../../cubic_grid/fkbp_ad4/results/metadata.json) · [无注入重放](results/capture.csv)

两个新臂使用各自 AD4 地图制备时的同一蛋白 PDBQT 提取空腔几何。盒心沿用原基准的口袋位置先验。先对两臂构建同一候选库，再保留所有候选质心、取向边缘集合和内部构象，交换取向与质心的对应关系作为对照。两臂分别按同一非能量几何分选一名。AD4 对照均使用原 FKBP 配体 PDBQT 的推断拓扑。额外受体几何来自同一制备，不涉及额外受体构象。药物编号、晶体对齐、实验值均在生成之后才用于评价。全部轨迹使用固定受体、配体微态及 PDBQT 质子化状态，显式平移、旋转和转动单键。两份受体的 Top-1 经验分等权平均，权重未经物种丰度标定。

## 成本与重放

每臂有 16,384 个三点对应拟合可与另一臂共享，之后各做 514,048 次配体重原子到受体最近距离查询。建立两种受体的腔点共作 9,826 次最近邻和 1,925 次半径计数；构建共 0.051 秒墙钟 / 0.051 秒 CPU。16 个事件共享三点拟合 0.097 / 0.097 秒，匹配、打乱分别粗排 0.221 / 0.220 和 0.219 / 0.218 秒。配置、运行、输出的对接进程实测分别为 16.516 / 16.462、16.562 / 16.508 秒，每个臂共 16 池。两臂的 hunt + 二次局优总目标/梯度调用分别为 1,152,990、1,152,914。当前 Pro 历史实测 18.374 / 18.282 秒、1,152,989 次调用，带只读起点提取器的 16 次额外重放 17.508 / 17.427 秒。另用原生场插值计数器逐池重放，输出坐标逐字节一致。AD4 每个原子位置同时查类型、静电和去溶剂三个通道；当前 Pro、匹配、打乱和双预算 Pro 的通道插值数依次为 108,538,317、108,538,878、108,531,111、216,957,906。[逐池原生插值、目标和重放成本](../results/field_replay.csv)。不同时间运行的秒数受机器负载影响，没有据此估计加速比。Python 实验流程需先跑一遍原生搜索获取源态，这笔工作实际发生，不能当作免费。不含后验独立评分与复核的分析耗时。[建场](results/pocket.csv) · [逐项定位时间和查询](results/placement.csv) · [每次对接](results/runs.csv)

分数域为 AD4 经验 kcal/mol，显式态中没有水、离子或受体重组，也没有结合与游离两侧的统一 Hamiltonian、标准体积与约束释放。对 Davis 原始 Supplementary Table 4 的六个 Kd 重新从电子表读取，298.15 K 下三项 RT ln 比值之和为 −8.580231574846 kcal/mol。此处比较的是三个靶点上的选择性浓度比，未得到预测性自由能或误差。原有证书的 12 个可行点及 267 个覆盖框复查通过。[换算和原始表哈希](results/exchange.json)

以下命令从仓库根目录运行。EXE 按上级构建说明生成；FK 是可写临时路径。独立测定复算可直接使用本轮原始包，跳过三次预测命令。

```sh
D=benchmarks/cavity_triplet/fkbp
export OPENBLAS_NUM_THREADS=1
python "$D/place_assay.py" prepare "$FK"
python "$D/place_assay.py" capture "$FK" --exe "$EXE"
python "$D/place_assay.py" place "$FK"
python "$D/place_assay.py" run "$FK" --exe "$EXE"
python "$D/check_assay.py" "$FK" "$CHECKED"
```

直接复核归档时，先执行 prepare，再在 FK 中解压 [blind_forks.tar.xz](blind_forks.tar.xz)，运行 check_assay.py。压缩包含 16 个源态、32 个注入参数、32 个真实分叉的全日志、发布 PDBQT、观察坐标与轨迹池变化、全部候选的变换和排序。原有对照的发布池、原始地图和源配体由 prepare 按 [输入 SHA](results/inputs_fkbp.json) 重建。用原文电子表重算自由能对照的命令为 `python benchmarks/receptor_linkage/aurora/internal_loops/rigid_fkbp/verify_exchange.py "$DAVIS_XLS" "$CHECKED/exchange.json"`。
