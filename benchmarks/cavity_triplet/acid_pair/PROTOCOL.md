# 追加验证：三个羧酸的两种微态

追加原因是前两块采用单一配体微态。主试验已完成，这块另行冻结，不能作为原始预注册面板。纳入 frozen acid_states 的全部三个配体，取每个唯一异源共晶受体，即 2NNQ→3FR2、3FR2→2NNQ、3FMZ→1RBP。按输入文件取同一分子的中性酸（HA）与羧酸根（A），不据历史表现挑分子或状态、不用测定。受体/盒在每对微态内相同，输入重原子位置相同，去质子化更改 O 电荷、供氢与 OH 扭转自由度。各态保持自己的原图，使用基于 PDBQT SMILES/INDEX 的完整显式边表；对照官方 Vina 按上游推断。每格种子 91813、两条轨迹、单核、每轨迹 25k 名义上限、9 模式，Pro 使用 late，并保留 50k Pro 和官方 Vina 25k/50k。每个新臂只替换首轨第一步，随后正常搜索，使用相同已冻结三点算子和取向置换，不在此面板调参。

若形状项可以跨电荷态稳定提高覆盖，matched 的实际发布池 Oracle 应在同一配体两种状态中均比 sham 更低，且多个分子重现；反例为换状态即换方向，或生成覆盖进步而粗排和最终发布未获益。只有同一微态内部的 match/sham/base 配对可归因于提议器；去掉羧酸质子也改变 Meeko 扭转树和真实 MC 起点，不把 HA 对 A 的差值全部归因于电荷。所有候选及入选、hunt、最终排名用查询态化学图对应到晶体，A 等价羧酸根两 O，HA 固定羰基和羟氧，同时给出允许交换的敏感性。报告逐格、分态及成本。本轮仍不推断溶液 pKa、微态占比、实测多态构象或标准自由能。
