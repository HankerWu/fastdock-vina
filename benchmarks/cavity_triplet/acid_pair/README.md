# 羧酸 HA 和羧酸根 A 的配对异受体对接

三个有共晶的羧酸具有三个不同的 Bemis–Murcko 骨架。前两个结合脂肪细胞脂肪酸结合蛋白 FABP4，A1120 结合视黄醇结合蛋白 RBP4。每个分子均投到另一份蛋白晶体受体。两种配体化学态的制备重原子坐标逐项相同，三对原子数分别为 36、23、28。A 相对 HA 少一个氢、净电荷从 0 变为 −1，去除了可动羧酸 OH 自由度，供氢与 Vina 原子类型也改变。相同种子的真实原生变异因扭转树和状态不同而改变。每个微态内部固定受体、盒、微态、真实源提议和完整键图，独立实例间不假定等价。此块在主结果之后追加，在首个新运行前另行冻结。结构数据库给出了一个位置作为参考，晶体没有给出每个微态独立占比或分离的 bound geometry。[追加协议](PROTOCOL.md) · [原始化学制备和证据](../../cubic_grid/acid_states/README.md) · [状态与映射数](results/microstates.csv) · [骨架和初始坐标差](results/scaffolds.csv)

所有组为每次两条轨迹、单核，盒宽 24 Å。Pro 输入由每个状态的 SMILES 键和保留显氢的 H PARENT 建立。官方软件自行推断拓扑，保留原生发布流程；官方两档各六池与上游计数版逐字节一致。36 个实验池又经独立场计数二进制重放，逐池字节一致。新干预每臂额外 178,176 次距离场查询、6,144 次共享三点拟合。生成前各受体建场 4,913 次最近邻，三受体另有 2,217 个合格点查询包埋近邻。三受体建场合计 0.059 / 0.059 秒（墙钟 / CPU），提取源态的费用包含在单独的 Pro 基线进程内。共享三点拟合 0.035 / 0.035 秒，匹配与打乱分别再用 0.109 / 0.109、0.102 / 0.102 秒粗排。官方预算两档的单次跨进程计时并不单调。[原始进程计时与求值](results/cost.csv) · [精确场调用与诊断成本](results/field_calls.csv) · [候选查询](results/generation_cost.csv)

36 个池无空池，307 个发布姿势最大重键长漂移 0.00131 Å，三个分子均无指定四面体手性中心。匹配和打乱最短受体–配体重原子距离分别 2.328、2.139 Å；官方单预算 6 个、双预算 4 个低排名模式有小于 2 Å 的重原子接触，最短 1.505 Å 出现在阴离子 A1120 的芳碳和 Ile41 CD1。这些是具体的短接触，不据此判定游离或结合自由能。利用另一套按制备原子序号、四元数受体对齐和氧等价处理的实现，从发布坐标逐模式复核两个氧映射口径，最大差 1.42×10⁻¹⁴ Å。[逐姿几何检查](results/chemistry.csv) · [独立复核](results/independent.json)

## 复现

仓库根目录下，W 为该实验工作路径；BIN 是上级 observer 构建，OFFICIAL 是官方 1.2.7 Linux 发行版，COUNTER 是已验证上游搜索计数程序。FCOUNTER/UCOUNTER 为上级协议中的 Pro/上游场计数版。统计使用 NumPy、SciPy、RDKit 及 Gemmi。输入、程序及档案哈希见 [输入](results/inputs.json)、[程序](results/binaries.json) 和 [档案](ARCHIVE.sha256)。

```sh
D=benchmarks/cavity_triplet/acid_pair
export OPENBLAS_NUM_THREADS=1
python "$D/run_acid.py" "$W" "$BIN" "$OFFICIAL" "$COUNTER"
python "$D/evaluate_acid.py" "$W" "$OUT"
python "$D/check_replay.py" "$W" "$OUT" --field-counter "$FCOUNTER" --upstream-field "$UCOUNTER"
```

只做离线复算时，把 [本轮原始归档](raw.tar.xz) 解到空 W，运行最后两个 Python 命令，并省去 field-counter 和 upstream-field 两个选项。归档含每个状态的实际输入、图、变异坐标和随机种子、6×2×1,024 个对应的变换/粗分、注入规格、各个实际池、日志、进出记录和二进制哈希。按重原子状态和独立原始 PDB/CCD 重算几何时，后验评价另外从仓库已有的 human_panel/depositions.tar.xz 取原始结构。
