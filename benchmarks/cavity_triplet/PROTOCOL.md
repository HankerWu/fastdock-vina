# 受体腔点三角对应能否把原生提议送入可捕获的结合位置？

事前冻结于父版 501ac58057a61e5d46cde2f4f3df4c8565ffb1ac。原生调用为 Vina::global_search → parallel_mc → monte_carlo::operator() → mutate_conf → hunt 的 quasi_newton → Metropolis → 可选第二次局优 → add_to_output_container → 合池、精修、late 发布。每次只在指定 mutate_conf 返回和 hunt 之间替换刚体位置、取向。扭转、图、接受、容量、精修与排名全部按对应亲本。

## 同一配对上的相反预言

1. 若口袋的多点对应具有超出位置与取向边缘分布的结合信息，在固定原构象上，完整对应比打乱匹配更常产生低受体框架 RMSD；送进 hunt 的坐标及返回值也应更低。开发以 18 个事件的逐事件最低生成 RMSD、送入 hunt 与返回 RMSD 的配对中位差为依据，优先看三个差值是否同向为负。端到端收益还需独立面板的发布池 Oracle 和 Top-1 同时改善，分子间方向相反或尾部恶化须单报。
2. 若效果来自长距离重置或匹配了错误的局部空腔，交换不同提议的取向并保留相同质心集合与取向集合会持平或更好。若最低生成 RMSD 确实降低，但粗排选择或 hunt 后优势消失，定位在已出现的首个损失环节。若两个臂都不生成近姿，这次试验只能限制这个形状提议器。若四项终点互相矛盾、或结论依赖单个分子，结论为局限或未决。阈值 2/3 Å 作计数，不以是否过线替代连续差；同轨迹事件、同配体种子及共享分子对均为相关观测。
3. 第 137 步的已知淘汰使用历史共同坐标和同容量单独复核。它不参与选择入口参数。候选已生成但从未入池和曾经入池后被逐出分别记录。若出现与其他轨迹合并后的相近构象，最终发布的几何接近与特定 ID 的存活区分。

## 放置、对照和锁定样本

在原盒的 1.5 Å 网格上，根据受体重原子近邻、距蛋白 3–5.5 Å 以及 8 Å 邻域包埋排序，取至多 32 个互距至少 2.5 Å 的点。配体三点为相距最远的重原子对与离其直线最远的第三原子。按三条边残差选至多 1024 个有序对应，用禁止反射的刚体拟合放置完整配体，同一套近邻几何粗分取一个送入 hunt。固定非零循环位移打乱取向，保留每个目的质心及两个边缘分布、内部构象、候选数和每个候选的评分成本。普通受体、普通配体和已有口袋盒是定位信息。查询晶体、身份、测定和旧漏边图不进入生成、剪枝、随机种子派生或排序。算法常数与并列规则随事前记录锁定。失败或无法构成三角时记录，不能看标签另换起点。粗分是提议的几何代理；只有原生引擎产生发布池。

- 开发使用完整图 AT9283、2X6E 加 1OL7 released、种子 61231。复用前轮按步号选择的全部 18 个提议（两轨迹第 1 步及每逢 100 步）；每臂每次只替换一处，继续整场搜索。
- 新种子 91813、91823 均用 AT9283、danusertib、BRD9 82I；只改轨迹 1 第 1 步。当前 Pro、匹配、打乱都用完整键图和相同 2×25k 软限，另跑官方 Vina 1.2.7 的 25k/50k 与 Pro 50k。两种 Aurora 查询及独立 BRD9 共晶只作评价。官方自行推断拓扑。新种子不同于既往开发；这三个分子的历史结果已知。
- FKBP12 的 4–11 号八个配体、1FKG/1FKH、原 AD4 盒与地图，种子 524287，单核 3×24k，第一个轨迹第 1 步单次替换。用对应普通受体重原子构造腔点。以同种子历史官方、当前 Pro、48k Pro 为对照，并核验无注入重放。七点秩相关、15 个三倍可辨方向、8/10 与 9/11 立体悬崖；报告受体分别与等权均分、大小/电荷/柔性。原生设置、图接口须与这组自身的对照一致。
- 所有分子分开列出。预设严重错姿 >5、>10 Å，另可列 ≥8 Å；Top-1 分布、Best@5、真实池最小、Regret、空池、化学图/手性/短接触。对每臂列几何查询次数、真实 hunt/second/explicit 求值、墙钟与 CPU，标记共享建场、提议提取、诊断与盲预测计算。进化预算不计作实测成本。无共同结合/游离系综和收敛证据，维持自由能未测。

## 源码及前序对照

Kuntz 等的早期 DOCK 几何匹配见 [JMB 1982](https://doi.org/10.1016/0022-2836(82)90153-X)。DOCK6 [orient.cpp 固定版本](https://github.com/docking-org/dock6/blob/c690a48a976980bd5100e69dd1fdc36bdddad2e0/src/dock/orient.cpp) 的 prepare_receptor / calculate_sphere_distance_matrix / calculate_ligand_distance_matrix 预计算内部距离，id_all_cliques 搜索相容配对，new_next_orientation 从 clique 取点、平移和求转动。对照 [DOCK6 手册](https://dock.compbio.ucsf.edu/DOCK_6/dock6_manual.htm)。本试验用网格口袋点和固定配体三元组，几何构造与 DOCK 的 sphgen、一般 clique 搜索不同。

[平移扫描](../rigid_translation_scan/README.md) 在固定方向下遍历平移且按能量筛选。5EPS 已生成近姿但在粗排丢失。[刚体前瞻](../rigid_lookahead/README.md) 对已有位置做一次受力松弛，能救回 5EPS，也会挤掉 3WKE。[主轴翻转](../rigid_flip/README.md) 改变局部取向。[POCKET_START](../../docs/POCKET_START.md) 移动质心，保留取向。[跨配体锚点](../anchor_search/transfer_holdout.md) 使用额外供体共晶，对大共同骨架有特异收益。本轮测试无供体对应的跨区域放置，沿用既有口袋位置先验和原始准备。
