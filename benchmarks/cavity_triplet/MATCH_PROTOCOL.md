# 固定的受体腔点与三点放置

普通输入为受体 PDBQT、已有搜索盒、原 MC 变异得到的查询重原子坐标（保持其序号）、运行种子。只用重原子间距，所有长度单位 Å，未读取查询晶体、系列、活性、受体名称、历史漏边图或共晶锚点。冻结如下算子，两臂共用受体与计算。

1. 在指定盒心加整数倍 1.5 Å 的所有盒内网格点，查询到最近受体重原子的距离。保留距离在闭区间 [3,5.5] Å 的点，以 8 Å 球内受体重原子数从多到少排序，同数先选离 3.8 Å 最近的表面间距，再按网格编号（x、y、z）升序。贪心保留距先选各点 ≥2.5 Å 的点，最多 32 点。这里用局部空间和包埋度近似腔体，未计算分子表面法向、真正的最大内切球或显式溶剂。
2. 根据内部重原子距离选最远两原子（从小序号指向大序号），第三原子选距该轴最远者。选择中距离四舍六入五成双至小数点后十位处理浮点并列，按原子输入顺序破平。枚举互不相同的有序腔点三元组，按三对边长与配体对应三边的平方误差和排序；同精度并列按三位点编号升序。选前 1024 个（不足则全选）。分别用三对对应点的无权最小二乘刚体配准，约束旋转行列式为 +1，所得平移和转动作用于全部配体重原子。受体共线三元组（叉积长度 <1e-8 Å²）不进入枚举，配体共线或不足三点不适用。
3. sham 在同一源事件上将有序的拟合旋转做一次整体循环移位；NumPy default_rng(运行种子) 从 1..N−1 均匀选偏移量，保留每个候选原拟合的**整个配体重原子质心**。两臂一一配对，内部构象、质心集合、取向集合、候选数、每个重原子场调用及筛选策略相同；两种近似相同的旋转经置换后仍可能相似。保存整数偏移、对应及所有旋转/质心，可精确重建坐标。记录未区分对应顺序的三角数目、独立质心和旋转数目（量化至 1e-8），以及逐对应拟合误差。
4. 每臂以相同的受体形状场做一次粗排。令 d 为每个配体重原子到最近受体重原子的欧氏距离，u=(d−3.8 Å)/(1 Å)，加和无量纲分数 max(0,−u)²−exp(−u²)。另加各重原子超出搜索盒各面距离按 Å 的平方和。按全分从低到高选一名，同精度并列按候选生成序号升序；仅将此刚体变换注入生产 hunt。无学习或能量拟合。该几何分没有 kcal/mol 单位，不能作亲和力预测；场查询、建图及计算时间与原生目标/梯度调用分列。
5. 在固定源坐标施加给定的任意刚体换系后，比较两臂每个候选的实际受体框架重原子坐标、粗排分与首名。此处验证源配体整体平移及取向不会泄漏给新提议。绝对搜索盒网格绑于受体坐标轴；不主张转动整个受体及盒后离散化结果不变。

几何匹配若定向捕获正确盆地，预期相较同质心同取向边缘分布的 sham，生成总体更接近实验的候选，且粗排首名的原生 hunt 返回和发布池也更接近。另一解释是几何简并或粗场优先奖励错误位置，sham 可追平或优于匹配；即使完整候选更近，若首名、hunt 或保存无改善，这次机制未打通对应环节。单一源态或单晶体的偶然胜出不能外推。具体面板与评价见同目录事前主协议。
