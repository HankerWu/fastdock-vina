# 口袋三点匹配能把正确的配体构象送进结合盆地吗？

BRD9 的两次独立种子搜索都在 1,024 个盲候选中生成了小于 1 Å 的姿势，但粗排选择了距晶体约 12 Å 的候选。AT9283 的困难更早：18 个真实内部构象中有 14 个用理想刚体变换可达 2 Å，固定本方法的空腔点和配体三点，枚举每个构象的 29,754 个有效对应，仍无一达到 2 Å。三种分子六次盲测的候选池和同测定 FKBP12 的排序未显示可归因于配对关系的一致收益。本分支保留原生产搜索作为默认。

## 固定构象和对照

在正常口袋盒内以重原子近邻距离和 8 Å 内重原子数取最多 32 个腔点。配体用最远两重原子与距其连线最远的第三原子构成三角。三条边的残差最小的 1,024 个有序对应各给一个无反射最小二乘刚体变换，按整分子与受体最近重原子的接触和穿插作无量纲粗排。打乱臂只循环置换候选取向，每个目的质心原样保留。两臂的转动集合、内部扭角、候选数与粗场查询数相同。每次让自己粗排第一的一个候选进入相同的原生 hunt，再完成 MC、第二次局优、常驻池、合池、精修和实际发布。研究代码可在任意具备非共线三角和足够腔点的正常输入上生成变换。

开发中只在第 61231 号种子的特定事件做一次干预，18 个分叉都是同一套原轨迹的反事实。六个独立种子工况用 91813、91823，并固定只改轨迹 1 第 1 步。两个 Aurora 分子在相同的 2X6E＋1OL7 撤约束补环上，BRD9 82I 在 6Y7L 上，分别以 2W1G、2J50、6YQW 作独立查询晶体。实验沿用既有口袋盒，位置先验已知；绑定到参考框架的查询坐标由评价进程读取。三分子的 Pro 对照均用同一显式化学图；官方 1.2.7 沿用自身的键推断和发布。AT9283 的官方推断曾漏 30–31 键，算法归因使用相同图的 Pro 和打乱对照。[输入哈希](results/pose_inputs.json)

## 从几何集合到接受、保存和发布

AT9283 开发集生成库最佳 RMSD 的配对中位差（匹配减打乱）为 −0.665 Å，粗排首名变成 +1.070 Å，hunt 返回为 +0.922 Å。两臂生成的 36,864 个候选均超过 3 Å。枚举全部三元组时，11/18 个内部构象至少存在一个 3 Å 内对应；这些对应全在边长预筛的 1,024 名之外。即使取消这个预筛，18 个源态仍无一生成 2 Å 姿势。该诊断没有重调生成器。[全部事后边长排名与几何距离](results/posthoc_edge_gate.csv)

质心与取向还可完全拆开检验。令参考为重原子坐标集，比较时枚举保留化学身份的等价原子映射。平方 RMSD 等于重原子几何中心距离的平方，加两组居中坐标的最小均方差。所有置换都保留几何中心，因此给每一个已生成质心配上每一个已生成取向，可以直接计算这 1,048,576 种组合中的最小值。18 个 AT9283 事件中，9 个有距晶体 ≤2 Å 的质心，8 个有居中误差 ≤2 Å 的转动，任意重配后仍是 **0/18 到 2 Å、13/18 到 3 Å**。任意重配所得最小 RMSD 的事件中位数 2.859 Å，允许任意连续刚体运动时为 1.602 Å。这些使用晶体的几何界限只约束固定内部形状在进入柔性局优前的表示。[可重算的逐构象上界](results/geometry_limit.csv)

BRD9 的两枚种子分别保留了 18 和 13 个 ≤2 Å 的匹配候选。最靠前的近姿在粗排第 8 和 34，正式胜者为 11.933 和 12.296 Å。事后分别取匹配或打乱库里粗排最靠前的 ≤2 Å 候选，在同一源态做四次单事件原生分叉。91813 两臂 hunt 返回 1.113 / 1.130 Å，原注入项随后在第 2 / 4 步逐出，两臂最终首位仍各达 1.162 / 1.082 Å。91823 匹配从 1.928 经 hunt 变为 2.343 Å，实际池最近 2.570 Å；打乱从 1.807 到 1.962 Å，直接注入项最终列第 3，池首位 1.142 Å。这是对“被丢弃的候选是否值得局优”的有标签干预，盲结果在下表。[四个有标签分叉](results/posthoc_branches.csv)

18 个开发匹配分叉有 17 次注入后的提议获 MC 接受，7 次直接入在线池，其中 5 个直接 ID 后来被逐出，2 个到轨迹末，仅 1 个直接发布（第 4 位）。打乱臂相应为 15 次接受、4 次入池、2 次逐出、2 个存至轨迹末、0 个直接发布。六个新种子工况中，两臂首步均全部入池，分别有 5、4 个直接 ID 逐出，最终均无直接 ID 发布。原 ID 消失后，后续轨迹仍可能发现几何相近的模式。历史第 137 步单独从 34 次原始 offer 重演：九格已满，得分 −5.601 的 10.503 Å 候选逐出 −3.579 的 1.566 Å 候选，两者按引擎定义相距 10.312 Å，当步池最近 10.001 Å。[逐步容器](results/residency.csv) · [旧坐标复核](results/historical_eviction.json)

## 同测定强弱和物理解释

Holt 等的 FKBP12 Table II 含七个 Ki 点值及一个区间，三倍以上可判方向的配体对有 15 个。对 1FKG、1FKH 的首位 AD4 分数等权平均，Pro、匹配、打乱分别判对 7、7、6 对，七点 Spearman ρ 为 0.107、0.143、−0.036，Kendall τ-b 为 0.048、0.048、−0.143。匹配相对 Pro 在 1FKG 上 6→9，在 1FKH 上 5→4。等权 8/10 立体悬崖仍错，9/11 仍对。匹配相对 Pro 的分数变化与重原子数、可转键数的 Spearman ρ 为 −0.189、−0.015，八种输入形式电荷相同。相对原 Pro，有晶体参照的四格匹配 Top‑1 均值 5.739→6.887 Å，Oracle 3.681→4.356 Å。额外的位姿机会与更准确的同测定排名需要分别验证。[逐分子逐对](fkbp/README.md) · [Holt 等原文](https://doi.org/10.1021/ja00075a008)

这里显式变化配体整体平移（Å）、取向（单位四元数）与原有扭转（原生局优，rad）；受体在每次搜索中是冻结的。经验 Vina/AD4 打分以 kcal/mol 形式报告，几何粗场无量纲。FKBP 的等权平均是预先规定的跨结构读分规则。各受体内的蛋白动力学、显式水交换与质子化耦合未采样。Davis 原始六格 Kd 在既定温度约定下给出交换差 −8.580231575 kcal/mol，本轮重新核对了其工作簿与区间证书。各臂没有统一结合/游离系综、微态化学势、约束释放、窗口重叠和收敛采样，不能报告新增绝对或相对结合自由能误差。虚假高亲和力的跨系列频率也没有独立测量。[六格原值与单位](fkbp/results/exchange.json)

## 成本与复现

两个姿势受体的腔点准备共作 9,826 次最近邻查询和 2,053 次半径查询。六个新工况每臂另作 151,552 次逐重原子粗场查询，18 个开发工况每臂 516,096 次。三点拟合为两臂共享。完整 24 个源态的两臂生成、Python 启动、压缩与写盘，从新进程实测 1.5475 墙秒 / 1.5203 CPU 秒。复算所有三角与各种质心—取向重配属于事后几何诊断。对于原生计算，另在网格实际插值函数处计数，逐字节对照各原始池；AD4 的每次原子位置访问包含类型、静电、去溶剂化三通道。[原生场查询](results/field_replay.csv) · [官方场查询](results/official_field_replay.csv)
