# 大环初始提议实验协议

起点为 5000d1e。既有 1FKB 的 20 Å 以上断环给出了发现病例。所有方法输入相同，包括 Meeko 生成的查询构象。对照原生上游、当前 Pro、只恢复环路径输入扭转的简单臂、一次闭环坐标下降的研究臂。仅在第一次普通随机扰动之后、第一次 hunt 之前改变配体环上扭转，不增加一次评分、候选、重启或任何后期精修。保留同一随机数消耗。一次解析坐标下降由叶向根，不在结果上选择顺序或扫描次数。优化两组实际 G–CG 端点平方残差之和。两研究臂独立与同一父版配对。

发现与历史复核用 1FKB、1FKF、1YET、5QCT，两枚种子 740317、458921，两档 max_evals 3000、12000，单核、一轨迹、五个输出上限，energy_range 100。5QCT 的教程配体构象与实验有关，单列。外部验证优先全新蛋白家族的人源大环共晶配体，须有可映射实验坐标并从无晶体坐标的化学图单独生成查询构象；记录所有准备失败与未入选原因。新体系额外保留种子 191009 用作复核。评价原始晶体坐标系对称性校正 RMSD、2 Å 首姿/前五/输出池、闭环键长及端点误差、受体碰撞、搜索阶段分解、实际求值和端到端时间。重复种子不视作独立配体。若某臂增加实际开销，用预设的较低上限 2000 对父版 3000、9000 对父版 12000 复核；在相同 CPU 上交错重跑计时，报告反例。固定评分和每个固定池排序的阴性对照单列。原则上只有独立新体系姿势和成本均支持，才考虑生产默认化。
