# 保持原生提议分布的持续固定环消融

查看持续固定环结果后，事前选定已报告的 5QCT、5K0X（沉积 A+B 晶体环境），均使用原种子 458921 和 740317、原上限 3000 和 12000、每轨迹一线程、同一盒、至多五个候选。在没有看到该消融输出前固定协议。这两个体系均属于机制复核。对照当前 Pro、持续固定环，以及保持相同输入环、相同受限 BFGS 和所有局优、接受、保存与排序步骤的空提议版本。后者按原生全实体列表抽取平移、旋转或一根扭转。若选中固定扭转，照常抽取新角再丢弃该角；仍执行此后的常规局优，不重抽。空提议 vs 持续固定环改变了固定的提议概率质量如何分配，两个版本均保持同样的环刚性。与原生具有相同的单次抽样律，不保证在轨迹分岔后消耗相同的随机数序列。

计数所有局优和联合能量/梯度调用，交错执行每臂四次并按配对条件核对坐标哈希及计数。每个条件依原始协议评价首姿、前五及池内最佳的对称校正重原子 RMSD，严重断环阈值 3 Å。额外检验 2000 对 3000、9000 对 12000 上限的两臂，以实测联合调用和四次墙钟中位值检查同等或更低成本；降低上限也会改变轨迹进程。若无稳定收益，记录并保留反例。5QCT 输入环接近晶体，5K0X 输入来自无晶体坐标的化学图。
