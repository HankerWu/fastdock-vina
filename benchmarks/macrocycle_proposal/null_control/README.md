# 固定环与提议重分配的消融

持续固定环有两处影响。它将环内扭转角固定在输入值，搜索时还将原本属于这些角度的提议概率分给其他可动分量。控制臂保持同样的环和 BFGS 投影，把提议换回原来的抽样律。选中被固定的键时，仍抽取角度、保持当前构象，然后进入原来的局优、接受和保留流程。控制没有跳过空提议之后的局优。[假设与预登记的复核范围](PROTOCOL.md) · [相对持续固定环的 C++ 修改](https://github.com/HankerWu/fastdock-vina/commit/fed12226584e21899bc9edcc8d6c789a15baebdf)

5QCT 的 24 个可选实体中有 10 个被固定，MerTK 5K0X 的 20 个实体中有 14 个被固定。在两份真实模型上分别检查 1024 个初始随机状态。控制在 416 和 714 次被固定的提议上保持构象不变，其余抽样与原实现得到相同的刚体和扭转结果。每次抽样后，随机数生成器状态均与不受限的原始单步相同。不同算法的接受率和后续轨迹可以分岔。[单步检查](draw.csv)

5QCT 的教程输入已接近晶体。种子 458921、12000 档的首姿 RMSD 分别为原版 4.723110 Å、固定环重分配 0.619726 Å、同样固定环但保留空提议 5.765450 Å。前者使用 12297 次联合求值，中位墙钟 0.191 秒。在 9000 档，重分配版本使用 9132 次、0.170 秒，仍得到 0.410759 Å；空提议版本使用 9276 次、0.161 秒，首姿 9.143763 Å。另一个 BACE1 种子以及 MerTK 的两个种子，在任何版本和预算上均未命中。相同刚性约束本身未能解释 5QCT 的此次命中。这一干预还会改变轨迹之后的随机数位置；不能由此证明某种特定的平移、转动或非环扭转独自带来该命中。

5K0X 使用同一沉积晶体中的 A、B 两条蛋白链。作者和 PISA 将每条链分别标为单体生物学组装，B 链在此还原晶体接触。两种配体都曾用于前一轮观测。不同种子、预算和重复计时的结果均不增加独立化合物数。[40 个独立程序设定及逐条件结果](results/summary.csv) · [160 次实测耗时](results/timing.csv) · [基线和实验构建散列](results/binaries.json)

## 复现

直接检出持续约束版本 `fda3793` 和空提议版本 `fed1222`，用相同的 `tools/build.py` 选项编译。两版本的差异仅涉及提议抽样。下列命令假定已经解开上一层历史输入以及 5K0X 的双链归档；最后两个表目录分别提供先前运行的父版及固定环逐池散列，脚本会在计时前后逐项核对。CPU 可换为本机可用逻辑核。

```bash
python "$D/paired.py" "$REPO" "$HIST_INPUTS" "$MERTK_INPUTS" "$HIST_LOCK_RESULTS" "$MERTK_RESULTS" "$WORK" "$PARENT" "$LOCK" "$NULL" --cpu 4
bash "$D/check_draw.sh" "$NULL_SOURCE" "$NULL_BUILD" "$BOOST_ROOT" "$HIST_INPUTS/tutorial/solution/BACE_1_ligand.pdbqt" "$MERTK_INPUTS/5K0X/ligand.pdbqt"
sha256sum -c raw.sha256
```

每一组配对条件依原协议测量实际能量/梯度与局优调用、严重断环和受体坐标系 RMSD。5QCT 使用仓库已登记的 MOL2 到晶体坐标对应。5K0X 使用 CCD 与沉积配体 SDF 的两套重原子对应复核。完整程序输出及日志包含在 `raw.tar.xz`。
