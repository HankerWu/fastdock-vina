# 首步复核后的固定环对照

首步恢复输入环后，1FKB 种子 740317 的初始 G–CG 残差约为零，但本轨迹 11 个 hunt 结果中有 3 个真实闭环碳距重新超过 3 Å。首步修复无法阻止后续独立扭转再打开环。这提供一个可证伪的替代解释：在同一输入上减少环内自由度，可能比对随机开放环只修一次更有效。只对实际跨闭环配对的扭转固定在输入偏移零，保留配体刚体、其余扭转和相同打分。此实验可能冻结错误的游离态环构象。5QCT 的近晶体输入必须单列。第三臂在未观察第三臂结果前冻结；外部体系此前已用于比较前两臂，故第三臂的这些数据属于复核，不能用作新的盲验证。

重复初次面板和两项外部结构的全部原种子及两档预算，另用原协议低预算控制开销。不增加轨迹和候选。首要读数为 >3 Å 断键、2 Å 实验姿势、原始计算计数/时间。要求报告不动环的构象偏差、是否出现已经存在的正确候选被精修破坏。亲和力沿用同一 FKBP12 ITC 配对；检查固定坐标打分一致性。固定环是已有的建模思想，此处检验保持同一化学表示和打分时，持续约束相较仅初始化的因果差异。

在第三臂运行前另登记 5K0X（MERTK）、3OWN（肾素）、5N1Z（BCL6）三个实验复合物。只按相同的输入准备、化学对应与口袋检查决定是否纳入，保留排除原因。对合格体系在两枚原种子、两档预算下比较上游、父版与三种研究臂，并用相同较低预算复核固定环。只有此批新体系可作为固定环方案完全未看过的新结构验证。10HY/10HZ 的传统 PDB 下载端点返回 404，未进入筛选。
