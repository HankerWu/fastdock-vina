# 大环对接中的闭环几何、姿势覆盖与实测亲和力

持续固定输入环能消除严重断键。在六种人源蛋白的主比较中，父版的 157 个输出有 14 个真实闭环碳距超过 3 Å，其中 4 个排第一。持续固定环的 189 个输出全部低于该阈值。相同的 48 个对接条件中，唯一新增的 2 Å 命中出现在输入构象已近乎重合于晶体的 BACE1 教程。对从化学图独立生成的配体，所有方法仍未在主比较中恢复实验结合姿势。生产默认保留父版实现。可执行 C++ 版本、约束投影测试、逐姿势坐标和实际求值计数随分支历史提供。

## 源码中的问题

在父版 5000d1e，环切开后成为可旋转的树。闭环由两个 CG–G 伪原子位置重合表示。MC 的初始角与普通扭转提议独立抽样。任意改变其中一个环路径扭转通常会把两个端点分开。hunt、保存时的二次局优和最终显式受体精修都能感受到闭环项，但其回复作用受截断与正能量软化的限制。最终亲和力分解中没有相同的闭环项。因此，断环构象在数值上可以成为首姿。上轮已修复闭环编号、四元环的最短键距，并测试延续远程闭环力。本轮仅研究可行搜索空间和提议分配。

历史病例 1FKB 的种子 740317 提供了直接定位。父版第一次随机提议的最大伪原子误差为 25.6 Å。一次几何调整将它降到 2.2 Å；直接恢复输入环则降到打印精度零。即使如此，恢复输入环的轨迹后续 11 个 hunt 结果中还有 3 个真实闭环碳距超过 3 Å。几何可行性必须沿轨迹检查。[阶段坐标与指标](historical/stages/models.csv) · [原始 Vina 方法](https://doi.org/10.1002/jcc.21334) · [大环断键对接方法与晶体环对照](https://doi.org/10.1017/qrd.2022.18)

坐标下降使用平方距离目标，单位为 Å²。对于一根轴，令单位向量为 u，可动端点和目标相对轴上支点的位置为 r、t，r⊥ 为垂直于轴的分量。用 Rodrigues 公式展开后，与转角有关的部分是 −2(A cos δ + B sin δ)，其中 A 为各受影响闭环对的 r⊥·t 之和，B 为 (u×r⊥)·t 之和。数学最优转角是 atan2(B,A)。两端都动或都静时，该对对本轴的目标是常数。近退化轴只在浮点可分辨范围内更新。由叶向根可保证尚未处理的轴不受后代旋转影响，因而只更新端点坐标。单次扫描在单配体上约为 O(N+TP)，N 为原子数、T 为扭转数、P 为闭环对数；对应端点标记的递归临时空间为 O(P×树深)。没有额外的对接能量或梯度评估。独立验证从每个角的三个完整正运动学结果重建正弦曲线，45 个起点上的最大原子位置差为 1.53×10⁻¹¹ Å。[CCD 原始论文](https://doi.org/10.1110/ps.0242703) · [全坐标独立复算](numeric/ccd_check.csv)

持续固定环使用同一份不可变的扭转掩码。BFGS 初始度量按坐标对角化，受限分量的位移和梯度差均为零，后续拟牛顿更新保留这一自由子空间。原有受体场、配体原子图、势函数、扭转归一化和最终评分沿用父版。50 个数值配置中，6,400 次合法 MC 提议和 400 次 BFGS 局优维持了闭环，最大端点误差 5.62×10⁻¹⁵ Å。对平滑周期扭转势做中心差分，投影方向导数最大误差 1.01×10⁻⁹。[测试实现和全表](numeric/lock_check.cpp)

## 姿势与成本

下面每种方法使用相同输入、单线程、每个种子一条轨迹、名义上限 3000 或 12000、至多五个输出。48 个条件使用八种配体，重复种子、重复预算和共享受体之间存在依赖。输出数由实际搜索决定。2 Å 成功使用受体坐标系内按化学图对称性校正的重原子 RMSD。因输出上限为五，Top‑5 和输出池 Oracle 在此相等。

一次性几何投影通过了数值验证，最终严重断环却由 14 个增至 19 个。固定池中把 3 Å 以内的候选排在严重断环前面，也无法补回缺席的正确姿势。例如在新外部面板中换了三个首姿，RMSD 两次上升、一次下降，另有四个池全部严重断环。该阈值仅检测明显过长的闭环碳键，另记录伪原子误差、最近受体重原子及小于 2 Å 的接触。阈值通过不代表全部键角、构象应变和口袋相互作用正确。[全部固定池](valid_first.csv)

- **BACE1–5QCT。** 教程输入环重原子单独最佳对齐 RMSD 为 0.000515 Å。种子 458921、12000 档，父版 4.723 Å，全程固定并重分配 0.620 Å，而同样固定环的空提议对照为 5.765 Å。9000 档固定并重分配得到 0.411 Å，消耗 9132 次求值，对照父版 12000 档为 12297 次。事后阶段回放显示高档正确姿势已出现在 hunt 中（最低 0.408 Å），经保存及显式精修后排第一。另一种子失败。固定环先验和提议分配在该轨迹均值得区分。[复核和全程实测](null_control/README.md) · [输入环几何](numeric/input_shape.csv)
- **FKBP12 与 HSP90α。** 雷帕霉素 1FKB 的四个条件首姿 RMSD 中位数从 11.85 降至 8.24 Å，FK506 1FKF 从 11.49 降至 10.47 Å。HSP90α–格尔德霉素 1YET 从 5.28 升至 8.76 Å。三者的正确候选均缺席，改善和退化都发生在较远的结合姿势上。[逐结构分布](target_summary.csv)
- **新骨架 5T9W / 7MBO。** 从十个事前筛查对象中，PPIA–78E 和因子 XIa–milvexian 通过单构象生成及口袋检查。各有三枚种子、两档上限。每臂均为 0/12。3000 档的父版及两种首步臂共 534 个阶段构象均超出 2 Å，持续固定环的 310 个阶段构象也无命中。两个晶体配体都有约 3.3 Å 的对称晶格接触，单链模型省略了这些环境。两套独立原子映射重算了每个输出的 RMSD。[数据来源及排除原因](external/sources.json) · [外部逐姿势与阶段复算](external/README.md)
- **尚未看过的新靶点 MerTK。** 5K0X 的 A 链配体距 B 链最近蛋白原子 7.34 Å。保留同一沉积的 A/B 链重建晶体接触；生物学组装为单体。两个蛋白均未补建重原子，最近的遗漏非水原子为 15.47 Å。两枚种子高档的父版→持续固定首姿分别为 8.863→4.928 Å 和 8.483→9.731 Å，四个主条件没有一个 2 Å 输出。其独立生成的整个配体经最佳刚体配准已距晶体构象 1.304 Å，这仍不足以确定口袋中的位置。3OWN 和 5N1Z 因近邻乙酸或氯离子被单列。[输入及排除依据](holdout/sources.json) · [全部姿势、费用与独立 SDF 对照](holdout/results/structures.csv)

### 实测时间约束

在两个外部体系，各用单独种子 281291 做纯计时校准，再冻结预算评价三枚原有种子。校准、预热的 132 次进程合计约 32.40 秒，供选择实验预算使用。表内每个方法的一次预测始终只运行一次。三枚种子各交错计时四次，六个单元的平均实际墙钟和求值数均低于父版。机器、编译和输入规模都会影响校准结果。[含每次计时的归档](external/wall_match/README.md)

FXIa 有一枚种子首姿从 14.581 降至 3.448 Å，另一枚从 9.516 升至 14.551 Å。相同比较中没有新增 2 Å 命中。未经计时校准、直接把两边的上限均设为 12000 时，FXIa 固定环的实际求值更少，平均墙钟仍从 270 增至 319 ms。这也是不能仅按上限判定等成本的直接实例。

## 实测 Kd、固定评分与旧 MMFF 反例

同一研究中的人 FKBP12，FK506 的 Kd 为 2.7±0.5 nM，APX879 为 119.4±15.8 nM，差异约 44.22 倍。相同温度、pH 与缓冲条件，注射方向和浓度因溶解度而异。两个查询都从独立化学图制备，在 1FKJ、1FKF 上做共同受体比较，同时保留重对接和交叉对接。按两枚种子的分差中位数判断方向，父版在 1FKJ 的两档都对，在 1FKF 都错；持续固定的结果恰好相反。首步坐标下降判对三个分层条件，但四个条件始终重复同一个独立分子对。无法从这一分子对估计有代表性的 Spearman、Kendall 或等重原子数子集表现。冻结父版 67 个候选的绝对坐标，用同一参考能量复算；再用 16 个自参考首姿隔离分子间评分，三种版本十项打印能量分解均相同。[原始量热测定](https://doi.org/10.1128/mbio.03000-21) · [分子对方向、逐姿势、成本](fkbp_affinity/README.md)

另从既有档案重新计算 42 个分子、168 个固定首姿的 MMFF94s 分解；五份分量和汇总表逐字节一致。BACE1 的判对数 23→54/72，去掉配体内静电后为 48/72，去四项局部成键贡献仍为 54/72。因子 Xa 的 223→206/295 有 14 个净损失集中在 CHEMBL369480，输入中一根单键长 2.094 Å，模型平衡长度为 1.492 Å。只替换其制备态并重对接的历史对照变为 216→215/295；换输入也换了结合姿势，不能将差额唯一归因于键伸缩。固定坐标的数值分解能揭示输入和参考态偏差，尚未测得溶液构象占有率。[分量与输入干预原始结果](../frozen_core/strain_transfer_audit/README.md)

下一项区分机制的实验应按当前失败分型。5T9W 的三个高档固定环首姿在最佳刚体配准后，内部构象仍差 2.79–3.37 Å；只改变受体框架内的平移和转动无法救回这三个候选。7MBO 相应内部误差为 1.11–1.45 Å，但质心偏差为 2.44–6.81 Å。前者适合检验保闭环的协同扭转和侧链相对构象，后者适合在固定内部几何上隔离刚体落位与取向。应以首次产生的正确候选能否沿阶段保留下来作为终点。[逐姿势误差分解](numeric/pose_shape.csv)
