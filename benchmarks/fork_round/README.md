## 复算

使用头文件和动态库一致的 Boost 1.83、GCC 14.2，Python 3.12 环境提供 NumPy 2.3.5、SciPy、RDKit、xlrd。原始业务运行和独立复算的完整 argv 在各目录的收据内。根目录执行以下两项。

```bash
export OPENBLAS_NUM_THREADS=1
python benchmarks/stage_local_hunt/verify_round.py
python benchmarks/fork_round/verify.py
```

重新执行盲预测时从固定提交导出源码，四臂按[结构说明](../fork_structure/)构建并运行。对新二进制 BIN，重建一个空的 W，随后执行亲和力研究。OUT 是新目录。独立编译器检查、耦合方向检验见 [builds](builds/) 和 [source_audit](source_audit/)。

```bash
S=benchmarks/search_trial_affinity/study.py
python "$S" setup "$W"
python "$S" run "$W" --binary "$BIN" --jobs 2
python "$S" collect "$W" --artifacts "$OUT"
python benchmarks/stage_local_affinity/paired.py "$OUT"
python benchmarks/stage_local_affinity/costs.py "$W" "$OUT/physical_costs.json"
```

复算前轮归档时，裸 Python 初次缺少 RDKit；一次切换到另一套 NumPy 导致历史 CSV 的小数末位与归档不一致。使用上述 NumPy 并单独提供 RDKit 后，前轮全套坐标、分测定和台账复算通过。首次轮前构建后与一个叫 candidate 的旧缓存比较失败，进一步核验显示新构建完整 SHA 与登记稳定 ELF 一致，随后用实际重建的 ELF 重跑 140 个固定亲和力格，全部 1205 模式及每格阶段计数复现。结构计时中误指缓存的 68 次执行及其费用单列于[身份排除目录](../fork_structure/rejected_identity/)。
