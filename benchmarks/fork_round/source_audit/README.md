# 正式候选的第十次试探、状态恢复与多运动根检查

[事前检查方案](PLAN.md)针对研究提交 `1c672a8e2ce12c7a16e20172a3315ea5a19c23d8`。逐文件确认两个实际构建目录内的 72 个 src/构建脚本与各自的 Git 对象完全一致。候选 ELF 与轮前不同；两版 `--version`、普通帮助和高级帮助（含所列默认值）输出分别为 33、7,294、13,171 字节，逐字节相同。[输入、源码树、ELF、命令输出及复算收据](receipts.json)。

**源码路径。** 在该固定提交的 `Vina::global_search` 中，读取实际搜索网格各启用轴的跨度（Å）除以网格间隔数，采用最小间距；Vina 与 AD4 各自使用对应网格。MC 将间距只传给 `candidate/hunt_cap` 的第一次局优分支。入池前 `saved/authentic_v`、显式精修以及单独的局部优化调用均使用零间距默认值。常规 hunt 的 BFGS 接收最后一次试探回调，回溯在第一到第九次沿用原方向和连续减半，最后一次采用

\[
\alpha_{10}=\min\left(2^{-9},\;h/\max_{i\in H}\|(Jp)_i\|_2\right).
\]

这里的 \(H\) 包含运动化学重原子，排除氢和虚拟原子；速度为零或非有限时回退到原末试系数。每个平移分量用 Å，每个旋转与扭转分量用 rad，\(h\) 是网格间距。这个限制使用起点切向量预测最大原子位移；有限旋转、层级扭转或最近的网格面仍可能使实际运动跨面。计算只在进入第十次时重新设置基态和遍历运动树，无额外能量/梯度调用，实际 CPU 包含这些运算。测试所得误差度量运动学求导。

**多运动根。** 每个配体均从其独立的三维平移、实验室坐标系角速度和本配体前序扭转段起步。每个子节点承接父节点给轴枢的线速度，并把本关节的角速度加在父角速度上。柔性残基根轴有独立扭转，根枢平移为零，依次遍历其子轴。3FMZ 原始分区含 GLN A98 三个显式扭转，两个配体来自真实 3FMZ 和 3FR2 输入。六种构象下，逐个单位自由度、零向量、耦合方向及专门由柔性受体或第二配体独立主导的方向全部进入分母。双配体共存用于验证构象布局，不作多配体结合实验解释。

| 模型 | 自由度 | 方向/构象数 | 最大速度对中央差分的绝对误差 |
|---|---:|---:|---:|
| 两个配体 | 21 | 150 | 6.42×10⁻¹⁰ |
| 单配体和柔性残基 | 14 | 108 | 4.21×10⁻¹⁰ |
| 两个配体和柔性残基 | 24 | 168 | 6.42×10⁻¹⁰ |

独立中央差分直接由 \((X(q\oplus hp)-X(q\oplus(-h)p))/(2h)\) 的逐重原子向量取最大范数，差分因子为 \(10^{-5}\)。426 项中，调用解析速度函数后，重新得到的模型坐标与基态模型逐分量完全相同。[全部布局与确定性对照输出](results.tsv)

**第十次耗尽。** 另用真实 `quasi_newton::operator()`、真实单碳配体解析和原生网格壁梯度，编程控制模型能量值以精确触发“先接受一步，再走完十次”的路径。关/开末次限制及拒绝/接受第十试探构成四组，各作 12 次联合调用（起点、第一次直接接受、第二次方向的十个试探）。第二个方向前九次试探位置完全一致。末次尝试的 x 从 1,026 变为 1,024.375 Å；耗尽时两臂均返回 x=1,024 Å、目标值 −1,000，接受时分别返回各自的末试坐标和 −2,000。模型内部的笛卡尔坐标、调用者得到的自由度和能量均一致。这些数字为状态机检查而设。源码只在接受时交换构象并更新当前能量；失败触发 `restore_coordinates` 和 `m.set(out.c)`。割线使用被接受的 \(\alpha\)，首轮尺度只在 \(s^Ty\)、曲率范数和新尺度的有限性、正值条件成立时更新。已有负曲率数值回归由同轮的 [numeric.log](../builds/numeric.log) 核验。

**失败记录。** 第一次编译因测试驱动缺少 `precalculate.h` 失败。随后一次运行和一次定位运行发现，受控能量原设 −100，不能满足 1,024 斜率对应的首步 Armijo 下降至少 104.8576；所以旧检查实际走了“未接受第一步”的不同路径。修正受控输入为 −1,000/−2,000 后触发事先指定序列。失败发生在诊断驱动；三份原始失败日志保留于此目录。最后一次独立进程逐字节复现全部七行。

从仓库根目录执行。SRC 与 BUILD 取 `1c672a8` 的干净导出和正式构建，ORIGINAL 取轮前可执行文件，BOOST 取对应 Boost 前缀，WORK 为不存在的目录。输入从原归档按原文件名抽取。

```sh
export SRC BUILD ORIGINAL BOOST WORK
bash benchmarks/fork_round/source_audit/run.sh
cmp "$WORK/results.tsv" benchmarks/fork_round/source_audit/results.tsv
```
