# 跨受体软排斥搜索及独立配体起点

本实验从六个实验复合物各自生成独立的配体输入。在每个靶点内做两个自身重对接与两个双向交叉对接。新实验选项 `--soft_receptor_search` 将偶数编号轨迹**受体网格**中的 Vina 二次排斥权重乘以 0.5。奇数轨迹、配体内部排斥以及随后的显式受体精修和本实验采用的原生 Late 排序均采用原始势。对照的混合 Vinardo 搜索使用研究提交 `4de709a6312c6424b0a78ec856f419c17c08b619`。该变体改变的还有原子半径、吸引势与氢键等项。两种方法的效应应分别归因。

将某接触的压缩量写为 x，受体局部可退让量写为 u。若局部接触和受体恢复力分别给出 k(x−u)² 和 κu²，消去 u 得到有效刚度 kκ/(k+κ)。当两个刚度相等时是 k/2。此模型给出搜索势的试验尺度。真实口袋有方向性，不同残基也有不同刚度；本轮未估计这些力常数。Ferrari 等用软化的 Lennard-Jones 排斥考察受体适应性，具体势函数与本实现不同。[原论文](https://pubmed.ncbi.nlm.nih.gov/15456251/)

已知口袋中心来自接收受体自己的配体，边长 24 Å。交叉条件下，查询配体晶体坐标只用于评估和单列的晶体起点诊断。每个对接起点来自 CCD 异构 SMILES、ETKDGv3 与 MMFF。受体采用 A 链，采用晶体中固定的重原子坐标，补齐已建模残基的缺失侧链，保留 PDE4D 的 Zn/Mg；常规实验采用干口袋。质子化和互变异构体固定为此输入的约定。PDE4D 的西洛司特按 CCD 中性酸处理；该微态未依据实测溶液占比定标。各接收受体的原子替补、原始数据哈希、配体立体与多套实验位置在归档的 metadata.json 中。

坐标变换用两座晶体口袋 14 Å 内共同的 Cα 和保序残基名/编号，全分子 RMSD 在接收受体坐标系计算。这里的两处 14 Å 球仅用于评估坐标变换。最初使用接收侧单球时，ESR1 的移动螺旋令 1A52→3ERD 的 Cα 拟合达 7.41 Å；实验在报告对接效应前改成共享口袋并记录此选择。保留等价化学图映射。独立审计另外允许顺反构造等价的环编号；仅使高预算软壁**自对接**的首位命中增加一个，所有交叉结果一致。晶体定义的口袋适用于已知位点任务。

## 同一靶点内两种故障

对每个配体，先用实际起始几何，把可动扭转角和刚体位置投影到查询晶体，再用原生显式势局部优化。这是有答案的诊断对照。双向 PPARG 都可得到 ≤0.54 Å 的姿势。5Y2O→2PRG 的投影精修后为 0.228 Å，INTER + INTRA 为 −12.334，优于高预算两个原生首位的 −11.773 与 −11.533，原生候选池都没有 2 Å 解。反向 2PRG→5Y2O 的投影为 0.535 Å，能量 −7.559，弱于两个原生首位的 −10.350 与 −11.595。这只比较已访问姿势与一个近晶体点。当前势下前一方向存在值得找到的近晶体低能状态，后一方向说明即便输入一个近晶体点，按能量也可能选走。直接用晶体刚性片段和投影到真实计算输入的两种对照均有存档。

## 用独立类似物生成候选

`tools/make_donor_starts.py` 使用仓库已有的立体相容最大公共子结构，先将四个原子均有对应关系的可动二面角移到供体实测值，再按共同重原子做刚体配准。保留最多四个起点。候选由供体对应残差排序，只用接收受体的共晶配体。控制臂枚举相同化学映射，仅做刚体配准，两臂各自在对应残差下截取相同数量的候选。两臂都用原生显式势局部优化并按同一配体的 INTER + INTRA 与相同原生候选池合并。重用同一局部候选的多个种子不能作为独立的供体预测。

罗氟司特进入西洛司特的 PDE4D 结构时，九个重原子匹配。新起点的最好评分姿势从刚性配准的 5.09 Å 改善到 1.29 Å。反例是罗格列酮进入吡格列酮结构，17 个共同原子的最佳几何配准残差从 1.11 降到 0.18 Å，最后整配体最佳可达 RMSD 却从 1.46 增至 3.26 Å。在六个交叉方向的共同候选池上，3,000 档原生、增加刚性模板、增加扭转迁移的首位命中为 5、7、7/18；12,000 档为 5、5、5/12。此项属于观测基础面板后的探索，未把局部候选数的增加当成扭转迁移的收益。

## 复现

从仓库根目录使用以下命令。主数据制备用 Python 3.12、RDKit 2026.9.2、Meeko 0.8.0、OpenMM 8.6.1、PDBFixer 1.12.0、Gemmi 0.7.5、NumPy 2.3.5、SciPy 1.17.0。研究对照可由对应提交的 tools/build.py 编译。

```bash
B=benchmarks/paired_crossdocking
W=$(mktemp -d)
V=$PWD/build/vina
MV=/absolute/path/to/mixed-vinardo/vina
python "$B/run.py" "$W" --prepare
python "$B/run.py" "$W" --vina "$V" --mixed-vina "$MV" --cap 3000 --seeds 43103 43117 43133
python "$B/run.py" "$W" --vina "$V" --mixed-vina "$MV" --cap 12000 --seeds 43913 43933
python "$B/crystal_start.py" "$W" "$V"
python "$B/donor_test.py" "$W" "$V"
python "$B/independent_cross.py" "$W" "$W/audit"
```

离线复算可将此目录四个 `.tar.xz` 归档解压到一个空目录，再复制 results/poses_*.csv 至该目录。independent_cross.py 从原晶体 PDB、配体 PDBQT、对接输出和日志独立计算配准、RMSD 与计数器。在相同固定原子映射约定下，1,779 个姿势的最大数值差为 1.91×10⁻¹⁴ Å。runtime_checks.py 的零排斥极限与不开启选项的默认输出均有逐字节检查。
