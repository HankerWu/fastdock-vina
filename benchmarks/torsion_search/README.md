# 有限角扭转、受体装配和实测 Ki/Kd 的配对检验

本轮以 `d5eb5739178adfb19d8be65680406843dff775fe` 为基线，直接测试了 17 种人源蛋白。不同面板有重叠，按蛋白去重；MEK1 的单个已知卤键几何对照另计。有一个能换种子和预算复现的结构改进：按 PDB 生物学装配恢复 TTR 结合通道后，8DW5 的一个配体可以回到实验支持的口袋位置。换成甲状腺素即失效。两种通用搜索提议均未在跨受体首姿和同靶点实测强弱排序上取得稳定净增益。生产默认保留原有搜索和终评分。

## 搜索算法

原生 `mutate_conf` 随机选一个可动实体。选中配体扭转时，抽一个绝对角并转动对应子树。不同的扭转树根给相同的相对角变化分配了不同的实验室坐标位移。为检验这种表示是否影响真实口袋内的搜索，新增 `--balanced_torsion_search`，对同一次角度抽取在键两侧分配转动。设两侧化学重原子到键轴的垂距平方和为 A、B，原生转动子树 B 的角为 δ，全分子可绕同一条键轴补转 φ。重原子总平方位移为

$$ D(φ)=2A(1-\cos φ)+2B[1-\cos(φ+δ)]. $$

除简并点外，极小值位于

$$ φ=-\operatorname{atan2}(B\sin δ, A+B\cos δ). $$

实现按真实扭转树遍历，以当前已接受构象重新生成轴、支点和两侧的几何矩，旋转配体根的姿态与位置。均匀重原子权重对应 RMSD 度量。这个优化保证给定相对角下、绕该轴的位移最小；它没有直接优化口袋接触、穿越势垒的几率或结合自由能。侧重质量或局部口袋约束将给出不同的目标函数。[Vina 原论文](https://doi.org/10.1002/jcc.21334) · [柔性对接的坐标流形](https://pmc.ncbi.nlm.nih.gov/articles/PMC4606885/) · [扭转空间近局域提议](https://arxiv.org/abs/cond-mat/0103580)

第二个选项 `--prepared_torsion_starts` 在偶数编号轨迹上使用 PDBQT 输入内构象作为起点。刚体平移、取向和后续随机序列按原方法生成。首个普通突变也照常执行。奇数轨迹完全保留原生行为，至少需两条轨迹。此假设在独立由分子图生成的构象上检验，借用了 ETKDG 的实验扭转先验。若用已知查询晶体生成输入，再测同一晶体的自对接，会把答案带入起点。[ETKDG 原论文](https://doi.org/10.1021/acs.jcim.5b00654)

数值独立检查从 PDBQT 的 BRANCH 序号重读键轴，使用 Rodrigues 变换，以 1° 网格扫描整周，再检查精确提议、反向恢复和分子内成对距离。8 个实际配体合计 322 个有限角度试验；对扫描最优值的最大正超差低于 1.2×10⁻¹³ Å²，构象逆转坐标误差均小于 3×10⁻¹⁴ Å。刚性片段空效应、关闭开关输出、新旧二进制逐字节比对、单/双线程重放、既有 Late 和重取向回归均通过。[数值原始记录](numeric.txt) · [二进制回归](regressions.txt)

## 结构结果与误差来源

| 面板 | 结果 |
|---|---|
| BACE1、EPHX2、CHEK1、BRD9 | 8 座晶体、7 种骨架、608 次对接、6,080 个姿势。3,000 次评价上限下平衡扭转和原生都是 5/48；12,000 次下为 5/48 和 8/48。 |
| 预制起点，两个预算交叉复验 | 12,000 / 24,000 时，原种子组命中较原生增加 5 / 4 格；新种子组减少 1 / 持平。计算预算和种子均有交叉对照。 |
| 高预算真交叉对接 | 八方向、两个新种子、每轨迹 250,000 次，原生与预制起点的首姿 RMSD ≤2 Å 为 1→3/16。候选可达 5→6/16，中位首姿 7.08→2.89 Å；联合 PoseBusters 全部物理检查成功为 0→1/16。后者新增 BRD9 82I→6Y7L，1.025 Å。 |
| TTR 装配 | 对 8DW5 的 3 个新种子，按同口袋实测多占据方向判定，60,000 上限为 0→3/3，240,000 为 0→2/3。若只认单个方向，两者皆为 0/3。独立 2ROX 甲状腺素在两档均为 0/3，BCL6 二聚体亦无新命中。 |
| 固定池卤键 | 九个氯代配体上，原生、只计距离、再计 C–Cl···O 方向三臂首位均为 2/27，池内可达 8/27。剔除 4 Å 内蛋白晶体对称接触后首位均为 2/12，池内可达 6/12。 |

试验以已知结合位点为条件。原生和候选方法共享配体、受体、盒、种子、轨迹数和每轨迹求值上限。高预算组实际每格平均求值 1,000,112 / 1,000,119。二方向共晶很适合检验搜索和评分的归因。BACE1 的 5HA 使用预制几何移植实验扭转后，在自身受体内原生局部精修得 0.489 Å，INTER + INTRA 比小预算最好首姿低 2.16 kcal/mol；在另一受体内仍可达 0.676 Å，却高 9.46 kcal/mol。后一个比较只涉及这个近晶体点，尚不能证明所有近天然构象均被压低。针对前者扩大采样有明确依据；针对后者需要检验受体状态与候选间能量差。[完整配对矩阵、受体配准与物理有效性](../torsion_proposals/README.md)

CHEK1 77A 的实验脲 NH 至嘧啶 N 距离 2.959 Å，候选可离 PoseBusters 阈值 2.904 Å 很近，可能存在分子内氢键。A42 的实验结构本身也未过该项。在 224 个固定池中丢弃触发此阈值的候选换了 7 个首姿，各组命中均未提高。进一步对 32 个高预算交叉首姿和另一面板的 30 个首姿做保位 MMFF94s 局部松弛，62 格的 RMSD 与物理检查联合结论均未改善。无位置弹簧时后面板联合成功从 4 降为 2/30。配体内势可能把配体从蛋白允许的位置移走。[固定池与晶体诊断](../torsion_proposals/README.md) · [位移与松弛实现、实验和复算](geometry/README.md) · [PoseBusters 原论文](https://doi.org/10.1039/D3SC04185A)

PDB 非对称单元、省略的生物界面和晶格接触有不同的物理含义。`tools/build_receptor_assembly.py` 用指定沉积装配和已配准受体刚性变换复制参与的链，TTR 四聚体补入 VCP-6 的 18 个重原子中 11 个的近邻。对两种装配的计算与两种实验参考方向定义分别作交叉检验。LCN2 则已有 0.50–0.88 Å 的姿势，三次都选出约 2.89 Å；两个种子的方向卤键相对补偿 0.158 和 0.163 均小于原生分差 0.750 和 0.951。局部接触的存在不足以判别整个分子的取向。[装配操作、正反例、固定池和受体独立复核](../assembly_halogen/README.md)

## 实测强弱排序

给定同靶点、同实验端点，用较低的预估能量预测较强者。每对分子只投一次票；种子和受体重复先合并。三倍分隔在室温下相当于约 0.65 kcal/mol 的标准结合自由能差，属于描述性入选门槛。动力学测得的初始 Ki 还依赖作者设定的结合阶段。表中采用各面板预先指定的主统计。AURKA 全系列的主展示用补齐 R/S 后的外消旋混合规则，原单手图处理也提供作为对照。

| 靶点与实测端点 | 合格分子对 | 原生 | 平衡扭转 | 预制起点 |
|---|---:|---:|---:|---:|
| Galectin-1 同系列竞争结合 Kd | 23 | 17 | 20 | 16 |
| Galectin-3 同系列竞争结合 Kd | 35 | 28 | 28 | 25 |
| 人 CHEK1 同平台 Kd | 66 | 42 | 43 | 38 |
| 人 Aurora A 同平台 Kd，Ki20227 显式 1:1 对映体混合 | 151 | 111 | 106 | 103 |
| 人 PNP，25 °C 初始 Ki | 9 | 9 | 5 | 8 |

两个凝集素都测 13 个相同分子；这两种蛋白并非独立化学系列。只取三唑类似物时 Galectin-1 是 7 / 10 / 6（13 对），Galectin-3 是 18 / 18 / 15（25 对）；简单重原子数基线分别为 6.5 和 24。用独立配体锚定糖环将 Galectin-3 候选池中正确核心的覆盖由 8/104 提高到 104/104，但锚定后的三唑排序仍为 18/25。9、13 号化合物在两靶点的实测强弱互换，锚定后反而把这两个符号均判错。只验证糖环的六个原子，并无查询分子全配体晶体真值。[Galectin 实测与原始姿势](../galectin_affinity/README.md)

单手输入的 AURKA 为 110 / 106 / 103。剔除实验外消旋体后仍为 98 / 94 / 92（136 对）。CHEK1 等权指数汇总改为 46 / 42 / 43；改用统一游离配体参考、算术汇总为 37 / 36 / 32。全 816 个首姿在保留原始拓扑的独立 C++ 坐标复评分后，主统计的逐对符号都复现。[激酶来源、额外 48 次 R/S 对接和复核](../torsion_kinase_affinity/README.md)

PNP 的 7 个配体有同一研究测得的四组亲和力端点。相同的预测在 37 °C 初始 Ki 的 15 对上为 11 / 13 / 7；25 °C 慢结合 Ki* 的 9 对为 8 / 6 / 7。温度、时间窗和入选分子对都改变了结果。不同端点不宜合并成一个“Ki 胜率”。[PNP 表 1、三聚体、磷酸根与原始数据](../pnp_kinetics/README.md)

## 可复用入口

```bash
python tools/build.py --output-dir build --jobs 4
build/vina --receptor receptor.pdbqt --ligand ligand.pdbqt --config box.txt \
  --exhaustiveness 4 --pose_selection late --prepared_torsion_starts --out poses.pdbqt
python tools/build_receptor_assembly.py deposition.pdb receptor.pdbqt assembly.pdbqt --assembly 1
python tools/relax_pose_geometry.py poses.pdbqt top1-relaxed.sdf
```

平衡扭转的独立入口为 `--balanced_torsion_search`。两个搜索选项各自与相同的原生搜索作过配对，将两者组合的效果需要另行验证。历史输出评分仍对应原位置，松弛后如需能量必须按新坐标重新评分。编译数值测试时将 `check_proposal.cpp` 链接到同次构建的库目标文件（排除 main.o）。二进制回归可运行 `python benchmarks/torsion_search/check_cli.py build/vina BASELINE_VINA`。
