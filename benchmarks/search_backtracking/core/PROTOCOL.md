# 等起点搜索局部优化诊断

在读取本轮局部回放结果前固定如下规则。复用 geometry_comparison/pose/inputs.tar.xz 与 geometry_comparison/basins/starts_and_relaxations.tar.xz 的全套八个靶点，每个取投影共晶、原生错误首姿 63419 和 63421 三种初态。各臂只运行一次原生网格 hunt 和随后的 save。固定轨迹、局部迭代上限、两次优化的能量与梯度和输入坐标；实际评估次数可不同，逐项记录。每次优化前后按存档图映射计算无叠合的对称性校正重原子 RMSD，保留各起点的三个阶段坐标、日志及行表。投影共晶使用答案，仅检查错误移位；错误首姿检查可否回到 2 Å。它们不进入无模板端到端成功率。

研发臂在 Monte Carlo 的 hunt、save 两个网格阶段使用相同模式。Native 复现现有二分与耗尽行为。Halving 在十次失败时保留上次接受点。Quadratic 在相同耗尽规则下，用当前方向导数和已经被拒绝的试步能量估计二次函数极小值，下一步限制在上一步的 0.1 至 0.5 倍。第一步、充分下降阈值、最多十次尝试、BFGS 其余参数、显式受体精修和排序均沿用原值。

首次三臂回放完成后，登记一次机制消融。固定缩至四分之一，相当于每次跳过一个二分试步。它沿用相同十次尝试与恢复规则，检验仅仅缩得更快能否解释拒绝次数和恢复次数，所有 24 个既有起点均复算。该探索只在同起点诊断中进行，无独立验证资格。
