# 从主实验事后提出的 p38α 受体构象诊断

主实验完成后，MAPK14 的 BIRB-796 对排序的贡献促成此项探索。固定查询为已对接的 CID 156422（BIRB-796）和 CID 176155（SB-203580），固定受体为原有 1A9U/SB2 和新增 1KV2/B96，两者分别提供 26 Å 盒中心。沿用两组种子 458921、703109，预算 12000、一个线程、一条轨迹、原有九模式上限及参数。比较当前 FastDock 和二次回退。原有 1A9U 结果直接复用。BIRB-796 的 DFG-out 晶体构象来自 Pargellis 等 2002 年工作（DOI 10.1038/nsb770）。每个查询单独验证 CCD 与实际 assay 输入 PDBQT 的化学身份、完整重原子、异构体和立体约束；不匹配的化合物不报告真值 RMSD。离子、邻体、重建原子、缺失残基及坐标完整性另行记录。只有一个实测状态的查询在另一受体中的位置用两个口袋的公共 Cα 对齐定义。报告晶体参考碰撞、盒边界、各臂 Top-1/Top-5/返回池 oracle 和全部结果，不合并两种受体的分数。这个追加实验无法独立验证整组 Kd 排序，不能用于参数选择。

首轮四个种子–受体条件的当前版本与二次回退结果完成后，在相同四个条件追加二分回退作为事后消融，用于解释主实验中该臂的 p38 排序。另检查排除活化环后的口袋对齐、全链公共 Cα 对齐，以及从已知 BIRB-796 晶体坐标出发在两个固定受体上的单次显式局部优化。这些诊断不进入盲对接成功率。
