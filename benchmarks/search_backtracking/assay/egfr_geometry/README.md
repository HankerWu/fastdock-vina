# EGFR 的亲和力排序是否用到了接近实验的厄洛替尼姿势？

厄洛替尼在 Davis 的 EGFR 测定中 Kd 为 0.67 nM，也是 1M17 共晶配体。对该次亲和力研究已保存的全部 14 个返回池、55 个 MODEL 重算实验坐标系内的重原子 RMSD。所有池的首姿、前五和完整返回池均未达到 2 Å。不同预算、算法之间会重复导出相同姿势，55 条记录不构成独立样本。[原始晶体学研究](https://doi.org/10.1074/jbc.M207135200) · [逐池结果](cells.csv) · [逐模型结果](modes.csv)

按第二枚种子得到 +47.302 的受保护二分首姿，两档预算都是 17.426 Å。最近蛋白质–配体重原子距为 1.340 Å，配体上有 5 个重原子距蛋白不足 2 Å，严重碰撞原子对共 23 对（实际距离低于两原子半径之和的 0.75 倍）。把实验厄洛替尼放入同一准备受体，最近距离为 2.699 Å，在 AQ4 N2 与 Met769 的主链 N 之间；两条碰撞判据的计数均为零。全部返回姿势中最接近晶体的是第二枚种子的父版本第四名，仍相差 5.341 Å。这些实验只追踪了返回池，无法判断更早的搜索状态是否曾短暂到达正确几何。

坐标来自 1M17 的 A 链 AQ4 999。采用 [wwPDB 化学组分 AQ4](https://files.rcsb.org/ligands/download/AQ4.cif) 的原子名、元素、键级与形式电荷关联 X 射线坐标。证实 29 个重原子均单一位置、占有率 1，CCD 与实际 PDBQT 的化学图一致，严格同构只有一个映射。Meeko 独立解码逐模型核对实际序号与图原子次序。原受体和准备态的 312 个共有 Cα 最大位移为零。RMSD 直接在受体坐标系计算，完整保留了位移与转动误差。晶体分辨率 2.60 Å，配体原子 B 因子 44.57–102.19 Å²，尾链坐标精度有限。此为一个已知共晶的事后对照。[映射、距离与校验值](reference.json)
