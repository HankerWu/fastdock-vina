# 配对姿势实验（运行前冻结）

在查看任一对接结果前选定三个不同的人源靶点，每个靶点两个配体、两个受体。PPARα 使用 1K7L/544、2P54/735；BRPF1 使用 4UYE/9F9、5FG4/5XE；孕激素受体 PGR 使用 1A28/STR、1SQN/NDR。均选 A 链。五个复合物未出现在基线 bcb5d83 的已跟踪基准文本，1A28 在早先的环构象研究中使用过。BRPF1 和 PPARα 是本轮新增目标，PGR 用于检验刚性甾体。不同核受体不视为完全独立的蛋白家族。输入筛选时发现两个 menin 结构的查询配体距离未定元素 UNX 约 3.3 Å，因此未选入。算法组不使用本组结构或结果设计局部步长。

每靶计算两个 cognate redock 和两个 reciprocal cross-dock。使用 CCD 化学图生成起始几何（ETKDGv3 → MMFF，一次）；在全部实验臂中固定同一微态，不以实测结构作初始姿势。受体使用现有制备流程；若任何新建重原子或被省略的非水原子距配体小于 8 Å，先记录再剔除该 **受体**，保留可评估的查询配体。记录晶胞接触和跨构象参考本身的碰撞。搜索盒采用受体原本配体中心、边长 24 Å；这是假设口袋已知。预先指定种子 297131、297149，max_evals 3000、12000，单线程、单轨迹、九个模式、energy_range 100。禁止援引跨体系均值掩盖回退。

四臂分别为 AutoDock Vina v1.2.7、当前 FastDock Pro、十次回退均失败则停止的二分对照、同样停止条件加区间保护二次插值。每个组合的四臂串行，按冻结种子打乱组合，循环平衡各臂的顺序，绑定同一核。以 ≤2 Å 的对称修正重原子 RMSD 判定成功；已有评估器遍历晶体构象与立体化学兼容的分子图映射，使用受体口袋 Cα 对齐后评价，不再拟合配体。保存 Top-1、Top-5、至多九个返回模式的 oracle、以 oracle 成功为分母的 Top-1、原子间冲突、实际搜索/二阶段/显式局部最小化调用和联合能量-梯度评估、端到端时间。记录失败回退统计。种子、预算、受体均为重复条件。单个靶点仅两个配体，评价为描述性；不以全部运行单元计算独立样本显著性。

若候选取得 Top-1 总收益但端到端耗时或联合梯度成本较父版本高逾 5%，在 297131 上逐组合按两档成本线性下调高预算，在 297149 上复验；若无 Top-1 收益不作成本配平后推广。对每个靶点最高预算第一个种子首个 cognate 组合独立重复当前版本与候选，同时检查输出文件字节一致性。晶体初始姿势单独作局部优化前后诊断，不能归入全局对接结果。保留全部纳入条件的逐行结果。
