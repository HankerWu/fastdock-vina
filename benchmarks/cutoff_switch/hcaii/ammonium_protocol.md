# Conditional tertiary-ammonium state test

The 3D prepared inputs select one configuration of an assigned protonated, acyclic, tertiary amine with three distinct substituents. Three of five input signs disagree with the deposited bound heavy-atom geometry on inspection. This finding motivates this retrospective intervention. Every ligand receives both proposed states in the experimental arm, without consulting its deposited sign. The study tests flexibility of the prepared chemical state conditional on the receptor-only zinc-vacancy search protocol. Only these five archived ligands qualify for the exact whole-coordinate mirror used here. Each has exactly one potential stereogenic element in the model, the tertiary ammonium. Each source PDBQT SMILES leaves the nitrogen configuration unspecified.

Use both shared receptor structures (6WQ4, 6WQ8) and all five ligands. Use trial seeds 314159 and 271828. Each trial has a common original-state search at that seed plus a second search at seed + 1, using the original state for the control or the reflected state for the two-state experiment. Apply the same zinc search anchor, explicit molecular graph, native Late refinement, 2 trajectories, and 50,000 nominal evaluations per trajectory to every search. Both arms therefore represent 4 trajectories. Keep up to 9 candidates per subrun, energy range 100. Pool both constituent subrun outputs in each arm. Determine each pose's native explicit inter and intra terms on its recorded coordinates with the matching prepared state and original ligand bond graph, choose the minimum raw sum and use its native flexibility-normalized inter term for the same-target assay ranking. A common additive unbound convention across poses is implicit in this choice. There is no fitted energy offset for either ammonium state.

Primary geometry endpoints are pooled top-1 and oracle heavy-atom receptor-frame RMSD ≤2 Å. Secondary endpoints are the same seven ≥3-fold Ki pairs in each receptor/seed block, per-pose signed pyramidal volume, absolute RMSD and selected state. Compute the signature as the determinant of the three heavy-neighbor vectors in a fixed CCD atom index order. Record the sign in every returned pose and whether the sign matches the bound reference as a retrospective diagnostic. A sign alone does not establish a biochemical microstate population. Report all cells including worsening cases. This test shares the five ligands that motivated it and is exploratory.
