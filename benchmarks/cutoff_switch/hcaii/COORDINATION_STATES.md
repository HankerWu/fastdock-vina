# 锌配位、尾部姿势与叔胺构型的配对实验

五个已发表的 hCA II 配体都含有苯磺酰胺头部和带三条不同重原子支链的叔胺。本次结构评估增加两项观测量。第一项分别测量十个苯磺酰胺头部重原子和其余重原子的 RMSD，两组共用使全配体平方误差最小的同一组化学等价原子映射。第二项测量中心氮三个重邻居向量的混合积符号，邻居按固定的原子身份排列。符号用来比较模型与实验中的重原子排列。X 射线坐标本身不能判定该位点的氢数或溶液微态丰度。实验报道五个配体共用锌配位与 Thr199 主链氢键，部分远端基团电子密度较弱。独立工作也发现对接程序对配体状态的判别存在误差。[Bonardi 等](https://doi.org/10.1021/acs.jmedchem.0c00733) · [Santos-Martins 等](https://doi.org/10.1021/ci500209e) · [ten Brink 与 Exner](https://doi.org/10.1021/ci800420z)

## 在真实候选池中分开测量头部和尾部

磺酰胺氮由准备图的唯一去质子化苯磺酰胺子结构识别。锌空位由刚性受体三配位几何求得。两者均可在读取查询配体晶体坐标前确定；事后与五份 PDB 的配位记录核对，全部氮的身份匹配。原有方向重排、径向重排、仅资格筛选、硬筛选与反向空位阴性对照使用同一批固定坐标。双接触要求 Zn–N ≤2.5 Å，同时任一磺酰基 O 与 Thr199 主链 N 的距离 ≤3.5 Å。该距离判据没有额外的氢键角度限制。

|---|---|---:|---:|---:|---:|---:|
| 原生搜索 | 原生 | 2 | 1.233 | 8.065 | 0 | 10/28 |
| 原生搜索 | 方向重排 | 8 | 0.996 | 7.174 | 0 | 16/28 |
| 原生 Late | 原生 | 1 | 1.280 | 8.067 | 0 | 14/28 |
| 原生 Late | 方向重排 | 11 | 0.752 | 7.754 | 0 | 15/28 |

方向重排中的 Ki 计数使用几何修正后的选择器分。两列都是同一七个实测分子对在两个受体和两个种子上的重复计数。两个池的上限都是 0/20。反向空位在两批池中均重现仅用资格筛选所得的名次与计数。原生主组与补充自身重对接、Late 三批合计 413 个姿势，其全分子 RMSD 与先前 RDKit CalcRMS 独立算法的最大差为 0.0000005 Å。[所有候选和控件](coordination_probe/)

## 先修正已知晶体姿势的投影

旧诊断按固定 CCD 原子名拟合扭转，即使几何评价允许等价的磺酰基氧、环和羧酸氧交换。6WQ4 旧投影的全配体 RMSD 为 0.360 Å，但 Zn–N 已达 3.125 Å，原生精修后为 3.583 Å。新投影为每个合法图映射拟合全部刚体与扭转，选取拟合误差最小的收敛结果。五个配体共 72 种映射，原始与反射的氮构型分别拟合。目标函数使用已最优刚体对齐的平方误差，每个扭转的解析导数用轴叉乘给出。五个配体逐扭转中心差分检验的最大绝对差为 1.27×10⁻⁸。

在原始输入构型上，6WQ4 的新投影 Zn–N 为 1.817 Å，精修后为 1.900 Å，全配体精修 RMSD 为 0.361 Å。五个原始构型的新精修正例均在 0.361–0.750 Å 内，Zn–N 为 1.900–2.327 Å。将一个正例分别加到同配体两个种子的原生自身重对接池后，原生打分在 10 个比较中均把诱饵排在前面。原生分使用相同零内能参考，精修正例的劣势为 2.544–2.989 个柔性归一化分数单位。改为另一氮构型后做同样的图对称拟合和精修，原生仍选中 0/10，劣势为 1.702–2.796。每种构型的方向锌后处理各选中 2/10。这里只测同一配体的几何正例排序，已知晶体坐标进入了投影，不计作盲预测命中。[正例和诱饵的配对结果](coordination_probe/spiked.csv)

## 等预算的氮构型检验

五个输入中，原始三维构象对应的已质子化叔胺，其局部符号在 6WQ5、6WQ8、6WQ9 与实验相反，在 6WQ4、6WQ7 一致。每个图的唯一潜在立体元素是该非环叔胺，输入 SMILES 没有指定构型。因此可反射完整坐标以获得另一种配置。操作保留 PDBQT 索引、扭转树、各原子间距离。它也反射各非手性片段的初始构象。此限制不允许把同一操作直接用于有其他手性中心的分子。

每个比较都由两个 2 轨迹的子运行构成。第一份原始状态子运行在两臂共用。第二份使用相同种子，分别中继原始构型或反射构型。两个受体、五个配体、两个主种子及其加一子种子均使用相同计算预算。按所有已输出候选的显式原生 INTER+INTRA 选姿。在保留构架先验的比较中，给每个候选加上其查询原子与独立供体路标距离的平均伪 Huber 代价，沿用搜索的原系数。最小纯几何代价作为消融。每一行所列 Ki 排序均用选中坐标的原生分和同一合并池的原生共同未结合参考。[设计与种子](ammonium_protocol.md)

| 搜索与最终选择 | 探索构型 | 全配体首位/候选池 | 同时符合全配体与氮符号的首位/候选池 | ≥3 倍 Ki |
|---|---|---:|---:|---:|
| 锌单点，原生选择 | 原始 | 0/0 | 0/0 | 15/28 |
| 锌单点，原生选择 | 两种 | 0/2 | 0/0 | 14/28 |
| 构架路标，原生选择 | 原始 | 5/9 | 0/1 | 9/28 |

每个“首位/候选池”格中的两个数字分别是 20 个条件中首位合格数以及池中至少一个合格姿势的条件数。锌单点新增的两个 ≤2 Å 候选均来自同一查询配体且氮符号与沉积结构相反。构架两状态池的八个双条件候选只出现在 6WQ5、6WQ8 上。另一个配体 6WQ4 在原始状态双份搜索得到的双条件候选因改配一半计算量而丢失。保留几何项后，六个双条件首位是由两个配体、重复受体和种子构成。全体中位 RMSD 从 5.097 升至 5.194 Å。纯几何选择也选出六个双条件首位。该系列支持有条件地改进姿势覆盖与挑选，Ki 与其他骨架的效果另计。[单点明细](ammonium_states/point/) · [构架明细](ammonium_states/scaffold/)

两组实验合计 120 个唯一子运行，各输出 538 个姿势。独立核查从 CCD 重原子邻接与原始 PDB 识别并测量氮三条重邻居，使用标量三重积再算符号，用 RDKit CalcRMS 复算 1,076 个姿势。所有输入内距离精确保持，每个输出的氮构型均保持对应输入符号，RMSD 舍入差小于 5.0×10⁻⁹ Å。独立几何先验实现逐一核对构架池 538 个姿势，最大记录差小于 5.0×10⁻⁹。每个子运行的 PDBQT 哈希列在候选表中。

## 复算

先按本目录 [README](README.md) 生成五个受体、固定图及原生池，运行 crystal_start.py 生成显式键和单姿势文件。预先运行原生 Late 与跨配体构架实验得到两个目录。环境要求与原 hCA II 评估一致，使用含 search_anchor 与多路标实现的 Vina 可执行文件。

```bash
hc=benchmarks/cutoff_switch/hcaii
python "$hc/project_symmetries.py" --work "$work" --binary "$vina" --output "$fits"
python "$hc/project_symmetries.py" --reflected --work "$work" --binary "$vina" --output "$mirrored_fits"
python "$hc/coordination_probe.py" --work "$work" --late-pools "$late_pools" --binary "$vina" --symmetry-poses "$fits" --reflected-poses "$mirrored_fits" --output "$probe"
python "$hc/ammonium_states.py" --work "$work" --binary "$vina" --output "$point"
python "$hc/ammonium_states.py" --work "$work" --binary "$vina" --scaffold-anchors "$scaffold_anchors" --output "$scaffold"
python "$hc/rank_state_pools.py" --runs "$scaffold" --prepared "$work/prepared"
python "$hc/check_ammonium_states.py" --work "$work" "$point"
python "$hc/check_ammonium_states.py" --work "$work" "$scaffold"
```
