# Kinase Kd, receptor-state sensitivity and a transferable search potential

Davis et al. measured all inhibitors in the same binding platform. Their Supplementary Table 4 contains dissociation constants in nM and leaves weak or undetected binding blank. The frozen panel retains exact positive Kd within each of the three unmodified assay rows confirmed in their Supplementary Table 1. There are 13 named compounds, 13 distinct Bemis–Murcko scaffolds across the panel, 22 measured target–ligand combinations and 60 within-target pairs separated by at least threefold. These are selected named inhibitors and measured binders. Potency, chemistry and targets in this retrospective selection do not represent uniform random draws from drug discovery. Compounds and their uses across receptors are present in panel.csv. The files include author-table URLs, identifiers, chemistry and original hashes. [Davis 2011](https://doi.org/10.1038/nbt.1990)

The same prepared molecule, receptor, box, seed and search budget are used in each arm. Native uses standard Vina search. Mixed allocates its second trajectory to Vinardo. Soft allocates its second trajectory to half-strength ligand–receptor repulsion. All arms use native final Late refinement and scoring. Each run allows 25,000 evaluations per trajectory, two trajectories, nine modes and one CPU. The raw outputs contain the actual number of returned modes. Search and line-search work can differ at the same cap. The first two seeds (271828 and 314159) and independent replication seeds (161803 and 141421) each cover every cell. This gives 528 searches across the three arms. The primary/replication labels refer to random seeds only. The experimental measurements are identical in both cohorts.

## Why the reference and weights matter

The native rank-one result uses the intramolecular value of a selected pose as the ligand's zero. Searching with another potential may move this zero even though the reported pose is rescored with the native objective. For the matched-reference arm, the ligand conformer selected before docking was generated by ETKDGv3 and chosen by the lowest converged MMFF energy among eight starts. Its intramolecular energy is evaluated by the native Vina potential once per ligand. The reported diagnostic score is s_l(E_inter+intra − E_intra,prepared). A numerical finite difference under the native explicit unbound-energy setting recovers the ligand-specific conf-independent scaling s_l. This is a consistent computational reference. A single MMFF-selected conformer does not supply the ligand's solution chemical potential. 528 serialized top poses were read back through the independent fixed-coordinate native C++ scoring path. Absolute per-pose discrepancies are below 0.009 kcal/mol and every four-seed pair sign agrees for both reference schemes. A pristine preparation reproduced all 19 receptor/ligand PDBQT inputs and six boxes byte for byte. Running all 176 native searches again in the soft-build binary with the new flag disabled reproduced every original output byte for byte.

For hypothesized state-restricted free energies G and common ligand-free state probabilities p, write K_l ∝ Σᵢ pᵢ exp(−G_li/RT). For weak ligand B and strong ligand A, K_A/K_B is a weighted average of exp[(G_Bi−G_Ai)/RT], with weights proportional to pᵢ exp(−G_Bi/RT). Thus the smallest and largest state-wise gap give sharp lower and upper bounds on RT ln(K_A/K_B) over the state probability simplex. When the interval contains zero, unknown populations allow a reversal or a tie. The CLI reports the exact two-state crossover fraction and equal-population diagnostic. Native empirical scores here substitute for the state free energies. The bounds describe population sensitivity conditional on the scores, chosen structures and ligand preparations. State-consistent signs can still be wrong. For example, on GSK3β the native default-reference arm agrees across states on 14 pairs and only three of those match the measured signs. [Minh 2012](https://doi.org/10.1063/1.4751284)

## Whole-ligand structure check

Staurosporine in GSK3β has an independent crystallographic ligand reference from 1Q3D. A ligand generated only from its 2D graph is docked to the 1Q3D protein and independently to 1Q5K. The 1Q3D co-crystal defines the cognate box. The 1Q5K box comes from its own TMU ligand. The atom graph and stereochemistry of STU are checked against the exact PubChem identity. RMSD uses 35 heavy atoms and exhaustive chemistry-preserving mappings, with no fit of ligand coordinates. Fifty local matched Cα atoms give a 0.629 Å alignment RMSD between the two receptors. All arms hit ≤2 Å at rank one in 3/4 cognate and 0/4 cross-receptor searches. On the cross, native and mixed never return a hit anywhere in their four pools. Soft has one 1.37 Å candidate (seed 161803) at a nonleading rank while the top pose is 5.81 Å. In seed 271828 the best cross-receptor candidate worsens from 2.36 Å under native to 11.18 Å under soft. [1Q3D](https://www.rcsb.org/structure/1Q3D) · [1Q5K](https://www.rcsb.org/structure/1Q5K)

## Input and scope

Receptor PDBQT includes chain A, the observed standard protein coordinates with PDBFixer-completed heavy atoms, and Meeko-added polar H. Alternate positions use blank or A. Water, ligand, ions and other chains are omitted. 2SRC tail pTyr527 is represented as Tyr in its fixed deposited conformation. Crystal construct lengths, crystallization ligands and regulatory states can differ from the binding assay. Deposited 2SRC is an autoinhibited multi-domain protein, and the two chosen states need not be exhaustive. Ligand starts use supplied stereochemistry and input formal microstates, without a pH-dependent tautomer or protonation ensemble. R406 uses the binding parent after explicit removal of its disconnected benzenesulfonate component. The authors' conditions are comparable within a kinase's panel. The assay does not supply an individual standard error for every bound pair in this analysis. The threefold threshold is a descriptive margin. 298.15 K is a conversion and pooling convention. All three targets are within the kinase superfamily. These limitations and the observed low hit rates motivate keeping the alternative potential opt-in.

## Replay

The source and prepared evidence use Python 3.12, RDKit 2026.9.2, Meeko 0.8.0, PDBFixer 1.12.0, OpenMM 8.6.1, gemmi 0.7.5, xlrd 2.0.1 and NumPy 2.3.5. Run commands in this benchmark directory. Use binaries from the stated implementations in build-provenance.json. The soft, mixed and native flags can also use a single binary if it implements all three arms.

1. Extract the input and output archive in the benchmark directory with `tar -xJf docking-evidence.tar.xz`. Raw pose files and logs for both seed cohorts are available. A fresh scratch directory plus `python source/fetch.py WORK` reconstructs the versioned original source inputs needed by the independent data checks. To use the saved PDBQT, leave the prepared files in place. To rebuild preparation in WORK, first run `python source/freeze.py WORK`, then `python source/prepare.py WORK receptor` and `python source/prepare.py WORK ligand`.
2. Search with `python source/dock.py WORK BINARY --arm native --jobs 3`. Repeat using `--arm mixed` and `--arm soft`. Every case uses the same box, seed and budget across arms. Run the second cohort in a fresh directory with the same prepared files and panel.csv, adding `--seeds 161803 141421`. Use fresh output directories when changing binaries or search settings.
3. Run `python source/collect.py WORK BINARY --arm native` for each arm and repeat with the independent seed list in the second directory. Place the replication directory under `WORK/independent-seeds`. Run `python source/pose_audit.py WORK` for the first cohort. Also run that script with the independent cohort directory and seed list, reusing the same raw/prepared inputs.
4. From the evidence directory, `python source/independent_audit.py . --replicate` independently recomputes outcome signs, analytic crossovers and paired uncertainty from both cohorts. Run `python source/rescore.py . BINARY` to re-read all final top poses with the fixed-coordinate native C++ scorer. To analyze another score CSV with the same equilibrated-state interpretation, run `python implementation/ensemble_affinity.py INPUT.csv`. Its input columns are target, ligand, state, replicate and energy. Experimental labels are unnecessary.
