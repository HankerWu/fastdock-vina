# 同预算更换游离态构象库的固定姿势反事实

在读取新构象能量前固定以下规则。沿用已有 14 个 BACE1 配体、28 个 FXa 配体和 13 个凝集素配体。保持每个结合重原子坐标、结合态能量、原生首姿、受体、种子和测定分组。FXa 主比较使用已归档的 CHEMBL369480 几何修复首姿，其余分子完全冻结。BACE1 和 FXa 采用原同测定至少三倍 Ki 分子对，凝集素采用原同测定至少三倍 Kd 分子对。沿用每项原定的种子和受体聚合方式。

用种子 777 的八个游离真空极小值，逐配体穷举所有四元子集，考察真空和 OBC-II 各自的最低能参考。每对配体的子集独立选择，同一配体的参考在所有种子、受体、模式间共用。统计所有子集组合下预报分差的范围、期望方向准确分以及方向是否始终一致。以四个而非更多构象进行诊断可以检验对已有极小值覆盖的依赖；此范围仅描述已采样几何，不作为置信区间。

**独立检验**。相同生成流程、相同每配体八次 ETKDGv3 尝试，仅将随机种子换为 1618033。真空 MMFF94s 松弛及 OBC-II 单点不变。不得合并两个库、择优选库、增加构象或重试失败。比较两批八构象的净排序变化、双向翻转，以及四元子集“方向恒定”的比较能否在新生成库上保持。以另一个已归档的 32 构象、种子 49043 的 BACE1 真空最低参考作额外核对。新构象不使用实验排序。真空势和溶剂势分别评估；不把它们的最佳结合视为一项算法。既有 BACE1/Xa/凝集素面板是历史数据，不能检验跨靶点泛化。

相同配体参考在任意两个姿势的分差中严格抵消，预测所有冻结池的姿势次序不受干预。只有跨配体分差可改变。若重采样后同一受体同一姿势上的分子对明显调换，原增益至少部分依赖有限构象库。稳定于两批八构象仍不能证明该参考近似热力学游离态。
