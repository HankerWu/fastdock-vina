# 更换八个游离参考构象会改变多少亲和力排序？

因子 Xa 在修复畸变输入后的 OBC-II 结果为 229/295。同一批 28 个配体、相同结合坐标和评分函数下，仅独立重抽八个游离参考构象，结果为 222/295。原生 Vina 为 216/295。9 对由错变对，16 对由对变错。BACE1 的真空 MMFF94s 总分在两批构象间仅变化一对；同样的参考更换也未能挽回 Gal-3 的排序损失。[计算前协议](PROTOCOL.md) · [实验测定、坐标及参考模型](../README.md)

对每个配体，完整替换分数写为 $S=C+f[B-F]$。$C$ 是原生首姿移除配体内部差项后的分数，$f$ 为原生柔性系数。真空臂的 $B$、$F$ 是 MMFF94s 能量，溶剂臂则含 OBC-II 极性反应场。两批分别独立生成、各自选库中最低能量 $F$。因此 $S_2-S_1=f(F_1-F_2)$。该偏移在同一配体所有受体、种子和候选姿势上相同，对跨分子的分差可以有影响。两批使用相同的微态、八次 ETKDGv3 尝试及真空极小化，种子分别为 777、1618033。所有 55 个配体每批均得到八个收敛构象。配体在溶液中各构象盆地的占有率还取决于各盆地的构型积分；ETKDG 构象的频数不能直接给出该占有率。[Gao、Park 和 Stern 对配体构象限制自由能的原始研究](https://doi.org/10.1016/j.bpj.2009.11.018)

## 子集稳定性可识别重复抽样风险

每个配体的旧库有 70 种四元子集。每对分子各选一组，一共有 4900 种组合。每次仅在各自子集中重新选择参考能量。统计分差在全部组合中的符号是否恒定；同一配体在全部对接重复中共用参考。此诊断只使用预测时可见的模型能量。下表对照该判据与事先冻结的新八构象库。

| OBC，同受体聚合 | 旧库子集方向恒定 | 其中在新库翻转 | 原生/新 OBC 判对 | 旧库子集方向可变 | 其中在新库翻转 | 原生/新 OBC 判对 |
|---|---:|---:|---:|---:|---:|---:|
|因子 Xa|184|3|137 / 153|111|22|79 / 69|
|Gal-1|7|0|5 / 4|16|4|12 / 11|
|Gal-3|15|2|12 / 9|20|6|16 / 8|

因子 Xa 中 111 个可变对占 37.6%，包含 25 次独立翻转中的 22 次。恒定组的绝对准确率在凝集素上仍低于原生。对 BACE1 真空 MMFF，旧库的 57 次恒定比较在独立八构象和已归档的独立 32 构象上均保持方向；余下的 15 次比较在两组复核中均有一次翻转。预测方向对重采样稳定和相对实测方向正确，是两个不同的观测量。

一个能直接复查的漏判是因子 Xa 的 CHEMBL369480（Ki 0.46 nM）和 CHEMBL24907（4.0 nM）。旧库 OBC 分差 2.846，所有四元子集中的范围为 [0.156, 3.283]。新库中二者分别产生 +1.285、−2.172 的分数偏移，配对分差变为 −0.612。该反例发生在相同净形式电荷 +2 的分子间；两者的所有结合坐标保持固定。[逐配体参考能量与分数偏移](ligands.csv)

因子 Xa 新库在 17 个等重原子数且等形式电荷的分子对上，原生/真空/OBC 为 8/9/10。全部 295 对的新 OBC 相对原生净赢 6 分，删除一个配体及所有相关分子对后的净优势介于 −12 和 +13 分。单是与 CHEMBL172831 有关的 22 对就贡献 +18 分。聚合分母和相关性随删除而变，逐分子删除范围仅是影响度。现有结果不足以按参考稳定性启用 MMFF/OBC，也没有确立跨靶点的亲和力收益。

## 复算

复用上级实验已记录的 2017 个结合姿势和 440 个原参考。新库的 440 个真空极小化、OBC 单点和原子间距见[原始新构象数据](independent_references.csv.xz)。不新增对接、BFGS 或候选精修。独立复算时，同一单进程顺序重建两批八构象库，含输入归档读取分别耗时 63.31 / 64.10 秒，CPU 用户态与内核态合计 63.21 / 64.00 秒；进程累计峰值内存 198.9 MiB。两批全部 880 个参考的真空能、反应场和两者之和均与各自归档逐值相等。单批游离态生成仍是原生分数之外的额外开销。固定汇总不计入新的对接端到端时间。

固定 Python 3.12、RDKit 2026.09.2、Meeko 0.8.0、gemmi 0.7.5、OpenMM 8.6.1，使用 Reference 平台、单工作进程，数据处理另用 NumPy、SciPy 及 pandas。生成器按原子和键重建相同图，移除所有旧坐标后嵌入。第一步可跳过，使用已提交的新构象表即可复算统计。第二个核验脚本独立从绝对结合态能和参考能重建 2262 个分差，并检查两种参考切换的全部 376 个池各姿势顺序。

```sh
D=benchmarks/frozen_core/solution_strain/reference_sampling
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1 OPENMM_CPU_THREADS=1
python "$D/generate.py" "$W"
python "$D/replay.py" "$W"
python "$D/verify.py" "$W"
for t in independent_references.csv.xz ligands.csv pairs.csv.xz summary.csv correlations.csv; do
  cmp "$D/$t" "$W/$t"
done
```
