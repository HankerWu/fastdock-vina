# 水反应场能否解释 MMFF 在 BACE1 与因子 Xa 上的相反结果？

在完全相同的原生首姿和真空游离参考态上加入配体的水反应场差，因子 Xa 同测定的 295 个三倍分离分子对从 206 个判对降到 202 个。在同一批八个游离构象上按溶剂能量重新选参考态，才能回到 221 个，原生 Vina 为 223 个。这个差别可以追溯到对游离态的选择。同一替换降低了两种凝集素的排序准确率，未进入默认评分。

## 冻结坐标的干预

使用此前 42 个 BACE1 / FXa 配体的全部 168 个原生首姿，外加 13 个硫代半乳糖苷的 208 个完整池。凝集素属于另一蛋白家族，历史数据已知。两种凝集素共用配体。实验保留此前的受体、配体微态、种子、坐标、MMFF94s 对固定重原子只优化氢的步骤、种子 777 的八个真空极小值和 Vina 柔性系数。三倍阈值来自已有实验。各分子四至十六个受体/种子条件是配对重复。没有重新进行候选生成。详见[计算前方案](PROTOCOL.md)、[蛋白酶输入和实验 Ki](../strain_components/README.md)、[凝集素池与实验 Kd](../transfer/galectin_mmff/README.md)。

令 B 为结合几何，E 为原有真空 MMFF94s 势，G 为原子 MMFF 电荷、OpenMM 标准 mbondi2 半径和屏蔽参数计算的 OBC-II 极性水化自由能，W=E+G。对真空力场使用内部介电常数 1，水相为 78.5，忽略非极性表面积项和盐，所有能量先换为 kcal/mol。设 F 为八个真空极小值中 E 最低的几何，Fw 为同一批几何中 W 最低者。C 是扣除 Vina 配体内部差值后的原生分数，f 是原 Vina 柔性系数。三个替换臂分别计算：

|方法|预测分数|
|---|---|
|完整真空 MMFF|C + f [E(B) − E(F)]|
|固定 F，加水反应场|C + f [W(B) − W(F)]|
|同库重选 Fw|C + f [W(B) − W(Fw)]|

重选带来的增量 f[W(F)−W(Fw)] 对每个配体恒定且非负。它可改变不同配体的排序，同一池各姿势之间的分差保持不变。全部 208 个池均逐项核对。OBC-II 在这里计算孤立配体处于冻结几何时的极化响应，没有对应蛋白质环境、相互作用及配体/受体去溶剂化。八个构象没有在溶液势下采样或优化。这个反事实检验只能定位显式数值贡献；经验混合分数缺少作为结合自由能的校准。[OBC 原始工作](https://doi.org/10.1002/prot.20033) · [OpenMM 方程](https://docs.openmm.org/latest/userguide/theory/02_standard_forces.html#gbsaobcforce)

FXa 先逐对取同种子、同受体分差的中位数再计方向。凝集素取每个受体种子分数的中位数，再对两个受体取算术平均。BACE1 两个 Ki 测定共 14 个分子，仅有 36 对不同化合物比较；两个受体重复观察这 36 对。FXa 两受体合并时重选相对原生新判对 45 对，失去 47 对，203 对相同。对单个配体及其相关边一起剔除，准确率差在 −6.59 到 +4.38 个百分点之间。FXa 的 17 个等重原子数、等电荷对分别判对 9、7、11、11 个。BACE1 中收益和退化可在同一测定的不同受体上出现。逐受体 Spearman、Kendall τ-b、同骨架、同电荷与高倍数分层见结果 CSV。

FXa 有五个净 +1 两性离子和 23 个净 +2 配体。每个配体先取四个首姿上 f[G(B)−G(F)] 的中位数，随后组内对配体取中位数，分别为 −60.24 和 −8.06 个分数单位，同为 +1 的两个 BACE1 测定仅为 −1.04 和 −0.97。这符合从紧密内盐换到较展开结合几何时，反应场补偿真空静电代价的方向。固定 F 的处理让 FXa 跨电荷的 90 对由真空的 72 降到 60，同电荷的 205 对由 134 增至 142。重选 Fw 后两组为 74 和 147。在五个两性离子中，仅 CHEMBL171966 的 Fw 与 F 不同，最近羧酸盐/脒基中心间距由 3.75 变为 8.53 Å。其他四个在该有限库内仍选同一紧密构象。23 个双阳离子中有 11 个改选参考态。已知两性离子和双阳离子在结构、测得 Ki 和电荷上均有组间差异，现有实验无法估计水溶液中的构象占比。

在看到原始 FXa 四臂结果后，追加一项独立于构象库的几何干预。仅用先前已归档的四个同种子、同预算首姿替换 CHEMBL369480 的异常准备态，另 27 个配体完全冻结。在原输入上，其 21 对关联边各臂为 **17/3/3/3**；修正准备几何后为 **10/14/13/14**。全体 295 对变为 **216/217/212/232**。因子 Xa 的回顾性组合结果比原生高 16 对，两个受体分别为 219.5→223/295 和 187→232/295。修复潜在输入依赖和更换游离参考对不同化合物各自有影响。这个 16 对的增量不足以选择预测算法。其余 274 对四臂为 206/203/199/218，两个输入版本完全一致。早期版本给出的 216/215/208/229 在更换准备态后仍使用五转子的旧系数。以上数字使用对应输入的七转子系数，并从原坐标重新进行了真空与两种 OBC 评分。[已归档的八次对接、畸变单键及原设置](../strain_transfer_audit/README.md) · [替换后的逐受体结果](corrected_summary.csv)

## 成本与复算

55 个独立配体各使用八个既有协议的游离构象，诊断共生成 440 个收敛的真空极小值，重新进行 2,017 次固定重原子的氢松弛，再做 2,457 次配体极性水化单点评估。四个几何修复首姿另行复算。主实验在 Reference 数值平台上蛋白酶用时 54.94 秒、凝集素用时 49.00 秒（单进程，从解包到算完分数，含数值核验，不含统计汇总）。第二次单进程从读取到写完所有分数与统计的完整重算为 107.54 秒墙钟、107.13 秒 CPU，进程内存峰值 203.07 MiB；另一个修复输入进程为 3.03 秒墙钟、3.03 秒 CPU。原生读取已有首姿无需以上求值。这些额外计算均进入成本，未进行等墙钟的全流程比较。新模型缺乏跨家族评分、姿势和成本优势。原生生产打分与搜索路径继续沿用分支行为。

独立切换至 OpenMM CPU 平台再算全部 2,017 个姿势、440 个参考与四个修复首姿。两平台的蛋白酶 957 行配对、凝集素 696 行配对方向以及所有 Top-1/5、相关性、逐分子留出统计完全一致。全部结合几何的反应场能量 G 在两平台间的最大绝对差为 0.000147 kcal/mol。BACE1 配体 CHEMBL2011965 的参考最低构象编号由 2 变为 7，两者在 Reference 上的 W 仅相差 0.0000055 kcal/mol，未使观察到的任何比较改变方向。精确参考编号不宜解释为有物理意义的态选择。

使用 Python 3.12、RDKit 2026.09.2、Meeko 0.8.0、gemmi 0.7.5、OpenMM 8.6.1、NumPy 2.3.5、SciPy 1.17.0，在仓库根目录执行。预存原始 PDBQT、结果和测量标签位于上述父实验目录，脚本直接读取。复算会核对每个冻结姿势的原生分数、完整真空分数、游离参考和重原子坐标，凝集素还逐池核对 SHA256。modes.csv.xz 和 references.csv.xz 保存了每个姿势及每个游离参考的能量。蛋白酶逐配对差、相关性、逐分子留出和全部凝集素配对均随代码归档。
