# 从受体羟基方向到实测配体排序

人碳酸酐酶 II 的 Thr199 在 4G0C 中离乙酰唑胺的 N1 仅 2.598 Å。中子模型把 Thr 的 D 放在朝向蛋白 Glu106 的方向。人醛糖还原酶 2R24 的 Tyr48 则直接向抑制剂 IDD594 的羧酸氧供氢。本目录复算这两种物理情形，并检验同一种受体取向模型能否改善三个测定中的配体排序。评分假设和测定事先冻结于 `0010f20`。后续根据第一轮退化加入的成键扭转势与 PPAR 迁移试验冻结于 `f17c265`。[第一轮积分实现](../hydroxyl_partition/README.md) · [独立结构与后续 PPAR 面板](../directional_polar_validation/README.md)

## 局部角势、参考态和实验坐标

对每个可动 Ser、Thr 或 Tyr 羟基，以碳氧轴的方位角 φ 表示取向。每个受体羟基只选一个角，与多个配体原子的作用共享该角。在 72 个等间距节点，令 U 为去掉配体后同一干燥受体重原子构型上与其他残基受体原子的角势。令 P 为在给定角度把 Vina 原径向氢键改成具有方向性项后产生的非负惩罚。模型对一个活动羟基采用

$$
C=-RT\log\!\left(\frac{\sum_k\exp[-(U_k+P_k)/(RT)]}{\sum_k\exp[-U_k/(RT)]}\right).
$$

再将这些 C 与非活动供体的固定角惩罚相加，除以生成该候选分数时的 Vina 转子分母，与原分数相加。使用 298.15 K；能量采用 Vina 的经验 kcal/mol 标度。第一轮的 U 缺少内禀扭转势，第二轮同时向分子和分母中的 U 加入 X–C–O–H 的 MMFF94s 正二面角势。Ser、Thr、Tyr 分别取乙醇、异丙醇、苯酚的参数，通过侧链局部原子坐标映射。每一项采用 $[V_1(1+\cos\phi)+V_2(1-\cos 2\phi)+V_3(1+\cos 3\phi)]/2$。三个类似物各 72 点相对能量均与 RDKit 独立力场的纯扭转项相差小于 $10^{-8}$ kcal/mol。未进行参数拟合。分母在这里代表特定固定重原子环境中的局部角度参考；模型没有配体水溶液游离态、口袋水交换、其他侧链协同松弛、酸碱平衡或标准态体积。[MMFF 原始扭转参数工作](https://doi.org/10.1002/(SICI)1096-987X(199604)17:5/6%3C587::AID-JCC4%3E3.0.CO;2-Q) · [蛋白羟基氢方向的中子研究](https://doi.org/10.1073/pnas.87.12.4468)

中子检验只涉及论文指明的两个接触网络。输入是沉积的重原子坐标、理想 0.97 Å 键长和 109.47° 键角。受体羟基 D 只用于评价；4G0C 的双向供氢对照使用了已测得的**配体** DN11。这里利用额外结构信息解释机理。角误差是同一圆锥上的方位差，不包含核坐标精化和热运动的不确定性。

|中子结构|从沉积坐标复算|相对实验羟基方向的结果|
|---|---|---|
|4G0C，Thr199|Thr–D···药物 N1 为 59.33°，Thr–D···Glu106 OE1 为 172.56°，受体 D 占有率 0.86|强制 Thr 向药物供氢时最优方位偏 134.26°。允许药物反向供氢后，单独的配体项对转角为常数；加入蛋白内接触，最优方位偏 0.74°。加入 MMFF 后偏 4.26°，落在实验方向 ±30° 的模型权重从 0.296 升至 0.384。|
|2R24，Tyr48|Tyr–D···IDD594 O33 为 171.11°，D 占有率 1.00|配体角势最优方位偏 5.49°，加入苯酚扭转势后偏 0.49°；±30° 权重从 0.252 升至 0.628。单独的扭转势有两个约差 180° 的等价极小点，配体接触在这个模型里区分了这两端。|

两例的 72 点均匀权重在 ±30° 内为 0.167。该概率是计算模型的角度质量；晶体模型每处只提供一个精化的主取向，无法据此校准真实概率。2R24 的 Lys77 NZ 距 Tyr48 O 3.031 Å，另有辅因子。干燥的受体供氢→其他受体原子项在此为常数，真实的局部电场和质子化仍然可能很重要。[4G0C 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3524527/) · [2R24 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2538850/) · [逐接触几何](results/neutron_contacts.csv) · [逐角权重](results/neutron_scan.csv)

## 固定首姿的同测定亲和力

使用既有归档的 234 个原生首姿，固定所有坐标、查询拓扑和游离态参考。按 `dec913f` 的转子计数把既有输出的 INTER 恢复到同一分数标度。每个配体先在各受体内取种子中位数，再跨受体平均。在同一次测定内评价至少三倍浓度差的分子对，精确相等的预测计半分。重复受体和共享配体的边存在依赖，不以边数作统计独立样本。[数据、参考和原始化合物来源](../../terminal_rotor_score/README.md)

|---|---:|---:|---:|---:|---:|---:|
|Galectin-3，47 配体 Kd|6/94|113/403|136/403|135/403|135/403|113/403|
|因子 Xa，28 配体 Ki|27/112|207/295|214/295|213/295|214/295|215/295|
|S6K1，14 配体 Kd|5/28|32/58|32/58|32/58|32/58|32/58|

Galectin-3 的完整积分改对 37 对、改错 15 对，但 Spearman 仍为 −0.262（原生 −0.363）。在该系列把其他供体全部恢复为原径向模型，净收益消失。因子 Xa 的单独羟基项改对 10 对、改错 2 对；逐个去掉一个配体后净增 1 至 9 对。该组结果可作为后续外部同类测定的假设。S6K1 合计方向相同，细小分值变化仍影响未达三倍的近邻。完整运行没有新增的对接求值；本机五份受体方向预计算合计 0.077 CPU 秒，234 个首姿的各评分对照合计 0.116 CPU 秒，均不含原搜索。准备态、真实受体构象和测定来源在三个系列之间不同，绝对分与 ΔG 没有单独标定。[逐首姿](results/affinity_poses.csv) · [逐分子对](results/affinity_pairs.csv.xz) · [逐受体、秩相关及逐配体删一](results/affinity_summary.csv) · [成键先验](results/bonded_affinity_summary.csv)

在 136 个冻结姿势池里，原生、固定角、共同最优取向、接触先验积分分别有 40、35、38、36 个首位命中。加入成键先验后为 37/136，唯一跨过 2 Å 阈值的变化是 FKBP1A 的原生首位从 3.399 Å 选回 1.556 Å。这个比较中的各臂 Top-5 都是 63/136，池上限 66/136。单独看未参与调整的 PPAR 挑战，完整积分和加成键先验都把 PPARG 的 1.925 Å 首位换成 9.093 Å。首轮独立面板两个合格体系的池均无命中。源自中子几何的机理支持不足以使完整积分成为默认重排器。[所有冻结池](results/bonded_pose_cells.csv) · [PPAR 原子与排序反例](../directional_polar_validation/README.md)

## 搜索失败的刚体与构象对照

对第一组新结构还做了参考辅助的坐标互换。MAP3K7 的 35 个盲搜输出，按所有合法图映射做最佳刚体叠合后，内部形状距晶体为 1.066–1.979 Å。在四个种子–预算组合中，各取原生首位，只把盲搜得到的形状放在参考位置和朝向，再做相同局部精修，4/4 落入 1.21–1.71 Å。反过来把参考内部形状放到盲搜的错误位置，四次均未命中。MALT1 的四个首位，即使纠正刚体定位，精修后仍为 2.39–2.61 Å。这个交叉干预分别保留内部距离或整体位置，能定位主要误差来源；真实盲搜无法使用当时提供的晶体定位信息。[逐坐标干预、距离与原始输出](basin/README.md)

## 复现

从仓库根目录运行。首轮参考 Pro 的来源是 `dec913f`。使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0 和第二轮 RDKit 2026.09.2，所有结构均有归档。输入的两份完整 PDB 由 RCSB PDB 提供，程序校验 SHA-256；可从 files.rcsb.org 的 download/4G0C.pdb 和 download/2R24.pdb 重新取得。最终拓扑修复二进制重跑 6 个共晶复合物、24 个条件，210 个释放姿势的完整 PDBQT 文件与原记录逐字节相同。旧档案中的其余候选只复算打分，没有重新搜索。[发布源码回放](results/release_replay.csv)

~~~bash
D=benchmarks/frozen_core/hydroxyl_evidence
W=$(mktemp -d)
tar -xJf "$D/neutron_pdb.tar.xz" -C "$W"
python "$D/check_bonded.py"
python "$D/neutron.py" "$W" "$W/results"
python "$D/affinity.py" "$W/results"
python "$D/replay_bonded.py" "$W/results"
python tools/build.py --output-dir build/core
python "$D/release_replay.py" build/core/vina "$W/results/release_replay.csv"
~~~

生产源码、XS 与 AD 格式以及柔性侧链回归均在 [GitHub Actions](https://github.com/HankerWu/fastdock-vina/actions/runs/45960014506) 通过。默认拓扑修复的同坐标结果、新旧搜索及化学图对照见[声明转轴实验](../../declared_rotor_bonds/README.md)。
