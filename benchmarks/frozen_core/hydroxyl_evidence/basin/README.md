# MAP3K7 的结合盆地是因定位还是内部构象而漏掉？

2YIY 的 35 个盲搜输出虽然没有一例在受体坐标系落入 2 Å，但逐个允许刚体最优配准后，每一个都能以原来的内部构象到达 1.066–1.979 Å。四个种子与预算组合各取原生首位，只给配体正确的整体位置和方向，再运行同一局部优化，四个均命中。这说明该池在评分前缺少正确的整体定位。内部构象仍影响能量和更细的几何精度。MALT1 使用相同操作时，四个盲搜首位全部未命中。[逐个盲搜构象的几何界](results/internal_coverage.csv) · [配对精修结果](results/factorial.csv)

## 坐标干预

模型、候选池、独立制备配体及晶体投影输入取自前一项盲测。取以晶体扭转角、游离配体键长键角重建的 best_projected-input 为参考 P，每个盲搜输出池分别取原生首位 B、受体坐标系下最接近晶体的一项。后者及所有使用 P 的行都有答案信息。对每种保留立体化学的等价重原子映射，在 B 与 P 间解 Kabsch 最小二乘刚体变换，选取内部配准误差最低者。对 2YIY/4I1R 分别枚举 12/1 个映射。变换的旋转行列式为 +1。对给定配体应用同一变换到所有原子，包括氢，全程保留原子编号。[结构、盲搜和参考投影输入](../../directional_polar_validation/first_stage/raw.tar.xz)

四臂构成一个配对实验：保留 B；以同一刚体变换把 B 的内部构象置于 P 的坐标框架；用逆变换把 P 的内部构象放回 B 的框架；保留 P。在各自模型内，精修前不改变任何原子间距。RMSD 评价始终在蛋白坐标系，最优刚体配准仅用于构造干预和单独标注内部形状下界。这套整体方向定义依赖所选重原子及其等权度量。

每个输入用原始配体 PDBQT 的全部拓扑行、类型与电荷，仅替换 XYZ 小数点后三位坐标。调用普通 --local_only 单线程原生优化器。C++ 解析器独立比较所有输入和精修输出与原始配体的元素/AD/XS 类型、电荷、共价连接、转轴、分支树、自由度和全部内部分项原子对及能量表索引，全部一致。与原始查询的个别共价键长度最多相差 0.00286 Å，其中包括多次 PDBQT 序列化。新序列化造成的单次刚体变换全重原子对距离变化最多 0.00129 Å。对最终输出另以原始配体拓扑与 --pose_coordinates --score_only 重算 INTER+INTRA。表中的 final_energy 采用此结果；与优化器打印的连续坐标能量和最多差 0.022。分值仅用于同一配体相同受体的姿势比较。

## 结果与反例

四格的盲搜使用 3,000/12,000 每轨迹的 max_evals、43103/43117 两个种子。因一项逆变换使重原子距原盒中心某一坐标轴 13.09 Å，主结果对所有臂统一用同中心的 48 Å 盒，再按原 24 Å 位点盒做敏感性对照。下表为 48 Å 盒、每个池原生第一名精修后的成功数和 RMSD 范围，P 控制在四格中实际只算一次。

| 受体与配体 | 盲搜形状与位置 | 盲搜形状放到投影位置 | 投影形状放回盲搜位置 | 投影形状与位置 |
|---|---:|---:|---:|---:|
| MAP3K7 2YIY | 0/4，5.35–14.42 Å | 4/4，1.21–1.71 Å | 0/4，5.59–19.63 Å | 0.326 Å |
| MALT1 4I1R | 0/4，6.90–7.73 Å | 0/4，2.39–2.61 Å | 0/4，7.05–8.09 Å | 2.302 Å |

MAP3K7 的四个首位纠正刚体定位后，分数范围为 −10.39 至 −7.48，带有参考扭转及位置的 P 精修至 −14.66。对于该组构象，正确放置足以通过 2 Å 判据，精确的内部构象对低能和亚埃精度仍有作用。将原始 24 Å 盒恢复后，放置干预的四次命中均保持；反向干预一例初态越界，其余三例均未命中。另有两个种子/预算单元复用了同一个“距离最近”形状，其纠正定位后的精修在 24 Å 范围得 1.70 Å、48 Å 范围得 27.81 Å。盒边界与大幅移动能影响局部精修轨迹，这两行源于同一组坐标，仅计一次构象反例。[原盒实测](results/box24.csv)

MALT1 有 26/36 个盲搜内部形状可以刚体配准至晶体 2 Å，晶体投影的初始 RMSD 为 0.947 Å，却经局部优化增至 2.302 Å；直接使用晶体内部几何的既有对照精修到 0.194 Å。对 14 重原子的刚性三环片段，与晶体最优叠合后的 RMSD 为 0.240 Å；两芳环面最小夹角为 11.48°（投影）及 5.99°（晶体）。另一段 7 重原子的片段有一对原子相距 2.462 Å，晶体为 2.810 Å。刚性片段内的距离不能用 PDBQT 的扭转坐标修正。上述几何差异与能量响应均有实测，但尚未隔离哪一处内部几何主导了实际的 2.302 Å。使用池中距晶体最近的候选会出现条件性救回：不同池中两种互换各有一次命中，分别是 1.74 和 1.97 Å。[刚性片段实测](results/rigid_fragments.csv) · [环平面](results/malt1_aromatics.csv)

64 个因子组合对应 47 个不同的初始坐标，主实验执行 47 次局部优化，合计墙钟 28.75 秒。另加每个输入/输出各一次固定坐标评分，原盒复核对 47 个坐标单独运行。这些数值来自带有晶体信息的干预，不能计入盲搜成功率。这里没有用新增随机搜索改变任一输出池，也没有对亲和力作独立检验。[数值复核](results/audit.json) · [全部输入、输出与日志](results/raw.tar.xz)

## 复算

从分支 dec913f 构建 Vina 和已有 C++ 拓扑探针。若使用定制 Boost，编译、链接和运行时应使用与 Vina 相同的头文件和库前缀。下列命令在仓库根目录执行，vina 指向该版本二进制，Python 使用 NumPy、SciPy；rigid_fragments.py 另需 RDKit。

~~~bash
D=benchmarks/frozen_core/hydroxyl_evidence/basin
W=$(mktemp -d)
g++ -std=c++17 -O3 -DNDEBUG -Isrc/lib benchmarks/rigid_lookahead/topology/probe.cpp \
    $(find build/obj -name '*.o' ! -name main.o) -lboost_thread -lboost_filesystem \
    -lboost_program_options -lboost_serialization -lboost_system -o "$W/probe"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python "$D/swap.py" "$W/replay" build/vina "$W/probe"
python "$D/coverage.py" "$W/replay"
python "$D/box_control.py" "$W/replay" build/vina
python "$D/rigid_fragments.py" "$W/replay"
~~~
