# Galectin-1 和 Galectin-3 的固定候选池构象应变检验

在这两个凝集素上，将 Vina 的配体内能差替换为单位权重 MMFF94s，原生首姿对 Kd 的判断在 Gal-1 为 17→17/23，在 Gal-3 为 28→21/35。用糖环的位置检查完整候选池时，两种凝集素的首位命中数分别由 32 降至 19、由 4 降至 3。两种游离态参考都没有足够证据用于默认评分。

## 分子、结构与对照

Peterson 等的竞争荧光偏振实验给出了同一组 13 个硫代半乳糖苷在两个蛋白上的 Kd。原论文 Table 1 的 5–16 均带芳基三唑，最弱的 17 缺少这个基团。本次对每个化合物保留既有原生对接的全部四个受体/四个种子组合，总计 208 个池、1,849 个姿势。这个系列曾用于评估搜索及核心定位；对建立全权重 MMFF 替换的 BACE1、FXa 是不同的蛋白家族和骨架。两个凝集素有亲缘关系，且共用全部配体。糖环参照来自不同的共晶配体，3T1L 使用 C2 构型不同的糖；本实验缺少查询配体在该受体中的全分子共晶坐标。[原始测定](https://doi.org/10.1021/acs.jmedchem.7b01626) · [受体、原输入和原生对接](../../../galectin_affinity/README.md) · [计算前确定的方案](PROTOCOL.md)

对每个冻结姿势 B，令 C 为原生分数扣掉柔性因子乘以保存的 Vina 分子内能差。完整替换分数为 C + f[E(B) − E(F)]，其中 F 是既有方案以种子 777 用 ETKDGv3 生成的八个真空构象中收敛且能量最低的 MMFF94s 极小值。准备态对照以 E(P) 代替 E(F)，其中 P 是实际对接输入。在 B、P 的每次氢原子松弛后均以数组严格相等核对全部重原子坐标，且逐模式核对配体化学图、Meeko 的原子顺序和原生分数。[原方法及之前的跨体系检验](../../strain/README.md)

## 固定原生首姿的亲和力

每个化合物先对一个受体的四个原生首姿分数取中位数，再对同一蛋白的两个受体取算术平均。双受体表每条化学配对只计一次。受体权重沿用原分析，溶液中各受体状态的占有率未知。以下比较均要求同测定中心值相差至少三倍。

|蛋白及子集|配对数|原生|完整替换|准备态参考|
|---|---:|---:|---:|---:|
|Gal-1，全部|23|17|17|14|
|Gal-1，仅 5–16|13|7|8|10|
|Gal-1，同分子式|1|1|1|1|
|Gal-3，全部|35|28|21|22|
|Gal-3，仅 5–16|25|18|20|22|
|Gal-3，同分子式|1|1|1|1|

Gal-3 的完整替换在 5–16 内净增两对。在与 17 有关的十对中，原生为 10/10，完整替换为 1/10，准备态参考为 0/10。原生已经正确识别这个弱配体；完整替换给它的双受体分数增加 7.97 个分数单位，其他 12 个化合物的增量中位数为 12.39。从数值上看，取代基不同的衍生物承担了更高的构象校正，足以颠倒原先的组间分差。在 Gal-1，17 和其余类似物的对应校正为 +12.58 和 +11.96。这里没有测量溶液构象占有率，也没有查询配体在两个实验口袋内的结合态结构；这些首姿计算不能给放置位置、去溶剂化或真实应变各自归因。

在 Gal-3 全组，原生 / 完整替换的 Spearman 为 0.484 / 0.187，Kendall τ-b 为 0.348 / 0.168；Gal-1 相应为 0.165 / 0.088 和 0.116 / 0.013。Gal-3 的两个受体分别为 24→18/35 和 31→21/35，Gal-1 为 15→15/23 和 18→14/23。两个受体的平均分重新排序后，计数可以与这两组结果的均值不同。完整替换在 Gal-3 全组的方向准确率差为 −20.0 个百分点。按化合物整体重抽样 4,000 次的描述性 95% 区间是 −70.4 至 +36.4 个百分点，显示这 13 种化学结构不足以确定总体效应。原 Gal-3 “重原子较多者更强”的对照为 34/35；同分子式的三倍分离比较每个蛋白各仅一对。[逐受体分层与相关性](affinity.csv) · [所有首姿配对分差](pairs.csv.xz) · [按化合物重抽样的配对准确率差值](bootstrap.csv)

## 在同一完整坐标池重排糖环

判据是六个已匹配的糖环重原子在受体坐标系中 RMSD ≤ 2 Å，无叠合。候选坐标在重排过程中全部固定。每行代表 13 个化合物各四枚种子，样本相关。

|蛋白 / PDB|原生 Top-1 → 完整替换|原生 Top-5 → 完整替换|候选命中数 / 池数|
|---|---:|---:|---:|
|Gal-1 / 1GZW|16→7|20→20|20/52|
|Gal-1 / 4Q26|16→12|18→15|18/52|
|Gal-3 / 1KJL|1→0|2→0|2/52|
|Gal-3 / 3T1L|3→3|6→5|6/52|

只看候选池中已有正确糖环位置的情形，Gal-1 首位命中由 32/38 降至 19/38，Gal-3 由 4/8 降至 3/8。两个参考态只在同一配体的所有姿势上增加同一常数，分别计算得到的结构排名一致。Gal-3 有 96/104 个池缺少正确糖环，重排无法补回这些候选。以上数字只衡量糖环位置。[逐受体姿势结果](geometry.csv)

## 成本与复算

复用此前原生坐标，新增对接调用为零。完整诊断使用 13 次配体柔性因子的引擎单点评估、13 × 8 个真空构象尝试、13 个准备态及 1,849 个候选的氢原子局部优化。F、P 各配体只算一次，随后两个受体和所有种子共享。首轮单进程从读取冻结坐标到全部评分为 48.16 s，包含对图、坐标、文件哈希及能量的逐例核验。另用基于 3663617 构建的分支程序独立重跑全部评分耗时 48.84 s，两次模式分量、所有配对和逐受体计数逐字节一致。只给固定首姿做亲和力预测时只需处理 208 个结合态，此处没有单独测这个墙钟。用原程序保存的 INTER 行独立代入 f[INTER + E(B) − E(F)]，与用原生分数和分子内能修正的完整公式最大相差 0.00134，符合 PDBQT 打印舍入。原生各受体和双受体的全部亲和力计数也与旧结果表逐行核对。[逐姿势能量与校验差](modes.csv.xz)

Python 3.12、RDKit 2026.09.2、Meeko 0.8.0、gemmi 0.7.5、SciPy 1.17.0。由仓库根目录运行以下命令，VINA 为支持固定坐标打分的本分支二进制文件。

```sh
D=benchmarks/frozen_core/transfer/galectin_mmff
W=$(mktemp -d)
(cd benchmarks/galectin_affinity && sha256sum -c evidence.sha256)
tar -xJf benchmarks/galectin_affinity/evidence.tar.xz -C "$W"
OPENBLAS_NUM_THREADS=1 python "$D/replay.py" "$W" "$VINA" "$W/result"
for table in affinity.csv geometry.csv bootstrap.csv modes.csv.xz pairs.csv.xz; do
  cmp "$D/$table" "$W/result/$table"
done
```
