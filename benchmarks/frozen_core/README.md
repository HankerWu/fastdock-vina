# 固定候选姿势下的 FastDock Vina Pro 排序实验

比较的两臂使用同一个候选池。姿势终点为受体坐标系、校正化学对称性后的配体重原子 RMSD ≤ 2 Å。亲和力终点为同一靶点、同一测定中相差至少三倍的实测 Ki 或 Kd 的方向。种子、受体构象和使用相同配体的比较均有相关性。新种子 Native 实验另对开启和关闭注释的 140 对完整对接作了字节与计算计数核对。

| 核心改动 | 固定候选或固定首姿的实测 | 使用范围 |
|---|---|---|
| 独立共晶配体的受体接触相似度 | 事前固定的新靶点 CDK2、PARP1 双向交叉中，原生和原有元素模板均为 0/8，新接触项为 2/8，候选池上限 2/8。两次命中来自同一 CDK2 方向的两枚种子。此前 BRDT 干池为原生 1/6、元素 2/6、接触 3/6。 | 有另一个配体的实验姿势和可信受体对齐时使用 `--pose_template ref.txt --template_stage contact_rank`。[方法与原始对照](contacts/README.md) · [新靶点测试及独立 SDF 核验](transfer/README.md) |
| 用 MMFF94s 的配体构象内能差替换原 Vina 内能差 | 五靶点、七受体的新 Native 种子固定首姿，原生 89/187，单位权重 132/187。独立因子 Xa 固定首姿由 223/295 降至 206/295。五靶点仅比较重原子数和形式电荷都相同的分子对时，新种子为 8/17 对 9/17。 | 亲和力研究注释，使用 `tools/score_physical_pool.py --mmff-affinity`。分开报告原生首姿与池内最优，在不动重原子坐标的前提下允许氢松弛。[实现、三组对照与外部系列](strain/README.md) |

三个产生条件性正结果的方法使用同一份候选记录就能比较。含模板的姿势分表示与另一配体结合模式的相似性；实测亲和力评价使用单独的分数。MMFF 注释与接触扭转注释是各自独立的替代公式，本表分别给出单项结果。后续[四臂实验](strain_rotor_interaction/README.md)在原始能量分项上组合两种修正，并复核了新旧因子 Xa 配体输入应使用的不同转子分母。直接比较所有输出模式的内部应变时，DYRK1A 有原生首姿约 0.78 Å 被替换成约 7.08 Å 的反例。候选池已经漏掉实验姿势的病例，在排序实验中仍算作失败。

运行命令、使用的 PDB/CCD 标识、实验数据源和保留/排除条件见各实验目录。代码可分别核对原生与启用选项的候选坐标、搜索计数、独立化学图的扭转切分、重原子匹配及分子对强弱方向。

固定 Native 首姿看五个靶点时，MMFF 八构象自由参考下 ALK 为 15→16/19、RET 为 13→14/19、TNK2 为 9→12/19、MAPK14 为 29→36/58、BACE1 为 23→54/72。总共净增 43 个分层比较，其中 31 个来自 BACE1；同一分子系列在两个受体中的重复比较会放大该靶点对总数的影响。两个独立自由构象参考在五靶点汇总上同为 132/187，逐靶点组成仍有差异。[原始分层结果](strain/fresh_mmff_summary.csv)

新增的 PARP1 迁移实验使用同一篇原始 SPR 论文的 4 个配体和两个受体构象。实测相差至少三倍的独立分子对仅 4 个；原生、接触扭转和 MMFF 固定首姿均为 4/4。按重原子数排序也为 4/4。新模型扩大了部分分差，无法从这组数据证实排序增益或分值定量准确性。[原始 SPR 数据、输入微态、逐分子对及独立复核](transfer/parp_affinity/README.md)
