# Second-stage PPAR challenge

After the four-target first-stage protocol showed no successful native candidate pools and scarce receptor hydroxyl contacts, choose a PPAR family challenge based on the established polar ligand headgroup pocket. Freeze chain A of human PPARG 2PRG/BRL (rosiglitazone) and human PPARD 3TKM/GW0 (GW0742) with no replacements. 2PRG is an existing repository development structure. 3TKM is new to the tracked prior studies, but PPARD (7VWF) and the PPAR family are already represented. This is mechanism-enriched testing, not a novel protein-family holdout. Compare the published native, fixed-HD, contact-minimum, uniform, receptor-contact-prior partition, rotor-only and nonrotor arms, plus the same partition with an additional MMFF94s proper-torsion prior for the receptor hydroxyl. Use the same saved poses and parameters, apply this addition to every eligible receptor, and report any parameterization failures. Disable all per-case fitting. No orthogonal assumptions about ligand ionization are introduced: flag the chosen CCD microstate.

Use the same inclusion/exclusion, preparation, box, seeds, two budgets, official upstream comparator and symmetry-corrected pose metrics as the first-stage PROTOCOL. The primary incremental comparison is MMFF-bonded plus receptor-contact prior versus contact prior on the identical candidates. Also compare against native and report donor-contact exposure. State conditional rank metrics only on successful native pools; report separately if a favorable crystal-like basin exists only in a supplementary crystal-guided diagnostic. Fixed structural inputs; no crystallographic orientation may update the model. This panel was specified before acquisition or examination of these candidates in this round.

The second arm uses RDKit MMFF94s proper torsion coefficients from ethanol (Ser), isopropanol (Thr) and phenol (Tyr), summed over all X–C–O–H proper torsions on the 72 existing nodes. Both reference and bound potentials gain the same intrinsic term. All other forces, candidates, temperature, integration weights and three first-stage affinity datasets are identical. The full first-stage pose and affinity outcomes were available before this amendment. The two new measurements are transfer of a mechanism after retrospective iteration; any previously measured PDB is identified explicitly.
