# 在同一首姿上联合替换配体内能和扭转代价

此前五个靶点上，MMFF94s 与接触扭转模型各自优于原生评分。冻结同一批 Native 首姿，将它们同时启用后，187 次分层比较中判对 131 次，单用 MMFF 为 132 次。相反，在修正输入几何的人因子 Xa 测定中，联合臂在 295 对中以 223 对略高于两个单项的 217 和 222 对。四臂差分恰为零。两种效应可以在特定测定中累加，目前没有跨测定的额外协同证据。[事前方案](PROTOCOL.md) · [逐测定排名与区间](summary.csv)

## 候选、模型和比较单位

四种模型获得完全相同的首姿。令 $E$ 为 Vina 的分子间能，$I$ 为 Vina 配体内能相对于同一池未结合参考的差，$D$ 为保持结合重原子固定、仅松弛氢后的 MMFF94s 能量减去八个游离真空极小值中的最低值，$f$ 为生成该姿势的 Vina 柔性乘数。令 $T=298.15$ K，$K$ 为转轴两侧均有口袋接触的键数，$C=KRT\ln3$。同一输入使用同一微态和测定。

|臂|作用于同一物理量的公式|
|---|---|
|原生|$f(E+I)$|
|仅 MMFF|$f(E+D)$|
|仅扭转|$E+I+C$|
|联合|$E+D+C$|

逐姿势计算使用归档分值，保留 PDBQT 打印精度。计算联合臂时先将 MMFF 修正除以 $f$，再加到接触模型分数上。这样的模型假设结合态内能和离散转子限制可分别估计。真空最低能构象的参考和独立三态转子的熵都没有囊括溶液中的构象权重；经验预测分数没有严格的标准结合自由能解释。相关原始研究分别讨论了结合几何的应变和结合时构象限制的自由能。[Perola 与 Charifson](https://doi.org/10.1021/jm030563w) · [Gao、Park 与 Stern](https://doi.org/10.1016/j.bpj.2009.11.018)

按同一 assay 的实测 Ki 或 Kd 至少三倍分离计方向。对每个分子在每个受体内取种子中位数，形成单受体分数后取受体等权均值。另复算已发表的两种口径。五靶点原研究逐个受体计方向，因子 Xa 原研究对每一对分子的受体–种子匹配分差取中位数。这两种数值与共识分数的对数会有差异。后者不能唯一确定每个分子的标量分数，因此仅为另行定义的标量预测报告等级相关。区间根据 5,000 次整分子配对重抽样，完整保留该分子的重复观察；它们描述各测定内部的不确定性。

交互为“联合 − 仅 MMFF − 仅扭转 + 原生”。计方向受分数跨过零的影响，所以交互可反映两种修正是否改变同一条边或作用方向相反，不能解读为热力学能量耦合。五靶点的 187 项含相同配体对在两个受体上的重复观察，不能和其他行相加。关联指标结论如下。

- **五靶点 Native**。先对种子和受体汇合，再在靶点内等权平均 assay，最后对五个靶点等权，原生、仅 MMFF、仅扭转、联合的 Spearman 依次为 0.210、0.376、0.341、0.360；Kendall τ-b 为 0.158、0.337、0.260、0.312；三倍分离对一致率为 59.09%、72.44%、66.33%、71.75%。在历史逐受体口径中，接触扭转纠正的 15 项原生错误有 9 项也被 MMFF 单项纠正。联合相对 MMFF 新判对 2 项，同时失去 3 项。ALK 的受体共识为 15/16/15/17；TNK2 为 9/12/13/11。两者各 19 对。[原面板](../../geometry_comparison/affinity/README.md) · [五靶点原扭转结果](../native/README.md)
- **因子 Xa**。修正输入的唯一受影响配体为 CHEMBL369480。原归一化对应 5 个转轴，修复后的准备态对应 7 个，$f=0.709612409702$。本实验从归档的结合及游离 MMFF 能量重新构造修正项，按输入各自的转轴数独立核对原生输出。匹配分差下，联合优于单用 MMFF 的 2.03 个百分点，分子重采样 95% 区间为 −1.35 至 +5.96；交互为 0.00 个百分点，区间 −6.86 至 +6.71。以每配体共识标量计算时，四臂的 Spearman 为 0.472/0.577/0.518/0.594，Kendall 为 0.340/0.441/0.378/0.457。可供查证的中间量与原始几何均已归档。[几何修复](../strain_transfer_audit/README.md) · [测定数据及来源](../../affinity_partition/README.md)
- **Gal3 与 S6K1**。Gal3 的联合相对 MMFF 失去 14/403，变化 −3.47 个百分点，95% 区间 −9.94 至 +3.14。限制为重原子数和形式电荷均相同的 35 对，四臂分别判对 11/15/12/19。Gal3 全系列联合 Spearman/Kendall 为 −0.045/−0.015，整体排序依然很弱。S6K1 中 LY-333531（CID 153999）的两份首姿包含大环 G0/CG0 闭合原子。C++ 单点接口对这两次明确拒绝接触扭转评分。四臂共同覆盖 13/14 个分子、26/28 个首姿、48/58 个三倍分离对。联合相比 MMFF 为 −2.08 个百分点，95% 区间 −16.13 至 +8.33。保留该分子的原生、MMFF 和缺测状态。[Gal3 测定及纳入标准](../../pair_gradient/galectin_external/README.md) · [S6K1 清单](../../affinity_reference_ensemble/results/s6k_panel.csv) · [覆盖与排除](transfer_coverage.csv)
- **PARP1**。四种模型都分开了两个较强与两个较弱抑制剂，达到了三倍分离子集的上限。在全部四个化合物上，原生与两单项的 Spearman 均为 0.8，联合为 0.6。对两个组内的细微差异，原文报告的测量误差足以影响顺序。[原始 SPR 来源与误差](../transfer/parp_affinity/SOURCE.md)

在完成四臂后加做了一项归因对照，使用 $E+D$。它移除原生扭转归一化，保留未缩放的 MMFF 应变，把接触转子代价设为零。五靶点 Native 判对 134/187，实际加回接触代价后为 131；因子 Xa 修正输入为 222→223/295，Gal3 为 183→185/403，S6K1 为 40→39/48。在这些案例里直接从单用 MMFF 到联合的全部改变，不能全部归因于新增的接触几何信息。实验没有根据这些结果再选权重。

## 原始证据和复算

[transfer.py](transfer.py) 从两个 Kd 面板的输入和输出 PDBQT 重算结合及游离能量。61 个配体均得到八个收敛的游离构象，保留了每个首姿的池哈希、转轴、约束键数、能量及失败状态。[逐姿势物理量](transfer.csv) · [四臂及额外消融的首姿](first_poses.csv.xz) · [所有非实验并列分子对的预测分差](pair_gaps.csv.xz)

[verify.py](verify.py) 从归档首姿的 INTER 能量、重新计算的 MMFF 能量差和编译后 C++ 单点接触计数独立恢复联合分数。122 个首姿中 120 个均与 Python 接触计数一致，剩余两次复现 C++ 的输入域限制。支持病例的联合分数最大绝对差 0.0010，处于 PDBQT 归档精度范围。三进程重新计算两组 Kd 面板的参考态和首姿耗时 46.5 秒，用户态 CPU 合计 134.0 秒，不计历史对接与独立复核。联合算法复用了两个单项的物理量，没有额外的对接搜索。[编译产物哈希与直接核对](verification.json)

使用 Python 3.12、RDKit 2026.09.2、Meeko 0.8.0、NumPy 2.3.5、SciPy 1.17.0，在仓库根目录运行。VINA 指向支持 --contact_rotor_score 和 --pose_coordinates 的本分支可执行文件。

~~~bash
D=benchmarks/frozen_core/strain_rotor_interaction
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1
python "$D/transfer.py" "$W/transfer.csv" --jobs 3
python "$D/replay.py" "$W" --transfer "$W/transfer.csv"
python "$D/analyze.py" "$W"
python "$D/verify.py" "$VINA" "$W"
~~~

数据涵盖已在此前研究中使用的受体与测定，包含原五靶点中的共同配体。新算的 Gal3 与 S6K1 是对冻结组合的检验，并非独立采集的前瞻性测定。四臂从头到尾选择同一个原生首姿，姿势误差与搜索候选没有变化。排序结果不足以支持将联合分数作为默认预测路径。
