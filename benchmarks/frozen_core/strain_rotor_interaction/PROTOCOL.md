# 配体构象能与接触扭转代价的双因素检验

冻结首姿，检验 MMFF94s 替换配体内能与接触约束扭转代价替换 Vina 柔性折减能否互补。沿用原来的单位权重、八构象真空参考、298.15 K 和结合接触判据；不选取权重、阈值或冠军姿势。两次替换分别作用于 Vina 的分子内能差和扭转归一化。共同模型的分数为原生分子间能加结合与游离 MMFF 能差，再加每个受限转子的 RT ln(3)。全组合不得相加两个完整的模型输出。

对原五个人源靶点的 Native 新种子以及两批 Armijo 搜索预算、两份人因子 Xa 输入（归档与已修正几何）、PARP1 SPR 进行固定首姿复算。另对既有的人 Gal3 的 Sörme 47 化合物和 S6K1 的 14 化合物固定坐标从头计算四臂。后一组用于测试预先冻结的组合，这些靶点已在其他分支研究中使用。保留各源候选原有的扭转归一化以复核历史单项结果；在 Gal3、S6K1 上另检查采用已修正重原子运动树计数的敏感性。

先在每个 assay、每个受体内取种子分数中位数，再对受体等权。报告 Spearman、Kendall τ-b 及实验值至少三倍分离时的正确对数，预测并列给半分。附加重现历史所用 FXa 的跨受体–种子配对分差中位数和五靶点的逐受体指标。对判对比例，定义交互为“两项均开 − 仅内能 − 仅扭转 + 均关”。同时比较联合臂与两个单项，逐分子重采样且各臂共用同一次抽样。不把同一配体参与的不同边、预算或受体视为独立样本。本实验检验经验亲和力排序；姿势、采样和物理自由能没有在本分析中重新估计。
