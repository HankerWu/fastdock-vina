# Fixed-pool receptor contact transfer

The new score compares which receptor atoms a query approaches with the footprint of a different experimentally bound compound in the same receptor. It needs a registered independent ligand in the known site. No query crystal coordinates, alignment to the template, fitting, minimization, training or new search enter scoring.

For every receptor heavy atom the general channel takes the strongest contact with any ligand heavy atom (unit value at or below 4 Å, linear ramp to zero at 6 Å). A second channel uses N/O atoms on both sides, with a ramp from 3 to 4.5 Å. It is a proximity descriptor, without an assigned hydrogen bond. Compare query and reference channel vectors with the continuous Tanimoto dot/(sum of squared norms minus dot), then average the nonempty channels. If both channels are empty the overlap is zero. All receptor atoms count in the denominator, including contacts formed only by a query. The primary score subtracts six times overlap before native torsion scaling, matching the existing element-template strength. Comparators are native score, the existing bidirectional nearest-element template, general contact only and contact overlap only. Native order breaks ties. No parameter sweep.

Use cross-compound frozen Native ten-direction pools from the five-target upstream test, separately for fixed cap, cohort cap and per-complex cap. Challenge panels use dry BPTF/BRDT and BCL6 cross directions, then archived ESR1/PDE4D/PPARG. No cognate self templates. Report native, existing template and new top-1 within 2 Å plus attainable pool, wins/losses and per-case data. Different caps are separate strata, never the treatment. Same-target experimental affinity is assessed separately by the affinity experiments. These datasets are retrospective.
