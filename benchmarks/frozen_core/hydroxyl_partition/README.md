# 受体羟基能否通过改变供氢方向改善姿势排序？

历史氢键角度模型在 FABP4 上把原来正确的配体姿势降到了第二、三位。受体制备给 Tyr、Ser、Thr 选定一个羟基氢方向，通常没有相应的衍射观测。这里实现了一个可直接打分的实验模型，让同一个羟基在所有受体–配体接触之间共享一个转角，再在干燥口袋的简化参考态上积分。FABP4 有两次排序回到正确首位，两次使用新种子的失败仍然存在，并出现一例新的 FKBP1A 失误。分支的默认打分不采用本模型。[事前冻结协议](PROTOCOL.md) · [旧供体角度实验](../angle/README.md) · [蛋白质–配体复合物中的可转动极性氢](https://pmc.ncbi.nlm.nih.gov/articles/PMC3225823/) · [羟基取向的中子衍射观测](https://doi.org/10.1073/pnas.87.12.4468)

## 如何计算

只替换原 Vina 分子间 N/O 氢键项的方向性比例。每对有资格的重原子，在坐标不变时的原始氢键吸引强度为 $a=0.587439\,\mathrm{clip}((R_D+R_A-r)/0.7,0,1)$，O/N 的半径为 1.7/1.8 Å。用 $g=\max(0,-\cos\angle DHA)^2$ 表示该供氢方向保留的吸引比例；双向和多氢接触对一个重原子对只取一次最大值。新模型保留旧角度实验的参数。蛋白 Ser OG、Thr OG1 和 Tyr OH 的氢可以绕各自 C–O 轴转动，键长、C–O–H 键角及所有重原子坐标固定。其他极性氢取制备方向。[Vina 的评分函数](https://doi.org/10.1002/jcc.21334) · [结构与量化计算对氢键方向的研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC406446/)

对每个可转羟基 $j$，$P_j(\phi)=\sum_i a_{ij}(1-g_{ij}(\phi))$ 是它对所有配体受体原子的共同接触惩罚。干燥游离蛋白角能 $U_j(\phi)=-\sum_k a_{jk}g_{jk}(\phi)$ 只计这个羟基向其他残基的固定受氢原子供氢。积分使用同一组周期节点，72 点、298.15 K，$RT$ 以 kcal/mol 表示。对每个姿势计算

$$
\delta_j=-RT\log\frac{\sum_\phi \exp[-(U_j(\phi)+P_j(\phi))/RT]}{\sum_\phi \exp[-U_j(\phi)/RT]}.
$$

天然径向分数已经给了最有利的吸引量，因而用非负的 $\delta_j$ 替换旧的固定氢角惩罚，对其余原子对保留固定角惩罚。相加后乘以产生该池的 Vina 分母的倒数，再加到原始输出分。历史候选用旧版本逐配体的分母，新 ESR2 用分支修订后的双侧转轴计数。不同配体、二进制或阶段的参考分不混用。

消融包括固定原始 H、共同转角下取配体惩罚最小值、令 $U=0$ 的均匀积分，以及只对可转羟基加积分惩罚的 rotor_only。惩罚是经验分数的差值，采用 298.15 K 规定的能量尺度。它遗漏 C–O 扭转势、氢的短程排斥、侧链与配体运动、相邻羟基的统计耦合、受体自身的受氢方向效应，以及溶剂和离子，不具备完整结合自由能所需的参考态。省去的项尤其影响苯酚羟基面内或面外旋转的代价。

新 ESR2 的 genistein 和 estradiol 取自人蛋白 1QKM、5TOA 的 A 链，分辨率分别为 1.8、2.5 Å。配体从 CCD 化学图经 ETKDGv3 与 MMFF 单独制备，共晶配体仅界定盒中心和事后 RMSD。两种子各运行两档预算，每次四轨迹、单线程，保留最多九个姿势。近期 Pro 与独立编译的上游 Vina（3c65c0b）在所有八格有相同的首位 RMSD，部分低位候选数不同。Genistein 的 52727 种子把预算提高五倍后，首位从 7.078 降至 2.303 Å，仍未访问 2 Å 的输出姿势。新模型在 ESR2 的 68 个姿势中有 10 个含活动羟基，八个池的首位均没变。干受体制备移除了距两个配体分别 3.13、3.44 Å 的最近水分子，最近的修补原子在 10.49、10.19 Å。两种 ESR2 配体提供了很有限的迁移证据。[1QKM 实验](https://doi.org/10.1093/emboj/18.17.4608) · [5TOA 实验](https://doi.org/10.1038/s41598-017-03774-x) · [同预算两版本逐池结果](results/esr2_controls.csv) · [输入质量](results/esr2_environment.csv)

**在同一姿势上，对角度取最小值和积分可以作出相反判断。** FABP4（3FR2 → 2NNQ，93529）中原生第一名为 0.990 Å，第三名为 5.202 Å，原分差 0.203。近晶体候选通过 Tyr128 接触两个配体受体原子，逐接触各自选角只需 0.067 原始惩罚单位，而同一个氢使用同一方向时的最小惩罚为 0.178。该侧链的角积分给出 0.420。错误候选通过 Tyr19 接触一个受体原子，最小值和积分仅为 0.037、0.097。连同不动氢和分母后，取最小值给近晶体与错误姿势 −8.645、−8.595，角积分则给 −8.445、−8.546。换成其他种子和预算（85237，同一受体方向），积分两次救回了被固定角惩罚否决的正确首位。[逐接触证据](results/case_contacts.csv) · [4,096 角独立复算](results/case_rotors.csv)

**FKBP1A 的新退化也发生在同一个酪氨酸上。** 1FKG → 1FKH、93529 的两个竞争姿势分别为 1.556、3.399 Å，原生第一名仅领先 0.045。两者对 Tyr82 的联合最小惩罚接近，分别为 0.546、0.516，但相对于最优方向，对全部方向求和使惩罚再增加 0.320、0.134。最终角积分以 0.055 的分差选中了错误姿势；固定 H 和共同角最小值均选对。局部 receptor prior 在两个姿势的 Tyr82 都是常数，因而这个名次变化完全由配体角势及其统计权重造成。在该模型中积分运算正确；把实际角取向分布当作近似均匀留下了可检验的物理缺陷。

## 成本、复核与复现

本目录 136 个池、1,213 个姿势中，458 个含活动受体羟基；总计 2,489 个 N/O 氢键重原子对、734 个活动供体–配体重原子接触。单线程受体环境预计算耗时合计 0.409 秒，所有姿势打分 0.437 秒，打分同时计算全部对照；测量不包括搜索。公用的两个新受体和配体制备耗时 2.88、6.16 秒。ESR2 的四个低预算搜索实测分别耗费 Pro 0.82 秒、上游 4.55 秒，四个高预算搜索耗费 2.25、5.00 秒。两套程序在本机每格运行一次，构建方式也有区别，时间仅说明此次实验成本。ESR2 原始 PDB、CCD、制备元数据、命令、日志和 Pro 坐标在 esr2.tar.xz，上游原始输出在 esr2_controls.tar.xz。[分阶段计时](results/cost.csv)

历史 1,073 个姿势的原生径向项与固定 HD 角惩罚复现已有独立 C++ 结果，最大误差均低于 $5\times10^{-12}$。所有 1,213 个姿势的主积分从 72 加密至 144 点，最大原始分差 $5.56\times10^{-5}$；相位移半格最大分差 $1.12\times10^{-4}$。在两个关键体系中，另一个脚本用 SO(3) 旋转矩阵和供体–受体矢量的标量积独立做了 4,096 点积分。在相同二进制上重新运行的八个 ESR2 Pro 输出可逐字节复现。对所有 68 个新姿势独立求 RMSD 与主评估程序相差小于 $4\times10^{-15}$ Å。[积分检查](results/audit.json) · [结构与剂量逐池核对](results/esr2_controls.csv)

从仓库根目录执行以下命令，前两项只需 Python 3.12、NumPy 2.3.5、SciPy 1.17.0。全量 ESR2 从头制备另用 RDKit 2025.9.3、Meeko 0.7.1、Gemmi 0.7.4、OpenMM 8.6.1、PDBFixer 1.12.0。制备食谱与数据质量门槛沿用 pair_gradient/pose。复算已保存姿势不需要网络。UPSTREAM 与 PRO 指向分别从上游 3c65c0b 与本分支 dec913f 编译的可执行文件。

~~~bash
D=benchmarks/frozen_core/hydroxyl_partition
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 OPENMM_CPU_THREADS=1
python "$D/evaluate.py" "$W/results"
python "$D/check.py" "$W/results"
python "$D/verify_esr2.py" "$W/verify" "$UPSTREAM" "$PRO"
python "$D/esr2.py" "$W/fresh"
python "$D/esr2.py" "$W/fresh" --binary "$PRO"
~~~

对另外的刚性受体和带有 Meeko 氢归属注释的配体，scorer.py 可独立读取一个冻结坐标池。参数 scale 是生成原始分数时的配体扭转归一化因子。在单一配体的标准 Vina 权重下，它等于 $1/(1+0.05846 N_{tors})$。输出包含每个模式的原始分、新分和各消融的未归一化惩罚。

~~~bash
python "$D/scorer.py" receptor.pdbqt query.pdbqt output.pdbqt --scale "$VINA_SCALE"
~~~
