# BACE1 与因子 Xa 的分子内能量为何给出不同排序

原有因子 Xa 面板把 28 个化合物交叉成 295 对。对一个已知输入畸变的强配体 CHEMBL369480，原生分数在与它有关的 21 对中判对 17 对，换成完整 MMFF94s 后只判对 3 对。其余 274 对从 206 变为 203。由此可以定位完整替换损失的 17 个净分中有 14 个来自哪里。浓度相近的分子、不利于新假设的分子以及这个输入畸变的分子全部保留。下列计数均使用原测定内至少三倍分离的比较，平局给半分。[原测定、分子选择及受体来源](../../affinity_partition/README.md)

## 在原生首姿上改变能量分解和参考态

设 B 为原生首姿，F 为八次 ETKDGv3 生成并经 MMFF94s 松弛的真空极小值中能量最低者，P 为原实验实际送入对接的配体。对 B 和 P 保持每一个重原子坐标不动，只松弛氢原子。令 C = S_native − f(I − U)，其中 f 是原 Vina 柔性因子。完整替换分数为 C + f[E(B) − E(F)]。本次第一项对照在完全相同的 B 和 F 上扣除键伸缩、键角、伸缩–弯曲耦合及面外弯曲的能量差，保留扭转、范德华和分子内静电。第二项用 E(P) 替代 E(F)。每套几何另算七个单项能量，并与同坐标新建完整力场的单点评估相加核对至 1e−6 kcal/mol。与历史优化器直接返回的数值之间，固定首姿的最大差为 0.000063 kcal/mol，保留在分量原表中；历史完整分数全部重现。f 为无量纲乘数，汇合后的经验分数不能解释为实测结合自由能。[事前假设及追加诊断时点](PROTOCOL.md) · [168 个首姿及完整分量](components.csv)

BACE1 的两个测定分别只有 6 和 8 个分子。同一组 36 对在两个受体上各测一次。去掉四项后仍为 54/72；将实际输入作参考态也仍为 54/72。两个 BACE1 系列中化合物的 f[E(P)−E(F)] 中位数分别为 −0.02 和 −0.06 个分数单位。这两种参考态接近，足以解释此对照没有明显改变排序。原有静电消融说明其余非静电分量保留了原生到完整校正的大部分净增益。数值贡献和分子真实的水溶液构象代价是不同的问题。热力学参考要考虑溶液中各构象的占有率；多项研究说明了对结合态精细几何与游离参考态的敏感性。[上一轮分量结果](../strain_components/README.md) · [Perola 与 Charifson，150 个复合物](https://doi.org/10.1021/jm030563w) · [溶液构象限制的自由能计算](https://pubmed.ncbi.nlm.nih.gov/20197044/) · [MMFF94s 的推导和参数](https://pubmed.ncbi.nlm.nih.gov/34376030/)

FXa 的完整校正对 1FJS 有害、对 2P16 有利。去四项成键项在两受体上分别只多 1 分、2 分，而按原方法先逐对取四个受体/种子差的中位数再计分可以多 12 分。合并分数非线性，不能把 12 分归给某个受体。对等重原子数且等形式电荷的 17 对，原生/完整/去四项/输入参考分别为 9/7/9/9。换为输入参考态后全队列从 206 升到 214，其中畸变分子相关的 21 对从 3 升到 18，其余 274 对从 203 降到 196。用四个激酶和 BACE1 的历史完整分数及配体单独先验作独立代数复算，五靶点的原生/完整/输入参考为 89/132/131（共 187 次分层比较）。所有边、分层、单受体 Spearman/Kendall 和逐分子删除敏感性均可核对。共同分子、受体和种子使这些配对相关。[逐对差值](pairs.csv.xz) · [精确分层](summary.csv) · [单受体相关性](correlations.csv) · [FXa 的逐分子影响](influence.csv) · [五靶点对照](panel.csv)

## 原始坐标和畸变来源

从 28 个已发布的微态重新执行原生成过程，全部 28 份配体 PDBQT 与受体目录中的原输入逐字节一致。种子为 2026。CHEMBL369480 返回“MMFF94 优化收敛”，但一个重原子单键长达 2.094 Å，MMFF94s 参数表的平衡值为 1.492 Å。另 27 个化合物以相同方法得到的最大键长偏差均小于 0.061 Å。对接中的刚体运动和绕转轴旋转保留键长，四次原生首姿中仍为 2.094–2.095 Å。对已准备态，该分子的 E(P)−E(F) 为 +648.68 kcal/mol，包含 +257.4 的键伸缩、+90.0 的键角和 +270.1 的范德华差。历史离子对研究已报告该输入的畸变，并试过 16 个初始构象；本次新增证据是上述畸变对冻结 MMFF 排序的影响及同种子单构象的配对试验。现有测定没有提供该配体的真实结合姿势。[坐标生成源码](../../affinity_partition/fxa_holdout.py) · [刚性片段运动](../../../src/lib/tree.h) · [过去的 16 构象修复](../../directional_ion_pair/README.md) · [从嵌入到首姿的键长](geometry.csv)

## 同种子、单构象重对接

仅把 ETKDGv3 的初始坐标构造方式改为 `useRandomCoords=True`。每个分子仍使用种子 2026，一次嵌入、一次最多 1000 步的 MMFF94 局优；记录全部 28 个输入的几何。新准备态中 CHEMBL369480 的最大重原子键长偏差降至 0.0494 Å。全组最大值为 0.0625 Å，缩小这个几何偏差的过程没有使用 Ki。两种输入各自对接两种固定受体、两枚原种子，并复算新首姿的 MMFF 全替换分数。八次运行保持原有单线程、每次四条轨迹、每轨迹 50,000 名义上限和九个输出名额。两个受体的气相分数参考仍取同一个 E(F)=49.9957 kcal/mol；四份原输入的完整输出池全部逐字节重现。对接更新仅作用于这个已知异常分子，另 27 个仍用历史原生首姿。[化合物、模型与计数](redock_cells.csv) · [准备态数据](input_geometry.csv) · [PDBQT 与原始日志](redock_raw.tar.xz)

| 队列，均包括全部 28 个分子 | 1FJS，原生 / 完整 MMFF | 2P16，原生 / 完整 MMFF | 原配对规则合并，原生 / 完整 MMFF |
|---|---:|---:|---:|
| 原准备态 | 231.5 / 217 | 187 / 208 | 223 / 206 |
| 只替换 CHEMBL369480 的准备态并重新对接 | 219.5 / 221 | 187 / 219 | 216 / 215 |

修复输入后，合并方向准确率中的 17 分差缩至 1 分。原生少判对 7 对，而 MMFF 多判对 9 对。在与该分子直接相关的 21 对上，原生/完整由 17/3 变为 10/12。化学键恢复合理长度和生成新的首姿同时发生；此干预可以定位对输入构象的依赖，不能把其中 9 分孤立归给某一根键。两个受体仍给出不同排序，未建立普适优势。该例也说明按亲和力方向判对，有时可以和明显畸变的输入并存。[全部对接重组结果](redock_summary.csv)

四个原输入/新输入分别实际执行 802,317/802,351 次局优中的联合能量–梯度调用，14,189/14,794 次局部优化。进程端到端耗时合计 4.79/4.63 秒。记录了合并前的搜索、第二次优化、显式精修各阶段计数，其他打分与网格预处理计入墙钟。含两次键长检查的单分子准备耗时为 0.16/0.26 秒，28 个分子合计 5.29/6.26 秒。全套诊断另执行了 42 × 8 次气相参考构象尝试、42 次准备态和 168 次原生首姿的氢原子松弛、七组分量评估，两进程约 28 秒。时间来自同一共享主机。改变准备态后并未建立提高单位时间对接准确性的证据。

## 复现

使用仓库化学实验的版本组合，Python 3.12、RDKit 2026.09.2、Meeko 0.8.0、gemmi 0.7.5、NumPy 2.3.5、SciPy 1.17.0。工作目录位于仓库根。第一步从既有压缩包提取输入和输出；第二步重建 28 个原准备态；第三步从固定盒、配体和受体重新执行全部八次对接。

```sh
D=benchmarks/frozen_core/strain_transfer_audit
W=$(mktemp -d)
export OPENBLAS_NUM_THREADS=1
python "$D/replay.py" "$W" --jobs 2
python "$D/geometry.py" "$W"
python "$D/redock.py" /absolute/path/to/vina "$W"
for table in components.csv pairs.csv.xz correlations.csv summary.csv panel.csv geometry.csv influence.csv redock_summary.csv; do
  cmp "$W/$table" "$D/$table"
done
```

原生重对接使用仓库此前以 GCC 14.2 编译的未修改 `ac0a2f6e` 默认程序，SHA-256 为 `513f7bbe33831becc0409e260055b746a4a665b0077c0db1d2db6a5720160e01`。这些测试均未打开实验性梯度开关。日志中包含临时路径，耗时随主机负载变化，逐行原始证据中保留了这些信息。

第二次用本轮分支源码构建的研究程序固定原生路径，从头重建同一组输入并重跑全部八次。两份配体输入、八份完整输出池均逐字节一致，逐运行计数、分数和全部配对方向也一致。
