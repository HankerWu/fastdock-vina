# 固定首姿上的 MMFF94s 参考态及局部成键几何对照

本次为对已知正负结果的回顾性机制诊断。分析前确定以下对照，禁止按结果改权重。使用原 BACE1 两个 Ki 系列和因子 Xa 一个 Ki 系列的全部 42 个分子、两受体和两种子。实验输入、候选坐标、原生首姿、气相八构象参考态、MMFF94s 氢原子放松、测量标签和配对统计均沿用 [上一轮固定坐标分解](../strain_components/README.md)。

检验两个可分开的假设。其一，平移、旋转和树上的扭转保持分子的重原子键长及大部分键角，但八个真空极小值中选出的游离参考态可以具有不同局部几何。如果这些成键自由度的能量偏差主导跨体系差异，从完整单位权重替换中删除 bond、angle、stretch–bend、out-of-plane 四项的差分，应该大幅缩小原生到完整替换的得失。在相同几何上计算七项 MMFF 分量，以逐项和等于完整能量作数值核验。补充给出仅使用上述四项差分的结果。这里的分项只是对既有预报的归因。

其二，如果只要扣掉对接前已存在的配体形变，就能改善转移，以实际输入的准备态 P 取代真空最小参考态 F。按同一规则只松弛 P 的氢原子，保持实验用准备态重原子坐标不变。令 C = 原生分数 − f(I−U)，比较 C+f(E_B−E_P)、C+f(E_B−E_F) 和原生。这个对照不再需要八次额外构象生成，但仍有氢原子松弛开销，P 也并非水溶液热力学参考态。

主终点沿用 ≥3 倍同测定方向计分，BACE1 按受体列出，因子 Xa 另报告原有双受体的配对差中位数。列出等重原子数且等电荷、≥10 倍、同电荷和同骨架子集，并提供单受体 Spearman 与 Kendall τ-b。每个分子多条边、受体和种子作为配对重复。各分量不得统计为独立观测。本诊断没有未观察的外部确认集，并不用于默认算法选择。

对准备态参考这一臂，再使用原五靶点所有已发布标量作代数复核；其中四个激酶不用于选择参考态。原有 ligand-only 对照为 S_prior = S_native + f(E_P−E_F)，因此准备态参考分数也可独立写成 S_full − S_prior + S_native。原五靶点的实验结果均已公开，不构成盲测。BACE1 与本次固定坐标直接计算的分数必须相符。

**事后追加的坐标诊断和重对接。** 七项分解后发现 CHEMBL369480 是准备态能量极端值。原仓库已有对此分子的 16 构象修复记录。本次预先选定只把 ETKDGv3 的 useRandomCoords 从默认 False 改为 True，使用原来的种子 2026，每个分子仍只嵌入一次、MMFF94 最多 1000 步。两个准备方案均检查所有 28 个原始图，不根据 Ki 或对接结果选择构象。仅将这个已知畸变分子的两种准备态各对接到两个原受体、各用原两枚搜索种子，保持相同盒、原生 late、4 条轨迹、单线程、每轨迹名义上限 50,000 和 9 个输出名额；分别记录实际评估、时间及首姿。用其新结果与另外 27 个冻结分子重组成单分子替换的反事实队列。原队列完整保留。这是一个已知病例的因果诊断，不能作为整个队列普遍更换起始构象协议的证据。
