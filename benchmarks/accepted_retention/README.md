# 固定精修名额下，保留哪些已接受姿势？

本轮从 31d073f 出发，在不改变 Monte Carlo 轨迹、第二次优化或显式精修名额的条件下，检验原生搜索是否漏存了可以成为正确预测的姿势。结果支持一个有限的收益：在一条 FABP4 跨受体轨迹中，无模板选择把近原位姿势送进返回池，首姿没有改变。另两条 FKBP1A 轨迹证明相同名额内原本有机会恢复正确姿势，但两种实际选择规则都没有识别它们。新的结构与同测定亲和力数据不支持替换默认算法。

## 原生调用链和两个候选选择规则

原生搜索先对提议作软化目标下的局优（hunt），再作 Metropolis 判断。接受态只有在能量优于此前保存过程维护的 best_e，或轨迹内原生池尚未装满时，才进入第二次网格局优。其余接受态可作为后续搜索起点，却没有机会直接竞争末端精修名额。原生合并还会再次去重，随后显式受体局优及最终计分。上轮 2 Å 的 ADORA2A 接受态是诊断线索。[原生循环](../../src/lib/monte_carlo.cpp) · [上轮逐阶段观察](../pair_gradient/stages/README.md) · [Vina 原文](https://doi.org/10.1002/jcc.21334)

- **按能量保留一个新颖接受态。** 在不触发第二次优化的接受态中，每条轨迹记录一个与当前已存池距离足够大、hunt 能量最低的候选。原生合并和最终去重完成后再次核对距离。若其软化 hunt 能量优于已有名额中最差的起始 hunt 能量，则占用这个名额。比较的两项能量使用同一个目标。沿用已有 RMSD 阈值，普通配置为 2 Å；引擎对此按原子编号比较，科学评价另用化学对称映射。在 K<2 时保留原结果。另建只去掉能量门槛的消融。[C++ 补丁与控制实验](core/README.md)
- **按连续访问的盆地选择。** 为避免个别低分错姿垄断唯一名额，记录连续处在同一几何盆地的已接受端点，优先选持续最久的一段。同段及等长时用原 hunt 能量判别。其余几何门槛、最终能量门槛及精修规则与第一种相同。[公式、C++ 实现、事前独立种子及结果](persistence/README.md)

实现修改了构象输出记录、MC 保存条件旁的观察逻辑、轨迹候选记录及显式精修前的名额分配。补丁直接编译到原生 C++ 搜索和精修调用链。生产分支默认路径继续使用原算法。每个候选的观测与坐标复制会消耗时间；一次联合能量/梯度调用可返回两者，计数只算一次。预测不使用正确姿势、额外模板、事后候选打分或新的搜索轨迹。

## 定位损失阶段

对已有六个蛋白家族的全部 22 个配体–受体方向、三枚种子、12,000 名义预算，执行普通单轨迹对接并保存完整阶段轨迹。原生 66 个返回池中有 16 个命中。19 条轨迹曾经接受过近原位姿势，只有 16 条曾经把近原位接受态送入第二轮局优。44 条在所有 hunt 局优终点及最终返回池中都没有命中。[逐靶点、逐种子、逐阶段数据](coverage/README.md)

在这三个病例中，另冻结全部 409 个漏存接受态的原始构象，在模型副本上独立计算能量。先把网格对正能量的软化上限从 hunt 的 10 改为 1000，三个预测首选的步号逐一相同。随后切换到实际显式原子受体的可导目标，保留同一配体内部能。FABP4 的首选从第 198 步变为同盆地的第 199 步；两条 FKBP1A 的错误首选都未改变。两个 FKBP1A 的最接近晶体端点，相对各自显式总能量赢家，受体项分别**有利** 0.278 和 0.527 kcal/mol，配体内部项却分别**不利** 0.988 和 0.931 kcal/mol，导致总分分别落后 0.710 和 0.404 kcal/mol。仅用显式受体项时，FKBP1A 重对接能选到 1.921 Å，交叉方向为 2.193 Å，FABP4 反而变为 4.574 Å。这是已知几何上的因果分项，不能据此统一删除配体内能。所有额外能量调用计入诊断而非预测，详见[固定构象的软化、网格和内能分解](soft_cap_probe/README.md)。

## 同靶点的亲和力

在新种子 614039、同样的 12,000 预算下，Gal-3 47 个原始来源可核验的 LacNAc 衍生物，403 个至少三倍 Kd 差的分子对，原生 Vina、父版本与门控的共识分别为 222、221、225 个正确方向积分。改善全部来自 1KJL 的化合物 32；等大小、等形式电荷子集仍为 19/35，跨骨架仍为 134/243。按重原子数的对照有 259.5/403。门控的 94 次端到端耗时总和比父版本高 3.97%（15.919→16.551 秒），联合调用减少 0.19%。在完全相同的 572 个坐标上，所有十项可见评分分解逐项一致。簿记、排序与坐标生成可改变谁排第一，末端评分公式本身没有改变。[实验证据及逐分子表](affinity/README.md)

人碳酸酐酶 II 的五分子同测定 Ki 系列，保留两个受体中的锌。四种实现都得到 2/7。十个受体–配体组合的返回池均无 2 Å 命中，也没有恢复 2.5 Å 内的实验 Zn–N 配位。此结果不能由候选保存规则外推到金属作用项。[配位与几何结果](affinity/caii_geometry.csv)

另用种子 614039 的计时按受体冻结两个较短上限：1KJL 为 11,000，3T1L 为 11,500。对从未用于该系列的种子 411119 完成 47×2 的 2×3 对照。完整 12,000 上限下，父版本、最低能量、连续访问分别为 **201、204、205/403**，等大小等电荷子集均 **17/35**。四个新增正确方向都涉及 1KJL 的 59 号分子，最低能量规则另损失一个分子对。短上限下三臂均为 **183/403**；候选采用父版本原完整预算为对照时看到的 18 对净损失，单独缩短父版本预算即可复现。缩短预算的两种选择比全预算父版本的实测墙钟和评估都少；这项进一步控制没有保住完整预算的正信号。完整预算追加的两种选择在另一计时块执行，所以不能据此断言有运行时间优势。[新种子逐分子全因子对照](affinity_time/README.md)

## 本轮决策

保留可复算的研究实现和数值观测，发行默认算法不变。候选保存确有可以当场证明的损失，也有一个在较低实际评估数下被算法救回的案例。但首姿、独立结构命中和等成本亲和力没有形成可迁移的收益。下一项可区分的科学问题来自 FKBP1A 的分解：对同一配体内、同一受体上不同盆地的竞争，如何给构象应变赋予可转移的参考，同时保留 FABP4 中有效的内能判别？同一配体的游离态常数在盆地间严格抵消；改变共同游离参考不能改正其姿势次序。应在冻结坐标上考察相对构象内能与溶剂/微态、受体环境的耦合，并同步检查哪些体系根本没有生成合理候选。

## 重放

在仓库根目录使用 Python 3.12、C++14、Boost 以及各子实验列出的化学依赖。研究构建程序从本轮起点导出源码、应用经测补丁并调用同一构建脚本。

```bash
D=benchmarks/accepted_retention
W=$(mktemp -d)
python "$D/core/build.py" parent "$W/parent" --jobs 3

python "$D/core/build.py" recurrence "$W/recurrence" --jobs 3
OPENBLAS_NUM_THREADS=1 python "$D/coverage/audit.py" "$W/archive" "$D/coverage/results" "$W/check"
cmp "$W/check/coverage.csv" "$D/coverage/results/coverage.csv"
```
